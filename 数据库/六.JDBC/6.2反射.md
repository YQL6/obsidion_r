# 一.class类

## 1.1什么是class

我们编写的 Java 程序先经过编译器编译，生成class文件，而class文件的执行场所是在 JVM机中

**“类的类”就是 `Class`，而 `Class` 的对象就是用来描述某个具体类的信息载体**。

## 1.3class类的细节

定义了一个类，编译后会生成一个 `.class` 文件，里面包含了这个类的**所有元信息**：字段、方法、构造器、注解等。

class处理流程：
1.  编译阶段：`.class` 文件
	- 定义的每个类（或接口）在编译后生成一个对应的 `.class` 文件。 
	- 该文件包含：类的完全限定名、字段、方法、构造器、常量池、注解等**所有类级别的元信息**。
2. 类加载阶段：`Class` 对象
	- JVM 启动后，通过类加载器读取 `.class` 文件，解析后在**方法区**（元空间）生成一个 `java.lang.Class` 对象。
	- 这个 `Class` 对象就是该类在 JVM 中的**运行时镜像**，包含：
	    - 所有字段的声明（名称、类型）
	    - 所有方法的字节码指令
	    - 构造器信息
	    - 静态变量（在 `Class` 对象中分配空间）
	    - 运行时常量池
	- 所以，**`Class` 对象保存了该类的全部“结构信息”**。
3. 创建对象（`new`）
	- 当执行 `new Student()` 时，JVM 会找到对应的 `Class<Student>` 对象（如果还未加载则先加载）。
	- 根据 `Class` 对象中描述的对象大小，在**堆内存**中开辟一块空间，用于存放该对象的**实例字段**（非静态字段）。
	- **对象头**中有一个指针指向它的 `Class` 对象，这样任何对象都能在运行时找到自己的“类模板”。
4. 方法调用：查找 `Class` 对象
	- 实例方法（非静态方法）的字节码并不存储在对象里，而是存放在方法区，与 `Class` 对象关联。
    - 当调用 `student.study()` 时，JVM 通过对象引用找到其对象头，再通过对象头找到对应的 `Class` 对象，从中查找 `study` 方法的字节码并执行。
    - 这就是**动态分派**的基础，也支持多态。
5. 补充细节
	- **静态字段**：属于类级别，直接在 `Class` 对象中分配空间（方法区），所有实例共享。
	- **实例字段**：每个对象在堆中有自己的副本。
	- **方法代码**：只有一份，存在方法区，所有实例共享。
	- **对象引用**：栈上的变量存储指向堆对象的指针。

注：定义一个类在编译时形成一个class文件，里面保存所有类信息，运行时，jvm读取class文件，形成class对象，里面保存了所有类的消息，有new这个对象时，对应这个类的class对象开辟一片空间保存new对象的字段消息，其他消息如方法调用时到class对象查询

# 二.反射

## 2.1反射

我们编写的<mark style="background: #FF5582A6;">程序</mark>从<mark style="background: #FF5582A6;">本质上</mark>来说也是<mark style="background: #FF5582A6;">文件</mark>， JVM 加载类的过程相当于对文件内容进行解析，解析内容就需要找到共有特征（ Class 类定义）``使用class文件，将class文件加载到jvm中``，然后再将这特征（使用 Class 对象）存储起来`每一个类都形成一个class对象`，在使用的时候再取出来。<mark style="background: #FF5582A6;">通过 Class 对象</mark>反向推到我们编写的类的内容，然后再<mark style="background: #FF5582A6;">进行操作</mark>——》执行类的操作例如：构造器创建对象，使用set方法赋值等，这个过程就称为反射。

对应关系：
1. class文件/class对象——类
2. class对象操作构造器：普通类的对象

## 3.2获得构造器:
```java
package com.jsp.relection;  
  
import com.jsp.relection.student;  
  
import java.lang.reflect.*;  
import java.util.Arrays;  
  
public class reflection {  
    public static void main(String[] args) {  
        Class<student> stu = student.class;  
        Constructor[] constructors = stu.getDeclaredConstructors();  
        for(Constructor constructor:constructors){  
            String name = constructor.getName();  
            Class[] parameters = constructor.getParameterTypes();  
            System.out.println(name);  
            System.out.println(Arrays.toString(parameters));  
            System.out.println(constructor.getModifiers());//获取构造器类型  
        }  
        System.out.println("=======================获得public的构造器====================");  
        Constructor[] constructors_public = stu.getConstructors();  
        for(Constructor constructor:constructors_public){  
            String name = constructor.getName();  
            Class[] parameters = constructor.getParameterTypes();  
            System.out.println(name);  
            System.out.println(Arrays.toString(parameters));  
            System.out.println(constructor.getModifiers());//获取构造器类型  
        }  
        System.out.println("=======================获得固定参数的构造器====================");  
        try {  
            Constructor constructors_parameter = stu.getConstructor(int.class,String.class); //公开的构造器 
            String name = constructors_parameter.getName();  
            Class[] parameters = constructors_parameter.getParameterTypes();  
            System.out.println(name);  
            System.out.println(Arrays.toString(parameters));  
            System.out.println(constructors_parameter.getModifiers());//获取构造器类型  
        } catch (SecurityException e) {  
            throw new RuntimeException(e);  
        } catch (NoSuchMethodException e) {  
            throw new RuntimeException(e);  
        }  
  
    }  
}
```

## 3.3获取字段：

```java
package com.jsp.relection;  
  
import com.jsp.relection.student;  
  
import java.lang.reflect.*;  
import java.util.Arrays;  
  
public class reflection {  
    public static void main(String[] args) {  
        Class<student> stu = student.class;  
        Field[] fields = stu.getDeclaredFields();  
        for(Field f: fields){  
            System.out.print(f.getName() + " ");  
            System.out.print(f.getType().getName() + " ");  
            System.out.println(f.getModifiers());  
        }  
        System.out.println("=====================以固定名字获得字段===================");  
        try {  
            Field field = stu.getDeclaredField("age");  
            System.out.print(field.getName() + " ");  
            System.out.print(field.getType().getName() + " ");  
            System.out.println(field.getModifiers());  
        } catch (NoSuchFieldException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```

注：
1. 获取具体对象的字段值：`field.get(对象)`
2. field对每一个字段都是一个field对象保存，里面可能有多个具体实例在名字相同的字段
## 3.4获得方法

```java
package com.jsp.relection;  
  
import com.jsp.relection.student;  
  
import java.lang.reflect.*;  
import java.util.Arrays;  
  
public class reflection {  
    public static void main(String[] args) {  
        Class<student> stu = student.class;  
       Method[] methods = stu.getDeclaredMethods();  
       for (Method method : methods) {  
           int mods = method.getModifiers();  
           String methodName = method.getName();  
           Class[] paramerTypes = method.getParameterTypes();  
           System.out.print(mods + " " + methodName + " (");  
           for(Class c: paramerTypes){  
               System.out.print(c.getName());  
           }  
           System.out.println(")");  
       }  
       System.out.println("===============通过名称获得方法=====================");  
        try {  
            Method method_name = stu.getDeclaredMethod("setName",String.class);  
            int mods = method_name.getModifiers();  
            String methodName = method_name.getName();  
            Class[] paramerTypes = method_name.getParameterTypes();  
            System.out.print(mods + " " + methodName + " (");  
            for(Class c: paramerTypes){  
                System.out.print(c.getName());  
            }  
            System.out.println(")");  
        } catch (NoSuchMethodException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```

注：
1. getDelaredMethod：获得自己定义的方法
2. getMethod：获得全部方法，包括继承的方法

## 3.5构建对象，并赋值

使用field赋值：
```java
package com.jsp.relection;  
  
import com.jsp.relection.student;  
  
import java.lang.reflect.*;  
import java.util.Arrays;  
  
public class reflection {  
    public static void main(String[] args) {  
        Class<student> stu = student.class;  
        try {  
            Constructor<? extends student> c = stu.getDeclaredConstructor();  
            c.setAccessible(true);  
            student s = c.newInstance();  
            Field nameField = stu.getDeclaredField("name");  
            nameField.setAccessible(true);  
            nameField.set(s, "小明");  
            Field ageField = stu.getDeclaredField("age");  
            ageField.setAccessible(true);  
            ageField.set(s, 18);  
            System.out.println(s);  
        } catch (Exception e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```
