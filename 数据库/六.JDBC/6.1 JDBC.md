# 一.JDBC

JDBC (Java Database Connection)是<mark style="background: #FF5582A6;">Java数据库连接技术</mark>的简称，提供<mark style="background: #FF5582A6;">连接数据库的能力。</mark>

# 二.API

Java 作为目前世界上最流行的高级开发语言，当然不可能考虑去实现各种数据库的连接与操作。但 Java 语言的开发者对<mark style="background: #FF5582A6;">数据库的连接与操作提供了相关的接口</mark>，供各大<mark style="background: #FF5582A6;">数据库厂商去实现</mark>。这些接口位于 <mark style="background: #FF5582A6;">java.sql 包</mark>中。

## 2.1driver

java.sql.Driver ：数据库厂商提供的 JDBC 驱动包中必须包含该接口的实现，该接口中就包含<mark style="background: #FF5582A6;">连接数 据库的功能。</mark>

核心作用：driver维护的是连接的信息对吗，需要时创建连接

核心方法：建立一个连接
```java
//根据给定的数据库url地址连接数据库 
Connection connect(String url, java.util.Properties info) throws SQLException;
```

## 2.2drivermanager

java.sql.DriverManager ：数据库厂商的提供的 JDBC 驱动交给<mark style="background: #FF5582A6;"> DriverManager 来管理</mark>， DriverManager 主要负责<mark style="background: #FF5582A6;">获取数据库连接对象 Connection</mark>

核心方法：
```java
//通过给定的账号、密码和数据库地址获取一个连接 
public static Connection getConnection(String url, String user,                                       String password) throws SQLException
```

注：
1. 基础概念：
	1. **脏读**：读到别人未提交的修改（你所说的“脏数据”）。
	2. **不可重复读**：同一事务内两次读同一行，得到不同值（别人修改并提交了）。
	3. **幻读**：同一事务内两次查询同一条件，发现多了或少了某些行（别人插入了新行并提交）
2. sql到数据库时未提交，就可能不是最后数据，不是永久生效，可能在这个事务中要改
3. 不可重复读，幻读都是在提交数据后发送的异常：**给你的事务提供一个不受外界干扰的“快照”或“锁保护”环境**。其希望获得一个对本事务稳定的视图，解决：
	1. 不可重复读：读的时候形成一个视图，保存原数据
	2. 幻读：对区域加锁，避免插入修改
4. 最高形式：串行化

### 补充：串行化

在数据库领域，**串行化（Serializable）** 是指<mark style="background: #FF5582A6;">事务隔离级别的最高等级</mark>。  
它保证多个<mark style="background: #FF5582A6;">事务并发执行的结果</mark>，与将它们<mark style="background: #FF5582A6;">按某个顺序一个接一个串行执行</mark>完全<mark style="background: #FF5582A6;">相同</mark>，仿佛根本没有并发一样。

## 2.5statement

java.sql.Statement ：SQL语句执行接口，数据库厂商提供的 JDBC 驱动包中必须包含该接口的实 现，该接口主要提供执行 SQL 语句的功能

```java
//执行查询，得到一个结果集 
ResultSet executeQuery(String sql) throws SQLException; 
//执行更新，得到受影响的行数 
int executeUpdate(String sql) throws SQLException; 
//关闭SQL语句执行器 
void close() throws SQLException;
//将SQL语句添加到批处理执行SQL列表中 
void addBatch( String sql ) throws SQLException; 
//执行批处理，返回列表中每一条SQL语句的执行结果 
int[] executeBatch() throws SQLException;
```

注：
1. execeuteBatch能执行非查询类型的语句
2. executeQuery只能执行查询语句，返回结果集合

##  2.6ResultSet

java.sql.ResultSet ：查询结果集接口，数据库厂商提供的 JDBC 驱动包中必须包含该接口的实现， 该接口主要提供查询结果的获取功能

//获取指定列的字符串值

# 四.示例

```java
package com.jsp.jdbc;  
  
import java.util.*;  
import java.sql.*;  
  
public class mysqljdbc {  
    public static void main(String[] args)  {  
        //解释：使用jdbc连接技术  
        //mysql://localhost:3306 使用但是mysql数据库协议，访问的是本地计算机的3306端口  
        //root:使用的什么数据库  
        //serverTimezone=Asia/Shanghai:时区设置  
        String url = "jdbc:mysql://localhost:3306/student?serverTimezone=Asia/Shanghai";//8.0以后要求添加时区  
        String username = "root";  
        String password = "root";  
        try{  
            //加载驱动  
            Class.forName("com.mysql.cj.jdbc.Driver");//Driver实现了必须提供的接口  
            //获取连接  
            Connection connection = DriverManager.getConnection(url,username,password);  
            //新建sql语句执行器  
            Statement statement = connection.createStatement();  
            //执行查询  
            ResultSet rs = statement.executeQuery("select * from account");  
            //先调用next到达第一行  
            while(rs.next()){  
                System.out.println(rs.getString("account") +"," + rs.getDouble(2) + "," + rs.getString("state"));  
  
            }  
            rs.close();  
			statement.close();  
			connection.close();
        }catch(ClassNotFoundException e){  
            e.printStackTrace();  
        } catch (SQLException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```

使用 PreparedStatement 时，<mark style="background: #FF5582A6;"> SQL 语句中的参数一律使用 ? 号来进行占位</mark>，然后通过调用setXxx()方法来对占位的 ? 号进行替换。从而将参数作为一个整体进行查询。

```java
package com.jsp.jdbc;  
  
import java.sql.*;  
import java.util.*;  
  
public class mysqlPreparedStatement {  
    public static void main(String[] args){  
        String url = "jdbc:mysql://localhost:3306/student?serverTimezone=Asia/Shanghai";//8.0以后要求添加时区  
        String username = "root";  
        String password = "root";  
        System.out.println("请输入要查询的物品名称:");  
        Scanner sc = new Scanner(System.in);  
        String name = sc.nextLine();  
        name = "" + name + "";  
        try {  
            Class.forName("com.mysql.cj.jdbc.Driver");//Driver实现了必须提供的接口  
            Connection connection = DriverManager.getConnection(url,username,password);  
  
            //当字符串出现在需要布尔值的地方时，会被强制转换为数字。  
            String sql = "Select id,name,number,price,agent_id from goods where name =?;" ;  
            PreparedStatement ps = connection.prepareStatement(sql);  
            ps.setString(1,name);  
            ResultSet resultSet = ps.executeQuery();  
            while(resultSet.next()){  
                int id = resultSet.getInt("id");  
                String goodName = resultSet.getString("name");  
                int number = resultSet.getInt("number");  
                int price = resultSet.getInt("price");  
                int agent_id = resultSet.getInt("agent_id");  
                System.out.println(id + " " + goodName + " " + number + " " + price + " " + agent_id);  
            }  
        } catch (ClassNotFoundException e) {  
            throw new RuntimeException(e);  
        } catch (SQLException e) {  
            throw new RuntimeException(e);  
        }  
    }  
}
```
