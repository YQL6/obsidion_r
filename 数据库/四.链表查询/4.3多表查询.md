# 二.内连接

内连接相当于在笛<mark style="background: #FF5582A6;">卡尔积的基础</mark>上加上了<mark style="background: #FF5582A6;">连接条件</mark>。当没有连接条件时，内连接上升为笛卡尔积。

```sql
SELECT 字段名1, 字段名2, ..., 字段名n FROM 表1 [INNER] JOIN 表2 [ON 连接条件];

SELECT 字段名1, 字段名2, ..., 字段名n FROM 表1, 表2 [WHERE 关联条件 AND 查询条件];
```

示例：
```sql
SELECT COUNT(*) FROM stu INNER JOIN score ON stu.id=score.stu_id;
SELECT COUNT(*) FROM stu, score WHERE stu.id=score.stu_id;
```

# 三.外连接

外连接涉及到两张表：<mark style="background: #FF5582A6;">主表</mark>和<mark style="background: #FF5582A6;">从表</mark>，要查询的信息主要来自于哪张表，哪张表就是主表。

<mark style="background: #FF5582A6;">外连接查询的结果为主表中所有的记录。如果从表中有和它匹配的，则显示匹配的值，这部分相当于内连接查询出来的结果；如果从表中没有和它匹配的，则显示null。</mark>

![[Excalidraw/重构/连表查询|连表查询]]

<mark style="background: #FF5582A6;">外连接查询的结果 = 内连接的结果 + 主表中有的而内连接结果中没有的记录</mark>

注：
1. 外连接分为左外连接和右外连接两种。左外连接使用LEFT JOIN关键字，LEFT JOIN左边的是主表；
2. 右外连接使用RIGHT JOIN关键字，RIGHT JOIN右边的是主表。

## 3.1左外连接

```sql
SELECT 字段名1, 字段名2, ..., 字段名n FROM 主表 LEFT JOIN 从表 [ON 连接条件];
```

注：
1. on表示了两个外表怎么拼，笛卡尔积怎么留，一定程度上体现了where的作用
2. where：on筛选过后再筛选，但是可能导致左右连接退化为内连接

## 3.2 右连接

```sql
SELECT 字段名1, 字段名2, ..., 字段名n FROM 从表 RIGHT JOIN 主表 [ON 连接条件];
```

# 四.子表查询

## 4.1子查询

子查询就是嵌套在其他查询中的查询。因此，子查询出现的位置只有3种情况：在<mark style="background: #FF5582A6;">SELECT... FROM </mark>之间、在<mark style="background: #FF5582A6;">FROM...WHERE</mark>之间、在<mark style="background: #FF5582A6;">WHERE</mark>之后。

## 4.2 select...from

```sql
SELECT

id,

`name`,

(SELECT text FROM dict WHERE type='sex' AND value=sex) sex, birthday,

class

FROM

stu;
```

解读：
1. 位于select的相关子查询，在<mark style="background: #FF5582A6;">select阶段进行子查询</mark>
2. 由于要使用外部查询的结果，所以要再select阶段，每读一行数据，找出对应需要的字段后紧随其后将子查询需要的字段交给子查询，让子查询进行一次查询
3. 对于不相关的子查询：应该是直接一次性查询，根据数据库不同设置可能不同

## 4.3FROM...WHERE

执行时机是一开始就执行,执行时机为from阶段，要作为表来提供数据

```sql
SELECT c.*, d.* FROM stu c

INNER JOIN

score d ON c.id=d.stu_id

INNER JOIN

   (SELECT

      TIMESTAMPDIFF(YEAR, a.birthday,NOW()) age,

      b.score

   FROM stu a INNER JOIN score b ON a.id=b.stu_id

   WHERE a.name='汤辰宇'

   AND b.course='Java') e

ON TIMESTAMPDIFF(YEAR, c.birthday,NOW())=e.age AND d.score=e.scoreWHERE d.course='Java';
```

## 4.4WHERE

位于where后的子查询一般是提供一个常量以供查表需要,一般是位于where阶段前或where阶段中查询

```sql
SELECT a.*, b.* FROM stu a INNER JOIN score b ON a.id=b.stu_id WHERE b.score=(SELECT MAX(score) FROM score WHERE course='Java')AND b.course='Java';
```
