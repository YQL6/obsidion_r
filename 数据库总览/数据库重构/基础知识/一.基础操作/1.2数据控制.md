# 一.视图

## 1.1数据库对象

---

- 数据库对象
	- 表：
		- 表时存放数据的逻辑单元，以行和列的形式存在
	- 数据字典：
		- 就是系统表，存放数据库信息，由数据库系统维护,例如:`mysql数据库的表`，一般不动
	- 约束：
		- 执行校验的规则，用于保证数据的完整性
	- 视图：
		- 一个或者多个数据表里的数据的<mark style="background: #FFB86CA6;">逻辑显示</mark>，只是一个<mark style="background: #FF5582A6;">虚拟表</mark>
	- 索引：
		- 提高查询性能，相当于<mark style="background: #FFF3A3A6;">目录</mark>
	- 存储过程：
		- 用于完成一次性的业务处理
		- 可能由返回值，可能由返回值
	- 存储函数：
		- 用于完成一次特定的计算，返回一个返回值
	- 触发器：
		- 相当于一个事件的监听器，<mark style="background: #BBFABBA6;">当发生一个事件时，触发相应的操作</mark>

## 1.2视图

---

- 表格可以经过查询获得，视图<mark style="background: #FFF3A3A6;">原理同样</mark>

- 引入：
	- 敏感数据：
		- `select 查询形成子表：`
			- 有的数据比较敏感，有的不能被随便查询，其他的数据可以查询 ——》 <mark style="background: #FFF3A3A6;">创建一张去掉敏感字段的新的子表</mark>
			- 所有操作都放到子表上，但是所有操作都不会对原表更改，不会同步
		- `VIEW视图`:
			- 使用`view形成一个视图`，更改视图，会同步到原表中
			- 同步机制：
				- <mark style="background: #BBFABBA6;">不存储数据</mark>，查询的数据都是原表中的，更改操作都是<mark style="background: #FFF3A3A6;">直接作用到原表中</mark>
				- 针对不同的管理员<mark style="background: #FFF3A3A6;">使用不同视图</mark>，不同视图开放不同内容/字段，同时为视图<mark style="background: #ABF7F7A6;">分配不同修改数据的权限</mark>

- 视图：
	- 是一个虚拟表，本身不存储数据，都是从基表中查询的数据，每次调用都是从基表中查询
	- 基于一个真实的表/原表实现 ——》 <mark style="background: #FFF3A3A6;">基表</mark>
	- 本质：
		- 就是一组定义好的`select`语句，<mark style="background: #BBFABBA6;">封装起来</mark>，等待调用，直接根据调用视图的部分 ， <mark style="background: #BBFABBA6;">去到基表底层查询，取数据</mark>
		- 可以通过简单的视图更改数据 ——》 视图更改数据的语句<mark style="background: #FFF3A3A6;">由数据库系统更改为对基表的操作</mark>
	- 删除：
		- 不影响基表，仅是将一个定义删除

## 1.3视图创建

----

- 创建视图
	- `CREATE`
		- 基于基表创建视图
		- <mark style="background: #BBFABBA6;">基于视图创建视图</mark>
- `查询视图`:
	- `select ... from 视图`
- 查询视图数量：
	- `show tables`:当前数据库的视图和表的信息
	- `show tables from database`：查询对应表的信息
	- `SHOW CREATE view 视图`:查询视图的结构
	- `SHOW table view status `:查询视图的具体信息,包括视图的定义和语法定义等信息
- 查询视图结构
	- `desc 视图`

```sql
-- 创建表格
CREATE DATABASE dbtest14;

-- 使用数据库
use dbtest14;

-- 复制数据
Create TABLE emp01 
AS
select *
from atguigudb.employees;

CREATE TABLE dpt01 
AS 
select *
FROM atguigudb.departments;

-- 列属性可以复制过来,但是主键没有复制过来
-- 查看表结构
desc emp01;
desc dpt01;

-- 查看约束键/索引
-- 没有任何约束键，说明只复制了列和数值
SELECT * FROM information_schema.table_constraints
where table_name = 'emp01';

-- 创建视图

-- 创建视图方式1：

-- 单表视图
CREATE VIEW vu_emp1
AS
select employee_id,last_name,salary 
from emp01;


-- 使用视图
select * from vu_emp1;

-- 限制数据，所有视图的查询都是基于封装的查询使用的

-- 创建视图
CREATE VIEW vu_emp2
AS
select employee_id,last_name,salary 
from emp01 
where salary > 10000;

-- 使用视图
select * from vu_emp2;

-- 创建视图方式2：

-- 使用视图标明底层查询的字段的名字
-- 1.使用别名
CREATE VIEW vu_emp3
AS
select employee_id emp_id,last_name lnane,salary s 
from emp01;

-- 查询视图
-- 名字变为别名形式
select * from vu_emp3;

-- 2.使用视图指明
CREATE VIEW vu_emp4(emp_id,lname,s)
AS
select employee_id emp_id,last_name lnane,salary s 
from emp01;

-- 查询视图
-- 名字变为视图指明形式
select * from vu_emp4;

-- 针对聚合函数

-- 视图中的字段可能在基表中没有对应的字段，例如：聚合函数
CREATE VIEW vu_emp_sal
AS 
SELECT department_id ,AVG(salary) avg_sal
from emp01
where department_id is not null 
group by department_id ;

-- 查询视图
select * from vu_emp_sal;

select * from vu_emp4;

-- 针对多表查询

CREATE VIEW vu_emp_dept
AS
select e.employee_id,e.department_id,d.department_name 
from emp01 e JOIN dpt01 d ON e.department_id = d.department_id 
;

select * from vu_emp_dept;

-- 利用视图的格式化
-- 通过查询语句和字符串函数固定一种不在同一个表的字段组合格式
-- 例如：employee_id(department_name)
CREATE VIEW vu_emp_dept1
AS 
select CONCAT(e.employee_id ,'(',d.department_name,')')
from emp01 e JOIN dpt01 d ON e.department_id = d.department_id ;

-- 查询结果
select * from vu_emp_dept1;
select * from vu_emp_dept;

-- 基于视图创建视图

Create VIEW vu_emp1_emp
AS
select employee_id,last_name
from vu_emp1;

select * from vu_emp1_emp;

-- 查看视图

-- 方式1：查看本数据库的表对象和视图对象

SHOW TABLES;

-- 方式2：查看视图结构

DESC vu_emp1;

-- 方式3：查看视图属性

SHOW TABLE STATUS like 'vu_emp1';

-- 方式4：查看视图的详细定义信息
show create view vu_emp1;
```

注：
1. <mark style="background: #FFB86CA6;">视图本质是转为基表的查询</mark>，所以修改基表，视图查询结果就会改变

## 1.4视图修改

---

- 修改数据：
	- 基表数据修改
		- 修改数据`UPDATE ... set ... where`同步影响视图
	- 视图数据修改
		- 数据：
			- 简单视图数据可以修改，转换为基表的修改语句，修改基表，<mark style="background: #ABF7F7A6;">修改语句和表一致，只是表从基表变为视图了</mark>
		- 视图：
			- 修改视图：
				- `create or replace ....`:若是有覆盖，若是无创建
				- `ALTER VIEW .... AS ....`
			- 删除视图：
				- `DROP VIEW if exists ...`
			- <mark style="background: #FFB86CA6;">若是视图依靠视图创建，若是底层视图被删除，依靠的视图不会自动删除，而是使用时报错</mark>

```sql
-- 视图修改数据

-- 更改基表
update emp01 
set last_name =  '666'
where employee_id = 101;

-- 视图数据已经改变
select * from vu_emp1;

-- 删除视图的数据，由于约束键没有，可以修改
-- 更新视图数据，不一定成功，可能更新失败
-- 例如：视图中的聚合函数，只要是含有聚合函数的视图就不能更新
-- 只有当视图是和基表一一对应的情况才有可能更新，例如：连接的表更新对象不明确
delete from vu_emp1
where employee_id = 101;
show create view vu_emp1;

-- 视图发生变化
select * from vu_emp1;

-- 基表发生变化
-- 视图的操作自动转化为了基表的操作
select * from emp01;

-- 更改视图定义

-- 方法1：OR REPLACE

-- 若是有视图就更改，没视图就创建
-- 原来就有的表格修改
create OR REPLACE VIEW vu_emp1
AS
select employee_id,last_name,salary,email 
from emp01 
where salary > 10000;

-- 没有的表格创建
create OR REPLACE VIEW vu_emp001
AS
select employee_id,last_name,salary,email 
from emp01 
where salary > 10000;

-- 查看视图
select * from vu_emp1;

-- 方法2：使用ALTER

-- 使用ALTER修改定义
ALTER VIEW vu_emp1
as 
select employee_id,last_name,salary,email 
from emp01 
where salary > 7000;

-- 删除视图，和表的方法类似，使用drop

-- drop
drop view if exists emp1;
```

# 二.存储过程与函数

## 2.1引入

---

- 存储函数：
	- 将一定的逻辑封装好，提供别人使用
	- 一定有返回值
- 存储过程：
	- 将逻辑封装进去
	- 可能有返回值
- <mark style="background: #FFB86CA6;">两者最大区别就是存储过程没有返回值</mark>

## 2.2存储过程

---

- 存储过程：将一组经过<mark style="background: #ADCCFFA6;">预编译</mark>的`sql语句`<mark style="background: #FFF3A3A6;">放到服务器上</mark>，用户使用时直接发送指令，调用存储过程即可，服务器直接执行存储的`sql语句`

- 存储过程 `VS `视图：
	- 视图一般就当作虚拟表使用，只进行查询
	- 存储过程存储一组`sql语句`,可以进行各种各样的复杂操作，增删改查都可以

- 存储过程分类：按照参数分
	- 没有参数，无参无返回
	- `仅仅有IN类型`，有参数无返回
	- `仅仅带有out类型`,有返回无参数,存储过程内部不看外部传递变量，`默认out参数为null，需要初始化后使用`
	- `既带有IN又带有OUT`,有返回值又有参数
	- `有INOUT`,有参数有返回值
	- `IN,OUT,INOUT可以有多个`

- 语法结构：
```sql
-- in ——》 输入的参数，out ——》 输出的参数， inout ——》 既可以是输入的也可以是输出
CREATE PROCEDURE 存储过程名(IN|OUT|INOUT 参数名 参数类型,...)
# 说明信息，例程特征
[characteristics ...]
BEGIN
	存储过程体
END
```

- 例程特征可写的字段：
	- 数据访问性：[[表资源/数据库/例程特征/1.1数据访问行|1.1数据访问行]]
	- 是否确定：[[表资源/数据库/例程特征/1.2是否确定|1.2是否确定]]
	- 安全上下文:[[表资源/数据库/例程特征/1.3安全上下文|1.3安全上下文]]
	- 注释：[[表资源/数据库/例程特征/1.4注释|1.4注释]]
- 可写，可不写，没有用，仅是给程序员看的

```sql
DELIMITER $

CREATE FUNCTION count_by_dept(dpt_id INT)
RETURNS INT
DETERMINISTIC
READS SQL DATA
SQL SECURITY INVOKER
COMMENT '统计指定部门员工数'
BEGIN
    RETURN (SELECT COUNT(*) FROM employees WHERE department_id = dpt_id);
END $

DELIMITER ;

SELECT count_by_dept(10);
```

- `DILIMITER`:定义分隔符
	- 将一段`sql语句`包裹，然后包裹的内容使用分隔符可以使用`DILIMITER`定义的分隔符
	- 原来的分隔符`;`不能使用了
	- 使用场景：
		- 存储过程：
			- 存储过程整体语句会被`;`打断，换一个分隔符
			- 原来的分隔符用来告诉那些语句是单独的
	- <mark style="background: #FFB86CA6;">注意使用完一定要该回去</mark>

- 类型1：无参无返回值类型的存储过程
```sql
-- 准备工作

CREATE DATABASE dbtest15;

use dbtest15;

create table employees
as 
select *
from atguigudb.employees;

create table departments 
AS
select * 
from atguigudb.departments;

-- 无参无返回值类型的存储过程

-- 创建存储过程select_all_data(),查看employees表中的所有的数据
-- 更改分隔符为$
delimiter $ 
create PROCEDURE select_all_data()
BEGIN
    select * from employees;
-- 存储过程创建结束
END $
-- 修改分隔符回到；
delimiter ;

-- 调用存储过程
-- 存储过程使用call,函数使用select
call select_all_data();

-- 创建一个存储过程avg_employee_salary()，返回所有员工的平均工资

delimiter $

create procedure avg_employee_salary()
begin 
    select AVG(salary) from employees;
END $

delimiter ;

call avg_employee_salary();

-- 创建存储过程show_max_salary(),用来查看employees表中最高工资
delimiter $

create PROCEDURE show_max_salary()
begin 
    select max(salary) from employees;
end $

delimiter $

call show_max_salary();
```

- 类型2：无参有返回值的存储过程
```sql
-- 类型二：带out
-- 有返回值，无参数

-- 创建存储过程show_MIN_salary(),查看员工表中最低的工资，并将最低工资返回
-- 通过out参数`ms`输出

-- 查看表格中的工资的类型，设置返回值类型最好是一样，若是不一样，也要默认转换
DESC employees;

delimiter $
-- 知道是double(8,2),若是转换为double可以，
-- double才是规范写法，double(8,2)已经被启用了
create procedure show_min_salary(out ms DOUBLE)

BEGIN
    -- 使用into复制给ms，变量赋值 ——》 变量精讲中有
    select min(salary) into ms 
    from employees;
end $

delimiter ;

-- 调用

call show_min_salary(@ms);

-- 查看变量

select @ms;
```

- 类型3：有返回值无参类型
```sql
-- 类型3：带in的情况

-- 创建存储过程show_someone_salary(),查看表中的某个员工的工资
-- 使用in参数empname输入员工姓名

delimiter $

create procedure show_someone_salary(in empname VARCHAR(20))
begin 
    select salary from employees 
    where empname = last_name ;
end $

delimiter ;

-- 调用

-- 调用方式1：
call show_someone_salary('Abel');

-- 调用方式2：
set @empname= 'Abel';
call show_someone_salary(@empname);
```

- 类型4：有返回值有参类型
```sql
-- 类型4：带in和out

-- 创建存储过程show_some_salaruy2(),查看白哦中某个员工的工资
-- 使用in参数empname输入员工姓名，使用out参数empsalary输出员工工资

delimiter $
-- 注意类型转换问题，若是设置类型过小/无法转换，会报错
create procedure show_someone_salary2(in empname varchar(20),out empsalary double)

begin 
    select salary into empsalary
    from employees 
    where last_name = empname;
end $

delimiter ;

set @empname = 'Abel';
call show_someone_salary2(@empname,@empsalary);
call show_someone_salary2('Abel',@empsalary);
select @empsalary;

```

- 类型5：`inout`类型
```sql
-- 类型5：带inout
-- 创建存储过程show_mgr_name(),查询某个员工领导名
-- 使用inout emp_name传入员工名字，返回领导名字

delimiter $

create procedure show_mgr_name(inout emp_name varchar(20))
begin 
-- 使用自查询，效率更高
    select last_name into emp_name 
    from employees e1 JOIN employees e2 ON e1.manager_id = e2.employees_id 
    where e1.last_name = emp_name ;
end $

delimiter ;

-- 调用存储过程
set @emp_name = 'Abel';
call show_mgr_name(@emp_name);
select @emp_name;
```

## 2.3存储函数

---

- 与存储过程差不多，只是必须有返回值，且只能有一个

- 模板：
```sql
Create function 函数名(参数名 参数类型,....)
# 明确返回值类型
RETURNS 返回值类型
-- 例程声明，可有可无
[characteristics ..]
begin
	函数体  # 函数体中一定要有retrun语句
end 
```

- 参数属性：
	- 只有入参，没有输出参数，没有特殊标记`in`

```sql
-- 创建一个存储函数email_by_name()，参数为空
-- 该函数查询Abel的email,并返回，数据类型为字符串类型

delimiter $

create function email_by_name()
returns varchar(25)
# reads sql data
-- 必须加特性 ，可以手动关闭
begin 
    return (select email from employees where last_name = 'Abel');
END $

delimiter ;

-- 关闭特性
SET GLOBAL log_bin_trust_function_creators = ON;

select email_by_name();

-- 创建存储函数，名为email_by_id()，参数传入emp_id，该函数查询EMP_id的email
-- 返回时数据类型为字符串类型

delimiter $
create function email_by_id1(emp_id DOUBLE  )
returns varchar(25)

begin 
    return (select email from employees where emp_id = employee_id);
end $

delimiter ;

-- 方法1：直接放入参数
select email_by_id1(100);
-- 方法2：使用变量
set @emp_id:= 102;
select email_by_id1(@emp_id);

-- 创建存储函数count_by_id(),参数传入dpt_id，该函数查询dpt_id部门的员工人数
-- 返回人数,数据类型为INT

delimiter $

create function count_by_id(dpt_id INT)
returns int
begin 
    return (select count(*) from employees group by(department_id) HAVING dpt_id = department_id);
end $

delimiter ;

select count_by_id(10);
```

- `存储过程 VS 存储函数`:
	- 存储过程：
		- 调用方式：`call`
		- 返回值可以有可以没有
		- 返回值：通过变量注入返回
		- 参数：通过注入，使函数过程有值
	- 存储函数：
		- 调用方式
		- 返回值必须有，且只能有一个
		- 返回值：通过`return`返回
		- 参数：通过注入，使存储函数内部有值

# 三.变量

## 3.1全局变量和会话变量

---

- 变量：
	- 存储查询或计算的中间结果数据或者删除最终结果的数值
	- 分类
		- 系统变量
		- 用户自定义变量

- 系统变量
	- 非用户定义，<mark style="background: #ABF7F7A6;">服务器层面</mark>，由系统定义
	- 启动`mysql`服务时，<mark style="background: #BBFABBA6;">生成`mysql`实例</mark>，里面由多个系统变量

## 4.1程序出错的处理

---

- 由于各种原因可能执行失败 ——》报异常

- 异常处理:
	- 定义条件：预先定义可能用到的问题
		- 错误码：
			- 两种码：指的都是一个错误
			  ![[图片/Pasted image 20260921182751.png]]
				- 红色：`MYSQL_error_code` <mark style="background: #FFB86CA6;">,数值类型</mark>错误代码 ——》数据库系统自己定义的
				- 蓝色:`SQLstate_value` ， 长度为5的<mark style="background: #BBFABBA6;">字符串类型</mark>代码 ——》`sql标准语句的错误码`
	- 处理程序：若是遇到问题后，根据编写的应对代码执行
		- <mark style="background: #FFF3A3A6;">处理格式：</mark>
			- `DECLARE 处理方式 HANDLER FOR 错误类型 处理语句`
			- 含义：若是出现错误类型就按处理方式处理，处理语句自定义
		- 处理方式：
			- `CONTINUE`:
				- 进行执行程序
			- `EXIT`:
				- 退出程序
			- `UNDO`:
				- 标识遇到错误后撤回之前的操作，回滚操作，`mysql`不支持
		- 错误类型：
			- `SQLSTATE '字符串错误码'`:
				- 标识长度为5的`sqlDATE_value类型的错误代码`
			- `mysql_error_code`:
				- 匹配数值类型错误代码
			- `报错名称`:
				- 定义的错误名称，方便阅读
			- `SQLWARING`:
				- 匹配所有以`01`开头的`SQLSTAE`错误代码
			- `NOT FOUND`:
				- 匹配没有以`02`开头的`SQLSTATE`错误代码
			- `SQLEXCEPTION`:
				- 匹配所有没被`SQLWARING 和 NOT FOUND`的错误代码
		- 处理语句：
			- `set ... `:定义用户变量
			- `begin .... end`:复杂处理语句

    select avg(salary) into avg_salary from employees ;
    
    repeat
        # 此时没有检查，每次都能执行一次再退出，bug
        #循环体
        update employees set salary = salary * 1.15;
        set repeat_count = repeat_count + 1;
        select avg(salary) into avg_salary from employees;
        #结束条件
        UNTIL avg_salary >=13000
    end repeat ;
    set num = repeat_count;

## 4.5游标的使用

---

- 游标/光标：
	- 指向某条数据表项，对一条数据进行操作——》类似一个指针，指向一个具体的表项
	- 一般对数据的操作，都是获得一个结果集进行操作——》`update,delete`

```sql
-- 游标

-- 声明游标

-- DECLARE 关键字来声明游标
-- DECLARE 游标名 COURSOR fro 结果集

-- 打开游标，此时将结果集送到游标的工作区
-- open 游标名

-- 使用游标，变量名一般和字段一致，变量名和字段数量一致
-- Fetch 游标名 INTO 变量名

-- 关闭游标
-- close 游标名

-- 示例：创建存储过程'get_count_by_limit_total_salary()',声明in参数limit_total_salary
-- double类型，声明out参数total_count,int类型,函数的功能可以实现累加薪资最高几个员工的薪资值，
-- 知道薪资综合达到limit_total_salary参数的值，返回累加的人数给total_count

delimiter $
create procedure get_count_by_limit_total_salary(in limit_total_salary double , out total_count int )
BEGIN
    # 定义局部变量
    declare sum double default 0; #记录累加的工资总和
    declare emp_sal double default 0; #记录一个员工的工资
    declare count int default 0;
    -- 游标最后声明
    declare emp_salary_cursor cursor for select salary from employees order by salary  desc;
    
    -- 打开游标
    open emp_salary_cursor;
    
    -- 使用游标
    while sum < limit_total_salary do 
    
        fetch emp_salary_cursor into emp_sal;
        
        set sum = sum + emp_sal;
        set count  = count + 1;
    end while ;
    
    set total_count = count ;
    
    -- 关闭游标
    close emp_salary_cursor;
end $
delimiter ;

drop procedure get_count_by_limit_total_salary;

call get_count_by_limit_total_salary(100000,@count);
select @count;
```

## 4.6错误处理补充

---

- `SIGNAL sqlstate 'HY000' set message_test = '薪资高于领导';`:
	- <mark style="background: #ABF7F7A6;">错误抛出处理，主动抛出</mark>
- `RESIGNAL ...../错误处理语句`
	- <mark style="background: #FFF3A3A6;">捕获的错误重新抛出，主动抛出</mark>
	- 再`begin ... end ...`中定义错误处理，然后捕获错误的处理中，对错误可以重新抛出，并可以对显示的错误信息进行定义

```sql
DELIMITER $

CREATE PROCEDURE check_salary()
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        RESIGNAL SET MESSAGE_TEXT = '处理过程中发生错误';
    END;

    IF (SELECT salary FROM employees WHERE employee_id = 100) >
       (SELECT salary FROM employees WHERE employee_id = 101) THEN
        SIGNAL SQLSTATE 'HY000'
        SET MESSAGE_TEXT = '薪资高于领导';
    END IF;
END $

DELIMITER ;

# resignal

DELIMITER $

CREATE PROCEDURE p()
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        -- 这里可以记录日志、回滚等
        RESIGNAL;   -- 原样抛出错误
    END;

    -- 可能出错的语句
    INSERT INTO employees(employee_id, last_name)
    VALUES (NULL, 'test');
END $

DELIMITER ;
```

## 5.1触发器创建

---

- 例如：若是商品信息和库存信息分为两张表格，若是商品已卖出，库存表格应该<mark style="background: #BBFABBA6;">同步执行</mark>，若是没有执行则应该全部回退(将两个操作关联起来放到事务中：商品卖出 + 同步信息) ——》 事务 + 触发器

- 触发器不单独使用事务，自动放到关联操作的事务执行 ——》 关联操作 + 触发器 一起

- 触发流程：
	- 事件执行
	- 事件绑定了一个监听器/触发器 ——》 自动执行监听器/触发器的代码
	- 触发器/监听器 实现功能

    declare mgr_salary int default 0;
