# 一.快速入门

## 1.1java存储数据

---

- 数据在代码运行时，数据放在内存中
	- 内存小且重启后会消失
- 使用`I/O`流获得数据
	- 数据看不懂
	- 没有结构和逻辑，难以使用
- 数据库
	- 使用java程序获得数据库数据和操作数据库数据

## 1.2概述

---

- `jdbc`:`java database connectivity`
	- <mark style="background: #FFB86CA6;">独立</mark>于各个数据库的接口
		- 多个不同的数据库，不可能程序员都学怎么实现，而数据库也不允许，但方面的连接——》`java提供接口,数据库进行实现接口`
		- 数据库厂商封装提供`jar包` _ 数据库驱动`jar包`

- 程序通过接口调用：
	- 接口调用：调用不同的驱动
		- 驱动：连接数据库

## 1.3核心组成

---

- `java.sql`:
	- 定义了`java的sql接口`
	- 类型
		- `java.sql`：
			- 基础使用的接口
		- `javax.sql`:
			- 扩展的接口
- 实现过程：
	- 有不同厂商的驱动，使用流程不同，驱动去官网下载
	- 导入厂商提供的驱动

```
JDBC（规范）
├── java.sql        JDBC 核心 API
├── javax.sql       JDBC 扩展 API
└── 驱动实现         MySQL、Oracle、PostgreSQL 等厂商提供
```

注：
1. jdbc不是一个接口名，是一个规范，使用jdbc意思是使用jdbc接口规范的接口，有两个包`sql,javax.sql`

# 二.使用JDBC

## 2.1搭建

---

- 准备数据库
- 下载驱动`jar包`,[官网](https://downloads.mysql.com/archives/c-j/)
	- 尽可能选择`8.0.25以后的版本，无需设置时区`
- 创建java项目，复制`jar`包到`lib文件`中，然后集成`jar包`
	- 
  ![[图片/Pasted image 20260926172004.png]]

```java
import java.sql.*;

public class mysql {
    public static void main(String[] args) throws Throwable {
        //1.注册驱动
        /*
        * 将数据库厂商提供的驱动类通过类加载方式加载到程序中
        * */
        Class.forName("com.mysql.cj.jdbc.Driver");
        //2.连接对象
        /*连接数据库需要
        * 地址:jdbc:mysql://地址:端口号/数据库
        * 用户名
        * 密码
        *
        * */
        String url = "jdbc:mysql://localhost:3306/atguigudb";
        String username = "root";
        String password = "root";
        Connection con = DriverManager.getConnection(url, username, password);

        //3.获取sql执行的对象

        Statement stmt = con.createStatement();

        //4.编写sql语句执行,执行sql语句，接收返回的结果集
        String sql = "select * from employees;";
        //sql执行查询以后获得是一个表格，resultset中就封装了表的行和列
        ResultSet rs = stmt.executeQuery(sql);

        //5.处理结果

        //rs中有行和列，要进行循环，不断获得下一行
        while(rs.next()){
            //对每一行数据进行获取 ——》 每行都有多个列，获得列——》使用第几列或列名
            int emp_id = rs.getInt("employee_id");
            String emp_name = rs.getString("last_name");
            System.out.println(emp_id + " " + emp_name);
        }
        //6.关闭资源：连接资源，执行资源，结果资源
        //原则：先开后关
        rs.close();
        stmt.close();
        con.close();
    }
}

```

## 2.2核心API讲解

---

- 类加载：
	- 注册驱动程序，使`JDBC API`能识别并与特定的数据库进行及爱哦胡
	- `jdk6以后可以不写`
	- 使用注册的具体实现：
		- 加载类`Driver`时，会触发静态代码，执行注册,在`DriverManager中使用registerDriver注册一个Driver`
	- 接口：
		- `Driver`:
			- 创建厂商实现的驱动类，每个厂商的驱动类的名字可能相同，但是路径不同
		- `DriverManager`:
			- 管理驱动类：
				- 管理各个驱动，每个驱动创建后都要在这里注册，保证管理
				- 获得`url`后，对各个驱动类进行匹配，看看是哪个驱动类的`url`
				- 返回建立的连接
```java
    //Class.forName("com.mysql.cj.jdbc.Driver");
        //手动注册一个驱动类
        //6.0以后会自动注册
        DriverManager.registerDriver(new Driver());
        //2.连接对象
```

- `Connection`:
	- 数据库的连接，维护，代表一次数据库的连接/会话
	- url:
		- `jdbc:mysql//localhost:3306/atguigu`
		- 若是`mysql`，则`jdbc:mysql//主机号:端口号/数据库?参数键值对1&参数键值对2...`
		- 若是主机和端口未改过：
			- `jdbc:mysql:///数据库`
	- 可以通过连接创建`Statement`执行对象

- `Statement`:
	- 执行`sql`语句并于数据库进行交互，并获得`ResultSet`结果
	- 结果：
		- 增删改：受影响行数
		- 查：结果表
	- 以后不用，可能发生`sql`注入
		- 若是输入`sql的条件`可能发生一些特殊符号的注入，直接发给数据库执行，发生特殊操作
		- 例如：删库
```java

        //sql注入可能输入不是用户权限的操作执行
        String name = sc.nextLine();
        //可以输入abc' or 1 = '1' = '
        //组成 name = 'abc' or '1' = '1'脱离本意
        String sql = "select * from employees where last_name = '" + name + "'";
```

- `PreparedStatement`:
	- 是`Statement`的子接口
	- 预编译`sql语句`,创建`PreparedStatement`时便已经编译了`sql语句`,对`sql`中需要注入的地方使用`?`进行占位，无法对`sql`进行注入
	- 防止注入：
		- 输入的值都会加上一对单引号在放进去，<mark style="background: #FFF3A3A6;">同时对特殊符号转义为普通字符</mark>，这样即使是注入也会当作一个字符串
		- 例如：`'abc' or '1' = '1' '`
	- 效率提高
```java
//对条件使用?占位
        String sql_p = "select * from employees where last_name = ?";
        //必须对其传入一个sql语句
        PreparedStatement p = con.prepareStatement(sql_p);
        //对占位符进行赋值
        /*
        * 参数：
        *   第几个占位符：从1开始
        *   占位符的值
        * */
        p.setString(1,"King");
        ResultSet rs = p.executeQuery();
        while(rs.next()){
            //对每一行数据进行获取 ——》 每行都有多个列，获得列——》使用第几列或列名
            int emp_id = rs.getInt("employee_id");
            String emp_name = rs.getString("last_name");
            System.out.println(emp_id + " " + emp_name);
        }
```

- `ResultSet`:
	- 一个接口
	- 方法：
		- `next()`:
			- 看有没有下一个行，有向下，没有接收，放到`while中`
			- <mark style="background: #FFF3A3A6;">刚开始是再0行，使用后进入第一行——》一定要执行一次进入第一行</mark>
		- `getString/Double...(string name)`:
			- 获得对应列名的数据
```java
 while(rs.next()){
            //对每一行数据进行获取 ——》 每行都有多个列，获得列——》使用第几列或列名
```

```java
package mysql;

import org.junit.Test;
import org.springframework.transaction.annotation.Propagation;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

public class Mysql_CUDA {
    @Test
    public void testQuerySingLeRowAncol() throws Throwable{
        //连接
        Connection con = DriverManager.getConnection("jdbc:mysql:///atguigudb", "root", "root");
        PreparedStatement p = con.prepareStatement("select * from employees;");
        ResultSet rs = p.executeQuery();
        while(rs.next()){
            String name = rs.getString("last_name");
            int id = rs.getInt("employee_id");
            System.out.println(name + " " + id);
        }
        rs.close();
        p.close();

        con.close();
    }
}

```
