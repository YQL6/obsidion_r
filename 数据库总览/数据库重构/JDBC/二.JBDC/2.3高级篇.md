# 二.工具类

## 2.1JDBCUtil01

---

- 讲数据源创建连接等操作进行封装，只对外进行暴露一些公共用法即可

- 创建 ——》 共用一个数据源，静态代码块
- 连接 ——》 获得一个连接由接口提供，静态方法
- 回收 ——》 由接口提供，静态方法

```java
// 示例

package mysql.Util;  
  
import com.alibaba.druid.pool.DruidDataSource;  
import com.alibaba.druid.pool.DruidDataSourceFactory;  
  
import javax.sql.DataSource;  
import java.io.IOException;  
import java.io.InputStream;  
import java.sql.Connection;  
import java.sql.SQLException;  
import java.util.Properties;  
  
public class jdbcUtil {  
  
    //共同使用一个数据源，所有连接都是从这里获得  
    //声明一个接口，若是要换数据源直接换驱动，无需重新声明  
    private static DataSource dataSource;  
    static{  
        Properties prop = new Properties();  
        InputStream in = jdbcUtil.class.getClassLoader().getResourceAsStream("jdbc.properties");  
        try {  
            prop.load(in);  
            dataSource = DruidDataSourceFactory.createDataSource(prop);  
        } catch (Exception e) {  
            throw new RuntimeException(e);  
        }  
    }  
    public static Connection getConnection() throws SQLException {  
        return dataSource.getConnection();  
    }  
    public static void release(Connection con){  
        try{  
            con.close();  
        }catch(Exception e){  
            e.printStackTrace();  
        }  
    }  
}
```

## 2.2JDBCUtil02

---

- 若是一个线程/用户中多次使用连接，但是操作时间不确定，可能过长导致连接回收，多次回收浪费资源 
	- 例如：
		- 查看商品：一个连接
		- 添加购物车：一个连接
		- 提交订单：一个连接
		- 支付：一个连接
	- 这个操作可能时连续的，但是可能不连续 ——》<mark style="background: #FFF3A3A6;">连接可能不是同一个，建立了多个连接，开销大</mark>，多个操作，多个连接

- 解决问题：
	- `ThreadLocal`:
		- 再本地线程中绑定一个连接，使不同操作只要在线程中，就能<mark style="background: #FFB86CA6;">共享这个连接</mark>，避免多连接的创建
	- 实现：
		- 每一个线程中都有一个`ThreadMapper<Threadlocal,Object>`
		- 使用`Threadlocal的方法set和get，remove方法来处理`

- 代码优化：
```java
package mysql.Util;  
  
import com.alibaba.druid.pool.DruidDataSource;  
import com.alibaba.druid.pool.DruidDataSourceFactory;  
  
import javax.sql.DataSource;  
import java.io.IOException;  
import java.io.InputStream;  
import java.sql.Connection;  
import java.sql.SQLException;  
import java.util.Properties;  
  
public class jdbUtil02 {  
  
    //共同使用一个数据源，所有连接都是从这里获得  
    //声明一个接口，若是要换数据源直接换驱动，无需重新声明  
    private static DataSource dataSource;  
    //绑定到threadlocal上  
    //使用threadlocal是为了在线程中多次数据库操作中，使用同一个连接  
    //同时保证了事务的统一  
    private static ThreadLocal<Connection> threadLocal = new ThreadLocal<>();  
    static{  
        Properties prop = new Properties();  
        InputStream in = jdbUtil02.class.getClassLoader().getResourceAsStream("jdbc.properties");  
        try {  
            prop.load(in);  
            dataSource = DruidDataSourceFactory.createDataSource(prop);  
        } catch (Exception e) {  
            throw new RuntimeException(e);  
        }  
    }  
    public static Connection getConnection() throws SQLException {  
        //从threadlocal中取connection  
        Connection conn = threadLocal.get();  
        //判读是否为第一次存储  
        if (conn == null) {  
            //是第一次 ——》 创建  
            conn = dataSource.getConnection();  
            //存储  
            threadLocal.set(conn);  
        }  
        return conn;  
    }  
    //释放连接  
    //无需在传递连接，传递连接，在多个层级间易出错  
    public static void release(){  
        try{  
            Connection conn = threadLocal.get();  
            //有连接存储  
            if(conn != null){  
                //移除绑定的连接  
                threadLocal.remove();  
                //归还连接给连接池  
                conn.close();  
            }  
        }catch(Exception e){  
            e.printStackTrace();  
        }  
    }  
}
```
