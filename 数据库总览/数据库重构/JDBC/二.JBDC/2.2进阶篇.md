# 一.实体类

## 1.1实体类

- 数据库一行是一个对象，描述一个实体 ——》 java中一切皆对象
	- 实体/表格  ——》 一个实体
	- 字段 ——》 类中的属性
	- 实体和类一一对应

- `ORM思想`:
	- java对象和数据库表进行联系起来
		- 表 ——》 类
		- 字段 ——》 属性
		- 一行实体 ——》一个对象
- `JDBC手动完成ORM`
	- 将封装以后的结果进行集合返回
- `JDBCTemplate 传入 rowMapper重写方法完成映射关系`
- `使用`:
	- 插入：封装一个对象，数据从对象中那
	- 查询：结果封装到一个对象集合中
```java
@Test  
public void testORM() throws Throwable{  
    Connection con = DriverManager.getConnection("jdbc:mysql:///atguigudb","root","root");  
    PreparedStatement p = con.prepareStatement("select last_name,employee_id from employees;");  
    List<employees> list = new ArrayList<employees>();  
    ResultSet rs = p.executeQuery();  
    while(rs.next()){  
        employees e1 = new employees();  
        e1.setLast_name(rs.getString("last_name"));  
        e1.setId(rs.getInt("employee_id"));  
        list.add(e1);  
    }  
    System.out.println(list);  
    rs.close();  
    p.close();  
    con.close();  
}
```

## 1.2主键回显

---

- `对预编译设置对应的值`
- 执行，但是主键自增长
- 执行回显，接收

- 略

```java
import java.sql.*;

public class JdbcKeyEchoDemo {

    /**
     * 插入用户，并回显自增主键
     * @param user 待插入的用户对象（此时 id 为 null）
     */
    public void insertUser(User user) {
        // SQL 语句，占位符 ? 对应 username 和 password，注意不包含 id
        String sql = "INSERT INTO user(username, password) VALUES(?, ?)";

        // 使用 try-with-resources 自动关闭资源（Connection、PreparedStatement、ResultSet）
        try (Connection conn = JDBCUtil.getDataSource().getConnection();
             // 关键点1：创建 PreparedStatement 时，必须指定 Statement.RETURN_GENERATED_KEYS
             PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {

            // 填充占位符
            ps.setString(1, user.getUsername());
            ps.setString(2, user.getPassword());

            // 执行插入操作，返回受影响的行数
            int affectedRows = ps.executeUpdate();

            // 判断是否插入成功
            if (affectedRows > 0) {
                // 关键点2：通过 getGeneratedKeys() 获取数据库刚刚生成的主键
                // 返回的是一个 ResultSet，里面封装了生成的主键值
                try (ResultSet rs = ps.getGeneratedKeys()) {
                    // 因为一次插入通常只生成一个主键，所以 rs 里只有一行一列
                    if (rs.next()) {
                        // 获取第一列的值（即自增主键）
                        int generatedId = rs.getInt(1);
                        
                        // 关键点3：将获取到的主键值回填（回显）到 User 对象中
                        user.setId(generatedId);
                        
                        System.out.println("插入成功，回显的主键 ID 为：" + user.getId());
                    }
                }
            }
        } catch (SQLException e) {
            throw new RuntimeException("插入用户失败", e);
        }
    }
}
```

## 1.3批量处理

---

- 使用`for修改`,多次和数据库操作，时间极长
- 告知连接这一次发送给你的是一个`sql`，即`insert into(...) values(),values()...`

```java
@Test
    public void test_batchInsert() throws Throwable{
        Scanner sc = new Scanner(System.in);
        /*
        * 1.开启批处理操作，使用参数开启rewriteBatchedStatements=true
        * 2.关闭事务自动操作，避免执行一次虽然放到一起，但是提交就是一个一个提交
        * 3.书写新增的sql必须用values，且语句不可以使用;
        * 4.调用addBatch()操作，将sql进行添加操作
        * 5.统一执行批量操作executeBatch()
        * */
        Connection con = DriverManager.getConnection("jdbc:mysql:///atguigudb?rewriteBatchedStatements=true","root","root");
        PreparedStatement p = con.prepareStatement("insert into employees(last_name,employee_id) values(?,?)");
        List<employees> list = new ArrayList<employees>();
        for(int i = 0 ; i < 100000 ; i++){
            String name = sc.nextLine();
            employees e1 = new employees();
            e1.setLast_name(name);
            e1.setId(i);
            list.add(e1);
        }
        //务必关闭事务自动提交
        con.setAutoCommit(false);
        for(int i = 0 ; i < 100000 ; i++){
            p.setString(1,list.get(i).getLast_name());
            p.setInt(2,list.get(i).getId());
            p.addBatch();
        }
        p.executeBatch();
    }
```

# 二.数据源

## 2.1概述

---

- 每次执行代码都是获得新连接
- 多个用户使用，都获得新连接，每次都关闭 ——》 `connection`不断创建，销毁 ——》JVM虚拟机不断执行，花销大
- 多个`connection`可能太多，数据库设定连接数达到上限，同时对服务器压力非常大

- 连接流程：
  ![[Excalidraw/数据库总览/数据库重构/JDBC/二.JDBC/2.2进阶篇/二.数据源/2.1概述/连接过程|连接过程]]

- 解决问题：
	- 连接池:进行分配连接给用户，相当于连接的缓冲区
		- 类比：电信客服 与 电信用户，用户打客服，不可能客服和用户一样多，而是用户等待与客服连接，相当于连接池，等待连接
	- 使用：
		- 预先创建数据库连接放到连接池中
		- 用户请求连接，通过连接池获得
		- 使用完以后，重置可以重置的东西，放回连接池中
		- 若是没有连接且用户请求：
			- 达到上限：等待
				- 设置等待时间等
			- 未达到上限：创建连接
	- `JDBCTemplate`使用数据源进行获得连接，`Spring对JDBC的封装`

- 示例：
```java
import com.zaxxer.hikari.HikariConfig;
import com.zaxxer.hikari.HikariDataSource;
import java.sql.*;

public class HikariPoolDemo {

    private static HikariDataSource dataSource;

    private static void initDataSource() {
        HikariConfig config = new HikariConfig();

        // ---- 基本连接信息 ----
        config.setJdbcUrl("jdbc:mysql://localhost:3306/atguigudb"
                + "?useSSL=false"
                + "&serverTimezone=Asia/Shanghai"
                + "&characterEncoding=utf8"
                + "&rewriteBatchedStatements=true");
        config.setUsername("root");
        config.setPassword("root");
        config.setDriverClassName("com.mysql.cj.jdbc.Driver");

        // ---- 连接池核心参数 ----
        config.setMinimumIdle(5);          // 最小空闲连接
        config.setMaximumPoolSize(20);     // 最大连接数
        config.setConnectionTimeout(3000); // 获取连接超时(ms)
        config.setIdleTimeout(600000);     // 空闲连接超时(ms)
        config.setMaxLifetime(1800000);    // 连接最大存活时间(ms)

        // ---- 连接有效性检测 ----
        config.setConnectionTestQuery("SELECT 1");

        // ---- 连接池名称（方便日志排查）----
        config.setPoolName("MyHikariPool");

        // 创建连接池
        dataSource = new HikariDataSource(config);

        System.out.println("HikariCP 连接池初始化完成");
    }

    public static void queryDemo() {
        String sql = "SELECT employee_id, last_name FROM employees WHERE employee_id > ?";

        // try-with-resources 自动归还连接
        try (Connection con = dataSource.getConnection();
             PreparedStatement ps = con.prepareStatement(sql)) {

            ps.setInt(1, 100);

            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    System.out.println(rs.getInt("employee_id") + " - "
                            + rs.getString("last_name"));
                }
            }

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public static void closeDataSource() {
        if (dataSource != null) {
            dataSource.close();
            System.out.println("HikariCP 连接池已关闭");
        }
    }

    public static void main(String[] args) {
        initDataSource();
        queryDemo();
        closeDataSource();
    }
}
```

## 2.3Druid实现

---

- 引入`jar包`
- 使用：

		- 和`java耦合到一起`
	- 配置文件/软编码:
		- 放到配置文件中，使用`I/O`流获得
		- 实现：`Spring有IOC容器实现，一般使用注解实现注入，使用注解类引入配置文件搭建一个数据源的组件`

```java
package mysql;

import com.alibaba.druid.pool.DruidDataSource;

import java.sql.Connection;
import java.sql.SQLException;

public class DruidTest {
    public void testHardCodeDruid() throws SQLException {
        /*
        * 硬编码：将配置信息和java代码耦合到一起
        * 1.创建DruidDataSource连接对象
        * 2.设置连接池配置信息
        * 3.通过连接池获取连接
        * 4.回收连接：放回连接池中，不是销毁
        * */
        //1.创建连接池
        DruidDataSource ds = new DruidDataSource();
        //2.配置连接池信息
        //2.1配置驱动
        ds.setDriverClassName("com.mysql.cj.jdbc.Driver");
        //2.2配置url
        ds.setUrl("jdbc:mysql:///atguigudb");
        //2.3配置user
        ds.setUsername("root");
        //2.4配置password
        ds.setPassword("root");
        //2.5可选择配置
        //初始化的连接的数量
        ds.setInitialSize(2);
        //最大的数量
        ds.setMaxActive(5);
        //3.获得连接方法
        Connection con = ds.getConnection();
        //基于 con 进行 CRUD
        
        //4.回收连接
        con.close();
    }
}

```
