# 一.什么是DQL

DQL全称是Data Query Language，表示数据查询语言。体现在数据的查询操作上，因此，DQL仅包括 SELECT语句。

# 二.select

```sql
SELECT ALL/DISTINCT * | 字段名1 AS 别名1[,字段名1 AS 别名1, ..., 字段名n AS 别名n] FROM 表名 WHERE 查询条件
```

注：
1. ALL表示查询所有满足条件的记录，可以省略；DISTINCT表示去掉查询结果中重复的记录 
2. AS可以给数据列、数据表取一个别名，as可以省略，直接`旧名 新名` 

示例：
```sql
select name '学生姓名' from student where age=18;
```

## 4.2分组查询

```sql
SELECT ALL/DISTINCT * | 字段名1 AS 别名1[,字段名1 AS 别名1, ..., 字段名n AS 别名n] FROM 表名 WHERE 查询条件 GROUP BY 字段名1，字段名2,..., 字段名n
```

示例：
```sql
SELECT * FROM student WHERE score>80 GROUP BY sex;
```

注：
1. where在分组查询以后再进行淘汰
2. 对于每一组要求输出信息时，随机输出一条
3. 分组是按值将各条数据分为不同组，后要查询一条数据里面的一个属性，由于分组只能是各组返回一条数据来显示这个属性，甚至有的数据库不支持
4. <mark style="background: #FF5582A6;">往往是需要聚合函数作为查询值使用</mark>

### <mark style="background: #FF5582A6;">分组本质：</mark>按值分组
1. 逐行计算派生值：数据库先扫描 stu 表的<mark style="background: #FFB86CA6;">每一行</mark>，对每行的 class 列执行 LEFT(class, 2) 函数，截取字符串的前2个字符。

- 例如： class="计科2401"  → 计算结果为 "计科" 

- 例如： class="软工2402"  → 计算结果为 "软工" 

2. <mark style="background: #FF5582A6;">按派生值分组</mark>： GROUP BY 会把所有计算结果相同的行归为同一个组。

- 所有 class 以"计科"开头的行 → 全部归入"计科"组

- 所有 class 以"软工"开头的行 → 全部归入"软工"组

3. <mark style="background: #FF5582A6;">分组聚合统计</mark>：对每个独立的分组执行 COUNT(*) 函数，统计该组内的总行数（即该专业大类的学生总数）。

4. 返回结果：输出每个分组的键值（即 LEFT(class, 2) 的结果）和对应的统计数，这就是你图中看到的"计科4994人、软工5006人"的结果

# 4.3聚合函数

### count

COUNT() ：统计满足条件的数据总条数

```sql
SELECT COUNT(*) total FROM student WHERE score>80;
```

### sum

SUM()：只能用于数值类型的字段或者表达式，计算该满足条件的字段值的总和

```sql
SELECT COUNT(*) totalCount, SUM(score) totalScore FROM student WHERE score<60;
```

### AVG

AVG()：只能用于数值类型的字段或者表达式，计算该满足条件的字段值的平均值

```sql
SELECT sex, AVG(score) avgScore FROM student GROUP BY sex;
```

### MAX

MAX()：只能用于数值类型的字段或者表达式，计算该满足条件的字段值的最大值

```sql
SELECT MAX(age) FROM student;
```

### MIN

MIN()：只能用于数值类型的字段或者表达式，计算该满足条件的字段值的最小值

```sql
SELECT MIN(score) FROM student;
```

## 4.4分组结果筛选

```sql
SELECT ALL/DISTINCT * | 字段名1 AS 别名1[,字段名1 AS 别名1, ..., 字段名n AS 别名n] FROM 表名 WHERE 查询条件 GROUP BY 字段名1，字段名2,..., 字段名n HAVING 筛选条件
```

对结果组进行筛选，直接淘汰组

示例：
```sql
SELECT * FROM student WHERE age BETWEEN 20 AND 30 GROUP BY sex HAVING avg(score)>74;
```

# 五.排序

```sql
SELECT ALL/DISTINCT * | 字段名1 AS 别名1[,字段名1 AS 别名1, ..., 字段名n AS 别名n] FROM 表名 WHERE 查询条件 ORDER BY 字段名1 ASC|DESC，字段名2 ASC|DESC,..., 字段名n ASC|DESC
```

注：
1. desc——从大到小，asc——从小到大
2. 可以有多个字段来排序，先是第一个字段来判断，一样，第二个来

示例：
```sql
select * from student where age between 18 and 30 order by score desc , age asc;
```

# 六.分页

```sql
SELECT ALL/DISTINCT * | 字段名1 AS 别名1[,字段名1 AS 别名1, ..., 字段名n AS 别名n] FROM 表名 WHERE 查询条件 LIMIT 偏移量, 查询条数
```

注：
1. LIMIT的第一个参数表示偏移量，也就是跳过的行数。 
2. LIMIT的第二个参数表示查询返回的最大行数，可能没有给定的数量那么多行。

示例：从学生表分页查询成绩及格的学生信息，每页显示3条，查询第2页学生信息
```sql
SELECT * FROM student WHERE score>=60 LIMIT 3, 3;
```

注：<mark style="background: #FF5582A6;">如果一个查询中包含分组、排序和分页，那么它们之间必须按照分组->排序->分页的先后顺序排列。</mark>
