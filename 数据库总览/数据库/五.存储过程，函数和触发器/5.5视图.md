# 一.视图

视图是一张<mark style="background: #FF5582A6;">虚拟表</mark>，<mark style="background: #FF5582A6;">本身并不存储数据</mark>，当SQL操作视图时所有数据都是从其他表中查出来

注：
1. 视图无法影响原始数据
2. 本身只是一个对<mark style="background: #FF5582A6;">查询语句的封装</mark>，需要时调用

# 二.创建视图

```sql
- 创建视图

CREATE VIEW 视图名称 AS SELECT 列1[,列2,…] FROM 表名 WHERE 条件;

- 更新视图

CREATE OR REPLACE VIEW 视图名称 AS SELECT 列1[,列2,…] FROM 表名 WHERE 条件;

- 删除视图

DROP VIEW IF EXISTS 视图名称;
```

示例：

获取销售人员编号、姓名和代理商名称，可以创建视图：
```sql

CREATE VIEW v_sales AS SELECT s.id 销售编号 , s.name 销售名称 , a.name 代理商名称 FROM sales s , agent a where s.agent_id = a.id;

SELECT 销售编号,销售名称,代理商名称 FROM v_sales;
```

注：
1. 视图形成一个虚拟的表供我们查询
2. 视图的属性别名为查询时提供方便
3. <mark style="background: #FF5582A6;">视图设计时便可以将一些数据排除在外，无论如何查找视图属性，都无法查询一些敏感的属性</mark>

注：<mark style="background: #FF5582A6;">视图并不能提升查询速度，只是方便了业务开发，但同时也加大了数据库服务器的压力，因此，需要合理的使用视图</mark>
