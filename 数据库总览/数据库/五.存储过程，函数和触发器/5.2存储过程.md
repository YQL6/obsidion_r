# 一.定义存储过程

在大型数据库系统中，存储过程是一组为了<mark style="background: #FF5582A6;">完成特定功能</mark>而存储在数据库中的SQL<mark style="background: #FF5582A6;">语句集</mark>，<mark style="background: #FF5582A6;">一次编译后永久有效</mark>

```sql
- 声明分隔符

[DELIMITER $$]

CREATE PROCEDURE 存储过程名称 ([IN | OUT | INOUT] 参数名1 数据类型, [[IN | OUT |

INOUT] 参数名2 数据类型, . , [IN | OUT | INOUT] 参数名n 数据类型])

- 语句块开始

BEGIN

- SQL语句集

END[$$]

- 还原分隔符

[DELIMITER ; ]

- 调用存储过程

CALL 存储过程名(参数1,参数2,…);
```

注：
1. 分隔符可以在存储过程开始处定义，在还原前使用其为分隔符
2. 语句块的分隔符不变
3. in，out，inout：
	1. in：作为输入，仅可以读取，不可以修改
	2. out：作为输出，不可以传入，可以读，可以修改
	3. inout：可以读，修改

# 二.使用

示例：银行转账
```sql
CREATE if not exists PROCEDURE transfor(IN transforFrom BIGINT , IN transforTO BIGINT , IN transforMoney BIGINT)
BEGIN
UPDATE account SET balance = balance + transforMoney where account=transforTO;
UPDATE account SET balance = balance - transforMoney where account = transforFrom;
END

DROP if EXISTS procedure transfor;

CALL transfor(123456,123457,1000);
```

存在问题：如果余额不足会变为负数

改进：
```sql
CREATE  PROCEDURE  transfor(IN transforFrom BIGINT , IN transforTO BIGINT , IN transforMoney BIGINT)
BEGIN
-- 必须在所有语句之前定义，记录所有最后结果
DECLARE result Tinyint(1) default 0;
 -- 判断是否够转账
UPDATE account SET balance = balance - transforMoney where account = transforFrom and balance >= transforMoney;
-- 设置局部变量记录是否成功
IF row_count() =1 THEN
  update account set balance = balance + transforMoney where account = transforTO;
  IF row_count()=1 THEN
    SET result=1;
  END IF;
END IF;
select result;
END

DROP  procedure IF EXISTS transfor;

CALL transfor(123456,123457,1000);
```

存在问题：万一卡号输错或异常，一个扣钱，一个收不到，

改进：保证数据一致性，可撤销，引入事务

# 三.事务

## 3.1事务

事务( Transaction)是访问并<mark style="background: #FF5582A6;">可能操作</mark>各种数据项的一个数据库操作序列，这些操作要么全部执行,要么全部不执行，是一个不可分割的工作单位。事务由事务开始与事务结束之间执行的全部数据库操作组成。

## 3.2特点

特性：
1. 原子性（Atomicity）：事务的<mark style="background: #FF5582A6;">各元素是不可分的</mark>（原子的）,它们是一个整体。<mark style="background: #FF5582A6;">要么都执行，要么都不执行。</mark>
2. 一致性（Consistency）：当事务完成时，必须保证<mark style="background: #FF5582A6;">所有数据保持一致状态</mark>。当转账操作完成时，所有账户的<mark style="background: #FF5582A6;">总金额应该保持不变</mark>，此时数据处于<mark style="background: #FF5582A6;">一致性状态</mark>；如果总金额发生了改变，说明数据处于非一致性状态。
3. 隔离性（Isolation）：对数据操作的<mark style="background: #FFB8EBA6;">多个并发事务彼此独立</mark>，互不影响。比如张三和李四同时都在进行转账操作，但彼此都不影响对方。
4. 持久性（Durability）：对于已提交事务，系统必须保证该事务对数据库的改变不被丢失，即使数据库出现故障

## 3.3语法

```sql
START TRANSACTION;   -- 或 BEGIN;
   SQL 语句...
COMMIT;              -- 提交
-- 或
ROLLBACK;            -- 回滚
```

## 3.4部分回滚

```sql
SAVEPOINT 保存点名;          -- 设置保存点
ROLLBACK TO SAVEPOINT 保存点名;  -- 回滚到该保存点，保存点之后的操作被撤销
RELEASE SAVEPOINT 保存点名;      -- 删除保存点（不影响数据）
```

注：
1. `ROLLBACK TO SAVEPOINT` 只撤销**保存点之后**的操作，保存点之前的操作依然保留。
2. 回滚到保存点后，后续设置的保存点会失效。
3. 事务最后仍然需要 `COMMIT` 或 `ROLLBACK`。

```sql
CREATE  PROCEDURE  transfor(IN transforFrom BIGINT , IN transforTO BIGINT , IN transforMoney BIGINT)
BEGIN
-- 必须在所有语句之前定义，记录所有最后结果
DECLARE result Tinyint(1) default 0;
-- 添加异常处理器
DECLARE continue HANDLER FOR SQLEXCEPTION SET result=0;
-- 启动事务管理
START TRANSACTION;
 -- 判断是否够转账
UPDATE account SET balance = balance - transforMoney where account = transforFrom and balance >= transforMoney;
-- 设置局部变量记录是否成功
IF row_count() =1 THEN
  update account set balance = balance + transforMoney where account = transforTO;
  IF row_count()=1 THEN
    SET result=1;
  END IF;
END IF;
IF result=1 THEN COMMIT;
ELSE ROLLBACK;
END IF;
select result;
END

DROP  procedure IF EXISTS transfor;
UPDATE account SET balance=10000 where account=123456;
CALL transfor(123456,123457,1000);
```

改进：设置result为输出
```sql
DROP PROCEDURE IF EXISTS transfer;

CREATE PROCEDURE transfer(IN transferFrom BIGINT, IN transferTo BIGINT, IN

transferMoney BIGINT(20), OUT result TINYINT(1))

BEGIN

- 为SQL异常声明一个持续处理的处理器，一旦出现异常，则将result的值更改为0

DECLARE CONTINUE HANDLER FOR SQLEXCEPTION SET result = 0;

- 开启事务

START TRANSACTION;

UPDATE account SET balance = balance - transferMoney WHERE account =

transferFrom AND balance > transferMoney;

- 设置result的值为SQL执行后受影响的行数

SET result = ROW_COUNT();

IF result = 1 THEN

UPDATE account SET balance = balance + transferMoney WHERE account =

transferTo;

SET result = ROW_COUNT();

END IF;

- 如果result的值为1，表示所有操作都成功，提交事务

IF result = 1 THEN COMMIT;

- 否则，表示操作存在失败的情况，事务回滚，数据恢复到更改之前的状态

ELSE ROLLBACK;

END IF;

END

- 调用存储过程

CALL transfer(123456, 123457, 2000, @rs);

SELECT @rs;
```

# 四.异常处理器

```sql
DECLARE 处理方式 HANDLER
    FOR 条件值1 [, 条件值2 ...]
    处理语句;
```

注：
1. 处理方式：
	1. `CONTINUE`：捕获异常并执行处理语句，然后**继续执行**后面的代码。
	2. `EXIT`：捕获异常并执行处理语句，然后**退出当前 `BEGIN...END` 块**。 
	3. `UNDO`：MySQL 目前**不支持**，写上去会报错。
2. **DECLARE**：必须在 `BEGIN` 之后、其他语句之前声明。
3. **条件值**：指出要捕获的异常类型
4. **处理语句**：捕获后要执行的一条 SQL 语句；多用 `BEGIN...END` 复合语句包裹多条语句。
