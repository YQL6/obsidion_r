# 二.Sql操作

## 2.1建库操作

语法：
```sql
CREATE DATABASE [IF NOT EXISTS] 数据库名称 DEFAULT CHARACTER SET 字符集 COLLATE 排序 规则;
```

MySQL 的排序规则名称通常由 `字符集名_语言/通用_特性` 组成，后缀常见含义：

|后缀|含义|
|---|---|
|`_ci`|**Case Insensitive**，大小写不敏感，`'A'` 和 `'a'` 视为相等|
|`_cs`|**Case Sensitive**，大小写敏感，`'A'` 和 `'a'` 不同|
|`_bin`|**Binary**，按二进制值比较，严格区分大小写和字符编码|
|`_ai`|**Accent Insensitive**，不区分重音，例如 `'a'` 和 `'á'` 视为相等|
|`_as`|**Accent Sensitive**，区分重音|
|`_unicode_ci`|基于 Unicode 标准的通用排序规则，能正确处理多语言|
|`_general_ci`|通用排序规则，性能稍好，但对某些语言排序不完美|
|`_0900_ai_ci`|MySQL 8.0 引入，基于 Unicode 9.0，不区分重音和大小写，较新推荐|

注：
1. if not exists：如果不存在执行操作
2. DEFAULT CHARACTER ：设置字符集类型
3. COLLATE：设置排序规则——字符常量大小写是否相等，查询过程的字符比较方法，例：第一个字符是'a',另一个字符常量是'b',判断标准是ascall
![[图片/Pasted image 20260615202350.png]]

示例：
```sql
create database if not exists student;
```

# 四.数据表操作

## 4.1数据表类型

MySQL 中的数据表类型有许多，如 MyISAM 、 InnoDB 、 HEAP 、 BOB 、 CSV 等。其中最常用的就是 MyISAM 和 InnoDB

## 4.2MyISAM vs InnoDB

![[图片/Pasted image 20260615204755.png]]

当涉及的业务操作以查询居多，修改和删除较少时，可以使用MyISAM。当涉及的业务操作经常会有修改和删除 操作时，使用InnoDB。

## 4.3创建数据表

```sql
CREATE TABLE [IF NOT EXISTS] 数据表名称(   
	字段名1 列类型(长度) [修饰属性] [键/索引] [注释],   
	字段名2 列类型(长度) [修饰属性] [键/索引] [注释],   
	字段名3 列类型(长度) [修饰属性] [键/索引] [注释],   
	......   
	字段名n 列类型(长度) [修饰属性] [键/索引] [注释] 
	) [ENGINE = 数据表类型][CHARSET=字符集编码] [COMMENT=注释];
```

示例：
```sql
create table if not exists student(
    `number` VarChar(10) not null primary key comment '学生学号，主键',
    name varchar(10) not null comment '学生姓名',
    sex Tinyint(1) unsigned comment '性别，0男，1女',
    age tinyint(3) unsigned comment '年龄',
    score double(5,2) unsigned comment '成绩',
    class tinyint
) ENGINE=InnoDB charset=UTF8 comment='学生表';
```

注：
1. 与关键字冲突的命名要用反引号`包起来` ,而不是单引号'
2. 定义内部的注释comment不用=

## 4.4修改表

```sql
ALTER TABLE 表名 RENAME AS 新表名;
```

示例：
```sql
alter table student rename as stu;
```

## 4.5增加元素

```sql
ALTER TABLE 表名 ADD [COLUMN] 字段名 列类型(长度) [修饰属性] [键/索引] [注释];
```

示例：
```sql
alter table stu add class_name varchar(10) not null ;
```

注：
1. 主键只能在创建表单时在设置类属性一次性设置，也可以在设置列属性的最后添加`PRIMARY KEY (列1, 列2)`,也可以没有主键时用alter添加
2. 主键存在无法用alter添加，要删除以后在添加
3. `ALTER TABLE stu ADD PRIMARY KEY (number, class_name);`

## 4.6删除列

```sql
ALTER TABLE 表名 DROP 字段名;
```

示例：
```sql
alter table stu drop class_name;
```

## 4.7修改列属性

```sql
-- MODIFY 只能修改字段的修饰属性 
ALTER TABLE 表名 MODIFY 字段名 列类型(长度) [修饰属性] [键/索引] [注释]; -- CHANGE 可以修改字段的名字以及修饰属性 
ALTER TABLE 表名 CHANGE 字段名 新字段名 列类型(长度) [修饰属性] [键/索引] [注释];
```

注：
1. <mark style="background: #FF5582A6;">不可以修改索引与键</mark>
2. 键由add，drop管理
![[图片/Pasted image 20260615212915.png]]
3. change修改时都要两个名字，不改新旧一样

# <mark style="background: #FF5582A6;">五.修改操作总结</mark>

1. alter...add:<mark style="background: #FFB86CA6;">不可修改列属性</mark>
	1. 列添加
	2. 键，索引的添加：键/索引
2. alter...change/modify:<mark style="background: #FF5582A6;">本质是从新定义一列</mark>
	1. change vs modify：仅change可以改列名
	2. 因为是重新定义，所以直接在后面加键或索引即可（主键要求唯一，表中有主键则不可以添加）

注：自增长只能有一个

注：change修改时，若原来是主键，修改后也是主键，要求先删主键，在修改

示例：
```sql
alter table student drop primary key;

alter table student change `number` number int not null auto_increment primary key comment '学生学号，主键';
```
