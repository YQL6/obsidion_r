# 一.表与表间的关系

数据表是用来描<mark style="background: #FF5582A6;">述实体信息</mark>的，比如可以使用数据表来描述学生信息，也可以用数据表来描述班级信 息，这样就会存在学生表和班级表。而学生和班级显然存<mark style="background: #FF5582A6;">在着一种关系</mark>：

![[图片/Pasted image 20260617121446.png]]

这种关系在数据库中体现就称之为表与表之间的关系。数据库通过<mark style="background: #FF5582A6;">主外键关联关系来</mark>体现表与表之间的关联关系。

# 二.主外键关联关系

两个表：
![[图片/Pasted image 20260617122117.png]]
如图所示，此时学生表和班级表并没有任何关系，然而实际上学生和班级是存在<mark style="background: #FF5582A6;">归属关系</mark>。可以在学生表中添加一个字段，表<mark style="background: #FF5582A6;">名该学生所属班级</mark>，该字段值使用的是班级表中的主键，在学生表中称之为外键。这样学生表中的所属班级（外键）与班级表中的编号（主键）就<mark style="background: #FF5582A6;">产生关联关系</mark>，这种关联关系称为主外键关联关系。

![[图片/Pasted image 20260617122257.png]]

外键：
1. **外键引用的是另一张表的主键（或唯一键）**
2. **外键** 设在 **本表**（子表）上。
3. 它引用的是 **外表（父表）的 主键**。注意唯一性

设计外键：
1. **在绝大多数设计中，表的主键（Primary Key）一般不兼任外键（Foreign Key）。**
2. 特殊情况：
	1. **1 : 1 关系，且子表完全依赖父表**  
    比如：`用户表` 和 `用户钱包表`。  
    `用户钱包表` 的主键直接就是 `用户ID`，它同时也是指向 `用户表` 的外键。  
    这样设计很自然，因为钱包和用户是“一个用户一个钱包”，生命周期完全一致。
	2. **多对多关系的中间表（特殊情况）**  有些设计会把中间表的两个外键联合起来作为联合主键。  
	3. 比如：`选课表`（`student_id`, `course_id`），这两列共同作为主键，且每一个又都是外键。 这时，主键的**组成部分**就是外键。

# 三.定义外键

![[图片/Pasted image 20260617122342.png]]

代码：
```sql
create table student(
     number int(5) not null primary key,
     name varchar(10) not null,
     age int(10) ,
     class int 
     //可以在最后添加主键，外键
     primary key(number);
     FOREIGN KEY(cls_number) REFERENCES cls(number)
     );
     
create table class(
    no int primary key not null,
    name varchar(10),
    grade varchar(10) );
```

注:
1. 外键的外表必须对应的那一列是<mark style="background: #FFB86CA6;">主键或为唯一键（unique）</mark>，外键的外表与本表一定是类型相同

# 四.修改外键，主键

## 4.1 外键

```sql
-- 添加外键约束

ALTER TABLE 表名1 ADD CONSTRAINT 外键名称 FOREIGN KEY(表名1的字段名) REFERENCES 表名2(表名2的字段名);

-- 删除外键约束

ALTER TABLE 表名 DROP FOREIGN KEY 外键名称;
```

示例:
```sql
alter table student add foreign key(class) references class(no);
```

## 4.2主键

```sql
-- 添加主键约束：保证数据的唯一性

ALTER TABLE 表名 ADD PRIMARY KEY(字段名1,字段名2, ..., 字段名n)
-- 删除主键约束

ALTER TABLE 表名 DROP PRIMARY KEY;
```

示例:
```sql
alter table student add primary key(number);

alter table student drop primary key;
```

## 4.3唯一约束

```sql
-- 为字段添加唯一约束

ALTER TABLE 表名 ADD CONSTRAINT 约束名称 UNIQUE(字段名1, 字段名2, ..., 字段名n);-- 删除字段的唯一约束

ALTER TABLE 表名 DROP KEY 约束名称;
```

## 4.4索引命名管理

定义时命名管理：
```sql
CREATE TABLE 表名 (
    列名 数据类型 ...,
    [CONSTRAINT 约束名] PRIMARY KEY (列名),
    [CONSTRAINT 约束名] UNIQUE (列名),
    [CONSTRAINT 约束名] FOREIGN KEY (列名) REFERENCES 父表(列名)
);
```

添加时命名管理：
```sql
ALTER TABLE student ADD CONSTRAINT pk_student PRIMARY KEY (no);
ALTER TABLE student ADD CONSTRAINT uq_email UNIQUE (email);
ALTER TABLE student ADD CONSTRAINT fk_class FOREIGN KEY (class_id) REFERENCES class(id);
```

删除键的本质是对键名的管理查找到键名来删除：
```sql
alter table student drop index unique键名; 
```

### <mark style="background: #FF5582A6;">总结</mark>

所以主键删除也是同样的操作，但是主键有规定命名，总结：
![[图片/Pasted image 20260617130139.png]]

普通索引：
```sql
ALTER TABLE student ADD INDEX idx_name (name);
ALTER TABLE student DROP INDEX idx_name;
```

外键：
```sql
-- 如果创建时写的是：
ALTER TABLE student ADD CONSTRAINT fk_class FOREIGN KEY (class_id) REFERENCES class(id);
-- 删除时写：
ALTER TABLE student DROP FOREIGN KEY fk_class;
```

注：
1. 如果创建外键时没写 `CONSTRAINT`，MySQL 会自动生成一个约束名
2.  `SHOW CREATE TABLE student` 查出这个名字
![[图片/Pasted image 20260617130438.png]]

主键：
```sql
ALTER TABLE 表名 DROP PRIMARY KEY;
```

注：
1. 这里的 `PRIMARY KEY` 是**固定的关键字**，不是名字。
2. 因为任何表的主键索引都叫 `PRIMARY`，所以直接写 `DROP PRIMARY KEY` 就行，不需要（也不能）指定自定义名字。

## 4.5非空约束

```sql
-- 为字段添加非空约束

ALTER TABLE 表名 MODIFY 字段名 列类型 NOT NULL;-- 删除字段非空约束

ALTER TABLE 表名 MODIFY 字段名 列类型 NULL;
```

## 4.6默认值约束

```sql
-- 为字段添加默认值

ALTER TABLE 表名 ALTER 字段名 SET DEFAULT 默认值;-- 删除字段的默认值

ALTER TABLE 表名 ALTER 字段名 DROP DEFAULT;
```

## 4.7自增长约束

```sql
-- 为字段添加自增约束

ALTER TABLE 表名 MODIFY 字段名 列类型 AUTO_INCREMENT;-- 为字段删除自增约束

ALTER TABLE 表名 MODIFY 字段名 列类型;
```

注：
1. 一个表一个自增长约束
2. 自增长放在唯一或主键上面
