- 打包到根目录的dist下面

注：
1. 前端模块化规范——ES6，后端——commonJS
2. node——js运行的平台，`node .js`可以直接运行`.js`
3. 自定义命令：在package.json的`scripts`中
```javascript
{  
  "name": "webpack",  
  "version": "1.0.0",  
  "description": "",  
  "license": "ISC",  
  "author": "",  
  "type": "commonjs",  
  "main": "index.js",  
  "scripts": {  
    "test": "echo \"Error: no test specified\" && exit 1",  
    "bulid": "webpack"  
  },  
  "devDependencies": {  
    "webpack": "^5.108.1",  
    "webpack-cli": "^7.1.0"  
  }  
}
```
4. 打包过程：
	1. 确定主文件：配置文件里面存在：`main:.js`
	2. 在主文件开始找模块文件，到模块文件看还有模块文件吗，看副作用代码和是否调用决定打包与否
5. 配置第三方工具`jQery`——webpack直接将jquery打包到main.js——》打包所有引入的js文件到一个文件——》优化：按需打包——vite
```text
npm install jquery --save
yarn add jquery //运行时依赖
```
6. **局部依赖（本地依赖）是针对项目文件夹而言的**：局部依赖安装会安装到**当前项目根目录下的 `node_modules/` 文件夹**中，并且仅在**这个项目范围内**可用。
7. 范围：npm 通过检查**当前目录或其祖先目录中是否存在 `package.json`** 来确定一个 Node.js 项目。这个文件夹就是一个**独立的项目环境**，依赖属于它，不影响系统全局。
8. 暴露对象外的副作用代码：**副作用代码只在模块被第一次引入时执行一次，而不是每次调用暴露对象时都执行。**，加载时自动使用
9. 只能判定：当对象被暴露，但没有使用，此模块不被打包，副作用代码一定会被打包
