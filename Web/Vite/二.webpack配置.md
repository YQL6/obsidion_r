# 一.entry

## 1.1配置入口

- <mark style="background: #FF5582A6;">约定大约配置</mark>

- 改变入口位置,尽量不改变入口配置

```json
module.exports ={//以后端规范编写——commonJS，对node开放  
    //webpack配置对象，对外暴露  
    mode:"production",//生产模式，上市使用，对外使用，development——开发模式  
    entry:"./src/index2"//指定打包的主文件，即入口文件,默认是src/index.js  
}
```

## 1.2多文件打包

- 与`.js`配置同，可以输入数组

```javascript

}
```

# 三.loader

## 3.1案例

补充知识点：
1. defer：`<script defer></script>`,异步加载——异步下载，不阻塞`html`编译，等编译完后直接执行`script`内容

```javascript
document.body.insertAdjacentHTML("before","<h1>今天风很大</h1>");
```
- 直接引入后无发直接执行，如果放在`body`之前就无法找到，需要`<script defer src= ></script>
- 同时要是将`css`配置放在目的目录下可能会`clean`

- 将项目工程化——》开发的所有文件都应该通过`js`管理，即`webpack`管理，不能是在目的目录下在自己手动写，`dist`不要动，仅接收`webpack`的打包文件即可

## 3.2工程化处理

- `webpack`仅能处理`.js`,处理其他文件——`loader`,`css`,`png`等特殊文件要引入对应的loader

- 打包过程：
当你配置了 `file-loader` 或 Webpack5 内置的 `asset/resource` 模块后，打包过程大致为：

1. **解析依赖**：Webpack 遇到 `import logo from './logo.png'` 时，Loader 将其识别为**资源模块**。
    
2. **处理文件**：Loader 会把 `logo.png` 文件**复制**到输出目录（如 `dist/images/`），并给它生成一个带有哈希值的唯一文件名（如 `logo.a1b2c3d4.png`），以利于缓存。
    
3. **返回路径**：`import` 的返回值不再是图片本身，而是一个**字符串路径**，例如 `"/images/logo.a1b2c3d4.png"`。
    
4. **注入代码**：打包后的 JS 里，`logo` 变量就是这个字符串路径，浏览器执行 JS 时就能直接用它设置 `src` 属性或 CSS 背景，从而发起请求获取图片。

# 四.babel

## 4.1场景

```javascript
import "./style/style.css"  
  
const a = 10;  
  
console.log(a);  
  
document.body.onclick=()=>{  
    alert("string");  
}
```

- 变量和一些可以只返回一些结果的函数或使用场景固定的函数，打包时优化，直接将返回结果拿出来，放在返回位置，这样就没有函数了
- 但是一些不确定的，无法优化，只能保留，可是一些函数使用的可能是`es6`的内容，无法使用

- 将`es6`——》旧版本的`es`
- babel——js编译器:使新旧版本能互换

## 4.2使用babel

- 实现要有`babe-loader`,使webpack能使用babel
- 安装babel-loader,`@babel/core`——babel的核心功能实现，`babel/preset-env`——预设环境，一些常用插件，babel也是由一个一个插件实现的
```test
npm install babel-loader @babel/core @babel/preset-env --save-dev
```

- 配置
webpack的配置：
```javascript
module.exports ={  
    module: {  
        rules:[  
            {  
                test:/\.css$/i,  
                use:["style-loader","css-loader"]  
            },  
            {  
                test:/\.m?js$/,//对.js或.mjs的文件处理  
                exclude: /(node-modules|bower_components)/,//不处理这些文件夹下的文件  
                use:{  
                    loader:"babel-loader",  
                    options:{  
                        presets:["@babel/preset-env"]//对babel的配置使用默认配置  
                    }  
                }  
            }  
        ]  
    }  
}
```
