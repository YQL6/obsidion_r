# 简介
JavaScript 是一种<mark style="background: #FF5582A6;">解释性脚本语言</mark>（<mark style="background: #FF5582A6;">不用编译</mark>），主要用于向 HTML 添加<mark style="background: #FF5582A6;">交互行为</mark>，语法与 Java 语言类似。

JavaScript 由 ECMAScript（简称 ES）、DOM（Document Object Model） 和 BOM（Broswer ObjectModel） 三大部分组成。

# 基本结构
```java
<script type="text/javascript">
	//javascript代码
</script>
```
该结构可以在HTML中的<mark style="background: #FF5582A6;">任意位置书写</mark>，但必须保证 JavaScript 脚本中<mark style="background: #FF5582A6;">使用到的元素</mark>必须在 JavaScript脚本<mark style="background: #FF5582A6;">执行前完成加载</mark>

# 接入方式
如同css:
1. 行内样式
2. 内部样式
3. 外部样式

行内样式：
```java
<input type="button" value="点击" onclick="alert('你点击了按钮');">
```
内部样式：
```java
<input type="button" value="点击" id="btn">

<script type="text/javascript">

	document.getElementById("btn").onclick=function(){

		alert('你点击了按钮');

	}

</script>
```
外部样式：src找来源，没有link，href链接
```java
<script type="text/javascript" src="demo.js"></script>
```
