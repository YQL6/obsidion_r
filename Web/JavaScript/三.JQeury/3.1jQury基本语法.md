# 简介
[JQury](https://jquery.com/)由美国人JohnResig于2006年创建。它是对<mark style="background: #FF5582A6;">JavaScript对象和函数的封装</mark>。其设计思想是write less,do more。

<mark style="background: #FF5582A6;">注：document——元素选择器</mark>

# 引入
```text
<script type="text/javascript" src="jQury/jquery-3.6.0.js"></script>
```

# JQury选择器

```java
//jQury选择器，返回一个元素数组——htmlcollection  
$("form");//标签选择器：所有form标签  
$("#username");//ID选择器：所有ID为username  
$(".form-group");//类选择器：所有使用了form-group的  
  
$("input[type=text]");//选中所有文本框  
$("input[name=username]");//选中所有username的输入框  
  
$("div , span");//并集选择器：选中所有div，span标签  
  
$("div input");//后代选择器：选中所有div的input后代  
$("div > input");//子代选择器：选中所有div的下一个直接input后代  
  
$("div:first");//过滤选择器：选中div下的第一个标签  
$("div:last");//过滤选择器：选中divxia的最后一个标签  
  
$("div:even");//过滤选择器：选中div标签为偶数下标的标签  
$("div:odd");//过滤选择器：选中div标签在下标为奇数的标签  
  
$("div:eq(0)");//过滤选择器：选中div标签中下标为0的标签  
//great than  
$("div:gt(0)");//过滤选择器：选中div标签在下标大于0的标签  
$("div:lt(0)");//过滤选择器：选中div标签在下标小于0的标签  
  
$("div:focus");//过滤选择器:选中div标签在获得焦点事件的标签  
  
$("document");//选中整个文档
```

# ready方法

ready 方法表示 jQuery选择器选择的标签准备好了之后需要执行的<mark style="background: #FF5582A6;">后续动作</mark><mark style="background: #FF5582A6;">。通常用于表示文档准备好 之后需要做的后续动作。</mark>

```java

	//jQury选择器，返回一个元素数组——htmlcollection  
$("form");//标签选择器：所有form标签  
$("#username");//ID选择器：所有ID为username  
$(".form-group");//类选择器：所有使用了form-group的  
  
$("input[type=text]");//选中所有文本框  
$("input[name=username]");//选中所有username的输入框  
  
$("div , span");//并集选择器：选中所有div，span标签  
  
$("div input");//后代选择器：选中所有div的input后代  
$("div > input");//子代选择器：选中所有div的下一个直接input后代  
  
$("div:first");//过滤选择器：选中div下的第一个标签  
$("div:last");//过滤选择器：选中divxia的最后一个标签  
  
$("div:even");//过滤选择器：选中div标签为偶数下标的标签  
$("div:odd");//过滤选择器：选中div标签在下标为奇数的标签  
  
$("div:eq(0)");//过滤选择器：选中div标签中下标为0的标签  
//great than  
$("div:gt(0)");//过滤选择器：选中div标签在下标大于0的标签  
$("div:lt(0)");//过滤选择器：选中div标签在下标小于0的标签

```
