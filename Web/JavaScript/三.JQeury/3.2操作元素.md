# 操作元素样式

## 操作元素宽度和高度

```javascript
$(选择器|DOM元素).width();//获取标签的宽度 
$(选择器|DOM元素).width(宽度值); //设置标签的宽度 
$(选择器|DOM元素).height();//获取标签的高度 
$(选择器|DOM元素).height(宽度值); //设置标签的高度
```

## 操作行内样式

```javascript
$(选择器|DOM元素).css(样式属性名);//获取标签上给定样式属性名对应的样式属性值 
$(选择器|DOM元素).css(样式属性名, 样式属性值);//设置标签上给定样式属性名对应的样式属性值 
$(选择器|DOM元素).css({    //css样式， 样式属性名中存在中横线时，使用驼峰命名法对样式属性名进行组装 
});
```

驼峰命名法：当遇到横线时，后面第一个字母大写，代表前面有横线

## 操作类样式

```javascript
$(选择器|DOM元素).addClass(类名); //为标签添加类样式 
$(选择器|DOM元素).removeClass(类名); //将给定的类样式从标签上移除 
 $(选择器|DOM元素).toggleClass(类名); //如果元素上存在给定的类样式，则移除改类样式；否则，则为标签添加上该类样式；
 $(选择器|DOM元素).hasClass(类名);//判断标签上是否存在给定的类样式
```

注：
1. 类样式的创建有自己建立
2. 类样式的优先级——行内》类》js，类内看先后。优先级高的覆盖优先级低的

# html（）的问题

- **`.html()` 方法的行为**：类似原生 `innerHTML`，会**先用新内容<mark style="background: #FF5582A6;">替换元素内部的所有子节点</mark>**，而<mark style="background: #FF5582A6;">不是追加</mark>。所以原先内部的文本或元素都会丢失。
    
- **元素本身不受影响**：`.t` 这个元素（比如 `<div>`）依然存在，其属性（`class`、`id` 等）保持不变。
    
- **如果你只想追加而不是覆盖**，可以使用 `.append()`、`.prepend()`、`.after()` 等方法。
