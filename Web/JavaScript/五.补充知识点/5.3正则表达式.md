# 一.简介

## 1.1使用场景

- 用户输入电子邮件格式：`admin@qq.com`,检查格式是否正确

- 计算机检查，如何识别电子邮件：什么是电子邮件，什么不是电子邮件——》配置规则

- 规则：xxx+ @ + xxx  + .com——》让计算机看懂——》正则表达式——》定义字符串的规则，获取字符串后将字符串符合规则的内容提取出来

- 正则表达式——》对象

# 二.正则表达式

## 2.1正则表达式的定义

```javascript
var reg = new RegExp("正则表达式 " , "匹配模式");

var reg = new RegExp("a");//reg上一个对象
console.log(reg);//   /a/

```

注：
1. 正则表达式是一个对象，使用`RegExp`构建

## 2.2测试方法

```javascript

var reg = new RegExp("a");

var str = "a";

reg.test(str);//true

reg.test("aaacb");//true

reg.test("ccsa");//true

reg.test("dd");//flase
```

注：
1. `test`方法检查是否包含`a`,只要包含返回`true`
2. 严格区分大小写，若想要大小写全都匹配，输入匹配模式
3. 只要包含即可

## 2.3匹配模式

```javascrpt
var reg = new RegExp("a" , "i");
```

注：
1. `i`:忽略大小写，`g`:全局匹配模式

## 2.4字面量的正则表达式

```javascript
/*
语法：var 变量 = /正则表达式/匹配模式
*/
var reg = /a/i;//var reg = new RegExp("a" , "i");效果同

```

注：
1. 创建对象的方式可以传入一个变量，灵活
2. 字面量简单

## 2.5多个字符匹配

```javascript
var reg= new RegExp("a|b");

reg = /a|b/;//匹配a或b

reg = /[ab]/;//优化：[]内部内容等于所有相或，省略了/

reg = /[a-z]/;//任意小写字母，从a到z

reg = /[A-Z]/;//任意大写字母，从A到Z

reg = /[A-z]/;//任意字母

reg = /[a-z]/;//任意字母
```

## 2.6字符串匹配

```javascript
reg = /abc|add|fds/;//匹配字符串

reg = /a[adc]e/;//第一个是a，第二个是括号内任意一个，第三个是e，括号是或的意思

reg = /a[^ cd]d/;//[^ ]:除了括号以外的东西

reg = /[0-9]/;//任意数字

reg= /[^ 0-9]/;//除了数字
```

注：
1. `[]`:括号任意一个，或，而`[0 - 9]`是括号内包含了所有数字，所以可以实现只要包含数字即可
2. `[^ ]`:出来括号内的东西皆可，先或在除了，而`[^ 0 - 9]`包含了所有数组，所以是数组除外皆可

# 三.字符串与正则表达式

## 3.1 split

- split（“”）:根据传入的字符串拆分位一个数组，将传入的字符串消掉，从此处拆开，变为数组

```javascript
var str = "123adfaefcdd";
str.split("c");//拆为两个放在数组里面，"123adfaef","dd"
```

- 方法中可以传递一个正则表达式作为参数，根据正则表达式拆分

```javascript
var reg = /[A- z]/;

str.split(reg);
```

注：
1. 默认是全局匹配

## 3.2serach

- search():字符串中是否含有指定内容

```javascript
str = "hell0 abc hello abc";
result = str.search("abc");//6，搜索到指定内容，则返回第一个的索引，没有-1
```

- 正则表达式作为参数，然后根据正则表达式检索字符串

```javascript
reg = /a[bef]c/;
result = str.search(reg);//依次查看是否包含
```

注：
1. search只能查找第一个。即使配置全局匹配也只能匹配第一个

## 3.3match

- match():从一个字符串中将符合条件的内容提取出来

```javascript
str = "1ac2f3df1";

result = str.match(/[A-z]/);//找第一个，返回a
```

- 默认情况下`match`只会找到第一个字母，就停下，想要全部找到——》全局模式——》全部都匹配一遍

```javascript
str = "1ac2f3df1";

result = str.match(/[A-z]/ig);//全部匹配，多结果数组返回
```

注：
1. match将匹配的内容放到数组中返回
2. i，g位置可以互换
3. 如果正则写成 `/ac/`，那就是匹配**连续子串** `"ac"`，而 `[A-z]` 只匹配一个字符。

## 3.4replace

- replace(old,new):new替换old

```javascript
result = str.replace(/a/ig , "@-@");

result= str.replace(/[A-z]/g,"");//用空字符串替换字母，这样就可以删除字符串
```

注：
1. 默认替换第一个,可以传入正则表达式

# 四.正则表达式语法

## 4.1量词

- 匹配`aaaa`:量词表示出现次数

```javascript
reg = /a{4}/;//aaaa

reg= /ab{4}/;//abbbb;

reg = /(ab){4}/;//abababab


```

- 范围表示：`/ab{1,3}/`——》b出现一次到3次
- {m,n}:m到n次
- {m,}:m次以上
- `a+`：a至少一个
- `a*`：表示0个或多个，有没有都行
- `a?`:0个或1个

注：
1. 只对前一个字符起作用，可以()括起来表示是一个整体

## 4.2开头匹配

- `/^a/`:开头必须紧跟着一个a
- `/a$/`：结尾必须是这个a，除这个不能有其他东西
- `/^a$/`:a是开头，同一个a也必须结尾——》只能只有同一个a——》必须完全符合正则表达式
- `/^a|a$/`:开头是a或者a是结尾
- `/(^a).*(a$)`:必须以a结尾，以a开头
- `/^aa$/`:只能是“aa”
- `.*`:中间任意多个字符串

例：手机号匹配
```javascript
reg = /^1[3-9][0-9]{9}$/;
```

## 4.3任意匹配

- `/./`:匹配任意字符,在正则表达式中是一个**元字符**，它匹配**除换行符以外的任意单个字符**。  包括字母、数字、符号、空格、中文等任何字符。
- 单纯匹配`.`——》转义字符`\`——》`/\./`
- 单纯匹配`\`——》`/\\/`——》匹配一个`\`
- `/\w/`:表示任意字母，数字，下划线_——》`/[A-z0-9_]/`
- `/\W/`:与`/\w/`相反：除了任意字母，数字，下划线——》`/[^A-z0-9_]/`
- `/\d/`:任意数字
- `/\D/`:除了数字
- `/\s/`:空格
- `/\S/`:除了空格
- `/\b/`:单词边界，相匹配`child`,但是`children`,可能会误会，匹配：`/\bchild\b/`表示child前面不能有单词，后面是否有单词
- `/\B/`：除了单词边界

例：空格去除
```javascript
str = "             hell  o          ";
str.replace(/\s/g,"");//hello，所有的空格都去除

str.replace(/^\s/g,"");//去掉一个开头空格，只有一个开头

str.replace(/^\s*/,"");//去掉开头多个空格
str.replace(/\s*$/,"");//去掉结尾空格

str.replace(/^\s*|\s*$/g,"");//全局匹配，先是开头匹配到开头的，然后到结尾匹配到结尾的
```

注：
1. 字符串中`\`也是转移字符，必须也要转义
2. 使用构造函数时，由于参数是字符串中`\`也是转义字符，要使用转义字符转义
```javascript
reg = new RegExl("\\.");//表示\.
```
3. `/\b/`:检查是以是否为构成词汇的元素即`/\W/`为标准，有其隔离就算是一个单词

# 五.邮件正则

## 5.1示例

- 邮件一般格式：任意字母数字下划线  .任意字母数字下划线 @ 任意字母数字 .  任意字母(2到5位) .任意字母(2到5位)

```javascript
reg = /\w{3,}(\.\w+)*@[A-z0-9]+(\.[A-z]{2,5}){1,2}/;
```
