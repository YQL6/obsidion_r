# 二.全局作用域变量

## 2.1范围划分

- 全局范围：整个页面——》有一个全局变量对象——window
- 局部范围：函数内部

## 2.2范围影响

- var:在函数范围内
	- var定义：在函数的整个范围可用
	- 直接赋值使用：默认挂在全局范围对象window下面
- var在全局范围：全局可用，挂在window下面，直接赋值也是
- let：在上面括号内定义就是什么范围

注：
1. 变量var声明，在页面生成时便生成，在所有代码之前，<mark style="background: #FF5582A6;">若不使用var，不会</mark>
2. 函数的声明提前：以函数声明创建的函数function 函数（）{}会在所有代码前有先创建，可以提前使用，但是赋值内的创建不具有特性
3. 无类型的变量，默认挂在`window`下面
