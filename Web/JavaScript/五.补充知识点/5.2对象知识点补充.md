## 2.4原型对象

![[图片/Pasted image 20260624134315.png]]

- 任意一个函数都有一个属性`prototype`，里面存放着一个对象的地址，指向整个对象
- 调用输出最高对象——object
- 构造函数生成的对象，里面也有一个属性指向这个对象与函数的指向一样，只要是一个函数生成的对象都指向一个原型对象
- 生成的对象里面是`__proto__`属性保存
- 这个原型对象可以设置值

```javascript
function MyClass(){

}

MyClass.prototype.a=1;

var mac=new MyClass();
mac.__proto__.a=11;//mac找属性先是在自己里面找，没有向原型对象找
```

为避免污染与避免全局冲突——》原型中写入：
```javascript
function myclass{}

mac = new myclass{};
mac.__proto__.sayname=function(){};//写入原型对象
```

注：
1. 共有属性方法写入——》<mark style="background: #FF5582A6;">类似static与方法</mark>
2. in方法：检查对象中是否有属性，即使原型对象有也可以，`"name" in mac`
3. hasOwnProperty:对象自身是否有属性，`mac.hasOwnProperty`,必须是自身，原型对象的方法也没有，原型对象也是对象，其也有`__proto__`,原型对象的原型，向下还有几层不一定，至此向下无原型为null——》object对象的原型，object对象无原型，原型为null
4. 没有的属性返回undefined
5. 原型的递归类似继承

object：
- `Object` 本身是个构造函数（Function），它自己**有原型**（`Function.prototype`）。
    
- `Object.prototype` 是所有普通对象的根源，它自己的原型是 `null`（`Object.prototype.__proto__ === null`），也就是原型链的终点。
    
- 所以严格来说，`Object.prototype` 是“无原型”的，但普通对象的原型是 `Object.prototype`。

### `new` 操作符的背后流程

当你使用 `new Person(...)` 时，JS 引擎会执行以下操作：

1. **创建一个全新的空对象**  
    `const obj = {};`
    
2. **设置该对象的原型（`__proto__`）**  
    `obj.__proto__ = Person.prototype;`  
    这使得新对象能够继承构造函数原型上的方法。
    
3. **将构造函数的 `this` 绑定到新对象**  
    `Person.call(obj, 'Alice', 30);`  
    函数体内的 `this.name = name` 等语句就变成了为 `obj` 添加属性并初始化。
    
4. **执行构造函数内部代码**  
    为对象添加实例属性（如 `name`、`age`），可能还有判断逻辑。
    
5. **返回结果**
    
    - 如果构造函数没有显式返回一个对象，则自动返回这个新创建的对象（`obj`）。
        
    - 如果手动返回了一个对象（非原始值），则 `new` 的结果就是这个手动返回的对象；否则仍然返回新创建的对象。

根源对象：
- 构造函数的原型对象其实是object函数的实例，根据这个实例补充内容
- 向上就是根源对象，**根源对象是 `Object.prototype`，也就是 `Object` 构造函数所指向的原型对象。**

# 四.函数对象的方法

## 4.1call()与apply()

**`object Object]`**  :
1. 第一个 `object` 是固定的前缀（表示这是一个对象类型）。  
2. 第二个 `Object` 是**内部类名**，对于通过 `{}`、`new Object()`、自定义构造函数（未改写 `Symbol.toStringTag`）创建的对象，这个类名都是 `"Object"`。

- call(),apply():改变`this`的值，指定调用对象
- <mark style="background: #FF5582A6;">任意函数都可以调用</mark>
- 区别：
	- call():函数的传入其他实参，原本自己的实参靠call传入，参数是一个一个传入
	- apply():参数是数组方式传入

```javascript
function fun(a,b){

}
fun.call(obj,a,b);
let arr = [a,b];
fun.apply(obj,arr);
```

## 4.2隐藏的传入对象this,arguments

- 函数默认可以使用这两个对象，由浏览器传入
- this:调用者
- arguments:类数组，所有传递的实参都放在其中保存，非数组类型，instanse和isArray无法判断为Array，使用下标来访问传入的参数

- 只要传入，arguments就保存，属性length表示数量
- callee：这个属性对应一个函数对象——》当前的函数对象
