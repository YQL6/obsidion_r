# 一.基础数据类型

## 1.1null

- 专门表示空的对象
- `typeof`检查时，返回object

## 1.2undefined

- 未声明类型,空值
- 声明一个变量，未赋值时为undefined
- 可以为一个声明类型的变量赋值为undefined，`typeof`检查为undefined

## 1.3强制类型转换

- 转换为——》`string boolean number`

- 向`string`转换:所有类型都可以
```javascript
var a = 123;

// b = a +"";任意数据类型都可以使用

var b = a.toString();//转换结果返回

d = null;

var c = d.toString();//报错

d = undefined;

c = d.toString();//报错

c = String(a);//转换为String类型,底层调用toString();

c = String(d);//String函数可转换null,undefined
```

- 向`number`的转换：`NaN`表示一个无效的数据，不等于任何数，包括自己
- 算数运算时将一个表示`number`的转换为`number`计算
- 注：<mark style="background: #FF5582A6;">任何值与字符串相加都会转换为字符串在拼串</mark>
```javascript
var a = "123";

var b = Number(a);//纯数字可以直接调用Number转换

a = "abc";

b = Number(a);//将a转换为NaN

a = "";//空字符串

```

## 1.4其他进制数字

- 16进制：以`0x`开头，`a=0x10`,输出时仍为十进制输出
- 8进制:以`0`开头
- 2进制:以`0b`开头，不是所有浏览器支持

- 字符串`"070"`,使用函数`parseInt()`转换可能认为10进制，可能是8进制,指定进制`parseInt("070",10)`指定进制

# 二.运算符

## 2.1加法运算细节

- 当两个数不是`Number`时先将其转换为`Number`在运算
- <mark style="background: #FF5582A6;">特殊：当一个是字符串时将另一个数变为字符串，进行拼接操作</mark>
- 字符串的特殊操作仅限于加法，减法就不生效

- 任何` - * /`字符串同样都是自动转换为`Number`在运算
- 利用这个特点为数据进行隐形的里欸选哪个转换
```javascript
d = "123";

d = d - 0;//123
```

## 2.2+/-

- 先将数转换为`number`,`+`不变，`-`取反

## 2.3自增自减的细节

- 将自己运算后看符号位值判断是将原来的值计算，还是新值计算，在参加运算之前便已经出来结果为自己重新赋值了

```javascript
var a = 10;

b = a++ + ++a + a;//10 + 12 + 12;

a = a++;//先是a = a + 1; 13    然后是a = 12;
```

## 2.4逻辑运算符

- 进行逻辑运算是进行转换为`Boolean`，进行运算
- 隐式处理——》`!!a`,a转换为`boolean`
- <mark style="background: #FF5582A6;">返回结果为决定结果的那个数的原始值，不是`boolean`，当放在条件判断的位置时会进行类型转换判断`boolean`</mark>

- 机制：
	- `&&`:当第一个为`true`时会检查第二个值，当第一个为`flase`时不会检查第二个
	- `||`:当地一个值为`flase`时会检查第二个，当第一个为`true`时不会检查第二个

## 2.5关系运算符

- 比较`>`等：
	- 先转换为`number`,比较，特殊：两个字符串比较时，从左向右比较编码
	- `NaN`不可比较，出现时直接`flase`
	- 当一个比较是价格比较时，但是字符串形式输入，可以直接使用`+`来转换

- 相等`==`:
	- 判断数值相等，如果类型不同，进行类型转换，然后比较，大部分情况转换为数字
	- 特殊：`null`衍生`undefind`,两者比较相等，`NaN`不与任何相等，自己也不等于自己
	- isNaN():检查是否为`NaN`

- 全等`===`:
	- 类似相等，不会进行类型转换，直接比较，类型不同`flase`
	- 不全等`!==`
