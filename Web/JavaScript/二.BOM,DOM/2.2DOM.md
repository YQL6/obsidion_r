# 一.概念
DOM（Document Object Model），即文档对象模型，DOM主要提供了对于页面内容的一些操作。在 DOM中，<mark style="background: #FF5582A6;">所有的内容（标签和文本）都是DOM节点，所有的标签都是DOM元素。</mark>

- js对html页面进行操作
- 文档——》html页面
- 对象——》html页面每一个节点都是一个对象，页面每一个部分都是一个节点，例如：`<h1></h1>`，内部包含节点的属性，可直接读取
- 模型——》对象间关系，例如：从`div`找到`title`，两者有同一个父类型
# 二.模型

## 2.1模型内节点的关系

![[图片/Pasted image 20260528160510.png]]

本质：**本质上是将 HTML 或 XML 文档表示为一棵**树形结构的<mark style="background: #FF5582A6;">对象模型</mark>，它定义了程序中<mark style="background: #FF5582A6;">访问和操作</mark>文档内容、结构和样式的一套<mark style="background: #FF5582A6;">标准接口</mark>。
体现：
1.  **抽象表示**：把网页中的标签、属性、文本等都抽象成**节点（Node）**，形成一棵**节点树**（例如 `<html>` 是根，`<head>`、`<body>` 是子节点）。
    
2. **平台无关、语言无关**：DOM 是一套标准 API（由 W3C 维护），在 JavaScript、Python、Java 等语言中都可以实现（但浏览器中主要是 JavaScript 绑定）。
    
3. **动态性**：通过 DOM 提供的接口，开发者可以**增删改查**页面上的任何元素，从而让静态页面“活”起来——这正是 Ajax、动态交互的基础。

节点：4中对象
1. 文档节点——》整个html文档
2. 元素节点——》HTML文档中<mark style="background: #FF5582A6;">HTML标签</mark>，例如：`<h1></h1>`，`<input />`没有`innerHtml`,自闭和
3. 属性节点——》元素属性，例如:`<h1 id="a"></h1>`,id就是属性
4. 文本节点——》html标签中的文本属性，元素节点间的内容

# 七.Primse——承诺

Promise 对象代表了<mark style="background: #FF5582A6;">未来将要发生的事件</mark>，用来传递异步操作的消息，其状态<mark style="background: #FF5582A6;">不受外界影响</mark>。Promise 对象代表一个异步操作，有三种状态： 
1. pending: 初始状态，不是成功或失败状态。 
2. fulfilled: 意味着操作成功完成。 
3. rejected: 意味着操作失败。 
只有异步操作的结果，可以决定当前是哪一种状态，<mark style="background: #FF5582A6;">任何其他操作都无法改变这个状态</mark>。这也是 Promise 这个名字的由来，它的英语意思就是承诺，表示其他手段无法改变。 一旦 Promise 对象从初始状态改变，就不会再变，任何时候都可以得到这个结果。
Promise 对象的状态 改变，只有两种可能：从 Pending 变为 Resolved 和从 Pending 变为 Rejected。只要这两种情况发生， 状态就凝固了，不会再变了，会一直保持这个结果。

结构：
```html
函数 {
	let p = new Promise(function (resolve , reject){
		if(条件){
			//满足错误
			reject(new Error());
		}else{
			//正确
			resolve();
		}
	})
	p.then(function (result)){//正确之后的执行结果，result——结果
		
	}
	p.catcth(fuction (error){//错误，捕捉错误，处理
		
	})
}
```
