# 用途

alter，confirm，prompt浏览器提供的**模态对话框**（modal dialog）方法，属于 `window` 对象（可省略 `window.` 直接调用）。它们会**阻塞** JavaScript 执行，直到用户关闭对话框。

# alter

```javascript
alter(message);
```

用途：弹出含有message内容——字符串的窗口，只有一个确认窗口

返回：undefined

# confirm

```javascript
confirm(message);
```

用途：用于再次确认，以返回结果来执行对应的操作——确认是true，取消是flase

# prompt

```javascript
prompt(message,defaultValue);
```

用途：获取用户输入，defaultValue是默认值，可以没有

返回：若无数据确认——”“，若取消——null
