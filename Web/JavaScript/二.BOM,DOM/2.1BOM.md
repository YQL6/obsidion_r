# 一.BOM模型
![[图片/Pasted image 20260528152128.png]]

BOM 负责管理浏览器窗口、历史记录、导航栏、屏幕等信息。在浏览器中，`window` 对象就是 BOM 的顶层对象。而 DOM 只是 `window` 的一个属性（`window.document`）。
有各种各样的节点：文本节点，元素节点——元素节点，注释节点等

## 2.2location对象
![[图片/Pasted image 20260528152919.png|892]]
```java
<a href="javascript:void(0)" onclick="showAddress()">显示地址栏信息</a>
<a href="javascript:void(0)" onclick="refresh()">刷新页面</a>
<a href="javascript:void(0)" onclick="changePage()">替换新页面</a> 
function showAddress() {   
	console.log(location.host);   
	console.log(location.hostname);   
	console.log(location.href);
} 
function refresh() {    
	location.reload(); 
} 
function changePage() {    
	location.replace()
}
```
注：javascript:void(0)——点击后不刷新页面，也不跳转到新 URL，用于保留链接

# 三.周期函数与延迟函数
![[图片/Pasted image 20260528153751.png]]
```java
<!DOCTYPE html>  
<html lang="en">  
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
</head>  
<body>  
   <div id="a">a</div>  
   <div id="b" class="c">b</div>  
   <div class="c">c</div>  
   <div name="d">d</div>  
    <div id="time"></div>  
<script type="text/javascript">  
    let count = 0;  
   function time(){  
       let date=new Date();  
       let year = date.getFullYear();  
       let month = date.getMonth() + 1;//从0开始  
       let day = date.getDate();  
       let hour = date.getHours();  
       let minu = date.getMinutes();  
       let second = date.getSeconds();  
       let str = fill(year,2)+":"+fill(month,2)+":"+fill(day,2)+":"+fill(hour,2)+":"+fill(minu,2)+":"+fill(second,2);  
       let div = document.getElementById("time");  
       div.textContent=str;  
       count++;  
       if(count == 3){  
           clearInterval(t);  
       }  
       return str;  
   }  
   function fill(num , len){  
       let str = num + "";  
       while(str.length < len){  
           str = "0" + str;  
       }  
       return str;  
   }  
   let t = setInterval(time,1000);  
</script>  
</body>  
</html>
```
