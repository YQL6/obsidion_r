# 一.简介

## 1.1简介

- ES6的依赖模块需要加载，这个依赖模块指的是编译文件要用，包括自定义，包，浏览器若支持es6，直接加载所有模块不必browserify
- 有的浏览器不支持es6，要编译成es5（旧版本，包含 CommonJS 模块格式），还要对模块化编译，browserify——babel实现es6变为es5

# 二.语法

## 2.1导出，导入

```javascript
export//暴露
import//导入
import xxx from "路径"//xxx是变量接收
```

main.js
```javascript
//引入其他的模块  
// import module1 from './module1';  
// import module2 from './module2';  
//  
// module1.fun();  
//不可用，不是直接返回一个对象  
//不能直接引入使用  
  
import {fun1,fun2,fun3} from './module1';  
import{fun} from './module2' ;  
  
fun1();  
fun();
```
module1.js:常规暴露
```javascript
//分开暴露  
export function fun1(){  
    console.log("这是module1的第一个方法");  
}  
  
export function fun2(){  
    console.log("这是module1的第二个方法");  
}  
  
export function fun3(){  
    console.log("这是module1的第三个方法");  
}
```
module2.js常规暴露
```javascript
//统一暴露  
function fun(){  
    console.log("string");  
}  
  
function fun1(){//定义的fun1与module1的fun1冲突  
    console.log("ss");  
  
}  
  
export{fun,fun1};
```

# 三.环境配置

## 3.1配置package.json

```json
{  
  "name": "es6_bable_browserify",  
  "version": "1.0.0"  
}
```

## 3.2下载babel-cli，babel-perset-es2015

命令行接口库-cli：多了Babel命令，内含命令
babel-preset-es2015:工具命令，工具库,例：jsx——》js

```text
npm install babel-cli browserify -g//全局安装
```

```text
npm install babel-preset-es2015 --save-dev
//局部下载工具类
```
`babel-preset-es2015` 是 Babel 的一个**预设（preset）**，集合了所有将 ES2015 语法转换为 ES5 语法的插件。

## 3.3配置文件

.bablerc:本质还是json
```json
{  
  "presets": ["es2015","react"]  
}
```

# 五.第三方工具的引用

## 1.1引用

```text
npm istall jQuery@版本//不指定下载最新的，多次引用覆盖，不重新开辟一片地区下载
```

```javascript
import $ from 'jQuery';
```

**导入时你用什么变量名接收，后面就用那个变量名来调用 jQuery 的选择器等功能。**

- `import $ from 'jquery'` → 用 `$('div')`
    
- `import jq from 'jquery'` → 用 `jq('div')`
    
- `import jQuery from 'jquery'` → 用 `jQuery('div')`
