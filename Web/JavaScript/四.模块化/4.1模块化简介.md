- IIFE模式增强：匿名函数的调用，依赖引入
```javascript
(function(window,$){//传入window挂在下面
	let mac ="string";
	function f(){
		console.log(mac);
	}
	f();
	window.module3={
		foo:foo//定义一个对象，挂在window下面，通过这个使用函数，且保证了mac属性不变
	};
	$('body').css('background','red');
})(window，jQuery);
```

机制：
-  外部通过 `window.module3.foo` 调用，实际执行的是内部函数 `f`。
    
- `f` 在自己作用域内找不到 `mac`，会沿**作用域链**向上查找，找到 IIFE 内的 `let mac = "string"`。
    
- 这就是**闭包**的经典效果：**函数能访问它定义时所在作用域的变量，即使该作用域已经执行完毕。**

注：
1. 不需要window跟着，默认是window的全局属性找
2. ` $`是一个参数没有特别含义，我用`$`引入才是调用jquery
3. jquery引入页面本质是将jQuery属性挂在window下面
4. 引入包是要有顺序，不能乱，各包间可能各有依赖
