# 一.简介

## 1.1介绍

- 每个文件可以作为一模块
- 服务器端：模块加载是运行时同步加载，运行时机——执行到require时，执行完在继续
- 浏览器端：浏览器不认识require语句，需要提前编译打包，让浏览器认识

![[图片/Pasted image 20260624151914.png]]

## 1.2方法补充

1. module.exports只能赋值一次，接下来在赋值就要被覆盖了，exports可以为其添加多个属性，赋值函数，requir返回一个exports值是对象，可以调用里面多个函数
2. `module` 是一个对象，代表当前模块本身。
3. `module.exports` 是模块对外暴露的接口，**只有这个对象会被 `require` 返回**。

## 1.3模块引入

- require：
	- 第三方模块：直接模块名
	- 自定义模块：文件路径

## 1.4实现

- 服务器端：node.js
- 浏览器端：browserify

## 2.2编辑模块

model1.js:
```javascript
//暴露一个exports对象  
module.exports={  
    msg:'string',  
    foo(){//省略了function  
        console.log(this.msg);  
    }  
};
```
model2.js:
```javascript
//暴露一个函数——exports  
module.exports=function(){  
    console.log('module2被调用');  
}
```
model3.js:
```javascript
//exports.xxx,直接为返回的对象的属性赋值  
exports.foo=function (){  
    console.log('module3被调用');  
}
```
app.js:
```javascript
let unniq = require("uniq");//在最上面引入  
  
let module1 = require('./modules/module1');  
let module2 = require('./modules/module2');  
let module3 = require('./modules/module3');  
module1.foo();  
module2();  
module3.foo();
```

执行：
```text
node app.js
```

注：exports作为返回对象，可以多个属性，可以函数
