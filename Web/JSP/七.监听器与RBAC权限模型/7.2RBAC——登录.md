# 一.RABC

## 1.1RABC术语

RBAC全称为Role-Based Access Control，表示<mark style="background: #FF5582A6;">基于<mark style="background: #FF5582A6;">角色的访问控制</mark></mark>。在RBAC中，有三个最常用的术语：
1. 用户：系统资源的操作者
2. 角色：具有<mark style="background: #FF5582A6;">一类相同操作权限</mark>的用户的总称，例：管理员，工程师
3. 权限：能够<mark style="background: #FF5582A6;">访问资源的资格</mark>
4. 资源：服务器上的<mark style="background: #FF5582A6;">一切数据都是资源</mark>，比如静态文件，查询的动态数据等。

RBAC的设计主要是<mark style="background: #FF5582A6;">控制服务器端的资源访问</mark>。

## 1.2 服务器与客户端建立连接

服务器感知用户是通过<mark style="background: #FF5582A6;">session</mark>来感知的，因此，RBAC的实现需要与session配合。<mark style="background: #FF5582A6;">前提是用户需要登录</mark>，登录后将<mark style="background: #FF5582A6;">用户信息存储在session中</mark>，这样才能在session中获取用户的信息。
