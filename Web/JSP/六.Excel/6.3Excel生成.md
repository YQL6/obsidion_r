# Excel

<mark style="background: #FF5582A6;">EasyExcel</mark> 是阿里巴巴开源的一个 <mark style="background: #FF5582A6;">Excel 处理框架</mark>，以使用简单、节省内存著称。 EasyExcel 能大大 减少占用内存的主要原因是在解析 Excel 时没有将文件数据一次性全部加载到内存中，而是<mark style="background: #FF5582A6;">从磁盘上一 行行读取数据，逐个解析</mark>。

# Excel生成

excel.java:
```java
package com.jsp.com.jsp.tools;  
  
import java.util.*;  
  
import com.alibaba.excel.EasyExcel;  
import com.jsp.pojo.student;  
  
public class excel {  
    public static void main(String[] args) {  
        String dir = "D:\\JSP项目\\jsp07\\Excel示例.xlsx";  
        List<student> list = new ArrayList<>();  
        for(int i = 0 ; i <= 100 ; i++){  
            student s = new student();  
            s.setAge(i);  
            s.setName("姓名" + i);  
            s.setSex(i % 2 == 0 ? "男" : "女");  
            list.add(s);  
        }  
        EasyExcel.write(dir,student.class).sheet("sheet1")  
                .doWrite(list);  
    }  
}
```
student.java:
```java
package com.jsp.pojo;  
  
import com.alibaba.excel.annotation.ExcelProperty;  
  
import java.util.*;  
  
public class student {  
    @ExcelProperty("年龄")  
    private int age;  
    @ExcelProperty("姓名")  
    private String name;  
@ExcelProperty("性别")  
    private String sex;  
  
    public String getSex() {  
        return sex;  
    }  
  
    public String getName() {  
        return name;  
    }  
  
    public void setName(String name) {  
        this.name = name;  
    }  
  
    public int getAge() {  
        return age;  
    }  
  
    public void setAge(int age) {  
        this.age = age;  
    }  
  
    public void setSex(String sex) {  
        this.sex = sex;  
    }  
}
```
