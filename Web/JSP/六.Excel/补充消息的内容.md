# 消息的组成

组成：起始行+消息头+消息体

# 起始行

组成：方法 + 空格 + <mark style="background: #FF5582A6;">请求目标（通常是 URL）</mark>+ 空格 + HTTP版本

使用：get将消息放于url中

# 消息头

作用：HTTP 消息头（Headers）是位于**起始行之后，消息体之前**的一组<mark style="background: #FF5582A6;">键值对</mark>，用于传递请求或响应的<mark style="background: #FF5582A6;">附加元信息</mark>**。它们不直接显示在浏览器页面上，但对数据的正确传输、安全性、性能、兼容性至关重要
