作用：<mark style="background: #FF5582A6;">获取</mark>客户端的参数和数据流


get与post：
1. GET 请求的参数在URL中，而 POST 请求的参数在请求体（body） 中 
2. GET 请求有数据长度限制，这个长度限制是浏览器或者服务器为了提升处理效率而做出的限制，而 POST 请求没有。
3. GET 请求的安全性低，因为参数在URL中，直接暴露了信息，而 POST 请求的安全性高，因为 POST 请求的参数在请求体（body） 中，隐藏了信

# 内置对象session

session: session 就是浏览器与服务器之间的一次通话,默认30分钟

本质：HTTP 协议是一种无状态协议，用户在访问服务器时，服务器无法感知到用户是哪一个用户，也就无法 <mark style="background: #FF5582A6;">追踪用户的后续操作</mark>。为了解决这一问题，服务器端设计了一个类 <mark style="background: #FF5582A6;">HttpSession 来感知用户</mark>，这个类 产生的<mark style="background: #FF5582A6;">对象就是 session</mark>。在用户第一次访问服务器时，服务器就会为该用户生成了一个 session 对 象，<mark style="background: #FF5582A6;">session 对象一产生就会生成了一个唯一标识符 JSESSIONID </mark>， 并将这个唯一标识符使用<mark style="background: #FF5582A6;">Cookie存 储在浏览器</mark>中，用户后续进行的每一个<mark style="background: #FF5582A6;">操作都将携带这个唯一标识符</mark>，服务器就根据这个<mark style="background: #FF5582A6;">唯一标识符追 踪用户</mark>。session 对象产生时就有一个过期时间，主要用于检测用户是否还在进行有效的操作。如果用 户具有有效的操作，那么每一次用户的<mark style="background: #FF5582A6;">有效操作都将重置该session的过期时间</mark>。这个过期时间就是检测 用户登录超时的依据。除此之外，<mark style="background: #FF5582A6;">session 还可以存储数据</mark>。

数据类型：javax.servlet.http.HttpSession

常用方法：
```java
//以key/value的形式保存对象值 
void setAttribute(String key, Object value); 
//通过key获取对象值 
Object getAttribute(String key); 
//设置session对象失效 ,例如：退出登录
void invalidate(); 
// 获取sessionid 
String getId(); 
//设定session的非活动时间 
void setMaxInactiveInterval(int interval); 
//获取session的有效非活动时间(以秒为单位) 
int getMaxInactiveInterval(); 
//从session中删除指定名称(key)所对应的对象 
void removeAttribute(String key);
```

由于session存储在浏览器中，所以可以用重定向，将要用的数据提前存储在其中，重定向的页面直接从session获得

session不随页面变化而变化

示例：
transition.jsp:
```java
<body>  
<%  
    String username = request.getParameter("username");  
    String password = request.getParameter("password");  
    if(username.equals("admin") && password.equals("123456")){  
        //request.getRequestDispatcher("response.jsp").forward(request,response);  
        session.setAttribute("user",username);  
        session.setAttribute("password",password);  
        response.sendRedirect("response.jsp");  
    }%>  
</body>
```
response.jsp：
```java
<body>  
<%  
//    String username = request.getParameter("username");

<div><%=password%></div>

```

>[!重点补充]
>- **“用户请求时，服务器发现没有 session 或 session 过期”** → 只有当你（或框架）**主动要求获取 session** 时，服务器才会创建新 session。
>- 否则，服务器不会主动分配 session。
><h1>session对象：</h1>
>1. 首先存储位置是服务器，当request.getsession时才会检查创建

# 内置对象include

问题：在开发过程中，开发的页面数量总是很多，如何确保用户的每一次操作都是有效操作呢？所谓的有效操 作是指在登录没有超时的情况下进行的操作。——include检验

检验方法：超时以后向浏览器发生，浏览器不认识，发现超时，会重新为创建一个session，里面ID不同，数据为空

```html
<%@ include file="文件名"%>
```
超时跳转到文件名处，这种写法本质是将<mark style="background: #FF5582A6;">两个代码合并</mark>只实现一次检查，所以<mark style="background: #FF5582A6;">变量名不能一样</mark>

# 内置对象application

数据类型：javax.servlet.ServletContext

作用：实现用户<mark style="background: #FF5582A6;">数据共享</mark>，将信息<mark style="background: #FF5582A6;">保存在服务器中</mark>，直到服务器关闭

常用方法：
```java
// 以key/value的形式保存对象值 
void setAttribute(String key,Object value); 
//通过key获取对象值 
Object getAttribute(String  key); 
//返回相对路径的真实路径 
String getRealPath(String  path);
```
相对路径的真实路径——带盘符的绝对路径

可以记录一个网站的访问次数：
application.jsp:
```java
<%@ page contentType="text/html;charset=UTF-8" language="java" %>  
<html>  
<head>  
    <title>Title</title>  
</head>  
<body>  
<%  
    Integer count = (Integer) application.getAttribute("count");  
    if(count == null){  
        count = 1;  
    }else{  
        count += 1;  
    }    application.setAttribute("count", count);  
%>  
</body>  
</html>
```

# Cookie

Cookie:Cookie 是 Web 服务器保存<mark style="background: #FF5582A6;">在客户端</mark>的一系列<mark style="background: #FF5582A6;">文本信息</mark>。<mark style="background: #FF5582A6;">Session </mark>机制采用的是在服务端保持状态的方 案，而Cookie 机制则是在客户端保持状态的方案，Cookie 又叫会话跟踪机制，用来弥补HTTP无状态协 议的不足

<mark style="background: #FF5582A6;">注：session自动建一个Cookie（session放在服务器端，，为session的cookie放在浏览器端，不会与new的cookie混淆）</mark>

<mark style="background: #FF5582A6;">注：response才是真正让cookie存入浏览器的方法</mark>

<mark style="background: #FF5582A6;">注：response添加新的同名cookie，新的覆盖旧的</mark>

作用：
1. 弥补HTTP无状态协议的不足 
2. 简化登录，比如记住密码、自动登录等

常用方法：
```java
//构造方法 
Cookie cookie = new Cookie("名称", "值"); 
//设置cooki的有效期，以秒为单位 
void setMaxAge(int expiry); 
//在cookie创建后，对cookie进行赋值 
void setValue(String value); 
//获取cookie的名称 
String getName(); 
//获取cookie的值 
String getValue(); 
//获取cookie的有效时间，以秒为单位 
String getMaxAge();
```

cookie保存账号，示例：
