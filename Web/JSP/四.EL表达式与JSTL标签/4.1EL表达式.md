# EL表达式

EL 全称为 Expression Language（表达式语言）

# 用途

在 jsp 页面中编写小脚本，会存在以下不足： 
1. 代码结构混乱 脚本与HTML混合，容易出错 
2. 代码不易于维护 
3. 获取JavaBean属性必须要实例化及强制类型转化
为了解决这些不足，JSP提供了 EL <mark style="background: #FF5582A6;">表达式</mark>来简化编码，可以使用 EL 表达式来<mark style="background: #FF5582A6;">替换 jsp 页面中的小脚本</mark>， 使得页面和业务逻辑处理相分离，同时还能实现<mark style="background: #FF5582A6;">数据类型的自动转型</mark>

# 使用EL表达式

# 获取对象

```java
${变量名}
```

示例：
```java
package com.web.servlet;  
  
import javax.servlet.ServletException;  
import javax.servlet.annotation.WebServlet;  
import javax.servlet.http.HttpServlet;  
import javax.servlet.http.*;  
import java.io.IOException;  
  
@WebServlet("/showUserInfo")  
public class Firstservlet extends HttpServlet{  
    public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {  
        HttpSession session = request.getSession();  
  
        session.setAttribute("user1" , "张三");  
        request.setAttribute("user1" , "张三");  
        request.getRequestDispatcher("user.jsp").forward(request , response);  
    }  
}
```
uesr.jsp
```java
<%@ page contentType="text/html;charset=UTF-8" language="java" %>  
<html>  
<head>  
    <title>Title</title>  
</head>  
<body>  
${user1}  
</body>  
</html>
```

结论：
1. 不论变量是存储在 request 中，还是存储在 session 中，都可以使用 EL 表达式进行取值。
2. 如果 reqeust 和 session 中都存有相同属性的变量，那么 EL 表达式会从 reqeust 中进行取值。需要session可以用隐式对象来

${sessionScope.user1}${requestScope.user1}

user.class:
```java
package com.web.servlet;  
  
public class user {  
    public String name;  
    public int age;  
    public user(String name, int age) {  
        this.name = name;  
        this.age = age;  
    }  
    public String getName() {  
        return name;  
    }  
    public int getAge(){  
        return age;  
    }  
  
}
```
FirstServlet:
```java
package com.web.servlet;  
  
import javax.servlet.ServletException;  
import javax.servlet.annotation.WebServlet;  
import javax.servlet.http.HttpServlet;  
import javax.servlet.http.*;  
import java.io.IOException;  
import java.util.ArrayList;  
import java.util.HashMap;  
import java.util.List;  
import java.util.Map;  
  
@WebServlet("/showUserInfo")  
public class Firstservlet extends HttpServlet{  
    public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {  
        HttpSession session = request.getSession();  
  
        session.setAttribute("user1" , "张三");  
        request.setAttribute("user1" , "张三");  
  
        session.setAttribute("user2" , new user("李四",18));  
        request.setAttribute("user2" , new user("李四" , 20));  
  
        List<String> list = new ArrayList<>();  
        list.add("王五");  
        list.add("李六");  
        session.setAttribute("user_list", list);  
        request.setAttribute("user_list", list);  
  
        Map<String,Integer> map = new HashMap<>();  
        map.put("小明",18);  
        map.put("小李",16);  
        session.setAttribute("user_map", map);  
        request.setAttribute("user_map", map);  
        request.getRequestDispatcher("user.jsp").forward(request , response);  
    }  
}
```
user.jsp:
```java

```

注：当 EL 表达式直接输出到页面时（例如 `${user != null && user.name == 'admin'}`），JSP 会自动将布尔值转换为字符串 `"true"` 或 `"false"` 显示。  
因此你可能误以为返回的是 String，实际上**EL 内部是布尔类型**，只是在输出时做了字符串转换。
