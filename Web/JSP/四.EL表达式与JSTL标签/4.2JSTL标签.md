# JSTL

JSTL 全称为 JavaServerPages Standard Tag Library，意味 JSP标准标签库

# 标签库分类

![[图片/Pasted image 20260531205643.png]]

# 引入包

```java
<%@ taglib uri="http://java.sun.com/jsp/jstl/core" prefix="c"%>
```
注：不同库要用不同的url，课件对应的那一节有对应的资源，要加入库

# 核心库标签

## 通用标签

![[图片/Pasted image 20260531210237.png]]

### <c:set>

```java
<c:set var="变量名" value="变量值" scope="变量的作用范围" /> //将value值存储到范围为scope的变量variable中
<c:set target="目标对象" property="对象属性" value="对象属性值" />//将value值存储到范围为scope的变量variable中
```
注：小脚本也可以定义变量，但是只能用小脚本调用，不能用JSTL

示例：
```java
<% request.setAttribute("user", new User()); %> 
<c:set var="user" value="<%=new User()%>" scope="page" />
 <c:set target="${pageScope.user}" property="username" value="admin" />
  页面中的${pageScope.user.username}   
  请求中的${requestScope.user.username}
```

### <c:remove>

```java
<c:remove var="变量名" scope="变量的作用范围" />
```

## 条件标签

### <c:if>

```java
<c:if test="条件表达式" var="存储表达式的结果的变量" scope="变量的作用范围">
</c:if>
```
注：result为true/flase，可以输出,以此判断中间的代码段是否执行，<mark style="background: #FF5582A6;">不会有else分支
</mark>
### <c:choose>

```java
  <c:choose >
	  <c:when test:"条件表达式">执行语句</c:choose>
	  <c:when test:"条件表达式">执行语句</c:choose>
	  <c:when test:"条件表达式">执行语句</c:choose>
	  <c:otherwise>执行语句</c:otherwise>
</c:choose>
```

### <c:ForEach>

```java
<c:ForEach items="遍历的集合" var="每次遍历的对象" begin="遍历开始的位置" end="遍历 结束的位置" step="遍历的步长">

</c:ForEach>
```

## <fmt:formatNumber>

![[图片/Pasted image 20260531212314.png]]
注：
1. 数字格式：####.##——》整数不限，小数两位
2. - **`maxIntegerDigits`**：限制整数部分的最大位数。如果实际整数的位数超过这个值，**只保留最低的 `maxIntegerDigits` 位，高位被截掉**。  
    例如：`maxIntegerDigits="2"`，数字 `12345` → 输出 `45`（只保留最后两位）
3. **`maxFractionDigits`**：限制小数部分的最大位数。超出时**按四舍五入**处理。  
    例如：`maxFractionDigits="2"`，`3.456` → 输出 `3.46`。
4.  对于百分比类型（`type="percent"`），`maxIntegerDigits` 同样适用（<mark style="background: #FF5582A6;">数值先乘以100，再限制整数位数</mark>）。
