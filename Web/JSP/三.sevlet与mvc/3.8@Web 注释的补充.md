# @WebFilter

![[图片/Pasted image 20260611155533.png]]

```java
@WebFilter(
    filterName = "encodingFilter",
    urlPatterns = { "/*" },
    dispatcherTypes = { DispatcherType.REQUEST, DispatcherType.FORWARD },
    initParams = {
        @WebInitParam(name = "encoding", value = "UTF-8"),
        @WebInitParam(name = "forceEncoding", value = "true")
    }
)
```

# @WebServlet

![[图片/Pasted image 20260611155629.png]]

```java
@WebServlet(
    name = "LoginServlet",
    urlPatterns = { "/login", "/signin" },
    loadOnStartup = 1,
    initParams = {
        @WebInitParam(name = "defaultRole", value = "user"),
        @WebInitParam(name = "timeout", value = "30")
    }
```
