
- 一个部署的应用——》一个上下文路径——》一个`context`——》一个`servletcontext`

- 对象使用：
```java
// 在任意 Servlet 里
ServletContext sc = getServletContext();

// ① 直接拿回"本应用的上下文路径"——这就是它们最直观的关系
String path = sc.getContextPath();   // 返回 "/app1"；根应用返回 "" 或 "/"

// ② 用"别的应用的上下文路径"去拿它的 ServletContext（跨应用，通常受限）
ServletContext other = sc.getContext("/app2");

// ③ ServletContext 的典型用途：整个应用共享的数据
sc.setAttribute("onlineCount", 100);

// ④ 应用级初始化参数（web.xml 里配的 <context-param>）
String siteName = sc.getInitParameter("siteName");

// ⑤ 应用内资源、转发
String real = sc.getRealPath("/WEB-INF/web.xml");
```

<mark style="background: #FF5582A6;">注：setAttribute是存入内存中，供应用使用</mark>

本质：一个处理器共用的空间，保存变量等数据
