```java
Servlet常用方法（支持 HTTP 协议的 Servlet） 用法 
//添加响应头信息

//设置响应状态 
void setStatus(int status);
```

|对比|`setStatus(int)`|`sendError(int)` / `sendError(int, String)`|
|---|---|---|
|作用|只改响应**状态行**的状态码|发送一个**完整错误响应**（状态码 + 错误页）|
|正文谁写|**你自己**继续用 getWriter 写|**容器**自动生成错误页（或按 `<error-page>` 跳转）|
|调用后还能写正文吗|✅ 可以|❌ 容器认为响应已提交，一般不能再写|
|是否触发 error-page 机制|❌ 不触发|✅ 触发（web.xml `<error-page>` 配置的页面）|
|抛异常|不抛|`throws IOException`|
|典型用途|自定义响应：如 200/302/404 后自己输出内容|直接交出错页：`sendError(404,"找不到")`|

# 三.常用方法

```java
//对父类抽象方法的实现，该方法是对HTTP协议的交互信息的实现，调用的是下面的 service 方法 
void service(ServletRequest req,ServletResponse res); 
//HTTP协议的交互信息的实现，该方法主要针对不同的请求方式进行处理。GET请求会调用 doGet 方 法处理，
 //POST请求会调用 doPost 处理， PUT请求会调用 doPut 方法处理， DELETE请求会调用 doDelete 方法处理 
 void service(HttpServletRequest  req, HttpServletResponseres); 
 //GET请求处理 
 void doGet(HttpServletRequestreq,HttpServletResponse res); 
 //POST请求处理 
 void doPost(HttpServletRequestreq,HttpServletResponse res); 
 //PUT请求处理 
 void doPut(HttpServletRequestreq,HttpServletResponse res); 
 //DELETE请求处理 
 void doDelete(HttpServletRequestreq,HttpServletResponse res);
```

注：
1. service调用Http的service。
2. Http的service,会根据数据传输的请求类型找到对应的方法来处理
3. 如果没有重写对应的service方法，则自动调用对应的do方法
4. 重写了service方法的调用service方法

示例：
```java
package com.web.servlet;  
import javax.servlet.http.HttpServlet;  
import javax.servlet.http.HttpServletRequest;  
import javax.servlet.http.HttpServletResponse;  
import java.util.*;  
  
public class SecondServlet extends HttpServlet {  
    public void service(HttpServletRequest req, HttpServletResponse res) {  
        System.out.println("开始获取头部信息");  
        Enumeration<String> names = req.getHeaderNames();  
        while (names.hasMoreElements()) {  
            String name = names.nextElement();  
            String value = req.getHeader(name);  
            System.out.println("头部信息为" + name + "：" + value);  
            String url_u = req.getContextPath();  
            System.out.println("上下文路径为："+url_u);  
            String url=req.getRequestURI();  
            String url_name = url.replace(url_u , "");  
            System.out.println("路径为：" + url_name);  
            String method_name = req.getMethod();  
            System.out.println("请求方法为：" + method_name);  
              
        }  
    }  
}
```
