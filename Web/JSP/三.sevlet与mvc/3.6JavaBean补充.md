# MCV的模型层

处理数据与逻辑处理

# 本质

javaBean:模型层的数据封装的地方，一种特殊类，由自己设计，用来保存数据，例如：数据库万能查询，用户提交的表单等

示例：
servlet：
```java
protected void doPost(HttpServletRequest req, HttpServletResponse resp) {
    // 获取参数
    String name = req.getParameter("name");
    int age = Integer.parseInt(req.getParameter("age"));
    // 创建模型对象
    User user = new User();
    user.setName(name);
    user.setAge(age);
    // 调用可能的业务逻辑（比如保存到数据库，这里省略）
    // 把模型存入请求
    req.setAttribute("user", user);
    // 转发到视图
    req.getRequestDispatcher("/showUser.jsp").forward(req, resp);
}
```
javaBean:
```java
public class User {
    private String name;
    private int age;
    // 业务方法：判断是否成年
    public boolean isAdult() {
        return age >= 18;
    }
    // getter/setter ...
}
```
showUser:
```java
<p>姓名：${user.name}</p>
<p>年龄：${user.age}</p>
<p>是否成年：${user.adult ? "是" : "否"}</p>
```

# @webServlet

```java
@WebServlet(
    name = "MyServlet",                 // Servlet 名称（可选，默认类名）
    urlPatterns = {"/test", "/test/*"}, // 同 value，声明映射的 URL
    loadOnStartup = 1,                  // 启动时加载（正整数，越小越优先）
    initParams = {                       // 初始化参数
        @WebInitParam(name = "encoding", value = "UTF-8"),
        @WebInitParam(name = "debug", value = "true")
    },
    asyncSupported = true,              // 是否支持异步处理
    description = "示例 Servlet"         // 描述信息
)
public class MyServlet extends HttpServlet {
    @Override
    public void init() {
        String encoding = getInitParameter("encoding");
        System.out.println("encoding = " + encoding);
    }
}
```
