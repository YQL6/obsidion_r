# ajax

AJAX 全称为 Asynchronous JavaScript And Xml ，表示异步的Java脚本和Xml 文件<mark style="background: #FF5582A6;">，是一种异步刷 新技术。</mark>可以对页面的部分页面单独刷新，而不是整个页面刷新

![[图片/Pasted image 20260611171719.png]]

# 用途

Servlet 进行网页的变更往往是通过<mark style="background: #FF5582A6;">请求转发</mark>或者是<mark style="background: #FF5582A6;">重定向</mark>来完成，这样的操作更新的是<mark style="background: #FF5582A6;">整个网页</mark>，如 果我们只<mark style="background: #FFB86CA6;">需要更新</mark>网页的<mark style="background: #FF5582A6;">局部内容</mark>，就需要使用到<mark style="background: #FF5582A6;">AJAX</mark>来处理了。因为只是更新局部内容，因此， Servlet 传输的数据量就减少了，这不仅有效的利用了带宽，提高效率的同时还增加了用户的体验度， 操作起来更为方便。

# ajax 使用

AJAX的<mark style="background: #FF5582A6;">核心是一个对象</mark>，既然是对象，那么就应该存在属性和方法。

不同浏览器的ajax：
1. IE浏览器： ActiveXObject 
2. 其他浏览器： XMLHttpRequest
# ajax方法

![[图片/Pasted image 20260611182103.png]]

属性的一些问题：
1. ContType——头部信息——请求或响应的请求体的<mark style="background: #FF5582A6;">解读方法</mark>，即请求体类型
![[图片/Pasted image 20260611185302.png]]
2. readystate——当前请求的响应状态，共五个阶段：
![[图片/Pasted image 20260611185005.png]]
常为了监听的完整性，要求onreadystatechange写在open后面，send前面
3. onreadystatechange——监听请求状态的变化，一变化就调用函数
4. `status` 是 HTTP 响应状态码，由服务器返回。

示例：
login.jsp
```java
<%@ page contentType="text/html;charset=UTF-8" language="java" %>  
<html>  
<head>  
    <title>Title</title>  
</head>  
<body>  
<form action="transition.jsp" method="get">  
    <div>        <span>账号</span>  
        <input type="text" id="username" name="username">  
        <span  id="tip" name="tip"></span>  
    </div>    <div>        <span>密码</span>  
        <input type="password">  
    </div>    <div>        <input type="submit" value="登录">  
    </div></form>  
</body>  
<script type="text/javascript">  
    let username = document.getElementById("username");  
    username.onblur = function(){  
        let val = username.value;  
        if(val !== ""){  
            let xmlHttprequest;  
            if(window.ActiveXObject){  
                xmlHttprequest = new ActiveXObject("Microsoft.XMLHTTP");  
            }else{  
                xmlHttprequest = new XMLHttpRequest();  
            }  
            xmlHttprequest.open("get" , "cheekusername?username=" + val, true);  
            xmlHttprequest.onreadystatechange = function(){if(xmlHttprequest.readyState === 4){  
                let result;  
                if(xmlHttprequest.status === 200){  
                    let tip = document.getElementById("tip");  
                    result = xmlHttprequest.responseText;  
                    if(result === "1"){  
                        tip.innerText="账号已存在";  
                        tip.style.color="red";  
                    }else{  
                        tip.innerText="账号可使用";  
                        tip.style.color="green";  
                    }  
                }  
            }}  
            xmlHttprequest.send();  
        }  
  
    }  
</script>  
</html>
```

cheekusernameServlet:
```java
package com.jsp.servlet;  
  
import javax.servlet.ServletException;  
import javax.servlet.annotation.WebServlet;  
import javax.servlet.http.HttpServlet;  
import javax.servlet.http.*;  
import java.io.IOException;  
import java.io.*;  
  
@WebServlet("/cheekusername")  
public class CheckUsernameServlet extends HttpServlet {  
    @Override  
    public void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {  
        String username = req.getParameter("username");  
        PrintWriter out = resp.getWriter();  
        if(username.equals("admin")){  
            out.write("1");  
        }else{  
            out.write("0");  
        }  
        out.flush();  
        out.close();  
    }  
    @Override  
    public void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {  
        String username = req.getParameter("username");  
        PrintWriter out = resp.getWriter();  
        if(username.equals("admin")){  
            out.write("1");  
        }else{  
            out.write("0");  
        }  
        out.flush();  
        out.close();  
    }  
}
```

重点错误：
1. print：都会变成字符串
2. write：unicode编码的码点——数字，字符串——字符串

# 头部信息

头部信息与表单数据：
1. GET 方式提交的表单数据包含在 **URL 的查询字符串（query string）** 中，属于 **请求行（request line）** 的一部分，而<mark style="background: #FF5582A6;">非 HTTP 头部。</mark>
2. 头<mark style="background: #FF5582A6;">部主要传递元信息</mark>（如内容类型、编码、缓存控制等），而不是业务数据。
