# 一.JSON

JSON 全称为 JavaScript Object Notation，表示 Javascript 对象符号，是一种<mark style="background: #FF5582A6;">网络数据交换的格式</mark>， 通常在服务器端和客户端之间使用。

它是一种轻量级的数据交换格式，常用于前后端通信。它包含<mark style="background: #FF5582A6;">键值对</mark>（对象形式），但也支持其他数据类型（如数组）。

值的形式：
![[图片/Pasted image 20260613232031.png]]

JSON 的数据结构只有两种：

1. **键值对集合（对象）**：用 `{ }` 包围，键必须用**双引号**括起来，键值对之间用逗号分隔。  
    示例：`{"name": "张三", "age": 25}`
    
2. **有序的值列表（数组）**：用 `[ ]` 包围，值之间用逗号分隔。  
    示例：`[10, "hello", true, null]`

# 二.定义JSON

```java
//JSON格式的对象 
let json = {    
	"属性名1": "属性值1",
	"属性名2": "属性值2",    
	"属性名3": "属性值3",     
	... 
}; 
//JSON格式的数组 
let jsonArray = [值1,值2,值3, ...]; 
//JSON格式的对象数组 
let jsonObjectArray = [   
	{"属性名1": "数值1","属性名2": "数值2", ...},   
	{"属性名1": "数值1","属性名2": "数值2", ...} ]
```

数组的JSON：
Java 中生成一个 **纯数组格式的 JSON**（即最外层是 `[ ... ]`，而不是 `{ ... }`），可以使用 `JSONArray` 类（例如 `org.json.JSONArray` 或类似的库），而不是 `JSONObject`。

```java
import org.json.JSONArray;
// 创建一个空的 JSON 数组
JSONArray jsonArray = new JSONArray();
// 添加各种元素
jsonArray.put("字符串");
jsonArray.put(123);
jsonArray.put(true);
jsonArray.put(new int[]{1,2,3}); // 内部数组会被转换为 JSON 数组
// 也可以一次性从现有集合构造
List<String> list = Arrays.asList("a", "b", "c");
JSONArray jsonArray2 = new JSONArray(list);
// 输出结果
System.out.println(jsonArray.toString());
// 输出: ["字符串",123,true,[1,2,3]]
```
