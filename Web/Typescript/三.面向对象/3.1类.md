# 一.类的定义

## 1.1语法定义

- 定义：
```typescript
class 类名{
	属性名：类型；//可以添加修饰词static——静态属性
	
	方法名(){
		定义语句//与属性同可以修饰：static
	}
}
```

- 注：
1. static静态属性不属于实体类，属于类本身，打印类的实例无静态类，可以直接类名.属性名调用
2. readonly：只读属性，不可以重新赋值
3. static+readonly：静态的只读属性
4. 自动类型判断也生效
5. 类方法：直接 类.方法

## 2.2类的new

- new：
```typescript
类名 变量 = new();
```

## 2.3构造函数

- 定义语法
```typescript
class 类名{
	constructor(...params:类型){
		//定义语句，当new时调用，根据参数的不同决定调哪个
	}
}
```

- 注：
1. 当不给值时报错，可以用构造器赋值，配合不同参数时调用，为类初始化
2. this：当前实例的类对象

# 二.继承

## 2.1语法

- 通过继承可以将其他类中的属性和方法引入到当前类中

- 定义
```typescript
class a extends b{
	//a继承b的所有属性，方法
}
```

## 2.2重写

- 发生继承时，如果子类中的方法会替换掉父类中的同名方法，这就称为方法的重写

- 语法：
```typescript
class a extends b{
	与父类同名的方法名(属性与父类同){
		//重写内容
	}
}
```

- 注：
1. super：引用父类内容，例如：子类用super调用父类构造器

## 2.3抽象类

- 继承的子类要实现为被实现的方法，本身不能new

- 语法：
```typescript
abstract class Animal{
    abstract run(): void;
    bark(){
        console.log('动物在叫~');
    }
}

class Dog extends Animals{
    run(){
        console.log('狗在跑~');
    }
}
```

# 三.接口

## 3.1语法

- 接口的作用类似于抽象类，不同点在于接口中的所有方法和属性都是没有实值的，换句话说接口中的所有方法都是抽象方法。接口主要负责定义一个类的结构，接口可以去限制一个对象的接口，对象只有包含接口中定义的所有属性和方法时才能匹配接口。同时，可以让一个类去实现接口，实现接口时类中要保护接口中的所有属性。

- 定义：
```typescript
interface Person{
    name: string;
    sayHello():void;
}

function fn(per: Person){
    per.sayHello();
}

fn({name:'孙悟空', sayHello() {console.log(`Hello, 我是 ${this.name}`)}});
```

- 注：
1. 只要传入的是name+sayhello就认为是person类型
