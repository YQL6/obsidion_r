# 二.变量变化

## 2.1类型声明

类型声明：
* 类型声明是TS非常重要的一个特点
* 通过类型声明可以指定TS中变量（参数、形参）的类型
* 指定类型后，当为变量赋值时，TS编译器会自动检查值是否符合类型声明，符合则赋值，否则报错
* 简而言之，类型声明给变量设置了类型，使得变量只能存储某种类型的值

注：
1. 原js对错误不会报错也可以执行，没有对变量的类型，是动态类型
2. ts对类型添加了限制，防止随意使用，编译报错，但不阻止使用

## 2.1类型声明方式

```typescript
let 变量: 类型;

let 变量: 类型 = 值;

function fn(参数: 类型, 参数: 类型): 类型{
    ...
}
```

实例：
```typescript
let a;  
a=10;  
a="string";//当定义时不为其赋值时可以随意使用，其实是any类型  
  
let b:number;  
b=("string" as unknown) as number;//定义时给出类型，固定了  
  
let c:number=10;//直接定义加赋值  
  
let d = 10; //隐式声明，由编译器自动判断类型 
d= "string";//虽然没有直接的定义类型但是编译器已经知道赋值类型了
```

* 类型：
  
  | 类型  | 例子  | 描述  |

## 3.1字面量

```typescript
let f:132|"string";  
f=132;  
f="string";  
f="666";//f已经定义为字面量类型，只能在132，“string”里面选一个个  
  
let s:number|string;  
s="666";//s定义为两个类型选一个
```

## 3.2any

```typescript
  
let any;  
any=1;  
any="string";//隐式声明，自动默认为为any  
  
let any01:any;//显示声明  
  
let any02 = any01;//any02为any  
  
let any03:string = any02;//any03依旧为string
```

注：
1. 刚开始，定义变量不赋值，不赋类型时，默认为any类型
2. any类型就和js一样，什么都可以赋值，没有类型，相当于编译器不检查且不对any限制
3. any作为变量为其他变量赋值时，也会消除对方的类型检查
	1. 对方是显示声明：本次过后仍为显示声明类型
	2. 隐式声明时赋值any类型的值：被传染为any
4. any很危险，不要轻易使用

## 3.3unknown

```typescript
let u01:unknown = 10;  
u01="string";//与any一样仅多一个安全检查  
  
let string01:string;  
string01=u01;//此时不知道u01类型，报错，安全检查  
  
if(typeof u01 === "string"){//检查为string类型  
    string01=u01;  
}  
  
string01 = u01 as string;//我知道u01类型为string，断言其为string

let u02 = u01 as string;//隐式赋值时赋值u01的unknown会传染，但是断言的类型优先
```

第二种断言判断：
```typescript
let someValue: unknown = "this is a string";
let strLength: number = (<string>someValue).length;
```

注：
1. 带安全类型检查的any
2. 可以使用断言来决定这类型，其他类型转化可以先断言为unknown，在断言为其他，避免编译器检查

## 3.4void与never

```typescript
  
function sum():void{//可以无返回值，可以为null,可以undefined  
    return undefined;  
}  
  
function nerver01():never{//什么都不能返回，作用时抛出异常，一调用这个函数就报错  
    throw new Error("不要调用这个函数了");  
}
```

## 3.5Object

```typescript
let o:object;  
o={};//{}代表了对象  
o=function(){}//函数也是对象  
//以上没有任何限制  
  
let o01:{username:string,password:number|string};//类似接口方式，提供了一个模板  
o01={username:123,password:"string"};//报错，定义时已经确定了第一个是什么类型
  
let o02:{  
    username:string,  
    password:string;  
    sex:0|1;  
}//定义模板：属性：属性值  
o02={  
    username:"string",  
    password:"string",  
    sex:1;  
}  
  
let o03:{username:string,[params:string]:any}//后面代表无限的属性名:属性值  
o03={username:"string",ff:123,fasd:33};

let o04:(a:number,b:number)=>number;  
o04=function(a,b){  
    return a+b;  
}//定义时模板已定，输入两个number，返回一个number，即使赋值时不定义，也默认为模板

let o05:(a:any,...params:any)=>boolean;//定义第一个是any，其他参数也是any
```

## 3.8enum

```typescript
let user:{name:string,gender:1|0};//数据库存储number内存较小，但是1是男生还是女生容易搞混  
console.log(user.gender === 1);  
  
enum Gender{  
    male,  
    female//无需知道male是是什么，在需要判断对错即可  
}  
let user01:{name:string,gender:Gender};  
console.log(user01.gender === Gender.male);//是否为男性
```
