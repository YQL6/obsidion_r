
```text

```

## 2.2include与exclude

include——一次性编译包含什么，exclude——一次性编译不包含什么

include:
```
{  
  "include": [",./app/**/*.ts",""]  
}
```

注：
1. ./:根目录下
2. `**`:所有目录，可以`**/app`代表到app目录再根据app后面内容在操作，`**`会对所有目录检查，查找，即使是多级目录
3. `*`:所有文件，可以加后缀

exclude：一次性编译不包含什么文件
```text
"exclude": ["./hello/**/*"]
```

默认值为：
```text
["node_modules", "bower_components", "jspm_packages"]//排除本身ts文件
```

# 三.编译器配置

compilerOptions:编译器配置内容都包含在里面
```json
"compilerOptions": {
    "target": "ES6"
}
```

## 3.1target

- target:指定编译后的`.js`为什么版本
```json
"compilerOptions": {
    "target": "ES6"
}
```

- 可用值：ES3（默认）、ES5、ES6/ES2015、ES7/ES2016、ES2017、ES2018、ES2019、ES2020、ESNext

## 3.2 outdir

- outDir：将`.ts`编译后放在哪里（目录）
```json
"compilerOptions": {
    "outDir": "dist"
}
```

- 默认情况下，编译后的js文件会和ts文件位于相同的目录，设置outDir后可以改变编译后文件的位置

## 3.3outFile

- outFile:编译后的`.js`合为一个文件
```json
"compilerOptions": {
    "outFile": "dist/app.js"
}
```

- 默认会将所有的编写在全局作用域中的代码合并为一个js文件，如果module制定了None、System或AMD则会将模块一起合并到文件之中

## 3.4lib

- lib:可以使用的库：
```json
"compilerOptions": {
    "target": "ES6",
    "lib": ["ES6", "DOM"],
    "outDir": "dist",
    "outFile": "dist/aa.js"
}
```

- 可用值：ES5、ES6/ES2015、ES7/ES2016、ES2017、ES2018、ES2019、ES2020、ESNext、DOM、WebWorker、ScriptHost ......

## 3.5module

- module：使用的模块化系统
```json
"compilerOptions": {
    "module": "CommonJS"
}
```

- 可选值：CommonJS、UMD、AMD、System、ES2020、ESNext、None

## 3.6rootDir

- rootDir:代码的根目录
```json
"compilerOptions": {
    "rootDir": "./src"
}
```

- 默认值：默认情况下编译后文件的目录结构会以最长的公共目录为根目录，通过rootDir可以手动指定根目录

## 3.7allowjs

- allowjs：是否对`.js`文件编译

## 3.8cheekjs

- cheekjs：是否对`.js`文件检查
```json
"compilerOptions": {
    "allowJs": true,
    "checkJs": true
}
```

## 3.9removeComments

- removeComments:是否编译后删除注释
```json
"compilerOptions": {
    "allowJs": true,
    "checkJs": true
}
```

## 3.10 noEmit

- noEmit:当有错误时无法编译为`.js`文件

## 3.11strict

- strict:启动严格模式，默认严格模式检擦全部启动

## 3.12关于严格检查的内容

```text
 alwaysStrict
          - 总是以严格模式对代码进行编译
        - noImplicitAny
          - 禁止隐式的any类型
        - noImplicitThis
          - 禁止类型不明确的this
        - strictBindCallApply
          - 严格检查bind、call和apply的参数列表
        - strictFunctionTypes
          - 严格检查函数的类型
        - strictNullChecks
          - 严格的空值检查
        - strictPropertyInitialization
          - 严格检查属性是否初始化
```
