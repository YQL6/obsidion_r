# 定位
![[图片/Pasted image 20260523232317.png]]
relative:<mark style="background: #FF5582A6;">相对自身定位</mark>
![[图片/Pasted image 20260523232257.png]]
```html
.c{  
    hight:100px;  
    position:relative;  
    background:blue;  
    top:10px;  
    right:20px;  
}top，right直接定义偏移位置
```
absolute<mark style="background: #FF5582A6;">:必须设置宽度，高度</mark>参照物为含有<mark style="background: #FF5582A6;">relative或absolute的父容器，最外面有body</mark>兜底，<mark style="background: #FF5582A6;">不占位</mark>
fixed：必须设置宽度，高度，参照物为浏览器页面，<mark style="background: #FF5582A6;">不占位</mark>
