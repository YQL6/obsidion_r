# css
css：Cascading（层叠，层层递进的） Style Sheet（表格）

# css选择器
选择器：
* 基本选择器：ID 》 类选择器 》 标签选择器
	* ID选择器
	* 类选择器
	* 标签选择器
* 层次选择器
# 选择器语法定义
```html
标签{
	样式
}
.类名{
	样式
}
#标签{
	样式
}
```
<mark style="background: #FF5582A6;">注：冲突看优先级，不冲突全都要</mark>
```html
<!DOCTYPE html>  
<html lang="en">  
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
    <style>        div{  
            color : red;  
        }  
        .content{  
            color:blue;  
        }  
        #a{  
            color:pink;  
        }  
    </style>  
</head>  
<body>  
<div id = 'a' class = 'content'>  
    这是一段文字  
    <input type = 'text' class = 'content'>  
</div>  
<div>  
    这也是一段文字  
</div>  
</body>  
</html>
```

# css样式
行内样式：
```html
<p style ="color: red">  
    666  
</p>
```
内部样式：
```html
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
    <style>        div{  
            color : red;  
        }  
        .content{  
            color:blue;  
        }  
        #a{  
            color:pink;  
        }  
    </style>  
</head>  
```
外部样式：
建立stylesheet来统一保存样式：
```html
div{  
    color : red;  
}  
.content{  
    color:blue;  
}  
#a{  
    color:pink;  
}
```
head在引入：
```html
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
   <link href="css/first.css" rel="stylesheet" type="text/css">  
</head>
```

```html
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
    <style>        @import url(css/first.css);  
    </style>  
  
</head>
```

# 高级选择器
后代选择器：
```html
div(第一级的基础选择器标签) ul(第二级，只要在第一级中即可哪怕之间隔着几个标签也可以){
	样式
}
```
字代选择器：
```html
div > ul > li{
	样式
}
```
