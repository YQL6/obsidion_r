# 间隔——gap
gap或margin都可以实现间隔

```html
<!DOCTYPE html>  
<html lang="en">  
<head>  
    <meta charset="UTF-8">  
    <title>Title</title>  
    <style>        
	    html,body{  
            height:100%;  
            width:100%;  
            padding:0;  
            margin:0;  
        }  
        .box{  
            display:flex;  
            flex-wrap:wrap;  
            flex-flow:row wrap;  
            justify-content:start;  
            height:100%;  
            align:stretch;  
        }  
        .f{  
            background-color:red;  
            height:200px;  
            width:20%;  
        }  
    </style>  
</head>  
<body>  
<div class="box">  
    <div class="f">1</div>  
    <div class="f">2</div>  
    <div class="f">3</div>  
    <div class="f">4</div>  
    <div class="f">5</div>  
    <div class="f">6</div>  
</div>  
</body>  
</html>
```
