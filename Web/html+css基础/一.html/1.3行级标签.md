# 特点
+ 其他元素都在一行上 
+ 高度，行高及外边距和内边距不可改变 
+ 宽度就是其内容的宽度，不可改变

# 超链接
```html
<a href="连接到什么网站",target="什么方式打开"> 链接显示名称 </a>
```
<a href="www.baidu.com",target="_blank"> 去百度 </a>
target:
+ _blank------新页面打开
+ _self-------当前页面打开
功能性链接：

# 输入标签
```html
<input type="类型" name="名称" value="值">
<input type="hidden" name="名称">隐藏域，一般无用，隐藏看不见
```

name:
	按name来收集处理数据，type="radio"或checkbox时可以用name作为分组，同一个name值为一个分组，radio中一个分组字可以选择一个
checked：
	刚开始默认选择的选项
button/sumbit:
	提交表单
value:
	有的类型不要输入，只需要选择，例如：radio，收集数据是name=value，后台根据value判断男女，text是直接将用户输入作为value
submit/button:
	自己不参加提交，只提供提交按钮

下拉框细节：
	可以作为表单内容提交，依赖两个属性：
		name——<select name="">键名，无name不会提交
		value——<option value+"">键值，若无value,则将显示值提交
只读与禁用细节：
1. 只读：输入表单类型的行级标签加文本框————input,textarea
2. 禁用：输入表单，文本框，下拉式文本框——input,textarea,select
