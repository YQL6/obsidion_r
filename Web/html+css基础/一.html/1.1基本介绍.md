# HTML
HTML ：Hyper Text Markup Language ， 超级文本标记语言 ， 运行在浏览器中，由浏览器执行，解析执行

基本结构：
```html
<!DOCTYPE html> //doc文档，type类型，html默认html5
<html>//html文档标签，一个html文档只有一对，文档定义只能在标签内部
	<head>//头部标签对，表示整个头部信息，文档的头部例如文档标题，使用的字符集编码等
		<meta  charset = "utf-8">//源数据的类型，utf-8可以是中文，对网页整体
		<title> 百度一下</title>
	</head>//缩放等也可以定义
	<body>//标签对，开放标签
	文档整体内容
	</body>//闭合标签
</html>
```
