更正：页面内容块——》独立内容快
操作导航常与页眉在一起
操作内容块的内容常为aside的其余部分

 ```html
 <!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>Grid布局示例</title>
    <style>
        *{
            margin:0;
            padding:0;
            box-sizing: border-box;
        }
        html,body{
            height:100%;
            width:100%;
        }
        header,footer{
            color:red;
            background-color:black;
            height:40px;
            line-height: 40px; /* 文字垂直居中 */
        }
        main{
            display:grid;
            grid-template-columns:200px calc(100% - 200px);
            height:calc(100% - 80px);
        }
        aside{
            color:blue;
        }
        section{
            display:grid;
            grid-template-rows: 40px 1fr;
            background-color: rebeccapurple;
        }
        nav{
            background-color: rebeccapurple;
        }
    </style>
</head>
<body>
    <header>页面头部</header>
    <main>
        <aside>侧边栏</aside>
        <section>
            <nav>操作导航</nav>
            <article>正文</article>
        </section>
    </main>
    <footer>底部</footer>
</body>
</html>
 ```
