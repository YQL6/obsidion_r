HTML标签：
1. 块级标签
2. 行级标签

# 块级
## 块级标签特征
*  a.总是在新行上开始
* b.高度，行高以及外边距和内边距都可控制
* c.宽度缺省是它的<mark style="background: #FF5582A6;">容器</mark>的100%
* d.可以容纳内联元素和其他块元素
![[Excalidraw/重构/html块级标签|html块级标签]]
<mark style="background: #FF5582A6;">注：高度——块的高度，行高——文本的间距</mark>

<h4>四级标题</h4>

<h5>五级标题</h5>

<h6>六级标题</h6>

# 有序列表项

```html
<ol>
<li>列表项</li>
<li>列表项</li>
<li>列表项</li>
</ol>
```

type可加在``<ol>``中，由1,A,I等
