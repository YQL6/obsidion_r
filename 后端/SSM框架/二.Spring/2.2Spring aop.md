## 1.3动态代理

---

- 动态代理：
  ![[Excalidraw/后端/SSM框架/二.Spring/2.2Spring aop/一.简单介绍/1.3动态代理/动态代理模拟|动态代理模拟]]
	- 代理分类：
	  ![[Excalidraw/后端/SSM框架/二.Spring/2.2Spring aop/一.简单介绍/1.3动态代理/代理类实现|代理类实现]]
		- `JDK原生代理`：在反射包下，需要被代理的目标类<mark style="background: #ADCCFFA6;">必须实现接口</mark>，必须有接口，才能<mark style="background: #BBFABBA6;">根据目标类的接口</mark>动态的<mark style="background: #CACFD9A6;">反射生成</mark>一个代理对象，代理类和目标类本质上都是实现了一个接口,最后的代理类和目标类没有关系，<mark style="background: #FFB86CA6;">所以要接口来接收代理类</mark>
		- `cglib代理`：已经融入`Spring包中`,通过继承目标类实现代理类，不需要目标类有接口

```java
//JDK动态类的大概底层实现

package com.atguigu.maven.DVK;

import com.atguigu.maven.Calculator;

import java.lang.reflect.InvocationHandler;
import java.lang.reflect.Method;
import java.lang.reflect.Proxy;

public class ProxyFactory {
    private Object target;
    public ProxyFactory(Object target) {
        this.target = target;
    }
    public Object createProxy() {
        ClassLoader classLoader = target.getClass().getClassLoader();
        Class<?>[] interfaces = target.getClass().getInterfaces();
        InvocationHandler invocationHandler = new InvocationHandler() {
            @Override
            /*
            *invoke:调用代理的方法都会在这里执行：非核心 + 核心
            *proxy：代理对象需要实现的方法
            ***/
            public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
                Object result = null;
                try {
                    System.out.println("proxy start");
                    result = method.invoke(target, args);
                    System.out.println("proxy end");
                } catch (Exception e) {
                    e.printStackTrace();
                    System.out.println("proxy exception");
                }
                return result;
            }
        };
        /*
        * 返回参数：
        * 1.classloader：类加载器，将传入的类的加载器取出
        * 2.interfaces：将传入的类的接口取出
        * 3.invcationHander：重写这个类，里面时实现方法
        * */
        return Proxy.newProxyInstance(classLoader,interfaces,invocationHandler);
    }
}

```

- 源码依然过于复杂——》<mark style="background: #FF5582A6;">不看，直接使用，使用aop框架写</mark>
- 使用场景——》解决干扰代码和核心代码的分离管理
	- `JDK`:<mark style="background: #FFF3A3A6;">需要接口接，不能使用目标类接</mark>
	- `cglib`：<mark style="background: #ADCCFFA6;">可以直接使用原类接</mark>

注：
1. `jdk代理`必须要有实现类的接口才能使用，**JDK 动态代理生成的代理对象，暴露出来的方法就是目标接口中声明的方法**。

# 二.AOP

## 2.1面向切面编程

- 面向对象编程/`OOP`:
	- 封装，继承，多态
	- 纵向的编程(继承使用/重写父类方法)——》纵向，针对对象是继承
- `面向切面编程/AOP`:
	- 对面向对象编程的补充主题仍是封装，继承，多态
	- 横向编程：本质就是将多个方法中的非核心代码进行提取为一个冗余方法，然后使用动态代理技术进行插入——》横向，针对的对象是方法
	- 将方法中的重复非核心代码<mark style="background: #FFF3A3A6;">提取</mark>成为一个方法，然后横向<mark style="background: #ADCCFFA6;">插入</mark>

## 2.2术语介绍

---

- AOP把软件相同分为两个部分：
	- 核心关注点:核心业务，程序的主体业务，正常使用，书写
	- 横切关注点:冗余代码，与核心业务无关，一些重复代码
- 增强(通知)：提取的代码
	- 前置通知：核心/目标方法之前执行<mark style="background: #FFB8EBA6;">(核心方法执行前执行)</mark>
	- 返回通知:核心/目标方法成功结束后执行<mark style="background: #ABF7F7A6;">(核心方法无报错后执行)</mark>
	- 异常通知:核心/目标方法异常结束后执行<mark style="background: #BBFABBA6;">(报错后执行)</mark>
	- 后置通知:核心/目标方法最终结束后执行<mark style="background: #BBFABBA6;">(核心方法执行完后一定要执行，无论是否报错)</mark>
	- 环绕通知：使用`try...catch...finally`
- 连接点：能被通知切入到方法中的方法
- 切入点：被切入的连接点
- 切面：切入点 + 通知
- 目标：被代理的目标对象
- 代理类：切入后形成的一个新类，返回这个类，使用接口来接
	- 核心方法
	- 增强方法
	- 转发给真实的类实现，自己<mark style="background: #FFB8EBA6;">仅转发</mark>
- 织入：切入增强方法的行为

## 3.2获取切点详细信息

---

- 增强方法获取目标方法信息：
	- 信息：
		- 方法信息：
			- 所有位置的增强都可以获取
			- 方法签名 = 方法名 + 参数列表（类型/个数/顺序）；修饰符，参数信息，所属方法的信息
			- 使用`JoinPoint做为参数，主动获取方法信息，反射`
		- 返回值：
			- 只有在返回增强才可以获取，只有此位置合理
			- 返回值
			- 使用`Object resutlt接收返回值  注解使用returning指定用什么参数接收`
		- 异常对象：
			- 异常增强中才可以获取
			- 异常对象
			- `使用Throwing e 接收异常值  注解使用throwing属性指定用什么参数接收`

```java
package com.atguigu.maven.Advice;

import org.aspectj.lang.JoinPoint;
import org.aspectj.lang.annotation.*;

@Aspect
public class MyAdvice {
    //以execution开头
    /*
    * 开头*不考虑返回值和修饰符
    * 类.方法.参数
    * */

    /*
    * 1.全部方法中获取目标方法信息(方法名，参数，访问修饰符，所属类的信息...)
    *   JoinPoint 参数主动获取接入点方法的信息
    * 2.返回值结果 ——》 @AfterReturning
    * 3.异常信息  ——》 @AfterThrowing
    *
    * */
    /*
    * 1.创建一个空方法，用来承载注解
    * 2.注解提取切点表达式
    * 3.引入方法——》方法名()相当于使用切点表达式,类外使用全类限定符.方法名
    * */
    @Pointcut("execution(public * com.atguigu.maven.Service.Impl.*.*(..))")
    public void pc(){}
    @Before("pc()")
    public void start(JoinPoint joinPoint){
        //1.获取方法所属类的信息
        String classes = joinPoint.getTarget().getClass().getSimpleName();
        //2.获取方法名
        String methodName = joinPoint.getSignature().getName();
        //3.获取参数列表
        Object[] args = joinPoint.getArgs();
        System.out.println("MyAdvice start");
        System.out.println(classes + "类" + methodName +  "方法已经开始");
    }
    /*
    * 获取返回结果
    * 1.形参接一个Object result,用它来接返回值
    * 2.在@AfterReturning中表明用什么形参变量来接返回结果，使用returning属性指定
    * */
    @AfterReturning(value = "execution(* com.atguigu.maven.Service.Impl.*.*(..))",returning="result")
    public void after_return(JoinPoint joinPoint,Object result){
        System.out.println("MyAdvice return");
        System.out.println("返回值为:" + result);
    }
    @After("execution(* com.atguigu.maven.Service.Impl.*.*(..))")
    public void after(JoinPoint joinPoint){
        System.out.println("MyAdvice after");
    }
    /*
    *获取异常值
    * 1.使用一个形参接异常
    * 2.注解中使用属性throwing指定用什么参数接收异常值
    * */
    @AfterThrowing(value = "execution(* com.atguigu.maven.Service.Impl.*.*(..))",throwing = "e")
    public void error(JoinPoint joinPoint,Throwable e){

        System.out.println("MyAdvice error");
    }
}


```

注：
1. <mark style="background: #FFF3A3A6;">注解中使用两个属性时，一定要指定属性名字，一个属性时可以默认一个属性，不指定</mark>

## 3.3切点表达式语法

---

- 切点表达式：
	- 作用：
		- 选中目标方法，通过字符串格式分析确定方法
		-   确定方法
			- 方法的类
			- 方法名
			- 方法的参数
			- 返回值和修饰符
	- 语法:`execution()`
		- `execution(public int com.atguigu.maven.Service.Impl.*.*(..))`
			- 访问修饰符 + 返回值：`public int`，若是所有都可以直接使用`*`表示
				- 访问修饰符任意:`int`,<mark style="background: #CACFD9A6;">访问修饰符省略默认任意</mark>
				- 返回值任意:`public *`
				- 两者都任意：`*`
				- 指定：都写
			- 类包:
				- 具体包：` com.atguigu.maven.Service.Impl`
				- 单层模糊:`com.atguigu.maven.*`，`maven`包下面所有的包
				- 多层模糊:`com..impl`,`com下面所有impl的包`,<mark style="background: #FFB8EBA6;">开头不能使用</mark>`..`
			- 接口/类:
				- 模糊:`*`,所有
				- 具体:`Classes`
				- 部分模糊:`*Impl`
			- 方法名:语法同类名一致
			- 形参列表：
				- 没有参数:`()`
				- 有具体参数:`(String,int)`，<mark style="background: #FF5582A6;">顺序有要求</mark>
				- 模糊参数:`(..)`
				- 部分模糊:`(String ..)`第一个参数是`String`

## 3.5环绕通知

---

- 环绕通知:<mark style="background: #BBFABBA6;">自定义位置</mark>
	- 步骤：
		1. 获取方法的属性对象`ProceedingJoinPoint`,<mark style="background: #FF5582A6;">此方法可以获得方法属性，也能执行方法</mark>
		2. 获取方法参数
		3. 在`try catch finally`中执行方法，对应位置配置增强操作
		4. 返回方法执行结果
		5. 配置注解：`组件 + 增强类`

```java
package com.atguigu.maven.Advice;

import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.springframework.core.annotation.Order;
import org.springframework.stereotype.Component;

@Component
@Aspect
/*
* 指定一个优先级的值，值越小，优先级越高，优先级越高的前置先执行，后置后执行
* 相当于排名
* */
@Order(1)
public class TxAroundAdvice {
    /*
    * 环绕通知，需要你在通知中，定义目标方法的执行和冗余代码的执行
    *
    * @Program 获得方法信息和执行方法的操作,此参数和之前的方法参数很像，只是比之前多了一个方法执行
    * @return  返回方法的返回类型
    * */
    @Around("com.atguigu.maven.Advice.MyAdvice.pc()")
    public Object transaction(ProceedingJoinPoint joinPoint) {
        /*
        * 使用方法：参数和方法
        * */
        Object[] args = joinPoint.getArgs();
        Object result = null;
        /*
        * 执行方法时会抛异常，一般只进行try，catch处理
        *若是不进行捕获异常而是抛出异常，则不能进行异常通知的处理
        * 在对应位置上写相应的增强处理
        * */
        try {
            System.out.println("事务开启");
            joinPoint.proceed(args);
        } catch (Throwable e) {
            System.out.println("事务异常，进行回滚");
            throw new RuntimeException(e);
        }finally{
            System.out.println("事务结束");
        }
        return result;
    }
}


```

注：
1. `proceed`是执行对象的核心代码，所有关于核心代码的操作都可以通过执行获得：`返回值和异常`

## 3.6切面优先级
