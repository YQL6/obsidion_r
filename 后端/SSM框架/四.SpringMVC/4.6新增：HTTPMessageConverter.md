# 一.简介

## 1.1引入

- `HTTPMessageConverter`:http信息转换器
	- 报文信息转换器
	- 实现功能
		- 信息封装：
			- `request`:请求信息 ——》`@RequestBody`
			- `response`：响应信息 ——》`@ResponseBody`
	- 报文信息/交互信息:`httpMessageConverter`本质：
		- 对接受值的`body/header`进行反序列化然后将值映射为`pojo`对象，直接映射到对应的变量中
		- 对返回值调用`@ResposeBody`(自动调用报文信息转化)进行序列化，写入响应体中

## 1.2配合使用

- 调用方法：
	- `@RequestBody`:
		- 将请求体变为实体对象
		- 接收：
			- `pojo`
			- `map`
	- `@ResponseBody`:将返回值反序列化为响应体
	- `RequestEntity<T>`:
		- 将请求
	- `ResponseEntity`

# 二.使用

## 2.1resquest

---

- `@RequestBody`:
	- 读取请求体变为实体类

- `RequestEntity`:
	- 本质：
		- 获得整个请求报文，里面存储所有信息，请求体/请求头/请求行
	- 泛形类：
		- 约定接收的请求报文信息的请求体转化为哪个实体类

```java
@PostMapping("/user")
public ResponseEntity<String> test(RequestEntity<User> reqEntity){
    // 请求行信息
    HttpMethod method = reqEntity.getMethod(); // POST
    URI uri = reqEntity.getUrl();              // /user

    // 请求头
    HttpHeaders headers = reqEntity.getHeaders();
    String token = headers.getFirst("token");

    // 请求体（底层和@RequestBody一模一样，走HttpMessageConverter）
    User user = reqEntity.getBody();

    return ResponseEntity.ok("ok");
}
```

注：
1. 一个方法只能获得一次请求信息，同理，获得请求体`@RequestBody`和获得请求信息`@RequestEntity`
