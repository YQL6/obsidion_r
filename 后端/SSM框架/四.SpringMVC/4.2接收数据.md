# 一.访问路径设置

## 1.1注册

---

- 通过注解注册路径地址：
```java
package com.atguigu.requestmapping;

import org.springframework.context.annotation.ComponentScan;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;

@ComponentScan
public class UserController {
    /*
    * 1.要想要处理器生效一定要是注册到mapping中
    *       方法1：使用注解@RequestMapping("/spring/login")
    *           webservlet注解是jsp的注解，要求必须/开头，但是这个注解比较宽限，可以不是/开头，可以不是精准的地址
    *           地址写法：
    *               1.精准地址：一个或多个 —— [一个/多个] , [地址1，地址2]
    *               2.模糊地址： *任意一层字符串 | **任意层任意字符串
    *           可以写在类上：类上的地址先匹配，匹配对的上才对方法匹配地址
    *                       类上提取通用地址，方法提供准确地址 类地址 + 方法地址 = 访问地址
    *           注意：即使是类上有注解，方法上的注解地址必须加
    *           请求方式指定：使用method参数指定,默认是全部都可以
    *               请求方式：http ——》 post,get.delete,put
    *               method = {requestMethod.GET,...}
    *               若是不满足对应的请求方式 ——》 报错405异常
    *       方法2：使用 @PostMapping("spring/logic")
    *           只适用于方法上，默认指定了对应的请求方式
    * */
    //将handler注册到handlermapping中
    @RequestMapping("spring/login")
    @PostMapping("spring/logic")
    public String login(){
        return "登录成功";
    }
}

```

# 二.接收参数

## 2.1param和json

---

- `param`:
	- `key = value & key = value`
	- 默认`ascii`编码，遇到空格会进行转义
	- 没有顺序，只是字符串，没有嵌套
	- 数值类型：字符串
	- 适合传递简单类型
- `json`:
	- `{key:value,key:value}`
	- 默认为`UTF-8`编码
	- 有格式，有顺序的，里面可以进行嵌套的，对象，数组等
	- 数值类型：字符串，布尔，数组，对象等
	- 本质：`json` ——》 `javascript object notation`的一种类型
	- 适合复杂类型 ， 必须使用`post`传递 ， 常用

## 2.2接收param

---

- 接收`param`:
	- 注解接收
	- 形参接收
	- 集合接收
	- 实体类接收（常用）

```java
package com.atguigu.requestmapping;

import com.atguigu.pojo.User;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.ResponseBody;

import java.util.List;

@Controller
@RequestMapping("param")
public class paramController {
    /*
    接收param的方式
    * 方式1：直接通过形参接收 ——》 通过适配器进行转换以后，直接接收
    但是只能接收参数名相同的可以接收
    * */
    //例如：前端传递过来  /param/data?name=root&age=18
    @RequestMapping("data")
    public String setupForm(String name,int age){
        if(name == null){
            name = null;
        }

        System.out.println("name" + name + " age" + age);
        return name + age;
    }

    /*
    方式2：注解传值
    * @RequestParam:
    * 第一个参数value：指定这个参数接收什么名字的参数的值，当形参和传递参数名一致，可以不写
    * 第二个参数required:是否必须传递，默认必须传递
    * 第三个参数defaultValue：没有这个参数，使用默认值,若是必须传递，报错400
    * */
    //示例： /param/data?account=root&page=1  ,要求account必须传递，不传递报错
    @RequestMapping("data02")
    public String data1(@RequestParam(value="account")String account ,
                        @RequestParam(required = false,defaultValue = "1") int page){
        System.out.println("account" + account);
        System.out.println("page" + page);
        return account + page;

    }
    /*
    * 方式3；一名多值
    * key=1&key=3
    * 必须使用注解指定，若是不使用注解，会默认将第一个参数对应的字符串赋值
    * 加了注解就会将对应的集合加入对应的参数中
    * */
    @GetMapping("data03")
    @ResponseBody
    //传递 /param/data03/list=1&list=2
    public List data03(@RequestParam List<String> list){
        System.out.println("list" + list);
        return list;
    }
    /*
    * 方式4：使用实体类接值  常用  —— 》 放入对应的实体类中 ——》 容易交给数据库中存储
    *
    * 实体类形参的参数名字必须和传递的参数名字相同，注解无法放到实体类中进行标记
    * */
    @GetMapping("data04")
    @ResponseBody
    public User data04(User user){
        System.out.println("user" + user);
        return user;

    }

}

```

## 2.3动态路径

---

- 使用动态路径指定参数
- 使用注解指定接收的参数是什么

```java
package com.atguigu.requestmapping;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.ResponseBody;

@Controller
@RequestMapping("path")
@ResponseBody
public class pathController {
    /*
    * 动态路径：/path/10001/100   10001是账号，100是密码
    * 使用{}指定动态路径位置，和使用什么参数接值
    * */
    @RequestMapping("{username}/{password}")
    //使用形参默认就是接收url的值，使用注解指定才可以接收
    public String path(@PathVariable(value="username") String username,@PathVariable(value = "password") String password){
        return null;
    }
}

```

## 2.4json

---

- 接收`json`
	- `json`本质就是一种`javascript`格式的类型
	- 使用实体类接收，默认使用`属性名`和`key`相同的接收
	- 使用注解表明这个参数接收请求体 ——》 `post`中的`json`，`json使用post传递`

```java
package com.atguigu.requestmapping;

import com.atguigu.pojo.Person;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseBody;

@Controller
@RequestMapping("json")
@ResponseBody
public class jsonController {
    @RequestMapping("data")
    //示例： data ——》 post : {name,age,gender}
    //使用注解@RequestBody表示这个接收请求体的参数
    /*
    * 响应内容会报错 ： 415不支持数据类型
    * handlerAdapter处理不了json
    * java原生的api只能支持处理路径参数和param参数，不支持json
    * json是前端格式
    * 解决问题：1.导入处理的依赖 2. 配置给handlerAdapterjson转换器
    * */
    public String data(@RequestBody Person person){
        System.out.println(person);
        return null;
    }
}

```

- 使用`@EnableWebMvc`注解
```java
package com.atguigu.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.EnableWebMvc;
import org.springframework.web.servlet.mvc.method.annotation.RequestMappingHandlerAdapter;
import org.springframework.web.servlet.mvc.method.annotation.RequestMappingHandlerMapping;

@Configuration
@EnableWebMvc//handlerAdapter配置json转换器
@ComponentScan("com.atguigu")
public class MvcConfig {
    @Bean
    public RequestMappingHandlerMapping requestMappingHandlerMapping() {
        return new RequestMappingHandlerMapping();
    }
    @Bean
    public RequestMappingHandlerAdapter handlerAdapter() {
        return new RequestMappingHandlerAdapter();
    }
}

```

- `@EnableWebMvc`:
	- 本质就是`xml中的<mvc:annotation-driven>`

- `<mvc:annotation-driven>`:
	- 对应一个类，里面进行了对`json`处理的添加和`RequestMappingHandlerMapping`和`ReuqestMappingHandlerApater`的创建
	- 就是将`json`处理放到了另外两个中

## 2.5请求头数据和cookie处理

---

- 接收`cookie`:
	- 直接使用标签指定一个形参接收对应名称的`cookie`

```java
package com.atguigu.requestmapping;

import jakarta.servlet.http.Cookie;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.CookieValue;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseBody;

@Controller
@RequestMapping("cookie")
@ResponseBody
public class cookieController {
    /*
    * 使用标签@CookieValue指定接收对应名称的cookie
      cookie再请求头中携带
    * */
    @RequestMapping("data01")
    public String data01(@CookieValue(value="cookieName") String value){
        System.out.println(value);
        return "data01";
    }

    @GetMapping("save")
    public String save(HttpServletResponse response ){
        /*
        * 先使用responxe存入一个cookie
        * 一个cookie只能存入一对值，但是一个网页可以有多个cookie
        * */
        response.addCookie(new Cookie("cookieName", "cookieValue"));

        return "save";
    }
}

```

- 接收请求头数据
	- 使用标签指定获得请求头，指定其中请求头中的什么`key`的内容

```java
package com.atguigu.requestmapping;
```

## 2.7共享域

---

- 共享域：
	- 数据传递的手段：
		- `servlet`进行跳转到另一个模板页面或`servlet`
			- 重定向:
				- 无法保存`request`数据，重新发送`request`
				- 可以将`request`数据存放到一个共享空间
			- 转发
			- `include`
	- 共享空间范围：
		- `request`:
			- 一次请求加响应
		- `session`：
			- 一次会话 ——》 多个请求
		- `servletContest`：
			- 整个项目
	- 操作方法：
		- 设置操作：`setAttribute(key,object value)`
		- 获得操作：`get....`
		- 更新操作：`set...` ——》连续两次对同一个`key`操作，新的覆盖旧的

```java
package com.atguigu.requestmapping;

import jakarta.servlet.ServletContext;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.servlet.http.HttpSession;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseBody;

@Controller
@ResponseBody
@RequestMapping("Share")
public class ShareController {
    //方案2：使用注入方式获得共享域
    @RequestMapping("data01")

    public String data01(HttpServletRequest request, HttpServletResponse response,
                         HttpSession session) {
        //方法1：使用原生api进行对共享域操作
        request.setAttribute("42",12);
        session.setAttribute("42",12);
        ServletContext servletContext = request.getServletContext();
        servletContext.setAttribute("42",12);
        return "data01";
    }
    /*
    * springmvc提供使用request共享域的方法：
    * 1.再形参列表中加一个形参Model类型
    * 2.形参列表中ModelMap类型
    * 3.形参列表中写Map类型
    * 4.形参列表中写modelAndView
    * */
}
```
