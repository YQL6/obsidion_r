## 1.2快速返回视图

----

- 配置视图解析器：
	- 标签已经包括配置视图解析器了
- 将配置类实现`WebMvcConfigurer`:
	- 其中可以重写方法来做为一些组件配置
	- 重写方法`configureViewResolvers`可以实现视图解析器的配置
- 使用控制器来返回字符串使用视图解析器：
	- 若是带有`@ResponseBaby`:
		- 将返回结果直接放入响应的响应体中
		- 若是不用将放回结果放到视图解析器中拼接字符，然后查找资源，返回资源
	- 返回的字符串是资源的名称：具体看拼接规则的制定

- 配置类:
```java
package com.atguigu.config;

import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;
import org.springframework.stereotype.Controller;
import org.springframework.web.servlet.config.annotation.EnableWebMvc;
import org.springframework.web.servlet.config.annotation.ViewResolverRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
@EnableWebMvc
@ComponentScan("com.atguigu")
/*
* 实现这个WebMvcConfigurer类，通过重写这个方法可以进行对视图解析器等部件进行配置
* */
public class MvcConfig implements WebMvcConfigurer {

    /*
    * 从写configureViewResolvers这个方法，来配置视图解析器
    * @EnableWebMvc实现了springmvc的几大核心部件：包括适配器，mapping，视图解析器
    * 视图解析器主要用来拼接资源的具体位置，进行获得资源
    * */
    @Override
    public void configureViewResolvers(ViewResolverRegistry registry) {
        //registry可以快速添加前后缀,controller直接使用字符串查找即可
        registry.jsp("/WEB-INF/views/", ".jsp");
    }

}

```
- 使用视图解析器：
```java
package com.atguigu.Controller;

import jakarta.servlet.http.HttpServletRequest;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;

@Controller
@RequestMapping("jsp")
public class JspController {
    @GetMapping("index")
    public String index(HttpServletRequest request) {
        //返回对应资源字符串即可
        /*
        快速查找
        * 1.方法的返回值时字符串类型
        2.不能添加@ResqponseBody,直接返回字符串给浏览器，不着视图，不走视图解析器
            @ResponseBody : 直接将返回值做为response body返回前端，不将它发给视图解析器
        3.返回值，对应视图中的视图名称即可，对应视图解析的拼接格式
        * */
        request.setAttribute("data","hello world");
        System.out.println(request.getAttribute("data"));
        return "index";
    }
}

```

## 1.3转发和重定向

---

- 使用返回结果中指定转发的对应的控制器
	- 重定向：
		- 使用`redirect`放在控制器路径前
			- api写法:指定具体路径
				- 项目内部：
					- 加上虚拟路径
				- 项目外部：
					- 从协议开始写
			- `springmvc`:
				- 项目内部：
					- 直接就是控制器路径，不需要写虚拟路径，视图解析器自动优化补上
				- 项目外部：
					- 从协议开始写
	- 转发：
		- 使用`forward`放在控制器路径前
		- <mark style="background: #FFB86CA6;">转发是将转发的地址交给tomcat来重新匹配，可能进入springmvc可能进入别的servlet</mark>

```java
package com.atguigu.Controller;

import jakarta.servlet.http.HttpServletRequest;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;

@Controller
@RequestMapping("jsp")
public class JspController {
    @GetMapping("index")
    public String index(HttpServletRequest request) {
        //返回对应资源字符串即可
        /*
        快速查找
        * 1.方法的返回值时字符串类型
        2.不能添加@ResqponseBody,直接返回字符串给浏览器，不着视图，不走视图解析器
            @ResponseBody : 直接将返回值做为response body返回前端，不将它发给视图解析器
        3.返回值，对应视图中的视图名称即可，对应视图解析的拼接格式
        * */
        request.setAttribute("data","hello world");
        System.out.println(request.getAttribute("data"));
        return "index";
    }
    /*
    * 转发：
    * 1.使用返回只写成字符串
    * 2.字符串表名forword：/转发地址
    * 3.不使用Response
    * */
    @GetMapping("forward")
    public String forward(HttpServletRequest request) {

        return "forward:/jsp/index";
    }
    /*
    * 重定向：
    * 1.方法返回值写成一个字符串类型
    * 2.不能添加responsebody展示
    * 3.返回字符串前面添加redirect:/重定向地址
    * */
    @GetMapping("redirect")
    public String redirect(HttpServletRequest request) {
        return "redirect:/jsp/index";
    }
    /*
    * 路径细节：
    *   转发是项目下的资源跳转，路径：项目下的地址 忽略虚拟地址
    *   重定向可以是项目下的资源可以是项目外的资源 ， 需要指定虚拟地址
    * 若是使用springmvc内部提供的视图解析器，可以不用考虑虚拟地址问题，重定向会自动添加
    *   springmvc指定重定向，若是项目外的地址怎么办，不想自动添加虚拟路径，直接写一个全的从协议开始写，就不会自动添加
    * */
    @GetMapping("redirect/baidu")
    public String redirectbaidu(HttpServletRequest request) {
        return "redirect:http://www.baidu.com";
    }
}

```

## 2.2json数据返回

---

- 导入依赖`jackon`
- 配置注解`@EnableWebMvc`
- `handler方法上返回对应的实体类对象即可`,再对应的`handler`上加`ResponseBody`注解(可以添加到类或方法上)，直接放到响应体即可，不走视图解析器
- 若是类上同时要添加`@Controller和@ResponseBody`可以合成一个`@RestController`

```java
package com.atguigu.config;

import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;
import org.springframework.stereotype.Controller;
import org.springframework.web.servlet.config.annotation.EnableWebMvc;
import org.springframework.web.servlet.config.annotation.ViewResolverRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
@EnableWebMvc
@ComponentScan("com.atguigu")
/*
* 实现这个WebMvcConfigurer类，通过重写这个方法可以进行对视图解析器等部件进行配置
* */
public class MvcConfig implements WebMvcConfigurer {

    /*
    * 从写configureViewResolvers这个方法，来配置视图解析器
    * @EnableWebMvc实现了springmvc的几大核心部件：包括适配器，mapping，视图解析器
    * 视图解析器主要用来拼接资源的具体位置，进行获得资源
    * */
    @Override
    public void configureViewResolvers(ViewResolverRegistry registry) {
        //registry可以快速添加前后缀,controller直接使用字符串查找即可
        registry.jsp("/WEB-INF/views/", ".jsp");
    }

}

```

- 返回`json`
```java
package com.atguigu.Controller;

import com.atguigu.pojo.User;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseBody;

import java.util.ArrayList;
import java.util.List;

@Controller
@RequestMapping("Json")
public class JsonController {
    @ResponseBody
    @RequestMapping("user")
    /*
    * 使用对象返回：
    *   类对象：json ——》 {}
    *   数组对象：json ——》 []，把数组当成一个对象来传递，json中也有对应数组类型
    * */
    public User data(){
        User user = new User();
        user.setAge(1);
        user.setName("小明");
        return user;
    }
    @ResponseBody
    @RequestMapping("users")
    public List<User> data02(){
        List<User> users = new ArrayList<User>();User user = new User();
        user.setAge(1);
        user.setName("小明");
        User user2 = new User();
        user.setAge(2);
        user.setName("小红");
        users.add(user);
        users.add(user2);
        return users;
    }
}

```

注：
1. 传入`json`数据使用`@ResquestBody`接收数据
2. 返回`json`数据使用`@ResponseBody`返回实体类，有适配器直接返回`json`数据

## 2.3返回静态资源处理

---

- 静态资源：
	- 类型
		- 纯`html`
		- 图片
	- 放置位置：
		- `webapp下面，可以创建文件夹，若是web-inf不可以，只能是控制器转发到这个位置`
	- 使用：
		- 直接路径访问：包括`webapp`,这个是根路径
		- 查找：
			- 使用`webMvvcConfigurer`中的方法`configureDefaultSservletHanding`指定是否允许查找静态资源
				- 不允许：
					- 直接通过`mapping`对应路径查找，若是没有对应的路径，报错`404`
				- 允许
					- 查找没有对应`handler`时去找静态资源
					  ![[Excalidraw/后端/SSM框架/四.SpringMVC/4.3响应数据/二.数据返回/2.3返回静态资源处理/静态资源流程|静态资源流程]]

```java
package com.atguigu.config;

import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;
import org.springframework.stereotype.Controller;
import org.springframework.web.servlet.config.annotation.DefaultServletHandlerConfigurer;
import org.springframework.web.servlet.config.annotation.EnableWebMvc;
import org.springframework.web.servlet.config.annotation.ViewResolverRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
@EnableWebMvc
@ComponentScan("com.atguigu")
/*
* 实现这个WebMvcConfigurer类，通过重写这个方法可以进行对视图解析器等部件进行配置
* */
public class MvcConfig implements WebMvcConfigurer {

    /*
    * 从写configureViewResolvers这个方法，来配置视图解析器
    * @EnableWebMvc实现了springmvc的几大核心部件：包括适配器，mapping，视图解析器
    * 视图解析器主要用来拼接资源的具体位置，进行获得资源
    * */
    @Override
    public void configureViewResolvers(ViewResolverRegistry registry) {
        //registry可以快速添加前后缀,controller直接使用字符串查找即可
        registry.jsp("/WEB-INF/views/", ".jsp");
    }
    /*
    * 通过WebMvcConfigurer的方法重写进行允许静态资源的访问
    * */
    @Override
    public void configureDefaultServletHandling(DefaultServletHandlerConfigurer configurer) {
        configurer.enable();
    }

}

```

- 本质：
	- 相当于就是`<mvc:defalut-servlet-handler/>`
		- 所有的以`mvc开头的都是以http\://www.springframework.org/schema/mvc=org.springframework.web.servlet.config.MvcNamespaceHandler这个类进行解析的`
		- 整个`ioc`容器家里一个处理器，每个请求都走整个处理器，内部进行了一个转发，转发到静态资源
