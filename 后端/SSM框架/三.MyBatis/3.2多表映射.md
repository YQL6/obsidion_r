# 一.简介

## 1.1引入

---

- 多表查询 ——》 多个实体关联的查询：
	- 自定义`sql语句`
		- `mybatis`:
			- 进行调用`ibatis`
			- 包装为代理对象
	- 指定查询返回结果:
		- `mybatis`:
			- 进行结果集映射后返回结果集映射
			- 执行`sql语句`
	- 设计多表查询结果数据存储的实体类 ——》 承接多个表的查询结果
		- 实体类中可能承载另一个表格的实体
		- 示例：
			- `Product`表格
				- `productName`
				- `Category表格的外键`:
					- `Cid`
					- ....
	- 自己写多表查询的映射关系：
		- 多层次的映射关系

## 1.2实体类的设计

---

- 表间的关系(关系是双向的)：
	- 一对一:
		- 一方：一对一
		- 另一方：一对一
	- 一对多：
		- 一方：一对多
		- 另一方：一对一
	- 多对多：
		- 一方：一对多
		- 另一方：一对多

- 实体类设计(仅看一方的关系):都是从一方来看的
	- 示例：
		- 客户和订单：
			- 客户：对于订单，是一对多的关系
			- 订单：对于客户，是一对一的关系
		- 表间的关系是看两方，但是<mark style="background: #FFF3A3A6;">设计实体类是看一方</mark>
		- 从订单来看：
			- 查询订单和订单对应的客户（一对一）
				- 返回订单实体
				- 客户实体放到订单实体中 —— 》 <mark style="background: #FFF3A3A6;">内部类</mark>
			- 查询客户和客户的订单（一对多）
				- 返回客户实体类
				- 订单的实体类装到一个集合中，放到客户实体类中
	- 只有真实<mark style="background: #ABF7F7A6;">发生多表查询时才考虑设计/修改实体类</mark>，否则<mark style="background: #ABF7F7A6;">不提前设计</mark>
	- 无论多少表联查，都是两个表两个表之间进行查询
	- 查询映射时，只对查询的相关属性进行赋值，不要关注以外的属性，否则容易死循环
		- 示例：
			- 订单表中有客户
			- 客户中订单集合
			- 查询订单和客户时，就不要关注客户中的订单，置空

# 二.多表映射

## 2.1对1多表查询

---

- 使用`association`标签来为内层赋值

- 实体类设计：
```java
package com.atguigu.MyBaits.pojo;  
  
import java.util.List;  
  
public class Customer {  
  
    private int customerId;  
    private String customerName;  
    private List<Order> orders;  
  
    @Override  
    public String toString() {  
        return "Customer{" +  
                "customerId=" + customerId +  
                ", customerName='" + customerName + '\'' +  
                ", orders=" + orders +  
                '}';  
    }  
  
    public String getCustomerName() {  
        return customerName;  
    }  
  
    public void setCustomerName(String customerName) {  
        this.customerName = customerName;  
    }  
  
    public int getCustomerId() {  
        return customerId;  
    }  
  
    public void setCustomerId(int customerId) {  
        this.customerId = customerId;  
    }  
  
    public List<Order> getOrders() {  
        return orders;  
    }  
  
    public void setOrders(List<Order> orders) {  
        this.orders = orders;  
    }  
}
```

- 映射配置
```xml
<?xml version="1.0" encoding="UTF-8"?>  
<!DOCTYPE mapper  
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"  
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">  
<mapper namespace="com.atguigu.MyBaits.mapper.OrderMapper">  
    <resultMap id="order_map" type="com.atguigu.MyBaits.pojo.Order">  
        <!--第一层属性的主键标签-->  
        <id column="order_id" property="orderId"></id>  
        <!--普通属性-->  
        <result column="order_name" property="orderName"></result>  
        <result column="customer_id" property="customerId"></result>  
        <!--内层属性-->  
        <!--内层是一个对象，为对象赋值  
                property:对象中内层对象的名字  
                javaType：内层对象的类型  
                    全限定符                    别名        -->  
        <!--可以继续为其赋值-->  
        <association property="customer" javaType="com.atguigu.MyBaits.pojo.Customer">  
            <id column="customer_id" property="customerId"></id>  
            <result column="customer_name" property="customerName"></result>  
        </association>    
    </resultMap>    
    <!--若是使用resultType则只能拿着表的字段名字去映射，内层表无法映射-->  
    <select id="queryById" resultMap="order_map">  
        select * from t_order as o join t_customer as c  
        on o.customer_id = c.customer_id  
        where o.order_id = #{id};  
    </select>  
  
</mapper>
```

- 映射配置:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.atguigu.MyBaits.mapper.CustomerMapper">
    <!--返回的应该是一个集合，但是只用写泛形，是集合还是返回一个实体类由接口返回类型决定-->
    <!--
        一对多不可以使用这个
        映射的本质：
            通过id识别那几行是一个数据，是一个实体类可以保存的
                每层都区分依次
                id可以是复合组
        若是使用这个：
            将外层识别为一个实体类
            内层又按其的id又识别一遍，然后分出3个实体类，进行映射
            这样一个类被多次赋值
    -->

    <resultMap id="customer_map" type="com.atguigu.MyBaits.pojo.Customer">
        <id column="customer_id" property="customerId"></id>
        <result column="customer_name" property="customerName"></result>
        <!--特殊为集合赋值
            property:属性名
            ofType:泛形
            -->
        <collection property="orders"ofType="com.atguigu.MyBaits.pojo.Order">
            <id column="order_id" property="orderId"></id>
            <result column="order_name" property="orderName"></result>
            <result column="customer_id" property="customerId"></result>
            <!--可以为其中的对象赋值，但是此次查询不相关,不适用-->
<!--            <association property="customer" javaType="com.atguigu.MyBaits.pojo.Customer"></association>-->
        </collection>
    </resultMap>
    <select id="queryById" resultMap="customer_map">
        select * from t_customer c join t_order o
        on c.customer_id = o.customer_id
        where c.customer_id = #{id};
    </select>

</mapper>
```

## 2.4优化多表查询

---

- 打开驼峰式
- 打开`autoMappingBehavior `:
	- 属性：
		- `none`:不映射
		- **`PARTIAL`**（默认值）:单层映射
		- `full`:深层映射
	- 默认情况下`resultMap`会自动映射一层的`resutlmap`标签，若是有`association/collection`则想要开到`full`
- 映射规则：
	- 属性名一样
	- 大小写忽略后相同
	- 驼峰式转换

- 配置文件配置：
```xml
  <!--打标签位置固定，一定不能更改顺序，具体顺序看官方文档-->

    <!-- 全局设置 -->
    <!--mybatis具体设置，具体功能-->
    <settings>
        <!-- 开启下划线到驼峰命名自动映射 -->
        <setting name="mapUnderscoreToCamelCase" value="true"/>
        <setting name="autoMappingBehavior" value="FULL"/>

        <!-- 控制台打印 SQL 日志 -->
        <!--日志系统可以通过value更改-->
        <setting name="logImpl" value="STDOUT_LOGGING"/>
    </settings>
```

- 映射文件配置：
```xml
    <!--开启自动映射以后可以不写一些普通属性，但是id和assosiation和collection必须写指定-->
    <resultMap id="customer_map" type="com.atguigu.MyBaits.pojo.Customer">
        <id column="customer_id" property="customerId"></id>
        <collection property="orders" ofType="com.atguigu.MyBaits.pojo.Order">
            <id column="order_id" property="orderId"></id>
        </collection>
    </resultMap>
    <select id="queryById" resultMap="customer_map">
        select * from t_customer c join t_order o
        on c.customer_id = o.customer_id
        where c.customer_id = #{id};
    </select>
```
