# 一.整合理解

## 1.1不同角度

---

- 应用角度/微观：
	- 将`spring springmvc mabtis`框架应用到项目中
		- `spring`:
			- 负责整体和业务层的声明式事务管理
		- `springmvc`：
			- 负责控制层
		- `mybatsis`：
			- 负责持久层数据访问
- 宏观：
	- 使用`spring接管一切，将框架核心组件交给spring进行ioc管理`
		- `spring`:
			- 管理业务层，持久层以及数据库相关的组件
			- 使用`ioc`管理一切所需的组件
		- `springmvc`：
			- 管理表述层，`springmvc`相关的组件
		- `mybatis`：
			- 使用`xml`进行配置`sql`语句
- 实施：
	- 使用写配置文件，实现`SpringIoc容器`接管一切组件

# 二.核心理解

## 2.1核心五问

----

- 第一问：`SSM框架整合想要几个IOC容器`
	- 二个，一个容器就够了，但是实际通常使用两个
		- `Web容器`:
			- 装`web容器`
		- `root容器`
			- 业务层和持久层
	- 在`springmvc`中使用一个类来实现`AbstractAnnotationConfigDispatcherServletInitializer`,然后通过方法传入两个容器
		- 父子容器:
			-  `root`容器 ——》 父容器
			- `web容器` ——》子容器
		- 父容器可以注入子容器，子容器不能注入父容器 ——》 父容器不能使用子容器的`bean`
	- 优点：
		- 两个容器关注点不同
		- 解耦合
		- 灵活配置
- 第二问：两个容器分别装声明组件
	- `Web`:
		- 所有`springmvc`相关的组件
			- `contoller`
			- `handlerMappin`
			- `handlerAdapater`
			- 静态资源处理
			- 拦截器等
	- `root`
		- `service + dao`
			- `service`:
				- `AOP`
				- `TX`
				- `service`
			- `dao`
				- `datasource`
				- `Mapper`
				- ....
- 第三问：两个容器间的关系
  ![[Excalidraw/后端/SSM框架/五.SSM框架练习/5.1整合理解/二.核心理解/2.1核心五问/父子容器|父子容器]]
	- 若是没有关系：
		- 两个容器的组件不互通
	- 若是父子容器关系：
		- 父子容器：
			- `root`父容器
			- `web`子容器
		- 父容器不能调用子容器，子容器能调用父容器
- 第四问：需要几个配置类
	- 至少两个：
		- 两个容器至少对应一个
	- 简单对应，三个：
		- 一个层一个配置类，将服务层和持久层的配置类放到`root`层
- 第五问：两个容器怎么对应到配置类上
	- `AbstractAnnotationConfigDispatcherServletInitializer`的具体实现方法提供了配置类的指定

package com.atguigu.config;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.*;
import org.springframework.jdbc.core.JdbcTemplate;

import org.springframework.jdbc.datasource.DriverManagerDataSource;

import org.springframework.transaction.annotation.EnableTransactionManagement;

import javax.sql.DataSource;


/*
* 1.配置类
* 2.扫描范围
* 3.开启AOP支持@EnableAspectJAutoProxy ，AOP类上注解对应的内容@Acspt
* 4.开启事务注解支持：1.对应的事务管理器实现传入ioc容器 2.开启事务支持@EnableTransactionManagement
*
* */
@Configuration
@ComponentScan("com.atguigu.service")
@EnableAspectJAutoProxy
@EnableTransactionManagement
@PropertySource("jdbc.properties")
public class ServiceJavaConfig {
    @Bean
    public DataSource dataSource(@Value("${username}") String user ,@Value("${password}") String password,
                                 @Value("${url}") String url,@Value("${driverClassName}") String driver) {
        DriverManagerDataSource dataSource = new DriverManagerDataSource();
        dataSource.setDriverClassName(driver);
        dataSource.setUrl(url);
        dataSource.setUsername(user);
        dataSource.setPassword(password);
        return dataSource;
    }
    @Bean
    public JdbcTemplate jdbcTemplate(DataSource dataSource) {
        return new JdbcTemplate(dataSource);
    }
    /*
    * 配置对应的事务处理源
    * */
    @Bean
    public PlatformTransactionManager transactionManager(DataSource dataSource) {
        return new DataSourceTransactionManager(dataSource);
    }
}

## 3.4持久层

---

- 使用流程：
	- `sqlSessionFactoryBuilder`：
		- 为了实例化`SqlSessionFactory`,无需`IOC`容器，`IOC`容器使用是为了使用重复使用
	- `SqlSessionFactory`
		- 可能重复获取，需要`IOC`容器
	- `SqlSession`
		- 通过代理对象来使用，同时可以通过`SqlsessionFactory`实例化，过程内容不加入`IOC`容器
	- `Mapper代理对象`调用接口方法
		- 从作用域中来将不应该加入`IOC`容器中
		- 从实际开发中，业务开发需要进行注入`IOC`容器，方便后续方法的调用

- 创建`SqlSessionFactory`的方法：
	- `使用一个@Bean自己声明创建过程`
	- 使用`factory`提供的框架创建

- `spring的注解 和 mybatis的factory冲突 不可以放到一起 ，顺序上mybatis更快，但是数据源在spirng中，所以冲突`
- 解决方法：
	- 将两者分开为两个配置类

- `spirng的注解创建dataSource`
```java
package com.atguigu.config;

import org.apache.ibatis.session.SqlSessionFactory;
import org.mybatis.spring.SqlSessionFactoryBean;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.PropertySource;
import org.springframework.core.io.ClassPathResource;
import org.springframework.core.io.Resource;
import org.springframework.jdbc.datasource.DriverManagerDataSource;

import javax.sql.DataSource;

@PropertySource("classpath:jdbc.properties")
public class DataSourceJavaConfig {
    @Value("${driverClassName}")
    private String driverClassName;
    @Value("${url}")
    private String url;
    @Value("${username}")
    private String username;
    @Value("${password}")
    private String password;
    @Bean
    public DataSource dataSource() {
        DriverManagerDataSource dataSource = new DriverManagerDataSource();
        dataSource.setDriverClassName(driverClassName);
        dataSource.setUrl(url);
        dataSource.setUsername(username);
        dataSource.setPassword(password);
        return dataSource;
    }

    //将sqlsessionfactory加入到ioc容器
    //mybatis提供一个sqlSessionfactoryBean，该方法的getobject方法进行创建
    //只需要将sqlSessionFactory配置到ioc即可
    //方法1：外部指定mybatis-config.xml[配置mybatis的配置，除了连接池和mapper指定]
    @Bean
    public SqlSessionFactory sqlSessionFactory(DataSource dataSource) throws Exception {
        //创建对应的SqlSessionFactory的对象
        SqlSessionFactoryBean sqlSessionFactoryBean = new SqlSessionFactoryBean();
        //为对象的连接池指定对象，指定配置文件
        sqlSessionFactoryBean.setDataSource(dataSource);
        //指定配置文件
        //引入来源接口,创建路路径下的io
        Resource resource = new ClassPathResource("mybatis-config.xml");
        sqlSessionFactoryBean.setConfigLocation(resource);
        //调用对应工厂的getObject方法
        return sqlSessionFactoryBean.getObject();
    }
}

```

        dataSource.setUrl(url);

        dataSource.setPassword(password);

    //只需要将sqlSessionFactory配置到ioc即可
