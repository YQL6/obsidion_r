# 一.概述

## 1.1引入

---

- 读取数据的解决方案 ——》 `java的IO流`

- 示例：游戏数据运行时数据都是一个一个数据组成存放到内存中，一旦断电或结束就无法保存重现 ——》 使用`IO流将数据存放到磁盘中`

- 存储数据
	- 存储数据的磁盘文件的路径
	- 如何读取/写入

## 1.2表示文件位置

---

- `File`:表示文件位置，可以查看文件的状态

- `IO流`:对文件内容读取/写入
- 读写参照：程序/内存(程序运行在内存中)

## 1.3分类

---

- 流的方向：
	- 输入流
	- 输出流

- 操作文件类型：
	- 字节流：可以操作所有类型的文件
		- 操作对象：图片，音频，文本等
		- 本质：<mark style="background: #FFB86CA6;">操作二进制数据</mark>
	- 字符流：文本类型文件
		- 操作对象：纯文本文件 ——》 能使用电脑记事本打开能看懂的文件
			- 示例：
				- `text`能总结打开读懂
				- `docx`与使用`word`文件打开情况不同
				- `md`可以总结读懂
				- `xlsx`与实际`Excel`使用打开的文件不同，甚至数据都不同

# 二.IO流体系结构

## 2.1基本方法

---

- 字节流：
	- `InputStream`:字节输入流
		- 实现：
			- `FileInputStream`:
				- 操作本地文件的输入流
				- 命名方式：操作对象 + 字节流
	- `OutputStream`:字节输出流
		- 实现：
			- `FileOutputStream`
				- 操作本地文件的输出流
				- 命名方式：操作对象 + 字节流
- 字符流：
	- `Reader`:字符输入流
	- `Writer`:字符输出流
- <mark style="background: #FFF3A3A6;">以上都是抽象类，要具体实现重写</mark>

- 数据传递流程：

	- 创建对象：
		- 参数表示一个具体的路径
			- `file`:表示一个具体文件的对象
			- 字符串表示一个路径
				- 相对路径：基于本项目的根路径
				- 绝对路径：带盘符

		- 写入数据的方式：
			- 文件为空文件：直接写入
			- 文件为非空文件：清空
	- 写入数据：
		- 例如：使用字节流写入

	- 释放资源：
		- 占用资源：
			- `此线程对资源进行占用，其他程序无法进行占用此资源`

## 2.2FileOutputStream使用

----

- `fileOutputStream`
	- 输出数据，调用方法`write`
		- 参数：
			- 整数：只取低字节使用
			- 字节数组
			- 字节数组 + 指定开始与一共输出的数量，左闭右开
		- 默认清空原文件:每次建立的连接都是默认覆盖

```java
 public static void main(String[] args) throws IOException {

        byte[] b = {12,34,21,32,12};
        FileOutputStream fos = new FileOutputStream("E:\\process\\IO_test\\IO_test01.txt");
        //从0开始到1
        fos.write(b,0,2);
        fos.close();
    }
```

- 问题：
	- 如何换行写
		- 使用换行符，翻译时进行换行
	- 如何续写
		- 打开续写开关，在构造器中传入字符串后跟着传入`true`即可

```java
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        byte[] b;
        FileOutputStream fos = new FileOutputStream("E:\\process\\IO_test\\IO_test01.txt",true);
        //传入xuexi,不会一个一个字符输入，而是通过字符串转换为数组输入
        b = "xuexi".getBytes();
        fos.write(b);
        //换行写 ——》写一个回车就行
        /*
        * 回车和换行是两个动作
        * 回车：将光标放到第一列 \r
        * 换行：将光标放到下一行 \n
        * linux: \n
        * mac : \r
        * windows:对此行为进行了优化，虽然完整的是\r\n，只写一个也可以，底层会进行补全
        * */
        String wrap = "\r\n";
        byte[] wrapBytes = wrap.getBytes();
        fos.write(wrapBytes);

        //若是想要换行写java字节加在后面
        b = "java".getBytes();
        fos.write(b);
        fos.close();
    }
}

```

## 2.3FileInputStream使用方法

- 使用流程：
	- 建立对象
	- 使用方法读取数据
	- 释放资源

- `FileInputStream`:
	- 调用方法读取`read`
		- 返回值：
			- `int`类型，只能读取一个字节的数据放到变量中
			- 可以对返回值强转为字符，输出
			- 细节：<mark style="background: #BBFABBA6;">若是没有数据了还取 ——》 返回`-1`</mark>
		- 多次取：
			- 循环取
	- 细节：
		- 与输出流不同，没有文件不会报错
			- 输出流要写数据，没有文件，若是有父级，创建，若是没有，一定要报错
			- 输入流要读取数据，无文件一定没有数据 ——》 设计为一定报错
		- 读取数据
			- 数据读取时按字节读取，不考虑是否一起表示一个字符(中文)
			- 若是没有数据了，返回`-1`
				- 若是文件中有一个`-1` ——》 本质上就是对多个字节进行转换为`-1`这个字符

```java
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        FileInputStream fos = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");

        //返回整数类型数据
        int b = fos.read();
        System.out.println(b);

        fos.close();
    }
}

```

- 循环读取所有的数据
```java
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        FileInputStream fos = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");
        int b;
        while((b = fos.read()) != -1){
            System.out.print((char)b);
        }
        fos.close();
    }
}

```

- `read`本质：
	- 读取字节，然后向后移动指针指向下一个字节，若是没有返回`-1`

## 2.4文件拷贝

---

- 通过字节流进行拷贝文件内容

```java
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        FileInputStream fis = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");
        FileOutputStream fos = new FileOutputStream("E:\\process\\IO_test\\IO_copy_test01.txt");
        int b;
        while((b = fis.read()) != -1){
            fos.write(b);
        }
        //先开的后关
        fos.close();
        fis.close();
    }
}

```

- 可以拷贝计较小的文件，拷贝大文件时非常慢，<mark style="background: #FFF3A3A6;">一次只能执行一个字节的拷贝</mark>，而且数据源和目的地都是<mark style="background: #FFF3A3A6;">磁盘上的文件(慢)</mark>
  ![[Excalidraw/后端/java补充内容/二.IO流/2.4文件拷贝/拷贝文件|拷贝文件]]

- 较大的文件拷贝
	- 提供一次性读取多个字节的方法`read(byte[])传入一个数组，让方法填满它`
		- 数组越大拷贝越快，但是占内存，一般设置`5MB - 10MB`的数组
		- 返回值：一次性读取的数据，字节数，若是没有读取到返回`-1`
	- 细节：
		- <mark style="background: #BBFABBA6;">这个保存一次性读取的数据的容器是自己创建 ——》 缓冲区</mark>
		- 若是装不满会从`0`开始存放到缓存数组中，<mark style="background: #FFF3A3A6;">可能有上一次残留的数据</mark>，使用返回的`len`和索引表示使用缓存数组的范围

```java
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        FileInputStream fis = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");
        FileOutputStream fos = new FileOutputStream("E:\\process\\IO_test\\IO_copy_test01.txt");
        byte[] buf = new byte[1024 * 1024 * 5];
        int len;
        while((len = fis.read()) != -1){
            //每次用完的缓存数组覆盖即可，上一次的数据已经传送到了
            //避免数据残留
            fos.write(buf,0,len);
            System.out.println(len);
        }
        //先开的后关
        fos.close();
        fis.close();
    }
}

```

# 三.异常处理

## 3.1捕获异常

---

- 释放资源可能因为异常可能执行不到 ——》 捕获异常，`finnaly`中写释放资源
- 若是`exit`是直接退出`JVM`，什么都不执行了，程序直接结束了

```java
import java.io.*;

public class ByteStreamDemo01 {
    public static void main(String[] args) throws IOException {

        FileInputStream fis =  null ;
        FileOutputStream fos =  null ;
        try{
            fis = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");
            fos = new FileOutputStream("E:\\process\\IO_test\\IO_copy_test01.txt");
        }catch(IOException e){
            e.printStackTrace();
        }finally{
            close(fis,fos);
        }
        //放到try创建的对象，自动关闭，必须实现了AutoCloseable的接口的类才可以，也可以将定义放到try外面
        try(FileInputStream fis2 = new FileInputStream("E:\\process\\IO_test\\IO_test01.txt");
            FileOutputStream  fos2 = new FileOutputStream("E:\\process\\IO_test\\IO_copy_test01.txt");){
            byte[] buf = new byte[1024];
        }catch(IOException e){
            e.printStackTrace();
        }
        
    }
    public static void close(InputStream is, OutputStream os) {
        try{
            if(is != null){
                is.close();
            }
        }catch(IOException e){
            e.printStackTrace();
        }
        try{
            if(os != null){
                os.close();
            }
        }catch(IOException e){
            e.printStackTrace();
        }
    }
}

```

注：
1. `try...cathch ... finally`是局部变量，要将定义放到外面，直接赋值为空即可
2. 内部赋值时可能文件位置出错，不会赋值 ——》 空指针异常

## 3.2编码格式

---

- 使用字节流读取中文，进行按字节转换输出会乱码 ——》字符集

- 将编码转换为十进制进行对应表格

- `ASCII`:
	- 1个字节的数据存储
	- 128种数据，对于英文体系够用了，对于不足一个字节的数据进行扩为1字节的数据，补0
	- 数据按照这个规则进行补位和存储，读出来后也按照这个规则进行转发转换

- `GBK`:
	- 2字节的数据存储：
		- 高位字节：一定时以1开头，与英文区分
		- 低字节：兼容`ASCII`兼容的基础上，继续使用其他的空间
	- `GB`表示不同国家标准的字符集，简体中文的操作系统使用`GBK`,所有国家的字符集统称为`ANSI`
	- 我国：`GB2312`无繁体 ——》 新的`GBK`进行扩展了字符集
	- 完全兼容`ASCII`

- `Unicode`:
	- 国际标准，将世界各种语言中将所有字符都对应一个编码
	- 完全兼容
	- 多个国家都设计了自己的字符集，有美国牵头兼容世界所有的编码，方便不同系统间进行沟通
	- 编码规则：
		- `UTF-16`:
			- 使用2~4字节保存
		- `UTF-32`
			- 固定使用4字节保存
		- `UTF-8`:
			- 使用`1~4`个·字节保存 ——》 统一标准
				- 英文：1个字节
				- 中文，韩文，日文等：3个字节
				- ...
			- 转换方案：
				- 官方文档查询
			- 本质就是一个编码方式
	- 本质：整合，不是一个字符集，只是为了多个国家间能互通的编码方式

- 乱码：
	- 原因1：
		- 未读取完整的整个文字，就进行转字符操作
		- 字节流只能读取一个字节，若是字节操作可能导致没有对应的字符 ——》 乱码
	- 原因2：
		- 编码和解码规则不一致
			- 示例：
				- 编码：`UTF-8`，三个三个编
				- 解码：`GDK`方式，两个两个读
	- 总结：不使用字节流读取(但是可以使用字节流写入,本质就是字节写入)，统一编码

- `java中查看编码方式`
	- `String`:
		- 编码：
			- `getByte[](传入编码方式)`，若是不传入方式，默认编码`UTF-8`
		- 解码:
			- 构造器中指定
			- `String(byte[] bytes,charsetName)`:指定解码方式

## 3.3字符输入流

---

- 为了解决乱码：
	- 统一编码：
		- 统一编码`UTF-8`
	- <mark style="background: #ABF7F7A6;">读取整个字符</mark>：
		- 字符流

- 字符流：
	- 输入流：
		- `Reader`:抽象类
			- `FileReader`:
				- 本地文件 + 继承的结构
	- 输出流：
		- `Writer`:抽象类
			- `FilterWriter`:
				- 本地文件 + 继承结构
	-<mark style="background: #ABF7F7A6;"> 默认使用操作系统的字符集，不能指定字符集</mark>
	- 本质：字节流，字节流 + 字符集，一次性对非英文字符也能操作，一次性读/写几个字节，和字符集相关

- 操作流程：
	- 创建对象
	- 读取数据
		- 按字节读取：
			- 中文：一次性读多个字节
			- 英文：一次性读一个字节
		- 可以读取一个缓存数组，传入`char数组`
	- 释放资源

```java
import java.io.FileNotFoundException;
import java.io.FileReader;

public class CharStreamDemo {
    public static void main(String[] args) throws Exception {
        FileReader fr = new FileReader("E:\\process\\IO_test\\IO_test02.txt");
        /*
        * 字符流底层依然是字节流，若是中文会读取多个字节
        * 内部维护了一个字符数组，若是够了，就解码，转换成对应的十进制返回
        * 返回对应的十进制信息，这个十进制信息可以转换为对应表中的字符
        * */
        int c ;
        while(( c = fr.read()) != -1){
            System.out.print((char)c);
        }
        fr.close();
    }
}

```

- 执行流程：
	- 看读几个字节，放到字符流内部维护的一个数组中保存
	- 读完以后，根据规则进行解码，返回解码后的十进制
	- 拿到十进制数据，按设定的规则，可以将其转换为字符

- 若是将数组做为缓存数组传入`char[] buffer`
	- 返回值：
		- 返回一次性读取了几个字符

```java
import java.io.FileNotFoundException;
import java.io.FileReader;

public class CharStreamDemo {
    public static void main(String[] args) throws Exception {
        FileReader fr = new FileReader("E:\\process\\IO_test\\IO_test02.txt");
       int len;
        char[] chars = new char[2];
        while((len = fr.read(chars)) != -1){
            System.out.printf(new String(chars,0,len));
        }
        fr.close();
    }
}

```

- 空参读取：
	- 将字符读取后，转换成对应的十进制返回
- 缓存数组读取
	- 将字符读取后，转换成对应的十进制，然后强转放入到缓存数组
	- 返回读取字符个数

注:
1. 若是读到换行符有两个`\r\n`，若是使用`println`可能导致两个换行符不在一起，可能无法使用换行符的功能，且特殊符号显示不出来

## 3.5底层讲解

---

- 读取数据的底层原理：
	- 建立对象：
		- <mark style="background: #FFF3A3A6;">开启通道</mark>
		- 内存中建立<mark style="background: #FFF3A3A6;">缓冲区</mark>`8192字节`字节数组
			- 若是超出缓冲区：
				- 先将前8192的放到缓冲区，等缓冲区空出来然后填入，像队列一样
				- 底层逻辑保证中文不会被截断
	- 调用方法读取数据：
		- <mark style="background: #ADCCFFA6;">判断缓冲区是否有数据读取</mark>
			- 有：从缓冲区读取
			- 否：从缓冲区中读取数据尽可能多的读到缓冲区中，若是文件也没有数据，返回`-1`
		- <mark style="background: #ABF7F7A6;">转换</mark>：`UTF-8`形式解码转换成十进制返回

- 输入数据的底层原理：
	- 建立对象：
		- 内存建立一个缓冲区8192字节数组
			- 先写到缓冲区中，写入时机
				- 缓冲区满时
				- 刷新`flush`
				- 关闭流：内部强制执行一次`flush`
		- 是否清空文件：
			- 是：创建流对象一瞬间：文件存在 → 直接【清空整个文件（截断成0字节）】，之后从头写入新数据
			- 否：续写

## 3.6示例

---

- 使用场景：
	- 字节流：
		- <mark style="background: #FFB86CA6;">拷贝任意类型</mark>的文件
	- 字符流：
		- 读取纯文本文件的数据
		- 写入纯文本文件的数据

- 拷贝文件夹：
```java
import java.io.*;

public class CharStreamDemo {
    public static void main(String[] args) throws Exception {
       /*
       * 将"E:\process\IO_test\copy"的内容拷贝到copy_test下
       * */
        //1.表示来源
        File src = new File("E:\\process\\IO_test\\copy");
        //2.表示目的地
        File dest = new File("E:\\process\\IO_test\\copy_test");
        //3.调用方法开始拷贝
        copydir(src,dest);
    }
    /*
    * @param src 数据源
    * @param dest 目的地
    * */
    public static void copydir(File src, File dest) throws Exception {
        //事先保证文件夹存在
        dest.mkdirs();
        /*
        * 递归拷贝:
        * 1.进入数据源
        * 2.遍历数组
        * 3.判断文件，拷贝
        * 4.判断文件夹，递归
        * */
        //1.获得这一层的所有的file
        File[] files =  src.listFiles();
        //2.对此层的file进行遍历
        for(File file : files){
            if(file.isFile()){
                //3.判断文件，拷贝 ——》 一定时文件开始到文件结束
                FileInputStream fis = new FileInputStream(file);
                FileOutputStream fos = new FileOutputStream(new File(dest,file.getName()));
                byte[] buf = new byte[1024];
                int len ;
                while((len = fis.read(buf)) != -1){
                    fos.write(buf, 0, len);
                }
                fos.close();
                fis.close();
            }else{
                //4.判断文件夹，递归
                copydir(file,new File(dest,file.getName()));
            }
        }
    }
}

```

- 文件加密:
	- 加密：对原始文件的每一个字节数据进行更改，然后存储到新的文件中
	- 解密：对加密文件的每一个字节数据进行解密，获得源文件数据

## 4.4字符缓冲流

---

- 字符流本身就带有同大小的缓冲区，速度不会提示太多，但是字符缓冲流有两个极好用的方法，使用方法依旧是传入一个基本流
	- 字符缓存输入流：
		- 特有的方法:`pulic String readLine()`，读一行数据，若是无数据可读，返回null`
		- 针对回车换行：只会读取一行数据，<mark style="background: #ADCCFFA6;">遇到回车换行就停</mark>，<mark style="background: #FFF3A3A6;">不读取回车换行的字符</mark>，输出时没有，但是<mark style="background: #FF5582A6;">输出流中特有的方法弥补了</mark>
	- 字符缓存输出流：
		- 特有的方法：`pulic void newLine()`,针对换行可以跨平台的换行，根据操作系统不同，换行符输入不同
		- 相当于新开一行，<mark style="background: #FFB86CA6;">适配平台</mark>

- 针对续写，同理，<mark style="background: #FF5582A6;">要写在基本流上</mark>

```java
import java.io.*;

public class CharStreamDemo {
    public static void main(String[] args) throws Exception {
       //1.创建缓冲流
        /*
        * 默认缓冲区大小为8192，可以自己手动指定
        * */
        BufferedReader br = new BufferedReader(new FileReader("test.txt"));
        BufferedWriter bw = new BufferedWriter(new FileWriter("test2.txt"));
        //2.使用方法(拷贝应该使用字节流的)
//        String line = br.readLine();
//        System.out.println(line);
        String line;
        while((line = br.readLine()) != null) {
            bw.write(line);
            bw.newLine();//适配平台的换行符
            System.out.println(line);
        }
        //3.关闭，释放资源
        /*
        * 关闭资源时，判断刷新数据时有没有异常，对基本流进行关闭
        * */
        br.close();
        bw.close();
    }

}

```

注：
1. `IO流`<mark style="background: #BBFABBA6;">随用随创建，使用完立即释放</mark>，<mark style="background: #FFF3A3A6;">避免占用或者可能发生清空文件</mark>

# 六.序列化流

## 6.1架构

---

- 序列化流：
	- 位于字节流的高级流中
		- 序列化流/输出流:
			- `ObjectOutputStream`
			- ![[图片/Pasted image 20261010212532.png]]
		- 反序列化流/输入流:
			- `ObjectInputStream`
	- 将类对象的数据写到本地文件中，但是看不懂——》就是要看不懂，避免泄露数据
		- 例如：角色对象需要看不懂，不让别人改
	- 使用：
		- 序列化：放入
		- 反序列化：反译

## 6.2写入/读取类

---

- 写入读取的类必须实现序列化接口
	- 序列化接口没有实现方法 ——》 <mark style="background: #FFB86CA6;">标记型接口</mark>，表示这个类可以被序列化

- 实体类：
```java
import java.io.Serializable;

public class User implements Serializable {
    private String name;
    private int age;
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

```
- 写入实体类：
```java
import java.io.*;
import java.nio.charset.Charset;

public class CharStreamDemo {

        User user = new User("小明",18);

- 读取实体类：

import java.io.*;
import java.nio.charset.Charset;

public class CharStreamDemo {
    public static void main(String[] args) throws Exception {
        //1.创建对象
        ObjectInputStream ois = new ObjectInputStream(new FileInputStream("test.txt"));
        //2.调用方法
        //User user = (User) ois.readObject();
        Object o = ois.readObject();
        System.out.println(o);
        //3.释放资源
        ois.close();
    }

```

- 细节：
	- 若是以实体类第一版写入磁盘，但是读取时使用的是实体类第二版会报错
		- 原因
			- 一个类实现了序列化/标记，则会根据这个类所有内容计算一个版本/序列号，写入磁盘时一起写入
			- 修改实体类后重新计算序列号，对比是否相同
		- 解决方案：
			- 手动设置：在类定义中固定这个类的版本号 ——》 <mark style="background: #FFF3A3A6;">序列号是类层面的标识</mark>
			- `idea中设置`:**编辑器 → 检查 → JVM 语言 → 序列化问题** 找到选项： **没有 serialVersionUID 的可序列化类**
			- 其中新加的字段，使用初始化值/`null`
	- 若是针对某个字段想要保护，不让他序列化到本地文件中
		- 使用字段标记`transient`,瞬态关键字，该字段不参与序列化
