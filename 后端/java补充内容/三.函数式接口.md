# 一.简介

## 1.1引入

---

- 函数：
	- <mark style="background: #FFF3A3A6;">固定的规律</mark>，根据固定的规律进行对输入的内容处理，然后进行输出
	- 类型:
		- 引入外部数据变量，外部数据可变 ——》 不是合格的函数，随意改变规律
			- 要求<mark style="background: #ADCCFFA6;">除了参数可变其他的进行固定</mark>
		- 引入外部数据变量，外部数据不可变 ——》 合格的函数，规律亘古不变

- 合格函数:
```java
static class buddha{
	final String name;
	public buddha(String name){
		this.name = name;
	}
}
static buddha b = new buddha("固定名称");
static String pray(String person){
	return (person + buddha.name + "合格函数");
}
```
- 不合格函数:
```java
static String name = "不固定名称，可以修改";
static String pray(String person){
	return (person + name + "不合格函数");
}
```

- 函数一般在`java`中没有这个概念，而是叫方法
	- 有`static`:
		- 有函数特点，可以不依赖的实现直接使用
	- 无`static`:
		- 成员方法，看着要依靠类的实现，但是本质仍然是函数

```java
public class person(){
	private name;
	public person(String name){
		this.name = name;
	}
	//看着没有输入，但是本质是默认一个输入参数
	public getName(person this){
		return this.name;
	}
}

person p1 = new person("小明");
person p2 = new person("小红");

/*
* 看着明明是一个方法，但是同一个方法的输出不同 
* 但是本质不是同一个方法，只是表象中一样
  本质上方法的输入是:
	  p1.getName(p1);
	  p2.getName(p2);
*/

System.out.println(p1.getName());  // 小明
System.out.println(p2.getName());  // 小红
```

- 总结:
	- 函数的特点:
		- 当<mark style="background: #FFF3A3A6;">同一个方法</mark>，<mark style="background: #FFB86CA6;">输入同一个参数时</mark>，<mark style="background: #D2B3FFA6;">输出稳定不变</mark>
		- 引用了<mark style="background: #FFF3A3A6;">外部非参数的数据</mark>，<mark style="background: #ABF7F7A6;">必须不变</mark>
	- 方法<mark style="background: #FFB86CA6;">(成员方法 + 静态方法)</mark>和<mark style="background: #FF5582A6;">函数本质相同</mark>

## 1.2有形的函数

---

- 想要使用函数 ——》 让函数有形，代码化，<mark style="background: #FFF3A3A6;">让函数化为对象</mark>
	- 纯粹的函数：
		- 普通的方法，内部固定不变
		- 哪里用要使用对象下的方法
		- 同样可以使用序列化进行传输，但是传输到达的对象也必须要有对应的类，这样同样相当于<mark style="background: #FFF3A3A6;">绑定了计算方法</mark>/<mark style="background: #FFB86CA6;">固定位置</mark>
	- 对象化的函数：
		- <mark style="background: #FFB86CA6;">将函数对象化</mark>
		- 做为一个对象，可以<mark style="background: #FFF3A3A6;">在任何位置</mark>，<mark style="background: #ADCCFFA6;">可以传入</mark>，可以直接调用
		- 做为一个对象甚至可以进行序列化进行传输
		- <mark style="background: #FFB86CA6;">计算方法和具体数据的分离</mark>
		- 具体的运算逻辑在另一端不需要，只要有接口接口，具体的实现逻辑，<mark style="background: #BBFABBA6;">随用随建立</mark>

```java
package com.atguigu;  
  
public class test01 {  
  
    /*  
    * 通过一个整体对象来实现函数，(a,b) -> a+b;就是一个对象  
    * 位置可以发生变化，哪里想要就在哪里建立，可以进行传递到不同的类中使用  
     * */    lambda lam = (a,b) -> a+b;  
  
  
}  
//创建接口就是为了接收函数对象，同时通过接口使用，同时接口只能有一个方法定义  
interface lambda{  
    int calc(int a, int b);  
}  
class lam{  
    private int a = 1;  
    private int b = 2;  
    public int calc(lambda method){  
        //这个类并不知道该用什么进行计算 ——》 通过传入的计算规则/函数进行计算，若是平常的一些方法无法传入  
        //但是函数对象可以直接传入使用，想去哪就去哪  
        return method.calc(a,b);  
    }  
}  
  
class test{  
    /*  
    * 位置固定，调用使用类来调用  
    * */    public int calculate(int a , int b){  
        return a+b;  
    }  
}
```
