# 二.vim

## 2.1vim的一般模式的命令

- vim直接进入——》一般模式

- `gg`:回到开头,无需`ESC`退出
- `shift + g / 大写的G`:去结尾，无需`ESC`
- `数字 + shift + g`:去指定行，无需`ESC`
- `shift + 6 / ^`:到行开头，无需`ESC`
- `shift + 4 / $`:到行结尾
- `shift`是为了大写或特殊符号，大写模式无需再按
- `ZZ`:退出保存
- `dd`:删除当行
- `数字 + dd`:删除数字行
- `u`:回退操作，即使保存也可以回退
- `x`:删除当前字符
- `shift + x`:删除前面字符
- `p`:按行粘贴
- `yy`:按行复制
- `yw`:复制一个词
- `dw`:删除一个词

## 2.2vim的命令模式与编辑模式

- 命令模式：快捷操作
- 编辑模式：编辑文本

- 编辑模式：
	- `a`：当前光标后
	- `i`：当前光标前
	- `o`:从下一行插入编写
	- `ESC`:退出
	- `s`:删除当前字符
	- `shift + r`进入替换模式：输入字符时替换当前文本

- 命令模式：
	- `: ZZ`:保存退出，直接退出文本
	- `: shift ; / :`:进入命令模式
	- `: w`:保存
	- `: q`:退出
	- `: wq`:保存退出
	- `/ + 文本`：对应文本变为高亮，下一个使用`n`，`N`上一个，无需预先进入命令模式,`/`直接进入命令模式
	- `%s/旧词/新词 + 回车`：替换操作
	- `: noh`:取消高亮
	- `：number / set number`：展示行号
	- `: no number`:取消行号
	- `: wq!`:强制更改，再权限不够时使用，提示尚未保存时也可以使用，不保存直接退出
