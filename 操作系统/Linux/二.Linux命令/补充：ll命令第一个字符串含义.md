`ll` 命令（相当于 `ls -l`）输出的**第一列（一串字符）** 是 **文件类型和权限**，通常由 10 个字符组成。

---

### 各字符含义（从左到右）

#### 第 1 位：文件类型

|字符|含义|
|---|---|
|`-`|普通文件（文本、图片、程序等）|
|`d`|目录|
|`l`|符号链接（快捷方式）|
|`c`|字符设备（如键盘、串口）|
|`b`|块设备（如硬盘、U盘）|
|`p`|命名管道|
|`s`|套接字|
|`?`|其他（极少见）|

#### 第 2～10 位：权限，每 3 位一组

- **2～4 位**：文件所有者（user）的权限
    
- **5～7 位**：所属组（group）的权限
    
- **8～10 位**：其他人（others）的权限
    

每组由 `r`（读）、`w`（写）、`x`（执行）组合而成：

- 示例：`rwx` → 可读、可写、可执行
    
- 如果某权限未授予，则显示 `-`，例如 `r-x`（可读可执行但不可写）
    

---

### 举例

text

-rwxr-xr--  1 kevin staff  1234 Jul 11 10:00 myscript.sh
| |  |  |
| |  |  └── 其他人权限：r--（只读）
| |  └───── 组权限：r-x（读+执行）
| └──────── 所有者权限：rwx（读+写+执行）
└────────── 文件类型：-（普通文件）

---

### 特殊权限（有时出现在执行位）

- **`s`**（setuid/setgid）：出现在所有者或组的执行位，表示以文件所有者或组的身份运行。
    
- **`t`**（sticky bit）：出现在其他人执行位，常见于 `/tmp` 目录，限制文件删除。
    

---

所以，你看到的第一个字符串（如 `-rw-r--r--`）就是**文件类型 + 所有者/组/其他人权限**。这是 Linux 文件安全的基石。
