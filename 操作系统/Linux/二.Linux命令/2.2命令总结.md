# 一.开关机命令

## 1.1语法

--- 

- 仅特定场合重启

- 操作流程：sync>shutdown>reboot>poweroff

- sync:预处理，将内存的数据同步到硬盘中
- shutdown:即是关机，也是重启，`shutdown -h`——》关机，`shutdown -r`——》重启
- poweroff：关机，立即关机，相当于`shutdown -h now`
- reboot:重启，立即重启，相当于`shutdown -r now`
- 定时重启/关机：shutdown -h/r 时间/now;时间单位为分钟

## 2.6防火墙

--- 

- 守护进程监听端口，客户端访问端口获得服务

- 客户端——》防火墙——》端口
	- 客户端访问端口，要经过防火墙同意才能访问
		- 端口在防火墙内注册：允许外部访问

- `firewall-cmd --permanent --add-port=端口号/协议`:添加端口
- `firewall-cmd --permanent --remove-port=端口号/协议`:删除端口
- `firewall-cmd --permanent --query-port=端口号/协议`:查询端口是否开放
- `firewall-cmd --list-ports`:列举所有允许的端口访问
- `firewall-cmd --reload`:重新加载防护墙
- `--permanent`:是永久生效

- `ubuntu的命令`:

| 命令                        | 作用      |
| ------------------------- | ------- |
| `sudo ufw enable`         | 启用防火墙   |
| `sudo ufw disable`        | 关闭防火墙   |
| `sudo ufw allow 22/tcp`   | 放行 SSH  |
| `sudo ufw allow 8080/tcp` | 放行 8080 |
| `sudo ufw status verbose` | 查看详细状态  |

## 3.4mkdir

---

- 报错：所有文件都交给`-batch`(批处理)处理，可能会报错

- 创建文件夹

```text
mkdir 路径
rmdir 路径
```

注：
1. 上一级目录不存在，则无法创建，<mark style="background: #FF5582A6;">父级目录要存在</mark>
2. 路径书写与`cd`一样
3. `mkdir -p`:自动创建父级目录，递归创建目录
4. `rmdir`：只能删除空目录
5. `rmdir -p`:rmdir -p可以递归删除文件夹，但是遇到非空文件夹时要报错，中断，从给定的路径一直递归删除到当前路径，即使错误也会尝试产出上级文件夹，但是依旧错误
6. 递归删除是按照返回路径一直向上删除，当到达一个文件夹里面有其他文件时，不会尝试删除
7. 注意这个递归删除是按照给出路径最后一个开始向上删

---

- 多个文件需要同一个文件内容，若都存一个文件所有内容——》浪费空间，链接对应文件

3. 软连接VS物理路径：区别在于逻辑路径与物理路径，逻辑路径记录从什么地方进入软连接，物理路径是绝对路径,使用`cd`时两者根据对应形式的路径返回

	- 第一组分为四部分：类型+权限
		- 类型：第一个字母，例：d——》文件夹
		- 权限：
			- 分为三组，每一组都是`rwx`,对应读，写，执行，第一组是第一个root，即创建者/所有者的权限，第二组是第二个root即用户组的权限，第三组对应其他，若权限位置为`-`，则代表其对应的没有这个权限，
			- 当一个用户即是所有者也是用户组，它的权限取并集
			-<mark style="background: #FF5582A6;"> 文件夹的写就是创建，删除其中的文件，执行就是进入到这个目录里面，读就是可以读取查看,使用`ll`看里面有什么文件，具体东西无法看到</mark>
	- 数字：硬链接数，软链接不算
	- 第一个root：所有者
	- 第二个root：所有组
	- 第二个数字：大小，单位`bit`
	- 最后：最后修改的日期
- 例如：
	- `/opt`:放下载的应用的文件夹：常创建一个`module`,存放工程框架

	- `crontab -l`:查询定时任务
	- `crontab -f`:删除当时用户所有的定时任务

- `crontab -e`:
	- 编辑执行时间——》5个`*`:
		- 第一个：一个小时当中的第几分钟
		- 第二个：一天当中第几个小时
		- 第三个：一个月中的第几天
		- 第四个：一年当中的第几个月
		- 第五个：一周当中的第几天/星期几
	- 编辑时间用的特殊符号：
		- `*`:代表任何时间，例如：第一个`*`代表小时内所有的分钟都执行
		- `,`:表示多个不连续的时间，例如：`0 8,12 * * *`表示每天的8点0分，每天的12点0分
		- `-`:连续的时间范围，例如：`0 5 * * 1-6`表示周一到周六的5点0分执行
		- `*/n`:隔多长时间执行，例如：`*/10`，表示隔十分钟执行一次

注：
1. 时间从小到大设计：一般不会在较小的时间上设置一个`*`,然后再大的时间上设置一个具体时间
2. 星期与天数常不会一起设置，他们都代表天，若一起设置可能导致管理员混乱

| 相对时间  | `now + N 单位`                | `at now + 5 days`     | 5天后（同一时刻）                |
| 相对时间  | 单位：minutes/hours/days/weeks | `at now + 30 minutes` | 30分钟后                    |
| 相对时间  | `now` 单独用                   | `at now`              | 立即执行                     |
| 英文日期  | `月名 日 [年]`                  | `at January 15 2018`  | 2018年1月15日；省年默认今年，过期默认明年 |
| 日期戳   | `MMDDYY`                    | `at 011518`           | 2018年1月15日（月日年各两位）       |
| 日期戳   | `MM/DD/YY`                  | `at 01/15/18`         | 美式，2018年1月15日            |
| 日期戳   | `DD.MM.YY`                  | `at 15.01.18`         | 欧式，2018年1月15日            |
| ISO日期 | `CCYY-MM-DD`                | `at 2018-01-15`       | 国际标准日期                   |
| 组合    | 时间+日期                       | `at 14:30 011518`     | 2018年1月15日14:30          |
