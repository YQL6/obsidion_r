# 二.RPM

## 2.1使用场景与介绍

---

- RPM是红帽系里面的软件安装包，类似windows的setup.exed/安装程序，是Linux者系列操作系统的打包安装工具，他是RedHeat的标志，以前用于统一安装方式

## 2.2RPM使用

---

- `ubuntu使用apt系管理工具`

- RPM包的格式：`Apache-1.3.23-11.i386.rpm`
	- Apache:软件名称
	- 1：主版本
	- 3：次版本
	- 23-11:日期或补丁
	- i386：硬件平台，Intel 32位微处理器的名称
	- rpm：文件扩展名，代表RPM安装包

- 查看系统内的RPM包：`rpm-qa`，一般使用过滤的形式：`rpm -qa | grep xxx`,一般使用Linux交互系统的方式安装的系统的东西较多
- 查看包的详细信息：
	- `rpm -qi 包名`
- 删除RPM包：`rpm -e 软件包`,有时依赖这个安装包，要是不检查：`rpm -e -nodeps 软件包`
- 安装命令:`rpm -ivh RPM 包全名`
	- `-i`:install安装
	- `-v`:verbose显示详细信息
	- `-h`:hash进度条
	- `-nodeps`:不检查依赖，即使有其他依赖这个软件，也直接卸载
- 安装方式：有对应的安装包，离线安装，获取安装包——》挂载

注：
1.  **rpm 自己不去任何地方找包——它只装你给它的那个文件路径**。包放在光驱里就装光驱的，放在本地就装本地的，下载来的也行。
2. 仅负责安装，不负责找安装包
3. 安装路径必须是绝对路径
4. <mark style="background: #FF5582A6;">不会对依赖进行检查</mark>

- 从光驱DV中下载无需联网：挂载一个镜像，从网上下载一个everything的安装包

# 三.YUM

## 3.1简单介绍

---

- 底层仍是RPM安装包
- 改进：联网，在线下载，上网拉取：自动处理依赖关系，依赖的东西一起安装
- 联网：配置上连接的镜像源

## 3.2YUM的使用

---

- 查看软件包信息：`yum list`，同时会显示连接的镜像源

- 更换镜像源：
	- 备份原镜像源
	- 更新下载新的镜像源
```text
# 备份原 /etc/yum.repos.d/ 目录下的 .repo 文件
sudo mkdir /etc/yum.repos.d/backup
sudo mv /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup/

#下载新的镜像源
sudo curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
sudo curl -o /etc/yum.repos.d/epel.repo https://mirrors.aliyun.com/repo/epel-7.repo

# 重新生成缓存
sudo yum clean all
sudo yum makecache
```

- 下载：`yum install 名称`或不需要确认`yum -y install 名称`

# 四.实战演练

## 4.1JDK安装

---

- 为了避免兼容性问题，一般是自带安装包，将jsk.tar.gz上传到opt目录下，然后解压缩，免安装

- 多个版本的jdk，容易出现兼容性问题：
![[图片/Pasted image 20260716222331.png]]

- 删除：`rpm -qa | grep jdk |xargs rpm -e --nodeps`,xarges用来接收参数，连接多个命令

- 再官网下载对应的文件，使用Xftp传输，使用`tar -zxvf jdkxxxx -C ./`解压
- 配置环境变量：`$JAVA_HOME`
	- 在`/etc/profile.d`下面创建一个`.sh`结尾的文件，里面写入配置
```text
#JAVA_HOME
JAVA_HOME=/opt/java/jdk1.8.0_401
PATH=$PATH:$JAVA_HOME/bin
export PATH JAVA_HOME
```
	- 使其生效：`source /etc/profile.d/my_env.sh`

## 4.2Mysql安装

---

- 不必考虑兼容性考虑，直接rpm安装，yum安装会跳过设置一些东西

- [官网下载](https://downloads.mysql.com/archives/community/)
- XFTP上传到`/opt/java/`
- 解压，逐步安装
  ![[图片/Pasted image 20260717220300.png]]
- 初始化：`mysqld --initialize --console`:使系统文件更新mysql的信息，添加mysql的系统文件
- 文件位置`/var/lib/mysql/`，修改系统文件的访问权限为`mysql:mysql`
  `chown -R mysql:mysql /var/lib/mysqld/`
- 查看`mysql`的临时密码：log日志，`/var/log/mysqld.log | grep localhost`
- 重启`mysql`：`systemctl restart mysqld`
- 启动mysql:`mysql -uroot -p"密码"`
- 修改密码：`alter user 'root'@localhost identified by 'root'
- 退出：`quit`
