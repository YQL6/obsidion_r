6. sourch使用：改变环境变量时，使用sourch继承一下变量

# 二.变量

## 2.1系统定义的变量

- 系统预先定义的变量:都是大写的或`_`隔开
- 常用的变量：`$HOME,$PWD,$SHELL,$USER等`

## 2.2自定义变量

- 定义：
	- `变量名=变量值`,不要有空格
	- 静态变量/只读变量：`readonly变量`,不能二次赋值且不能被撤销，只在当前窗口生效，另开一个窗口便失效了
	- 全局变量：`export 变量名`,将变量导出变为环境变量
- 撤销：`unset 变量名`

- 定义规则：
	- 变量名由字母，下划线，组成，不能以数字开头，环境变量大写
	- `=`两边不可以有空格
	- bash默认变量是字符串类型，无法计算，赋值的都直接当字符串
	- 变量值有空格时应用双引号括起来，空格会隔断字符串
	- 后写改先写，撤销变量后输出为空

注：
1. 环境变量会是子shell继承


## 2.3特殊变量

- 变量开头不能是数字——》数字开头已经被占用
- `$ + 数字`:表示给这个脚本传入的第几个参数，`0~9`直接写，`10`以上用`{}`括起来——》`{10}`
- `$0`:当前执行脚本名称/路径

- 运行脚本是可以传入参数，各一个空格开始传入，每一个传入的值都用空格隔开

```text
1.text:
#! /bin/bash
echo $0
echo $1
echo $2

./echo 666 "输出第二个参数"
```

![[图片/Pasted image 20260718192515.png]]

- `$#`:一共传入多少参数
- 以空格方式检测，几个空格几个参数
- 即使传入的参数没有使用，也算/多传也算

- `$*`：命令行传入的所有参数，将所有参数看作一个整体/字符串
- `$@`：命令行传入的所有参数，不将所有参数看作一个整体
- 使用循环时，使用`$@`，其将参数分开看待

- `$?`:返回上一个命令的结果状态：
	- `0`/1:正确执行，`0`——》上个结果是`true`，`1`上一个结果是`flase`
	- `非0`:非正常执行
- 直接在shell面板执行

# 三.基本语法

## 3.1运算符基本语法

- `$((表达式))`/`$[表达式]`
- 建议使用`$[]`，不易于小括号混乱

```text
#! /bin/bash

s=$[5*5 -1]
echo $s
```

## 3.2条件判断的基本语法

- `[ condition ]`：条件与`[]`各隔一个空格
- 如果是字符串，那么空字符串为`flase`,非空字符串为`true`
- 直接在shell面板操作，使用`echo #?`返回结果

- 条件判断：
	- 数字类型：
		- `-eq`:等于（equal）
		- `-ne`:不等于（no equal）
		- `-lt`:小于(less than)
		- `-le`:小于等于(less equal)
		- `-gt`:大于(greater equal)
		- `-ge`:大于等于(greater equal)
	- 字符串类型：
		- - **`=` 或 `==`**：判断两个字符串是否相等（推荐用 `=`，`==` 在某些 Shell 中可能不被支持）
		- **`!=`**：判断两个字符串是否不等
		- **`-z`**：判断字符串是否为空（长度为 0）
		- **`-n`**：判断字符串是否非空
	- 文件权限：
		- `-r`:有读的权限(read)
		- `-w`:有写的权限(write)
		- `-x`:有执行的权限
	- 文件类型：
		- `-e`:文件存在(existence)
		- `-f`:文件存在且是一个常规文件(file)
		- `-d`:文件存在且是一个目录(directory)

```text
[123 -eq 123]
echo $?              0

[ -r 1.text ]
echo $?

[ -d 1.text ]
echo $?
```

## 5.2自定义函数

- 写到shell脚本里面

```text
[function] funname[(可写，可不写)]

	[return ing;]   返回状态值，不写就是最后一行为结果，作为返回值

```

```text

        sum=0

fun $X $Y
```

5. 函数内的变量会影响到外面

## 6.1cut工具

- `cut`——》剪，拆分一行数据的列
- `cut [选项参数] filename`：
	- `-f`:列号，可以选择多列

```text
cut -f 1,2 -d " " cut1.text

cut -c 2-3 cut1.text
```

## 6.2awk

- 文本分析工具，自带过滤，匹配，自带分析
- `awk [选项参数] `/pattern/{}` `: `/pattern/{}`被单引号包裹
	- 选项：
		- `-F`:指定文件内以什么分割，相当于cut的参数d
		- `-v`赋值一个用户定义变量
	- pattern:指定过滤的内容，类似`grep`,匹配内容，匹配模式
	- {}:指定第几行的内容,多行用`","`隔开，在匹配模式的基础上进行执行命令

```text
awk -F ":" '/mysql/{print $1}' passwd
awk -F ":" '/mysql/{print $1","$2}' passwd
```

- 查询每一行的第一列和第七列，分隔符是`:`，且所有行前面都添加列名user,shell在最后一行添加`:dahaige,/bin/zuihuai`
  ```text
  awk -F ":" 'BEGIN{print "user,shell"} {print $1","$2} END{print "daihaige /bin/zuishuai"}' passwd
  ```

- `awk`可以进行计算，可以先用`-v`声明变量，在加入计算
  ```text
   awk -v i=1 -F ":" '{print $3+i}' passwd   计算是对变量的值进行计算
  ```

- `awk`<mark style="background: #FF5582A6;">内置变量</mark>：
	- `FILENAME`:文件名
	- `NR`:已读的记录数(行号)，当前的行数，要是不和`//`匹配搭配使用，就是一个整个的行数
	- `NF`:浏览记录的列个数（切割后的列个数），当行的列数

- 查询空行的行号：
  ```text
  ifconfig | awk '/^$/{print NR}'
  ```

注：
1. 只有当`pattern`匹配成功时才会执行`{}`的命令
2. `{}`:命令执行的本质上调用的变量是第几列的东西
3. 单引号包裹内容：本质就是执行命令，`//`找东西，匹配东西，后面紧跟的`{}`表示对找到的东西的操作
4. <mark style="background: #FF5582A6;">awk的匹配是按行来一个一个对分隔符来匹配的，要是一行找不到分隔符，那这个一行就是一个列</mark>
5. 表示空行使用正则表达式：`^`行首，`$`表示行尾，行首与行尾在一起就是空行

## 6.3sort

- 将文件内容排序，然后输出到控制台上

- `sort (选项) (参数)`:
	- 选项：
		- `-n`:按数值大小排序，默认从小到大，不使用就是字符串比较
		- `-r`:顺序相反的排序，使从小到大变为从大到小
		- `-t`:设置排序时所用的分隔字符
		- `-k`:指定需要排序的列

```text
sort -t ":" -nrk 3 passwd
```

## 6.4wc

- 统计文件信息，利用wc指令可以计算文件行数，字节数，字符数

- `wc [选项参数] filename`:
	- 选项参数：
		- `-l`:统计文件行数
		- `-w`:统计文件的单词数
		- `-m`:统计文件的字符数
		- `-c`:统计文件的字节数

```text
wc -l passwd
```

# 七.正则表达式

## 7.1使用场景

- 模糊一些查找内容

## 7.2正则表达式一般用法

- `^ + 字符串`：以字符串开头
- `字符串 + $`:以字符串结尾
- `.`：任意<mark style="background: #FF5582A6;">一个字符</mark>
- `.*`:任意个任意字符
- `[]`:某个范围的字符,以`Ascll码`表示
	- `[a-z]`
	- `[0-9]`
	- `[a-c,f-z]`
	- `[a-z]*`
- `\`:转移符号，避免无法匹配一个带有`*/[]`等特殊符号

量词：
- `字符/. + *`:出现多次或0次

注：
1. `^ + 字符串1 + 字符串2 + $`:只能是`字符串1+字符串2`的东西，不能是其他东西
2. 在 Shell 中使用 **`grep -P`**（Perl 兼容正则）或 **`awk`** 时，大部分 JS 正则可以直接套用（除了一些高级特性如环视、反向引用等的支持程度有差异）。
