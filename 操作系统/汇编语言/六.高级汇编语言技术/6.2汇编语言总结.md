# 一.指令汇总

## 1.1数据传送指令

---

- 通用传送指令：
	- `mov , push , pop ,xchg`
		- `xchg opr1 opr2 `:
			- 功能：
				- `(opr1) <——> (opr2)`
				- 交换数据，不适用第三方
			- 不影响标志寄存器
			- 不允许段寄存器使用

- 累加器专用传送指令:使用ax进行数据传送
	- `in , out , xlat`
		- `xlat`/`xlat opr`:
			- 功能：换码指令
				- `(al) <—— (bx + (al))`
				- 将al做为下标，bx做为基址，将内存对应的单元取一个字节
			- 不影响标志位
			- 字节表格长度不超过256字节——》al是8b，超过了就寻不到了
			- 首地址——》(bx)
			- 需转换的代码位移量——》(al)

- 地址传送指令：
	- `LEA , LDS , LES ,seg`
		- `LEA reg src`:
			- 功能：有效地址送寄存器
				- `src`：标号对应内存单元的偏移地址
				- `reg`:寄存器
				- 将偏移地址保存到寄存器中
				- `(reg) <—— src`
		- `LDS reg src`
			- 功能：指针送寄存器和DS
				- `src`:内存操作数，类似：寄存器，标号了
				- `reg`：寄存器
				- 将src对应的内存单元的前2个字节送入`reg`寄存器，后面继续2个字节送入`DS`寄存器中
				- (reg) <—— (src)
				- (DS) <—— (src + 2)
		- `lES reg src` 同
		- `seg`:
			- 获得标号段地址

- 标志寄存器传送指令：
	- `LAHF , SAHF , PUSHF , POPF`
		- `LAHF`
			- 组成：
				- `LOAD`:加载
				- `ah`
				- `FlAG`
			- （ah） 《—— （FLAGS的低字节）
		- `SAHF`
			- (FLAGS的低字节) <—— (AH)

- 类型转换指令
	- `cbw , cwd`
		- `cbw`
			- 组成：
				- `c`:convert
				- b:byte
				- w:word
			- 功能：
				- `AL ——》AX`
				- 执行操作
					- `AL 符号位 为 0`:(AH = 00h)
					- `AL 符号位 为 1`:(AH = ffh)
		- `cwd`
			- 功能：
				- `AX ——》 (DX,AX)`
				- 执行操作同
		- 不影响符号位

# 二.伪操作指令

## 2.1伪操作

- 汇编指令：对应将其指令，在重新运行器件由计算机执行
- 伪操作：汇编程序对源程序汇编期间，由汇编程序处理的操作，例如：数据定义，分配存储区间等

## 2.2段定义伪操作

- `data/code/stack segment`:段定义
- `assume 段寄存器：段名[,其他段声明]`
	- `segment [定位类型][组合类型][使用类型][类别] ... 段名 ends`:
		- 定位类型/align_type:对齐类型，<mark style="background: #FF5582A6;">下一个对齐到什么大小的倍数</mark>，提高速度
			- `align 16`:对齐到16倍数上
			- `para/16 byte word dword page/256`
			- 段对齐类型
		- 组合类型/combine_type:<mark style="background: #FF5582A6;">多文件组织时的开放权限</mark>
			- `PAIVATE , public , common , stack , AT exp`
				- `private`:两端源程序无关系，子程序不互通
				- `public`：两个源程序的带此标号的段混在一起
					- 由同段名/类别：混在一个段使用
					- 不同命：独立的两个段混一起
				- `common`:
					- 一般不用
				- `stack`
					- 将SS，SP设置为此段
				- `AT exp `
					- 将段名固定到一个地址
					- 调用段名做为段地址使用
					- 里面定义`?`数据，不改变原来的值
		- 使用类型/use_type:<mark style="background: #FF5582A6;">使用什么版本</mark>
			- `use16 use32`
		- 类别/`class`:
			- 优化内存排放问题，当多文件时将类别相同的放在一起
			- 其他地方皆不可使用，即使时assume也不行

- `algin idata`:**伪指令**
	- **强制将下一个数据或指令的存放地址对齐到特定的内存边界**。
	- 提高读写速度
	- 对齐时空出来的空间：
		- 指令：nop
		- 数据：00

## 2.3段定义的简化

- `.model 存储模式`
	- 功能：
		- 一个模板，使用了以后定义段，不必再写那么多参数了
		- 省略`assume`，默认配置asume

- 存储模式：段定义的模板：

| 模型      | 代码段                   | 数据段              | DGROUP     |
| ------- | --------------------- | ---------------- | ---------- |
| TINY    | 全挤进 `_TEXT` 一个段       | 同左               | 无          |
| SMALL   | `_TEXT` 一个            | `_DATA` 等，共≤64KB | 有（数据+栈归一组） |
| MEDIUM  | **每个模块一个** `模块名_TEXT` | 一个               | 有          |
| COMPACT | 一个                    | 可多个（far）         | 有          |
| LARGE   | 多个                    | 多个（far）          | 有          |
| HUGE    | 多个                    | 多个               | 有          |

- 数据初始化与不初始化之分：
	- 初始化：数据时程序运行必要的数据
	- 不初始化：预留空间，例如：缓存

| 区域            | 存进EXE文件吗 | 占运行时内存吗 | 初始值哪来的     |
| ------------- | -------- | ------- | ---------- |
| `.code` 代码    | 是        | 是       | 本身就是要执行的指令 |
| `.data` 已初始化  | 是（原始字节）  | 是       | 从文件复制      |
| `.data?` 未初始化 | **否**    | 是（预留）   | 加载时自动清零    |
| 栈（`.stack`）   | 否        | 是       | 运行时随手用     |
| 堆（malloc申请）   | 否        | 是       | 运行时动态分配    |

- 简化后的段定义：`.small`下的定义

| 简化指令          | 实际生成的段  | 段属性                 | 放什么            |
| ------------- | ------- | ------------------- | -------------- |
| `.code`       | `_TEXT` | WORD PUBLIC 'CODE'  | 代码             |
| `.data`       | `_DATA` | WORD PUBLIC 'DATA'  | 已初始化数据（占文件空间）  |
| `.data?`      | `_BSS`  | WORD PUBLIC 'BSS'   | 未初始化数据（不占文件空间） |
| `.const`      | `CONST` | WORD PUBLIC 'CONST' | 只读常量           |
| `.stack 100h` | `STACK` | PARA STACK 'STACK'  | 栈，链接器自动设 SS:SP |
- 未初始化与初始化的段名不同，不是一个段

- 知识点：

| 类别         | 知识点           | 说明                                                            | 写法/例子                       |
| ---------- | ------------- | ------------------------------------------------------------- | --------------------------- |
| **入口**     | `.model` 语法   | 声明内存模型，可带语言类型                                                 | `.model small, c`           |
| **模型**     | TINY          | 代码+数据+栈共用一个64KB段，.COM，CS=DS=SS                                | `.model tiny`               |
|            | SMALL         | 代码1段+数据1组，.EXE，**最常用**                                        | `.model small`              |
|            | COMPACT       | 代码1段，数据可多段(far)                                               | `.model compact`            |
|            | MEDIUM        | 代码按模块分多段，数据1组                                                 | `.model medium`             |
|            | LARGE/HUGE    | 代码、数据都可多段                                                     | `.model large`              |
| **简化段指令**  | `.code`       | 代码段，可带别名                                                      | `.code` / `.code myseg`     |
|            | `.data`       | 已初始化数据段                                                       | `.data`                     |
|            | `.data?`      | 未初始化数据段(BSS)，不占文件空间                                           | `.data?`                    |
|            | `.const`      | 只读常量段                                                         | `.const`                    |
|            | `.stack 100h` | 栈段，数字=字节大小(100h=256B)                                         | `.stack 100h`               |
| **自动段名**   | 代码段           | small→`_TEXT`；medium/large→`模块名_TEXT`                         | —                           |
|            | 数据段           | `.data`→`_DATA`、`.data?`→`_BSS`、`.const`→`CONST`              | —                           |
|            | 栈段            | `STACK`                                                       | —                           |
| **自动属性**   | 对齐/组合/类别      | 代码WORD PUBLIC 'CODE'；数据WORD PUBLIC 'DATA'；栈PARA STACK 'STACK' | 汇编器自动填                      |
| **分组**     | DGROUP        | `.data/.data?/.const/.stack` 同归一组，共用组基址，DS一个寄存器全访问            | `mov ax, @data`             |
| **@符号**    | @data         | DGROUP段地址，**最常用**                                             | `mov ax, @data; mov ds, ax` |
|            | @code         | 当前代码段地址（基本不用）                                                 | `mov ax, @code`             |
|            | @stack        | 栈段地址（别动SS）                                                    | 仅了解                         |
|            | @CurSeg       | 当前段名                                                          | 宏/调试用                       |
| **assume** | 自动生成          | 编译期声明CS/DS/SS指向，**不等于运行时赋值**                                  | 汇编器自动 `assume ds:DGROUP`    |
| **合并规则**   | 同名PUBLIC      | 同名段链接时合并成一个大段                                                 | 两个`.code`→`_TEXT`合并         |
|            | 别名/异名         | 独立段，不合并                                                       | `.code myseg`               |
|            | 链接期合并         | 编译时各段分开，LINK时才拼                                               | 看.map文件验证                   |
| **结束**     | 无ENDS         | 简化段靠切换自动闭合，`end`收尾全部                                          | `.data`后写`.code`即自动结束       |
|            | END           | 程序结束+入口标号                                                     | `end start`                 |
| **段寄存器**   | DS            | 必须手动设：通用寄存器中转                                                 | `mov ax,@data; mov ds,ax`   |
|            | ES            | 需要时同样操作（显存/字符串/far数据）                                         | `mov ax,0B800h; mov es,ax`  |
|            | CS/SS         | DOS设好，**不要手动改**                                               | —                           |
| **取具体段地址** | `seg 符号`      | 组内符号=@data；组外符号=独立段地址                                         | `mov ax, seg myvar`         |
|            | 段名            | 自定义段直接用段名取                                                    | `mov ax, myseg; mov es, ax` |

注：
1. `.stack.100h`：栈大小100h
2. <mark style="background: #FF5582A6;">多个相同段定义编译时都会变成对应的代码段/数据段/栈段一个大段的内容，除非进行别名的定义才会生成独立段</mark>
3. 简化定义会我们生成对应固定段名的段，合并/连接时看使用的模型是什么，不同模型对应生成的段名不同

## 2.6表达式赋值的伪操作

- 定义一个变量：
	- `EQU`:表达式名使用到就是一个固定的值
		- 类型：
			- 文本宏：右边无法执行前识别出数值的，无法使用`=`重新赋值
				- type识别时需要替换文本要有其类型`byte/word ptr`
			- 常量：可以执行前识别其数值的
		- `表达式名 EQU 表达式`
			- `ALPHA EQU 9`
			- `BETA EQU ALPHA + 18`
			- `BB EQU [bp +8]`——》<mark style="background: #FF5582A6;">用到时先算，会随着bp改变</mark>
	- `=`
		- 为表达式名重新赋值
			- `BB = 2`,BB为2
	- 本质：<mark style="background: #FF5582A6;">将一个表达式用文本代替，这个文本编译后换成对应的表达式</mark>
