# 一、重复汇编伪指令

## 三种形式

|伪指令|语法|重复规则|
|---|---|---|
|`REPT`|`REPT 次数 ... ENDM`|按**次数**重复|
|`IRP`|`IRP 形参, <项1,项2,...> ... ENDM`|按**列表项**逐个重复|
|`IRPC`|`IRPC 形参, 字符串 ... ENDM`|按**字符**逐个重复|

三者都以 `ENDM` 结束，而且**汇编时立即展开**（不像宏要等调用）。

## REPT：按次数重复

```
REPT 3
    db 0            ; 生成 3 个 0
ENDM
; 相当于: db 0,0,0
```

常用于生成固定长度的表：

```
TABLE = 0
REPT 10
    db TABLE
    TABLE = TABLE + 1
ENDM                 ; 生成 0~9 的表
```

## IRP：按列表重复，形参逐个代入

```
IRP reg, <ax,bx,cx>
    push reg
ENDM
; 展开成: push ax / push bx / push cx
```

尖括号里的逗号列表是分隔符，形参每次取一项。

## IRPC：按字符串的每个字符重复

```
IRPC ch, ABC
    db '&ch'
ENDM
; 展开成: db 'A' / db 'B' / db 'C'
```

区别记一句：**IRP 管"列表"（ax,bx,cx），IRPC 管"字符"（ABC）**。

# 二、条件汇编伪指令

## 完整结构

```
IF 条件
    ...        ; 条件为真（非0）时汇编
ELSE
    ...        ; 条件为假时汇编
ENDIF
```

## 常用条件一览

|伪指令|条件|
|---|---|
|`IF 表达式`|表达式**非0**才汇编|
|`IFE 表达式`|表达式**为0**才汇编|
|`IFDEF 符号`|符号**已定义**|
|`IFNDEF 符号`|符号**未定义**|
|`IFB <参数>`|参数**为空**（宏里判断）|
|`IFNB <参数>`|参数**非空**|
|`IFIDN <a>,<b>`|两个参数**相同**（文本比较）|
|`IFDIF <a>,<b>`|两个参数**不同**|
|`IF1` / `IF2`|汇编**第一遍/第二遍**时|

## 典型用途

**① 调试开关（最常用）**

```
DEBUG_FLAG EQU 1
IF DEBUG_FLAG
    ; 调试代码，只在开关为1时汇编
ENDIF
```

**② 宏里判断参数**

```
SAVE MACRO reg
    IFB <reg>
        EXITM               ; 参数为空，直接退出宏
    ENDIF
    push reg
ENDM
```

**③ 可移植代码**

```
IFDEF _WIN32
    ; Windows 代码
ELSE
    ; Linux 代码
ENDIF
```

# 三、共同要点

1. **都是汇编期**：REPT/IF 在汇编阶段展开或判断，生成的机器码是"定稿"的，程序运行时不参与；
2. **可以嵌套**：REPT 里套 IF，IF 里套 REPT，都合法；
3. **和宏的区别**：宏是"定义一次、调用时展开"；REPT/IRP 是"写在哪儿、当时就展开"；
4. **条件里的表达式**：必须是汇编器能算出的常量（不能用寄存器）；
5. **考试常考区分**：REPT=按次数、IRP=按列表、IRPC=按字符；IF=非0、IFE=为0、IFDEF=已定义。

**一句话总结：** 重复汇编三兄弟 `REPT`（次数）/`IRP`（列表）/`IRPC`（字符）负责"批量生成"，条件汇编 `IF/IFE/IFDEF/IFB/IFIDN...` 负责"按需生成"；它们都在汇编期定稿，配合宏和 `EXITM` 能写出很灵活的代码生成器——调试开关和数据表格就是最常见的两个应用。
