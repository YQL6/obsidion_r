# 一.总体设计

## 1.1结构

- 一个主程序调用多个子程序
  ![[Excalidraw/操作系统/汇编语言/四.流程转移与子程序/4.2模块化设计/模块化|模块化]]

- 例如：
```c
#include<stdio.h>
int fun;
int main(){
	printf("%d\n",fun());
}
int fun(){
	return 0;
}
```
- 程序分析
	- 调用子程序——》fun函数
	- 执行fun函数后，返回主程序继续执行

- 对应c语言
	- 调用子程序：call指令
	- 返回主程序：ret指令

## 1.2call指令与ret指令

- `call 标号`：跳转到标号的地址
- `ret`：返回使用`call`下一条指令
- 实质：流程转移指令
	- 修改ip
	- 修改cx，ip

- 示例：
```asm
mov ax,0
call s
mov ax,4c00h
int 21h

s:  add ax,1
	ret
```

- `call 标号`:调用子程序
	- 段内转移
	- 本质：流程转移
		- call实现转移方式与jmp指令原理相似
	- 与`ret`配合使用——》返回到上一个call指令的地址
		- 将档期那的ip或cs，ip压入栈中——》保存地址
		- 转移到标号处执行指令
	- 类似操作：
		- `push IP`
		- `jmp near ptr 标号`
	- 原理：
		- 16位位移 =` 标号地址 - call指令后的第一个字节的地址`
		- 16位范围`-32768~32767`,补码表示
		- 16位位移编译程序计算
- `call far ptr 标号`:调用子程序
	- 段间转移
	- 压栈时将cs：ip入栈
		- cs：标号的段地址
		- ip：标号的偏移地址
	- 操作
		- `push cs`
		- `push ip`
		- `jmp far ptr 标号`
- `call 16位寄存器/通用寄存器`
	- 段内转移（绝对）
	- 类似操作
		- `push IP`
		- `jmp 寄存器`/字节将寄存器的16位值赋值给ip
- `call word ptr 内存单元`:
	- 段内绝对转移
	- 类似操作
		- `push ip`
		- `jmp word ptr 内存单元`
- `call dword ptr 内存单元`
	- 段间绝对转移
	- 类似操作
		- `push cs`
		- `push ip`
		- `jmp dword ptr 内存单元`
	- 重点：转移的地址从内存单元取
		- 低字——》ip
		- 高字——》cs

- `ret`
	- 功能
		- 从栈中取出数据，修改ip内容，实现转移
		- 类似操作：
			- `pop ip`
- `retf`
	- `return far`
	- 功能
		- 第一次出栈：ip
		- 第二次出栈：cs
	- 类似操作
		- `pop ip`
		- `pop cs`
- 重点：
	- <mark style="background: #FF5582A6;">本质就是取段顶的值给ip，无论有没有call</mark>
	- 一定要为栈段初始化

- 示例：
```asm
assume cs:code,ss:stack
stack segment
	db 16 dup(0)
stack ends
code segment
	mov ax,4c00h
	int 21h
start:
	mov ax,stack
	mov ss,ax
	mov sp,16
	mov ax,0
	push ax
	mov bx,0
	ret  ;pop ip  
code ends
end start
```
- 代码分析
	- push压入栈的ax会被ret拉出来放入ip进入start前执行
	- 死循环

- 示例：进行2的3次方计算
```asm
assume cs:code,ss:stack
stack segment
	db 16 dup(0)
stack ends
code segment
main:
	mov ax,stack
	mov ss,ax
	mov sp,16
	
	mov cx,3
	mov ax,1
	
	call fun
	mov ax,4c00h
	int 21h
s:  add ax,ax
	loop s
	ret
code ends
end main
```

# 二.MUL

## 2.1mul

- `mul 乘数/寄存器/内存单元`
	- 类似div

| 乘数位数        | 乘数存放位置     | 被乘数（隐含） | 乘积总位数 | 乘积存放位置                             | 溢出判断                              |
| ----------- | ---------- | ------- | ----- | ---------------------------------- | --------------------------------- |
| **8 位**（字节） | 寄存器或内存字节单元 | `AL`    | 16 位  | `AX`（`AH` 存高 8 位，`AL` 存低 8 位）      | `AH ≠ 0` 时 CF=1, OF=1，表示结果超过 8 位  |
| **16 位**（字） | 寄存器或内存字单元  | `AX`    | 32 位  | `DX:AX`（`DX` 存高 16 位，`AX` 存低 16 位） | `DX ≠ 0` 时 CF=1, OF=1，表示结果超过 16 位 |

- 示例：
	- `mul bl`:
		- 被乘数：`al`
		- 乘数：`bl`
		- 结果存放位置：`(ax) = (al) * (bl)`
	- `mul byte ptr ds:[0]`
		- 被乘数：`[al]`
		- 乘数：`[0] 一字节`
		- 结果存放位置:`(ax) = (al) * ((ds) * 16 + 0)
	- `mul word ptr [bx + si + 8]`
		- 被乘数：`[ax]`
		- 乘数：`[bx + si + 8] 一字`
		- 结果：
			- `(ax) = (ax) * ((bx) + (si) + 8)的低字节`
			- `(dx) = (ax) * ((bx) + (si) + 8)的高字节`

注：
1. 自己设计是不是16位，看乘数是小于8位的极限还是16位的极限
2. **`MUL` 只能用于无符号整数乘法。**
3. 寄存器只能是`AX,BX,CX,DX,SI,DI`

# 三.模块化设计

## 3.1子程序

---

- 子程序：根据<mark style="background: #FF5582A6;">提供的参数</mark>处理一定的事务，处理后，将<mark style="background: #FF5582A6;">结果（返回值）提供给调用者</mark>

- 根据提供的N，计算N的3次方
	- 问题分析：
		- 参数存放在什么地方
		- 计算后返回的值存放在什么地方
	- c语言回答问题
```c
#include<stdio.h>
int cube(int x);
int main()
{
	printf("%d\n",cube(2));
	return 0;
}
int cube(int x)
{
	int f;
	f = x*x;
	f = f*x;
	return f;
}
```

## 3.2寄存器存储

---

- 问题解决：
	- <mark style="background: #FF5582A6;">寄存器来存储参数与结果</mark>
	- 参数放到bx中，即`(bx) = N`
	- 子程序使用多个mul指令计算N^3
	- 结果放到dx和ax中——》使用16位乘法
	- <mark style="background: #FF5582A6;">此方法当结果适合较小的数乘法——》超过16位，dx的数无法参与运算</mark>
- 编写程序
```asm
;子程序
cube:
	mov ax,bx
	mul bx
	mul bx
	ret
```

- 示例：将内存单元前8个字的数据进行3次方，然后存放在后16个字之中
	- 问题分析
		- 多个次方
			- 循环
		- 存放参数与结果
			- 参数：bx
			- 结果：ax，dx
		- 寄存器冲突
			- si来位移
		- 结果书写
			- di
	- 编程程序
```asm
assume cs:code,ds:data
data segment
	dw 1,2,3,4,5,6,7,8
	dd 0,0,0,0,0,0,0,0
data ends
code segment
start:
	mov ax,data
	mov ds,ax
	
	mov si,0
	mov di,16
	
	mov cx,8
	
s:
	mov bx,[si]
	call cube
	mov [di],ax
	add di,2
	mov [di],dx
	add si,2
	add di,2
	
	loop s
	mov ax,4c00h
	int 21h
cube:
	mov ax,bx
	mul bx
	mul bx
	ret
code ends
end start


```

## 3.3内存存储

---

- 问题解决：
	- <mark style="background: #FF5582A6;">内存来存储传递的参数与结果</mark>
	- 参数在内存中——》<mark style="background: #FF5582A6;">将内存的首地址放到寄存器中使用，为cx赋值确定范围</mark>
	- <mark style="background: #FF5582A6;"> 结果对内存/参数运算后，将结果放到内存位置上</mark>

- 示例：将`context`转换为大写
	- 问题分析
		- 如何将参数传递
			- 使用寄存器保存内存需要部分的首地址
			- 结束：cx不断循环到末尾，确定边界
		- 结果如何返回
			- 将计算结果代替原内存内容
		- 转换为大写
			- `and byte ptr [bx],11011111b`
```asm
assume cs:code,ds:data
data segment
	db 'context'
data ends
code segment
main:
	mov ax,data
	mov ds,ax
	
	mov si,0
	mov cx,7
	
	call tolower
	
	mov ax,4c00h
	int 21h
	
tolower:
	and byte ptr [si],11011111b ;小写——》大写
	inc si
	loop tolower
	ret
	

code ends
end main
```

## 3.4栈存储

---

- 问题解决
	- 将参数存放在栈中——》存放的是数据，结果存放在寄存器中
	- 参数进行入栈保存
	- 结果计算后存放在寄存器中

- 示例：计算`(a - b)^3`
	- 问题分析：
		- 参数传入：
			- 存放：进行入栈操作
			- 读取：由于标号的入栈影响，使用时不可以直接弹栈——》<mark style="background: #FF5582A6;">使用bp读取</mark>
			- 参数存放时，会保存一个节点/标号地址
		- 结果存放：
			- 寄存器
	- 编写程序
	  ![[Excalidraw/操作系统/汇编语言/四.流程转移与子程序/4.2模块化设计/栈中情况描述|栈中情况描述]]
```asm
assume cs:code,ds:data,ss:stack
stack segment
	dw 16 dup(0)
stack ends
data segment
	dw 0
data ends
code segment
main:
	mov ax,data
	mov ds,ax
	mov ax,stack
	mov ss,ax
	
	mov ax,3
	push ax  ;将b入栈
	mov ax,6
	push ax  ;将a入栈
	call fun  ;进入子程序计算(a - b)^3
	
	mov ax,4c00h
	int 21h
	
fun:
	push bp  ;保护bp旧值，防止冲突
	mov bp,sp
	mov ax,[bp + 4]  ;模拟出栈,sp不可移动，上面保存着标号地址和bp旧值
	sub ax,[bp + 6]  ;a - b,结果存放在ax中作为被乘数
	mov bx，ax
	mul bx
	mul bx
	pop bp  ;恢复bp
	ret 4   
code ends
end main
```

- `ret idata`
	- 类似操作
		- `ret`
		- `sp - idata`
	- ret只是将栈出一次栈——》回到标号位置
	- 原来的参数没有解决，将sp向下调，无视使用完的参数

# 四.寄存器冲突问题

## 4.1寄存器冲突

---

- 多个字符串进行大写
	- 调用子程序：大写
	- 循环：多次调用子程序
	- cx怎么办，都需要，冲突

## 4.2避免冲突

---

- 编写子程序时，不使用冲突的寄存器
- 调用子程序时，注意子程序有没有使用冲突的寄存器
	- 有，使用不冲突的寄存器

- 上述解决方法，各个子程序间不是独立的模块

- 标准子程序模块：
	- 编写调用子程序的程序时不必担心子程序内部使用什么寄存器
	- 编写子程序时不必关心调用者使用了什么寄存器
	- 不会发送寄存器冲突

## 4.3标准子程序

---

- 使用栈保存子程序使用过的寄存器，完成子程序功能后回复寄存器

```asm
子程序开始：
	子程序保存要使用的寄存器
	子程序内容
	子程序出栈，恢复寄存器内容
	返回(ret,retf)
```
