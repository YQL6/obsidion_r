# 一.转移

## 1.1指令执行过程

- 一般指令执行过程：按顺序向下逐条执行
- 转移指令：改变指令/程序执行流程

## 1.2转移综述

- 控制cpu执行某处代码的指令
- 修改IP，或者直接修改`CP:IP`

- 例如：
```asm
mov ax,0
jmp short s
inc ax
s:  add ax,1
```

## 1.3转移指令分类

- 按转移行为：
	- 段内转移：只修改`IP`
	- 段间转移：同时修改`CP:IP`,如`jmp 1000:0`
- 根据指令对IP修改的范围不同：
	- 段内短转移：IP修改范围是`-128~127/8b/1B`
	- 段内近转移：IP修改范围是`-32768~32767/16b/2B`
- 根据转移指令：
	- 无条件转移指令，例如：`jmp`
	- 条件转移指令，例如：`jcxy`
	- 循环指令,例如：`loop`
	- 过程
	- 中断

# 二.offset

## 2.1语法

- `offset 标号`：获得标号的<mark style="background: #FF5582A6;">偏移地址</mark>

## 2.2示例

- 示例：
```asm
assume cs:code
code segment
start:
	mov ax,offset start ;相当于获得start这个标号的地址，start标记了开始位置，偏移地址0
s:  mov ax,offset s     ;获得s标号的地址，s标号是3位置
code ends
end start
```

- 示例：将程序一条指令复制到另一个地方s0处
	- 问题解决：
		- s和so的内存单元地址是多少
			- s:cs:offset s
			- s0:cs:offset s0
		- 怎么复制指令
			- 复制指令的机器码
		- 地址怎么表示
			- 段地址：cs
			- 偏移地址：si和di
		- 指令大小：
			- s处指令大小：2字节，没有立即数
```asm
assume cs:code
code segment
start:
s:  mov ax,bx
	mov si,offset s
	mov di,offset s0
	mov ax,cs[si]
	mov cs[di],ax
s0: nop
	nop
code ends
end start
```

注：
1. 机器码翻译过来的结果就是直接将标号对应地址当作立即数使用
   ![[图片/Pasted image 20260801154142.png]]
2. `nop`:占位指令，占一个字节

# 三.jmp

## 3.1jmp

- `jmp`:
	- 无条件转移
	- 转移信息：
		- 转移的目的地址
		- 转移距离
			- 段间转移（远转移）:`jmp 2000:1000`
			- 段内短转移：`jmp short 标号`,修改范围为`-128~127`，8位的位移
			- 段内近转移：`jmp near ptr 标号`,修改范围`-32768~32767`,16位的位移


## 3.2转移依据

- 根据位移进行转移
	- 位移：<mark style="background: #FF5582A6;">相对当前的ip表示的偏移地址的偏移量</mark>
	- <mark style="background: #FF5582A6;">位移量用补码表示，有正有负</mark>

- 常见的指令中的立即数均在机器指令中有所体现
  ![[图片/Pasted image 20260801161143.png]]

- jmp指令：
```asm
assume cs:code
code segment
start:
	mov ax,0
	jmp short s 
	add ax,1
s:	inc ax
code ends
end start
```
- 编译成为机器码
  ![[图片/Pasted image 20260801161907.png]]
	- 显示立即数是跳转到标号的偏移地址
	- 实现的具体机器码：<mark style="background: #FF5582A6;">立即数为03与偏移地址08不符</mark>
	- 具体实现：
		- <mark style="background: #FF5582A6;">读取</mark>jmp指令放入指令缓冲器中
		- 读取完<mark style="background: #FF5582A6;">立即</mark>向下ip自行增加jmp指令长度——》`+2`
		- 解析后执行jmp指令——》`ip + 3`——》`ip为08`

## 3.3两种段内转移与远转移

- 短转移：`jmp short 标号`
	- 功能:`(ip) = (ip) + 8位位移`
	- 原理：
		- 8位位移计算：`标号处地址 - jmp命令后一个指令的地址`——》<mark style="background: #FFB86CA6;">本质：相对寻址</mark>
		- short 指明此处的位移为8位的位移
		- 8位位移的范围`-128~127`，<mark style="background: #FF5582A6;">用补码表示</mark>
		- 补码的计算由编译程序由编译算出
- 近转移：`jmp near ptr 标号`
	- 功能：`(ip) = (ip) + 16位位移`
	- 原理：
		- 16位位移 = `标号位置处地址 - jmp命令后一个指令的地址`
		- `near ptr`：此处的位移为16位的，进行从是段内转移
		- 范围:`-32678~32677`,补码表示
		- 补码由编译程序计算而出
- 远转移:`jmp far ptr 标号`
	- 功能:指明跳转到的目的地址，直接跳转到标号的`cs:ip`处
	- `cs:ip`
		  cs:标号处的段地址
		  ip：标号处的偏移地址

注：
1. <mark style="background: #FF5582A6;">当位移超出8位/16位时报错</mark>
2. 相对地址：短转移，近转移
3. 绝对地址：远转移

## 3.4jmp的使用方法

- `jmp 寄存器`
	- 绝对跳转
	- `ip = 寄存器`
	- 直接将寄存器的值赋值给ip进行跳转
- `jmp xxxxh`
	- **跳转到当前代码段内，偏移地址为 100H 处**
	- `ip = xxxxh`
	- 编译时转化为段内相对偏移来做
	- 直接将直接数赋值给ip，进行跳转
- `jmp word ptr 内存单元地址`
	- 间接跳转
	- `ip = [内存单元]`
	- 直接从内存单元取出一个字，放入ip，进行跳转
- `jmp dword ptr 内存单元`
	- 段间跳转
	- `ip = [低地址] , cs = [高地址]`
	- 直接将cs赋值为高地址的一个字，ip赋值为低地址的一个字
- `jmp near ptr 标号`
	- 段内偏移
	- 原理：计算标号到下一条指令的差
	- 偏移到标号位置
- `jmp short 标号`
	- 段内偏移
	- 原理：计算标号到下一条指令的差
	- 偏移到标号位置
- `jmp far ptr 标号`
	- 段间偏移
	- 将cs，ip都改变为标号位置的地址
- `jmp 段地址:偏移地址`
	- 将cs变为对应的段地址，ip变为对应的偏移地址
	- <mark style="background: #FF5582A6;">不可以再源程序使用，可以使用debug中跳转</mark>

**段内跳转（只修改 IP）**

|   |   |   |
|---|---|---|
|`JMP SHORT 标号`|段内直接短转移|`IP = IP + 8位位移量`|
|`JMP NEAR PTR 标号`|段内直接近转移|`IP = IP + 16位位移量`|
|`JMP 寄存器`|段内间接转移|`IP = 寄存器的值`|
|`JMP WORD PTR [内存]`|段内间接转移|`IP = [内存单元]`|

**段间跳转（同时修改 CS:IP）**

| 指令格式                 | 跳转类型   | 操作                        |
| -------------------- | ------ | ------------------------- |
| `JMP FAR PTR 标号`     | 段间直接转移 | `IP = 标号偏移`，`CS = 标号段地址`  |
| `JMP DWORD PTR [内存]` | 段间间接转移 | `IP = [低地址]`，`CS = [高地址]` |
|                      |        |                           |

注：
1. <mark style="background: #FF5582A6;">jmp 标号 与jmp 立即数本质上是一致的，jmp 标号机器码翻译为对应位置的立即数，同时具体指令中使用位置的方式进行偏移</mark>

# 四.其他跳转指令

## 4.1jcxz

- `jcxz 标号`
	- 相对位移实现
	- 对应if语法
	- 指令分析
		- j：jmp
		- cx：计数寄存器
		- z：判断zieo
	- 功能:
		- `(cx) = 0`：跳转标号处执行
		- `(cx) != 0`:向下执行
	- 原理：
		- 机器代码翻译后的汇编指令展现出将标号换位立即数，机器码使用位置偏移寻址——》`jmp 标号`
		- `(cx) = 0`:`(ip) = (ip) + 8位位移,原理与jmp同`
	- 特点
		- 所有条件转移指令都是段转移指令
		- 修改地址是`-128~127`

## 4.2loop

- `loop 标号`
	- 相对位移实现
	- 对应循环语法
	- 功能
		- `(cx) = 0`:向下执行
		- `(cx) != 0`:跳转到标号执行
	- 原理：与jmp同，机器码中一般都是补码的负数，向前跳转

相对位移的好处：
- 只要程序整体移动，相对位移找到指令位置就不会改变
- 要是绝对位置，可能程序内存所在地址的绝对地址改变或程序前方出现一些数据改变代码开始位置，就会使跳转出现偏差
