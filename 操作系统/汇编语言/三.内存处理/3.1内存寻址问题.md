# 二.`[bx + idata]`寻址

## 2.1`[bx + idata]`

- `[bx + idata]`——》一个内存单元
	- 偏移地址：`[bx] + idata`
	- 实际效果：`(ax) = ((ds) * 16 + idata + (bx))
	- 示例:`mov ax,[bx + 200]`
		- 将一个内存单元放入ax
		- 地址：
			- 偏移地址：`[bx] + 200`
			- 物理地址：`(ds) * 16 + (bx) + 200`
	- 不同形式：
		- `mov ax,200 + bx`
		- `mov ax,200[bx]`
		- `mov ax,[bx].200`

- 那么以此可以<mark style="background: #FF5582A6;">形成一个数组形式</mark>
	- 遍历：`bx`，不断增加向下遍历
	- 数组地址/数组首地址：idata——》固定不动
	- 实现不同的数组就是有不同的idata

- 示例：实现`BaSIC`小写，`MinIX`大写
	- 问题分析：
		- 两者可以组成两个数组
			- `BaSIC`:
				- `idata = 0`
				- `bx`：遍历
			- `MinIX`
				- `idata = 5`
				- `bx`：遍历
		- 两者可以同时在循环中操作
```asm
assume cs:code,ds:data
data segement
	db 'BaSIC' ;转为小写
	db 'MinIXi'
data ends
code segment
start:
	mov ax,data
	mov ds,ax
	
	mov bx,0
	mov cx,5
s:  mov al,[bx + 0]
	or al,00100000b ;转小写
	mov [bx + 0],al
	
	mov al,[5 + bx]
	and al,11011111b ;转大写
	mov [5 + bx],al
	
	inc bx
	
	loop s
	
	mov ax,4c00h
	int 21h
code ends
end start
```

1. 反映出高级语言的数组结构：
	1. 一个固定的地址开始偏移

# 三.SI,DI寄存器

## 3.1变址寄存器

- bx通常与ds一起使用

- `SI,DI`与`bx`功能相近
	- `SI`:source index,源变址寄存器
	- `DI`:destination index，目标编制寄存器
- `SI,DI`只是16位寄存器，不可以拆分为两个8位寄存器使用
- 示例：
	- 相同功能：只要有bx就可以替换为di,si
		- `mov bx,0  mov ax,[bx]`和`mov bx,0 mov ax,[123 + bx]`
		- `mov si,0  mov ax,[si]`和`mov si,0 mov ax,[123 + si]`
		- `mov di,0  mov ax,[di]`和`mov di,0 mov ax,[123 + di]`

- 示例：将`welcome to masm!`复制到后面的数据区内
	- 问题分析：
		- 数据区空间
			- 要为源数据留空间，为后面数据区留空间
		- 地址位置
			- 原位置：0
			- 目标位置：16
		- 实现：
			- loop
			- ds:si——》源地址位置
			- ds:di——》目标位置
		- 一次性复制的字节数
			- 2字节
			- `add si,2`
			- `add di,2`
	- 编写
```asm
assume cs:code,ds:data
data segment
	db 'welcome to masm!'
	db '................'
data ends
code segment
start:
	mov ax,data
	mov ds,ax

	mov si,0h 
	mov di,16

	mov cx,8

s:	mov ax,[si]
	mov [di],ax
	add si,2
	add di,2
	loop s 

	mov ax,4c00h
	int 21h
code ends
end start
```

注：
1. <mark style="background: #FF5582A6;">loop循环操作地址时一定要注意一次性操作多少字节，以此直到循环次数</mark>

## 3.2`[bx + si] ,[bx + di]`

- `[bx + si]`:表示一个内存单元
	- 偏移地址：`(bx) + (si)`
	- 数字化描述:`(ax) = ((ds) * 16 + (BX) + (SI))`
	- 示例：`mov ax,[bx + si]`
		- 将一个内存单元送入ax
		- 偏移地址：`(bx) + (si)`
		- 段地址：`(ds)`
	- 另一种写法:`[bx][si]`

- 具体使用：
	- 数组：`[bx + si]`
	  ![[Excalidraw/操作系统/汇编语言/三.内存处理/3.1内存寻址问题/基址变址寻址|基址变址寻址]]
	- 结构体`[bx + si + 位移量]`
		- 位移量为结构体内部要寻找元素的位置
		- bx：首地址
		- si：下标
		- ![[Excalidraw/操作系统/汇编语言/三.内存处理/3.1内存寻址问题/结构体|结构体]]

注：
1. 基址寻址与变址寻址间的关系
	-  基址：bx,bp
	- 变址:si,di
	- 相同点：
		- 可以实现数组，当bx/si/di单独出现时，物理意义上一样，都可以确定一段内存空间
		- 除了dp外，都是以ds为段空间
	- 不同点：
		- 一般bx作为基址寄存器，虽然可以作为数组下标使用，但是最好不用
		- si/di作为下标使用，与bx结合作为数组使用
		- bp，默认段空间是ss
2. 数组常用方式：
	- <mark style="background: #FF5582A6;">首地址（固定）：bx</mark>
	- <mark style="background: #FF5582A6;">下标（移动）：si/di</mark>
3. si/di设计两个是为了实现一些类似字符串复制的特殊操作

## 3.3`[bx + SI/DI + idata]

- `[bx + SI/DI + idata]`
	- 偏移地址：`(bx) + (SI/DI) + idata`

- 一般用于结构体语法

|组件|你描述的职能|具体作用|
|---|---|---|
|**BX（基址）**|结构体数组的**首地址**|指向整个结构体数组在内存中的起始位置|
|**SI（变址）**|**下标**，有固定的移动字节|代表访问第几个结构体，乘以结构体大小后，作为整个结构体在数组中的偏移|
|**idata（位移量）**|**内部具体元素的寻址**|结构体成员在结构体内部的偏移量，定位到具体的成员|

```asm
LEA BX, arr          ; BX = 数组首地址（基址）
MOV SI, 3            ; SI = 下标 3
SHL SI, 2            ; 下标 × 4 = 12（变址）
MOV AX, [BX + SI + 2] ; 基址 + 变址 + 位移量 → 访问 arr[3].y
```

- 数组实现：
```asm
LEA BX, arr        ; 1. 基址：BX 指向整个数组的开头
MOV SI, 2          ; 2. 变址：SI 是要访问的第几个结构体 (2)
SHL SI, 2          ; 3. 计算结构体偏移：下标 2 × 结构体大小 4，SI = 8
MOV AX, [BX + SI + 2]  ; 4. 基址变址 + 位移量：访问 arr[2].y
```

# 四.寻址方式总结

## 4.1 寻址方式

|寻址方式|语法示例|物理地址计算公式|备注|
|---|---|---|---|
|**立即寻址**|`MOV AX, 1000H`|无（数据在指令中）|操作数直接包含在指令里|
|**寄存器寻址**|`MOV AX, BX`|无（数据在寄存器中）|操作数在寄存器中|
|**直接寻址**|`MOV AX, [1000H]`|`DS × 16 + 1000H`|直接给出偏移地址|
|**寄存器间接寻址**|`MOV AX, [BX]`|`DS × 16 + BX`|寄存器里存放着偏移地址|
|**基址寻址**|`MOV AX, [BX + 100H]`|`DS × 16 + BX + 100H`|BX 默认配 DS，BP 默认配 SS|
|**变址寻址**|`MOV AX, [SI + 100H]`|`DS × 16 + SI + 100H`|SI/DI 默认配 DS|
|**基址+变址**|`MOV AX, [BX + SI]`|`DS × 16 + BX + SI`|一个基址 + 一个变址|
|**基址+变址+位移**|`MOV AX, [BX + SI + 100H]`|`DS × 16 + BX + SI + 100H`|最复杂的寻址模式|

注：
1. 寄存器基址寻址——》基址寻址+变址寻址

## 4.2高级语言

|高级语言语法（C）|对应的寻址方式|汇编表示|地址计算说明|
|---|---|---|---|
|常量赋值 `a = 100`|**立即寻址**|`MOV AX, 100`|操作数直接在指令中|
|简单变量 `a = b`|**寄存器寻址**|`MOV AX, BX`|操作数在寄存器中|
|全局变量 / 静态变量|**直接寻址**|`MOV AX, [var]`|`DS:offset(var)`|
|指针解引用 `*p`|**寄存器间接寻址**|`MOV AX, [BX]`|寄存器存地址，`DS:BX`|
|一维数组 `arr[i]`|**基址 + 变址**|`MOV AX, [BX + SI]`|`BX` = 数组首地址，`SI` = 下标×元素大小|
|`arr[i]`（下标是常数）|**基址寻址**|`MOV AX, [BX + 10]`|`BX` = 数组首地址，常数 = 偏移量|
|结构体成员 `p.x`|**基址寻址**|`MOV AX, [BX + 2]`|`BX` = 结构体首地址，`2` = 成员偏移量|
|结构体数组 `arr[i].x`|**基址 + 变址 + 位移**|`MOV AX, [BX + SI + 2]`|`BX` = 数组首地址，`SI` = 下标×结构体大小，`2` = 成员偏移|
|函数参数 / 局部变量|**基址寻址**|`MOV AX, [BP + 6]`|`BP` 默认为栈段 SS，偏移访问参数或局部变量|
|字符串常量|**直接寻址**|`MOV AX, [msg]`|`DS:offset(msg)`|
|动态数组 `ptr[i]`|**寄存器间接 + 变址**|`MOV AX, [BX + SI]`|`BX` = 指针值（首地址），`SI` = 下标×元素大小|
|二维数组 `arr[i][j]`|**基址 + 变址 + 位移**|`MOV AX, [BX + SI + idata]`|`BX` = 首地址，`SI` = (i×列数 + j)×元素大小|

![[图片/7768aa4f026d54db32581a2ba02d91b4.jpg|892]]

**核心对应关系速查**：

- **首地址** → `BX`（基址寄存器）
    
- **下标/索引** → `SI` 或 `DI`（变址寄存器）
    
- **常数偏移** → `idata`（位移量）
    
- **三个组合** → `[BX + SI + idata]` 实现最复杂的数据访问

# 七.div

## 7.1div

- `div`：除法
	- 被除数:
		- 默认，放在<mark style="background: #FF5582A6;">AX</mark>或<mark style="background: #FF5582A6;">DX和AX</mark>
		- 除数：8位或16位，再<mark style="background: #FF5582A6;">寄存器或内存单元</mark>中
		- 结果：
			- 余数：
				- 8位：AH
				- 16位：DX
			- 商：
				- 8位：AL
				- 16位：AX

| 除数位数         | 被除数存放位置                                | 被除数总位数 | 商存放位置 | 余数存放位置 |
| ------------ | -------------------------------------- | ------ | ----- | ------ |
| **8 位** (字节) | `AX` (16 位)                            | 16 位   | `AL`  | `AH`   |
| **16 位** (字) | `DX:AX` (32 位，`DX` 高 16 位，`AX` 低 16 位) | 32 位   | `AX`  | `DX`   |

- `div 寄存器/内存单元`
	- 示例：
		- `div bl`
			- 被除数：`[ax]`
			- 除数：`[bl]`
			- 商：`[al]`
			- 余数:`[ah]`
		- `div byte ptr ds:[0]`
			- 被除数：`[ax]`
			- 除数:`[0]`
			- 商:`[al]`
			- 余数:`[ah]`

- 切记使用除法前要将被除数设置好
	- 设置好被除数的值
	- 要是原来有用处
		- 固定内存单元保存
		- 栈
		- 其他寄存器

- 示例：`100001/100`
	- 问题分析：
		- 被除数：`100001D=186A1H`
		- 除数:`100D=64H`
		- 除法类型：
			- 16位——》被除数一个寄存器放不开，需要两个AX，DX，只能是16位的
			- 被除数保存位置：AX放低位，DX放高位
			- 除数：任意
		编写：
```asm
mov dx,1h
mov ax,86A1h

mov bx,64h

div bx
```
