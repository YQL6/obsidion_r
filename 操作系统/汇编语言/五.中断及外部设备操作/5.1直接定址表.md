# 一.移位指令

## 1.1SHL

---

![[图片/e1a781d86b6e0a02579063def6f1c4f7.jpg]]

- `SHL`/`Shift logic left`  操作数 移动位数:
	- 功能：
		- 逻辑左移
		- 将操作数向左移x位，低位补0
		- 考虑标志位

注：
1. cnt是idata是必须是1
2. cnt>1时，必须使用寄存器`cl`
3. 左移——》`操作数*2`
4. 右移——》`操作数/2`

## 1.2ROL

---

- `ROL/ROtate left opr cnt`:
	- 功能：
		- 循环左移
		- 将移出去的数放到空缺的最低位
		- 考虑标志位
			- CF：被移除的值同时作为CF值

## 1.3SHR

---

- `SHR/shift logical right opr cnt`
	- 功能：
		- 逻辑右移
		- 将操作数像右移动，最高位补0
		- 考虑标志位

## 1.4ROR

---

- `ROR/Rotate right opr cnt`
	- 功能：
		- 循环右移
		- 被移除的值放到最高位
		- 考虑标志位

## 1.5SAL

---

- `SAL opr cut`
	- 功能：
		- 算术左移
		- 操作数向左移，最低为补0
		- 考虑标志位

## 1.6SAR

---

- `SAR opr cnt`
	- 功能：
		- 算术右移
		- 操作数向右移动，将最高位复制到新的最高位上
		- 考虑标志位

## 1.7RCL

---

- `RCL opr cnt`:
	- 功能：
		- 带进位的循环左移
		- 操作数左移，将CF值放入最低位
		- 考虑标志位

## 1.8RCR

---

- `RCR opr cnt`
	- 功能：
		- 带进位的循环右移
		- 操作数右移，将CF值放入最高位
		- 考虑标志位

## 补充：标志位特殊表现

| 标志位    | 对移位指令的意义                                    | 示例                                                                                   |
| ------ | ------------------------------------------- | ------------------------------------------------------------------------------------ |
| **CF** | 保存移出的位。可用于判断原始数据的特定位、实现多字节移位。               | `MOV AL, 10000001b`  <br>`SHL AL, 1`  <br>左移一位，原最高位`1`移入CF，CF变为`1`。`JC`指令可据此跳转。      |
| **OF** | 在左移一位时，指示有符号数乘2是否溢出（符号位是否改变）。超过一位时值**未定义**。 | `MOV AL, 64`（正数）  <br>`SHL AL, 1`  <br>结果128（负数），符号反转，OF=`1`。`JO`指令可据此跳转处理溢出。        |
| **SF** | 反映移位后结果的符号位（最高位），用于有符号数比较或判断正负。             | `MOV AL, 64` (SF=`0`，正数)  <br>`SHL AL, 1`  <br>结果128（SF=`1`，变为负数）。                   |
| **ZF** | 指示移位结果是否为零。常用于判断数据是否被完全移空，作为循环终止条件。         | `MOV AL, 1`  <br>`SHL AL, 1`（AL=`2`, ZF=`0`, 非零）  <br>再执行`SHL AL, 7`后AL=`0`, ZF=`1`。 |

注：
1. ALU的运算结果会影响到标志位寄存器——》固定的物理电路
2. <mark style="background: #FF5582A6;">CF特殊表现在移位寄存器中：保存溢出位</mark>
3. <mark style="background: #FF5582A6;">算术右移能补全符号位——》复制原来的最高位——》设置SF</mark>

## 2.2标号

---

- <mark style="background: #FF5582A6;">标号</mark>：代码段中的标号可以用来标记指令，段的起始地址
	- assume：连接标号与段地址寄存器，告知编译器段寄存器对应哪段
	- 段标号/`xxx segment`：标记各段地址
	- 代码段/`main: 程序`：对代码的起始地址标号
	- 数据段标号/数据标号/变量标号/`xxxx db/dw/dd 数据`：对数据段的写入数据部分的标号
- <mark style="background: #FF5582A6;">标号的内容</mark>：
	- 段地址
	- 偏移地址
- 标号的使用：
	- <mark style="background: #FF5582A6;">读取标号存到标号对应表中，根据格式不同分辨出段标号，代码段的标号，变量标号</mark>
	- 代码段标号/变量标号:默认使用其中的偏移地址
		- 本质：指向`段地址:偏移地址`的内存单元
		- 使用内容的区别：根据指令不同执行不同指令
			- 作为地址使用
				- `mov ax,a[bx]`
			- 做为读取内存单元的数据使用
				- `mov ax,a`
	- 当作变量使用/首地址使用
	- 地址标号仅代码段可以使用

- 变量标号：
	- 标号后面没有了`:`
	- 基础信息：
		- <mark style="background: #FF5582A6;">段地址+偏移地址，一般只使用偏移地址，段地址使用默认的DS或强制指定</mark>
		- 一个操作默认的大小：
			- `db`
			- `dd`
			- `dw`
		- 操作大小：纯纯的地址标号，没有内存单元大小这一个信息
			- 寄存器
			- 指定
			- 默认大小
		- 大小冲突：
			- 使用适配的寄存器
			- 使用`byte/word ptr`强制读取/强制覆盖原来读取大小的信息

```Asm
assume cs:code
code segment
	a db 1,2,3,4,5,6,7,8
	b dw 0
main:
	mov si,0
	mov cx,9

s:
	mov al,a[si]  ;a为地址,0 , 使用al是为了适配标号的大小
	mov ah,0
	add b,ax
	inc si
	loop s
	mov ax,4c00h
	int 21h
code ends
end main
```
- 此代码的知识点：
	- <mark style="background: #FF5582A6;">段地址选取</mark>
		- **“标号 + BX” 的默认段不是看 BX，而是看标号属于哪个段、ASSUME 把它映射给了哪个段寄存器。标号在代码段、assume cs:code，所以默认 CS。**
		- 当没有标号时默认是ds（硬件），但是标号会覆盖（编译器）

- 指针：
	- 定义一个标号，里面存储变量标号的地址

```asm
data segment
	a db 1,2,3,4,5,6,7,8
	b dw 0
	c dw a,b  ;c dw offset a,offset b 仅保存偏移地址
	d dd a,b  ;c dd offset a,seg a,offset b,seg b 保存编译地址，段地址
data ends
```


- `seg 标号`
	- 功能：
		- <mark style="background: #FF5582A6;">获得标号的段地址</mark>

# 三.定址表

## 3.1数据定址表

---

- 引入：以十六进制的形式在屏幕中间显示给定的byte型数据
	- 问题分析：
		- 16进制形式：
			- 将字节数据分开：
				- 高字节：对应的16进制字符
				- 低字节：对应的16进制字符
		- 如何显示：
			- 直接的方法：
				- 使用跳转指令：
					- `0`:显示0
					- `...`
					- `15`:显示`F`
				- 使用对应的关系：
					- `0~9`:Ascii码值：`x+30h`
					- `A~F`:ASCII码值：`x + 37H`
			- 简介方法：
				- 直接定值表
					- 建立：`0~F`的字符表、
					- 对应关系：`0~15`对应到表格里面
	- 编写程序：
```asm
assume cs:code
code segment
main:
	mov al,2BH  ;参数，传入子程序中待写入的数据
	call showbyte ;调用子程序
	mov ax,4c00h
	int 21h
	
showbyte: ;参数是al，待显示的字符
	jmp short show
	table db '1,2,3,4,5,6,7,8,9,A,B,C,D,E,F'  ;创建表格，等待使用
show:
	push bx
	push es
	push cx
	
	mov ah,al  ;分离数据
	mov cl,4   ;>1的位移只能使用cl实现
	shr ah,cl  ;右移四位，将低位去掉，0000xxxx
	and al,00001111b  ;将al高4位去掉，同时处于低位上，0000xxxx
	
	mov bl,ah
	mov bh,0  ;使用偏移bx寻址
	mov ah,table[bx]  ;将ah变为数值对应的字符的ASCII码值
	
	mov bx,0b800h
	mov es,bx
	mov es:[160*12 + 40*2],ah;写入第40列的字符段中
	
	mov bl,al
	mov bh,0 ;使用bx偏移寻址
	mov al,table[bx]
	
	mov es:[160*12 + 40*2 + 2] ;写入41列的字符段中
code ends
end main
```

- 问题解决：
	- 使用一个表将两个数据集合中间建立一种映射关系（函数）
		- y：表格对应数据
		- x：数据

- 编写程序：x为{0,30,60,90,120,150,180}中的一个，求sinx
```asm
assume cs:code
code segment
main:
	mov al,60  ;以al传入参数
	call showsin
	mov ax,4c00h
	int 21h

showsin:
	jmp show
	table dw ag0,ag1,ag2,ag3,ag4,ag5,ag6
	ag0 db '0',0
	ag1 db '0.5',0
	ag2 db '0.866',0
	ag3 db '1',0
	ag4 db '0.866',0
	ag5 db '0.5',0
	ag6 db '0',0
	
show:
	push ax
	push bx
	push dx
	push si
	push di
	push es
	
	mov ah,0
	mov bl,30
	div bl
	mov bl,al
	mov bh,0  ;mov bx,ax
	add bx,bx   ;由于按字写入，扩大二倍对应到数组的偏移地址/下标上
	
	mov bx,table[bx] ; 获得字符串偏移地址/首地址
	
	mov dx,0B800h
	mov es,dx
	mov si,0
	mov di,160*12 + 40*2
s:
	mov ah,cs:[bx][si]
	cmp ah,0
	je showret
	mov es:[di],ah
	inc si
	add di,2
	jmp s
showret:
	pop es
	pop di
	pop si
	pop dx
	pop bx
	pop ax
	ret
code ends
end main	
```

## 3.2代码定址表

---

- 代码定址表：
	- 功能：
		- 通过指定程序，直接调用定址表对应的序号
		- 所有子程序组合成为一个表

```asm
assume cs:code
code segment
main: ;主程序
	mov ah,2 ;决定调用什么程序
	mov al,2 ;决定什么颜色
	call setscreen ;调用程序实现目标
	mov ax,4c00h
	int 21h
code ends
end main
setscreen:
	jmp short set
	table dw sub1,sub2,sub3,sub4
set:
	push bx
	
	cmp ah,3
	ja sret
	mov bl,ah ;ah不能动，al是固定的参数
	mov bh,0
	add bx,bx ;找到对应的程序的标号/数组中的偏移地址
	call word ptr table[bx] ;调用程序
sret:
	pop bx
	ret
;由ah决定功能号，al决定颜色
sub1:  ;实现清屏功能
	push bx
	push cx
	push es
	
	mov bx,0B800h
	mov es,bx
	mov bx,0
	mov cx,2000  ;一页一共2000字符
sub1s:
	mov byte ptr es:[bx],' '
	add bx,2
	loop sub1s
	
	pop es
	pop cx
	pop bx
	ret  ;sub1结束 ，实现清屏功能
sub2:
	
	mov bx,0B800h
	mov es,bx
	mov bx,1
	mov cx,1000
sub2s:
	and byte ptr es:[bx],11111000  ;设置前景色皆为0
	or  byte ptr es:[bx],al  ;通过先设置为0，然后或固定的值，决定颜色
	add bx,2
	loop sub2s
	pop bx
	pop cx
	pop es
	ret
sub3: ;将背景设置颜色
	push es
	push cx
	push bx
	
	mov cl,4
	shr al,cl  ;将颜色设置位于al对齐
	mov bx,0B800h
	mov es,bx
	mov cx,1000
	mov bx,1
	
sub3s:
	and byte ptr es:[bx],10001111
	or byte ptr es:[bx],al
	add bx,2
	loop sub3s
	pop bx
	pop cx
	pop es
	ret
sub4: ;实现向上滚动一行
	push cx
	push si
	push di
	push es
	push ds
	
	mov si,0B8000h
	mov es,si
	mov ds,si
	mov cx,24 ;循环24次，将24行向上移
	mov si,160 ;数据来源
	mov di,0 ;数据目的地
	cld 
	
sub4s:
	push cx
	mov cx,160 ;一行160字节
	rep movsb
	pop cx
	loop sub4s
	
	mov cx,80
	mov si,0
sub4s1:
	mov byte ptr es:[160*24 + si],''
	add si,2
	loop sub4s1
	pop ds
	pop es
	pop di
	pop si
	pop cx
	ret
```
