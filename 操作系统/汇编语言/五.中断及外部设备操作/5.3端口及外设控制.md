# 一.外部设备

## 1.1端口

---

- cpu访问数据：
	- cpu内部寄存器
	- 内存单元
	- 端口：与cpu之外的设备连接
		- 对应各种接口卡，网卡，显卡
		- 主板上的接口芯片
		- 其他芯片

- <mark style="background: #FF5582A6;">各种芯片工作时，都有一些寄存器由cpu读写，内部的寄存器在为外设提供信息</mark>
- 从cpu角度来讲，<mark style="background: #FF5582A6;">将寄存器做为端口，统一编制</mark>
- cpu使用统一方法与各种设备通信
- 一个外设常由多个端口

- 统一编址为64KB空间——》为各端口分配不同空间
- 与内存编址不同——》独立编一个空间`0000H~FFFFH`,只有16根地址线
- 一个端口——》一字节
- 可以两个端口凑成一个为16字节，被读取

## 1.2读写端口

---

- 本质：<mark style="background: #FF5582A6;">外部设备提供端口，cpu通过端口与外部设备交互</mark>
	- cpu 《——》 端口 《——》 外设

- `in`:从端口读取信息（以cpu为中心）
- `out`:向端口写入信息

- cpu操作端口过程：（以读取为例）
	- cpu通过地址总线发出地址信息
	- cpu通过控制总线发出端口读取命令，选中端口所在的芯片，告知要读取信息
	- 端口所在芯片将端口中的事件通过数据总线送入cpu

- 示例：
		- `in al,60h`
		- `out 61h,al`
	- 放入dx中读取：
		- `mov dx,3f8h`
		- `in al,dx ;从[dx]端口中读取`
		- `out dx,al`

![[图片/4a481a0377a4c523c59cdc6b35fb5406.jpg]]

注：
1. cpu发送地址信息是给所有芯片发送，然后由芯片的译码电路判断是不是自己的
2. 译码电路高位判断是不是自己的，低位判断是自己的那个寄存器
3. 端口号在`0~255`时以立即数给出
4. 端口号在`256~65535`的端口时将端口号放入dx中
5. <mark style="background: #FF5582A6;">只能使用ax/al存放从端口读入/发送的数据，访问8位端口使用al，访问16位端口使用ax</mark>

## 2.1CMOS RAM芯片

---

- cmos ram芯片——》外部设备的一部分
	- 组成：
		- 实时钟——》旁边配置一个单独的电源——》关机时仍工作
		- 128存储单元的ram存储器——》一个字节
			- 内部实时钟——》内部时钟信息以BCD码存储——》二进制
			  ![[图片/Pasted image 20260806203937.png]]
			- 系统配置信息
			- 相关程序（开机时配置系统信息），开机时按`F8`可查看
	- 提供的端口：
		- `70h`:指定要访问的存储单元
		- `71h`:指定单元的读取/写入的数据

- 示例：从cmos ram中读取月份时间信息
```asm
assume cs:code
code segment
main:
	mov al,8
	out 70h,al
	in al,71h
	
	mov ah,al  ;al是二进制月份信息，分离出十位数，个位数
	mov cl,4
	shr ah,cl
	
	add ah,30h
	add al,30h
	
	mov bx,0b800h
	mov es,bx
	mov byte ptr es:[160 * 12 + 40 * 2],ah
	mob byte ptr es:[160 * 12 + 41 * 2],al
	
	mov ax,4c00h
	int 21h
code ends
end main
```

## 2.2外部中断

---

- 外部中断：
  ![[图片/bead8d01806a495157857703325afa5e.jpg]]
	- 可屏蔽中断
		- 通过`IF = 0`屏蔽
		- 一般就是外部设备的中断信号
	- 不可屏蔽中断
		- 不可通过`IF = 0`屏蔽
		- 一般是一些特殊的突发情况，保护电脑使用

- 外部中断：
	- cpu执行过程中检测发送过来的中断，引发中断过程
	- 中断有物理电路触发
	- cpu检测中断信息：
		- IF = 1，则cpu执行中断例程
		- IF = 0，则不响应中断
			- 特殊情况：不可屏蔽中断，中断类型码一般是2
	- 中断处理流程：
		- 取中断类型码，外设通过数据总线传入cpu(不可屏蔽无这一步，固定为2)
		- 标志寄存器入栈，`IF = 0,TF = 0`
			- 当程序中需要可屏蔽中断设置`IF = 0`
				- `cli`:`IF =0`
				- `sti`:`IF = 1`
		- `CS,IP`入栈
		- 设置`CS,IP`

## 2.3PC键盘

---

- 输入过程
	- 键盘的键 《——》 开关
		- 按：
			- 按下接通开关，在芯片形成扫描码——》说明按下的键在键盘的位置
			- 扫描码送到接口芯片的寄存器中，<mark style="background: #FF5582A6;">该寄存器的端口地址为60h</mark>
		- 松开：
			- 松开断开开关，芯片上产生一个扫描码——》说明松开键在键盘的位置
			- <mark style="background: #FF5582A6;">松开按键时的扫描码也被送到60h端口</mark>
	- 键盘芯片扫描键的开关状态
	- 扫描码：
		- 一个字节
		- 按下——》通码，通码的第七位为0
		- 松开——》断码，断码的第七位为1
		- 通一个按键位置形成的通码与断码间的关系：`断码 = 通码 + 80h`

	- 大小写无区分——》使用`shift/capslock`确定大小写

- 键盘中断：
	- 按下：
		- 中断：
			- 送消息到60h
			- 芯片想cpu发出中断类型码为9的可屏蔽中断消息
			- cpu检测`IF = 1`吗，是，执行`int 9`中断例程
		- 数据：
			- <mark style="background: #FF5582A6;">字符键的字符值存放在BIOS键盘的缓冲区</mark>

				- 若是对应控制键/切换键的扫描码，则将其转变为状态字节(用二进制记录控制键和切换键的字节)写入内存中存储状态字节的单元

		- 低字节：字符码
		- 高字节：扫描码
		- 注意小端模式

## 2.4自定义键盘操作

---

- 在屏幕中间依此显示`a~z`，并让人看清,显示过程中,按下`ESC`后改变显示颜色
	- 问题分析：
		- 填写`a~z`
			- 长时间展示：空循环——》许多次
		- 按键中断操作
			- 安装新的`int 9h`操作
			- 仅对`ESC`自定义操作
				- 其他按键用原中断处理
					- 将原中断例程保存——》`ds:[0] ,ds:[2]`
```asm
assume cs:code,ds:data,ss:stack
data segment
	dw 2 dup(0)
data ends
stack segment
	db 128 dup(0)
stack ends
code segment
main:
	mov ax,data
	mov ds,ax
	mov ax,0
	mov es,ax
	
	;保存旧中断例程
	;靠栈传送数据
	push es:[9*4] ;9h的IP
	pop ds:[0]
	push es:[9*4 + 2] ;9h的CS
	pop ds:[2]
	
	;安装新的例程
	mov word ptr es:[9 *4],offset int9
	mov es:[9*4 + 2],cs

	;设置显存
	mov ax,0b800h
	mov es,ax
	
	mov al,'a'
	mov ah,'z'
s:  mov es:[160 * 12 + 40*2],al
	call delay
	inc al
	cmp al,ah
	jna s
	
	;恢复原有例程——》防止操作系统出错
	push ds:[0]  ;靠栈传送数据
	pop es:[9 * 4]
	push ds:[2]
	pop es:[9 * 4 + 2]
	
	mov ax,4c00h
	int 21h
delay: ;延时任务
	;存储寄存器
	push ax
	push dx
	
	;设置循环时间
	mov ax,0
	mov dx,10h
s1:
	add ax,1
	sbb dx,0
	cmp ax,0
	jne s1
	cmp bx,0
	jne s1
	
	pop dx
	pop ax
	
	ret
	
int9:
	;新的例程
	push ax
	push bx
	push es
	
	;读取扫描码
	in al,60h
	
	;模仿机器调用例程过程
	;标志位保存
	pushf
	;IF，TF置0
	pushf  ;入栈标志位寄存器，依靠栈传送数据
	pop bx ;靠栈获得数据
	and bh,11111100b ;高位的最后两个比特时TF，IF
	push bx ;靠栈传送数据
	popf
	call dword ptr ds:[0] ;调用原例程，同时call指令默认保存cs，ip
	
	;新的例程
	cmp al,1
	jne int9ret
	;改变颜色
	mov ax,0b800h
	mov es,ax
	inc byte ptr es:[160 * 12 + 40 * 2 + 1]
	
int9ret:
	pop es
	pop bx
	pop ax
	iret
	
code ends
end main
```

- 延迟代码：首先时ax一直加到进位我的bx才会减一，而我的bx设置的是10h，一直要ax进行10h次进位才行，而每一次进位都要进行2的16次方相加
- 使用栈传送数据

	- 按下：发送中断信号

- `int 16h`读取过程：
  ![[图片/Pasted image 20260807142820.png]]
	- <mark style="background: #FF5582A6;">取数据方式：环形队列</mark>
	- 缓冲区一共16个字
	- 操作过程：
		- 检测键盘缓冲区是否有数据

		- 将读取的扫描码送入ah,ASCII码送入al
		- 将已经读取的键盘送入从缓冲区删除
- `int 9h`是硬件控制，发出中断信号，`int 16h`是软件控制，由程序发出中断信号
	- 两者相互配合使用，一个读取一个写入
	- 两个使用时机不同

- 如何确定键盘缓冲区的数据读取位置
	- 使用队列指针
		- 队头指针：指向下一个待读取的数据
		- 队尾指针：指向下一个待写入的数据

- 示例通过用户输入的字符更改颜色,`r`将屏幕上的字符设置为红色，`g`,`b`
```asm

	;调用中断，等待输入
	mov ah,0
	int 16h ;一直等到输入才会向下走
	
	;识别按键
	mov ah,1 ;设置特殊功能——》字体颜色位置在倒数最后几个
	cmp al,'r'
	jmp red
	cmp al,'g'
	jmp green
	cmp al,'b'
	jmp blue
	jmp short sret
	
	;设置颜色
red: shl ah,1  ;左移到红色的位置上
green:
	shl ah,1
blue:
	mov ax,0b800h
	mov es,ax
	mov bx
	mov cx,2000
s:
	and byte ptr es:[bx],11111000b
	or es:[bx],ah
	loop s
mov ax,4c00h
int 21h
```

## 3.2实现字符串输入

---

- 设计一个基本的字符串输入程序
	- 输入字符串的同时显示这个字符串
		- 使用栈管理字符串的存储空间
		- 每次输入或删除时应重新显示字符串
	- 回车，字符串结束输入
	- 退格删除
```asm
assume cs:code,ds:data
data segment ;栈只可以一次性存储2字节，存储数据不好使用，模拟栈
	db 32 dup(?)
data ends
code segment
main:
	;寄存器初始化
	mov ax,data
	mov ds,ax
	;初始化栈底
	mov si,0
	;初始化函数调用的信息,dx——》行，dl——》列
	mov dh,12
	mov dl,40
	
	;调用处理函数——》处理字符显示与接收问题
	call getser
	
	;退出程序
	mov ax,4c00h
	int 21h
	
	;监听重新开始
getstr:
	;保存寄存器
	push ax
	
	;监听字符输入
lis: 
	mov ah,0
	int 16h
	
	cmp al,20h ;监听的字符输入大于20h是字符，小于不是
	jb nochar
	;属于字符的处理
	mov ah,1
	call str
	mov ah,2
	call str
	jmp lis
	
	
nochar:
	;不是字符的处理
	cmp ah,0eh ;退格的控制字符
	je backspace
	cmp ah,1ch  ;回车的扫描码
	je enter
	;非控制字符,回去继续读
	jmp short lis
	
backspace:
	;弹出字符，相当于退一个字符
	mov ah,1
	call str
	mov ah,0
	call str ;显示字符
	jmp short lis ;回去继续监听
	
enter:
	;回车结束
	mov ah,0
	mov al,0
	call str
	;显示字符
	mov ah,2
	call str
	
	;恢复寄存器
	pop ax
	;回车结束为字符添加一个/0结尾，同时结束程序
	ret
	;监听程序结束
	
	mov ax,4c00h
	int 21h
	
	;调用的函数，里面通过参数不同，使用不同子程序，实现不同功能
str:
	jmp start
	table dw pushstr,popstr,showstr ;建立向量表
	top dw 0  ;创建一个变量，做为栈顶
start:
	;保存寄存器
	push bx
	push dx
	push di
	push es
	
	;调用对应的向量子程序
	cmp ah,2 ;不是可用范围内的程序
	ja sret
	;获得程序入口
	mov bl,ah
	mov bh,0
	add bx,bx ;指定bx保存向量地址
	jmp word ptr table[bx]
	
	;各个不同功能的子程序
pushstr: ;将字符入栈，al为传入字符参数
	cmp top,32 ;判断是否满啦
	je sret
	mov bx,top  ;模拟实现栈功能，si——》栈底，bx——》栈顶
	mov [si][bx],al
	inc top
	jmp sret
popstr: ;将字符删除,ah——》功能，al——》保存/返回删除数据
	cmp top,0  ;栈顶为0，top指向要输入的地方
	je sret
	dec top   ;栈顶自减，指向需要出栈/删除的数据
	mov bx,top
	mov al,[si][top]
	jmp sret
show: ;展示字符，dh——》行，dl——》列
	mov bx,0b800h
	mov es,bx
	mov al,160
	mov ah,0
	mul dh
	mov di,ax
	add dl,dl
	mov dh,0
	add di,dx
	
	mov bx,0
charshows:
	cmp bx,top
	jne noempty
	mov byte ptr es:[di],' '
	jmp sret
	
noempty:
	mov al,[si][bx]  ;模拟bx从0栈底开始读取栈
	mov es:[di],al
	inc bx
	add di,2
	jmp charshows
	
sret:
	pop es
	pop di
	pop dx
	pop bx
	ret

code ends
end main
```

# 补充：软盘，硬盘

|用途|说明|
|---|---|
|**启动系统**|开机时 BIOS 从 A 盘的第一个扇区加载 DOS 引导程序，然后引导整个操作系统。当年的电脑没有硬盘也能用软盘启动到 DOS。|
|**安装操作系统**|Windows 3.1、Windows 95 等早期系统的安装盘就是几张软盘，一张一张插进去安装。|
|**运行和存储软件**|程序都装在软盘里，插进去运行，拔出来就没了。当年的软件也很小，一张 1.44MB 软盘能装不少东西。|
|**数据交换和备份**|没有 U 盘和网络的时代，软盘是唯一的便携存储介质。文件拷贝、文档传递全靠它。|
|**BIOS 升级和硬件驱动**|早期主板的 BIOS 升级工具和硬件驱动程序通常放在软盘里。|
