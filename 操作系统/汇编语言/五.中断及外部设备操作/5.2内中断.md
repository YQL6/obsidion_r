# 一.中断

## 1.1简介

---

- 中断：从原来顺序执行程序离开，执行其他中断信息
  ![[图片/Pasted image 20260805172623.png]]
	- 内中断：cpu内部发生的事件引起的中断
		- 除法中断：
			- 除数为0
			- 中断号为0
		- 单步中断：
			- 中断号为1
		- 溢出中断(into)
			- 数过大，溢出
			- 中断号为4
		- `int n`：
			- 立即数n为中断码
	- 外中断：外部设备引起的中断

## 1.2中断的使用

---

```asm
assume cs:code,ds:data,ss:stack
stack segment
	db 200h dup(0)
stack ends
data segment
	;以$结尾——》中断结束的标识符
	szmsg db 13,10,'hello world',13,10,'$'  ;13,10——》换行
data ends
code segment
main:
	mov ax,data
	mov ds,data
	lea dx,szmsg ;将标号的偏移地址取出
	mov ah,9  ;设置中断功能,21h的第9号中断功能——》输出一个ds:dx的字符串，以$结尾
	int 21h   ;中断号为21的中断——》处理DOS中断
	
	mov ax,4c00h ;ah:4c——》程序即可执行，退回DOS状态
	int 21h
code ends
end main
```

- cpu接到中断信息怎么办
	- 执行中断处的程序
- 中断处理程序
	- 中断信息和其处理程序入口间由关系，cpu根据中断信息找到要执行的处理程序
- 中断向量表：
	- 根据中断类型码，查找中断处理程序的入口地址，确定中断程序
	- 中断类型码——》识别什么类型的字段——》<mark style="background: #FF5582A6;">中断程序（包含多个中断功能）</mark>——》中断的功能
	- 中断信息——》发生中断的事件

- 中断向量表：
  ![[图片/Pasted image 20260805193309.png]]
	- 一个中断程序的入口固定：大小为4个字节
		  IP
		  CS
	- 一共256个中断程序
	- 中断号——》中断程序：`(IP) = (N * 4),(CS) = (N * 4 + 2) `
	- 中断程序保密

- 中断过程：
  ![[图片/Pasted image 20260805194615.png]]
	- 中断过程由cpu的<mark style="background: #FF5582A6;">硬件自动完成</mark>
	- 用中断类型找到中断向量，并设置`CS和IP`
	- 具体过程：
		- 从中断信息获得中断类型码
		- 保存现场——》标志寄存器的值入栈
		- 设置标志寄存器的第8位TF和第9位IF的值为0
		- <mark style="background: #FF5582A6;">CS入栈</mark>
		- <mark style="background: #FF5582A6;">IP入栈</mark>
		- 从中断向量表读取中断处理程序的入口地址，设置CS和IP

注：
1. 中断中机器处理的部分是cs，ip寄存器保存，cs，ip寄存器设置，标志寄存器保存
2. 中断返回由程序解决

# 二.中断程序

## 2.1编制中断处理程序

---

- 中断程序存放在中断向量表中
	- 中断程序，常驻内存之中
	- 中断处理程序的入口地址——》中断向量

- 示例：除法错误
	- 系统自备
	- 自己重新编写: 预期效果：屏幕中央显示`overflow`，然后返回操作系统
		- 问题分析：
			- 相关处理：
				- 保存现场
			- 想缓冲区发送`overflow!`
			- 返回DOS
			- 将自己编写的中断程序存放到一个地方
				1. 所有硬件资源都是由操作系统管理——》向操作系统申请
				2. 绕开操作系统（汇编是底层语言）
					- 找到一个无用的内存空间
						- 内存:`0000:0000~0000:03FE`保存256个中断程序，未用满
						- 选择`0000:0200~0000:02FF`256个字节存储
						- `CS：0000` `IP:0200`——》中断程序入口
						- `CS:0000 IP:0000~IP:0004`中断程序入口存放位置
```asm
assume cs:code
code segment
main: 
	;do0安装程序——》将程序放入固定位置
	mov ax,cs
	mov ds,ax
	mov si,offset do0
	mov ax,0
	mov es,ax
	mov di,200h
	mov cx,offset do0_end - offset do0
	rep movsb
	;设置中断向量表
	mov ax,0
	mov es,ax
	mov word ptr es:[4 * 0],200h
	mov word ptr es:[0*4 + 2],0
	mov ax,4c00h
	int 21h
	
do0:  ;显示字符串'overflower!`
	jmp short do_start
	db 'overflower!'  ;将数据存放在代码区，跟随代码一起移动
do_start:
	mov ax,cs
	mov ds,ax
	mov si,202h  ;变量标号不能表示
	
	mov ax,0b800h
	mov es,ax
	mov di,12*160 +35*2
	mov cx,10
	mov cx,11
s:
	mov al,[si]
	mov es:[di],al
	inc si
	add di,2
	loop s
	mov ax,4c00h
	int 21h
do0_end:
	nop
code ends
end main
```

注：
1. 中断程序之前硬件进行保存一部分寄存器，通用寄存器需要程序保存

## 2.2单步中断

---

- `t命令`
	- 原执行顺序：
		- 取指令
		- 改变`CS:IP`
		- 执行指令
		- ...重复
	- 单步中断执行
		- 使用<mark style="background: #FF5582A6;">cpu提供</mark>的单步中断功能
		- 将TF标志设为1，每执行一条指令查看TF是否停下
		- <mark style="background: #FF5582A6;">将TF，IF设为0——》中断程序也是一条一条指令构成，每执行一条，可能发送中断，不让它中断</mark>
		- 执行中断程序
		- 执行指令后
		- 执行中断程序：寄存器信息和下一条信息，中断号为1
	- 自定义单步中断程序——》实现特殊功能

## 2.3TF和IF

- TF(trap flag):调式时的单步操作，<mark style="background: #FF5582A6;">看执行完指令后是否要系统控制计算机</mark>
	- `TF = 1`:产生陷阱，由系统操作计算机
	- `TF = 0`:正常执行

- TF程序执行过程
	- cpu检测到`TF = 1`，执行中断操作
	- 执行`0000:0004`/1号的中断程序
	- 中断程序在操作系统中，交给操作系统执行

- `IF`(Interrupt flag):是否允许响应中断
	- `IF = 1`：<mark style="background: #FF5582A6;">允许外部响应中断</mark>
	- `IF = 0`:<mark style="background: #FF5582A6;">不允许外部响应中断</mark>
	- 有些情况下，cpu执行完当前指令后，即使发送中断，cpu也不响应——》IF = 0
	- 示例：
		- 代码：
			- `mov ax,1000`
			- `mov ss,ax`
			- `mov sp,10`
		- `SS,SP`的执行是特殊设计，SS后面必须与其一起执行——》`ss,sp`一起设置

- 中断执行：
	- 取得中断类型码1
	- 标志寄存器入栈，TF，IF为0
	- CS，IP入栈
	- 设置中断程序IP，CS

## 2.4 int

---

- `int N`:
	- `N`:中断类型码——》引发中断类型
		- 示例:
			- `int 0`:调用除法错误
	- 执行过程：
		- 取中断类型码
		- 标志寄存器入栈，IF=0，TF = 0
		- CS，IP入栈
		- 设置中断程序的CS与IP
	- int指令调用子程序
		- 子程序——》<mark style="background: #FF5582A6;">中断处理程序/中断例程</mark>——》自定义子程序，实现特殊功能

- 安装子程序过程：
```ams
assume cs:code
code segment:
main:
	;安装中断程序
	mov ax,cx  ;获得code段的地址
	mov ds,ax  ;设置movsb指令的数据原的段地址
	mov si,offset sbeg
	mov ax,0
	mov es,ax  ;设置es段的地址，做为目的地地址使用
	mov di,200h ;设置偏移地址
	mov cx,offset sbeg - offset send ;设置程序大小/循环次数
	cld  ;设置复制数据的方向，反方向走
	rep movsb   ;复制程序
	;设置中断向量表
	mov ax,0
	mov es,0  ;设置段地址指向子程序的保存位置
	mov word ptr es:[7ch * 4],200h
	mov word ptr es:[7ch * 4 + 2],0
	mov ax,4c00h
	int 21h
sbeg:
	;中断例程
	;按子程序格式写中断处理程序
	;除了CS，IP，标志寄存器都需要保存
	mul ax
	iret
send:nop
```

- `iret`:
	- 功能：
		- 执行恢复寄存器
	- 类似：
		- `pop IP`
		- `pop CS`
		- `popf`


注：
1. int与call类似，都是调用一段程序——》一些特殊功能的子程序以中断程序提供给应用程序使用

# 三.BIOS中断处理与DOS中断处理

## 3.1BIOS

---

- BIOS:系统板的<mark style="background: #FF5582A6;">ROM中存放的一套程序</mark>
	- 容量：8KB
	- 地址：（统一编码）从FE000H开始
	- 主要内容：
		- 硬件系统的检测和初始化程序
		- 外部中断和内部中断的中断例程
		- 对于硬件设备进行I/O操作的中断例程
		- 其他和硬件系统相关的中断例程
	- 直接使用BIOS的例程，直接使用指令设置参数，操作硬件

| 对比项  | 主板 BIOS              | 网卡 BIOS（EEPROM）                |
| ---- | -------------------- | ------------------------------ |
| 位置   | 主板上的 ROM 芯片          | 网卡上的 EEPROM 芯片[1]              |
| 负责对象 | **整台电脑**的启动和硬件初始化[2] | **网卡自身**的标识和配置[1]              |
| 主要作用 | POST、引导操作系统[2]       | 记录 MAC 地址、供应商信息、引导配置[1]        |
| 引导功能 | 从硬盘/光驱/网络启动系统[2]     | 无盘工作站从网络引导（BOOTROM）[3]         |
| 可升级性 | 通过刷写 BIOS 升级         | 可烧写，甚至可通过 BOOTROM 实现硬盘保护卡功能[3] |

- 示例：操作显示器，设置5行14列由3个高亮的`a`
	- 问题分析：
		- 直接操作显存
		- 使用BIOS提供的例程
			- 使用`10h`的例程
				- `(ah) = 2`：调用2号子程序，设置光标位置
				- `(ah) = 9`：调用9号子程序，设置光标位置处的字符
	- 编写程序：
```asm
assume cs:code
code segment
main:
	mov ah,2 ;置光标的功能
	mov bh,0 ;第0页
	mov dh,5 ;dh中方行号
	mov dl,14 ;dl中方列号
	int 10h ;执行中断
	 
	mov ah,9 ;显示字符
	mov al,'a' ;字符
	mov bl,11001010b ;设置字符属性
	mov bh,0 ;第0页
	mov cx ;字符重复3个
	int 10h
	
	mov ax,4c00h
	int 21h
code ends
end main
```

- BIOS功能大全——网上查询手册，有具体描述

## 3.3BIOS与DOS安装例程

- 过程：
	- 通电：
		- 初始化(cs) = 0FFFFH,(IP)=0,自动从`FFFF:0`单元开始执行程序
		- 此处由跳转指令，`jmp`跳转到BIOS检测及初始化
	- 初始化中断向量
		- 建立BIOS支持的中断向量到向量表中
		- 建立DOS支持的中断向量到向量表中
	- 硬件系统检测和初始化后，调用`int 19h`进行操作系统的引导，交给操作系统控制
	- DOS启动后，完成其他工作外，将DOS提供的中断例程装入内存，建立相应的中断向量
