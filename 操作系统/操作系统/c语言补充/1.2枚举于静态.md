## 一、枚举 enum：给整数起名字的类型

**是什么**：枚举是一种"整数常量集合"——把一组相关的常量用一个类型包起来。

```
enum Color { RED, GREEN, BLUE };

enum Color c = RED;      // 用法：像类型一样声明变量
```

**值怎么来**：默认从0开始递增，也可以手动指定：

```
enum Color { RED, GREEN = 5, BLUE };   // RED=0, GREEN=5, BLUE=6
```

**典型用途**：

- **状态机**（你的OS课程会狂用）：`enum State { IDLE, RUNNING, STOPPED };`
- **常量组**：错误码、菜单选项、方向；
- **位标志**：

```
enum Flag { F_READ = 1, F_WRITE = 2, F_EXEC = 4 };
// 组合：F_READ | F_WRITE
```

**匿名枚举**：不想声明类型，只想要一组常量：

```
enum { MAX_LEN = 100, BUF_SIZE = 256 };
```

**和 #define / const 怎么选**：

|方式|类型检查|调试友好|推荐度|
|---|---|---|---|
|`#define`|无|差（纯文本）|常量首选**不推荐**|
|`const int`|有|中|单个常量用|
|`enum`|有|**好（调试器认名字）**|**一组相关常量首选**|

**两个坑**：

1. 枚举的底层类型一般是 int（不同编译器可能有差异），别指望它一定很"小"；
2. 打印用 `%d`：`printf("%d", RED);`

## 二、static：一个词，两个完全不同的意思

**意思1：函数内的静态局部变量（生命周期延长）**

普通局部变量在栈上，函数结束就没了；加 static 后，变量**存放在数据段，程序整个生命周期都存在**，只在第一次进入函数时初始化一次：

```
void counter(void) {
    static int n = 0;    // 只初始化一次
    n++;
    printf("%d\n", n);   // 每次调用依次输出1,2,3...
}
```

这正是我们之前聊过的"已初始化数据"——`static int n = 0` 进 `.data`，没写初始值的 `static int x;` 进 `.bss`（自动清零）。**你在汇编里学的段知识，C语言里就是这么体现的。**

**意思2：文件内的静态变量/函数（限制可见范围）**

在函数外面写 static，意思是"**这个变量/函数只在本文件内可见**"，其他源文件引用不到：

```
// fileA.c
static int secret = 42;          // 只有fileA能用
static void helper(void) {}      // 只有fileA能调

// fileB.c 里用 extern 也找不到它们
```

作用：**防止多文件工程里的名字冲突**——两个文件都定义 `static int count` 互不干扰；不写 static 的全局变量，链接时全工程共享，重名会报错。这和你汇编里 PUBLIC/PRIVATE 的"跨模块可见性"是一个道理！

## 三、static 的完整对照表

|位置|作用|生命周期|可见性|存放位置|
|---|---|---|---|---|
|函数内局部变量 + static|值跨调用保留|整个程序|仅本函数|.data/.bss|
|全局变量 + static|文件私有|整个程序|仅本文件|.data/.bss|
|函数 + static|文件私有函数|整个程序|仅本文件|.text|
|普通局部变量|每次调用重建|函数执行期间|仅本函数|栈|

## 四、几个易踩的坑

1. **static 局部变量不是线程安全的**：多线程同时调 `counter()` 会竞争，OS课程里你迟早会撞上；
2. **递归函数里用 static**：所有递归层共享同一个变量（和普通局部变量每层一份不同），行为常常出人意料；
3. **static 数组很大时放数据段**：`static char big[1MB];` 不占栈，但占程序映像（.bss），嵌入式里要注意；
4. **C语言没有"static成员变量"**：那是C++的概念，别混。

## 一句话总结

- **enum** = 给一组整数常量起名字的类型，比 #define 类型安全、调试友好，状态机/常量组/位标志首选；
- **static** = 函数内的"活到程序结束的局部变量"（存数据段、初始化一次）+ 文件级"仅本文件可见"（跨文件隔离），两个意思一个管生命周期、一个管可见性，正好对应汇编里的段存储和PUBLIC/PRIVATE可见性。


匿名枚举 = `enum { 常量 }`，只产常量不产类型：单独用就是"一组有名字的编译期常量"（数组大小、case标签、标志位）；配合 `typedef enum { ... } 名字;` 才是给它"补发"一个类型名，变成既能用常量又能声明变量的完整枚举。
