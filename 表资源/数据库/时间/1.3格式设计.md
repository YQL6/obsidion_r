
- 常用

|类别|格式符|含义|示例|
|---|---|---|---|
|年份|`%Y`|4 位年份|`2026`|
|年份|`%y`|2 位年份|`26`|
|月份|`%M`|英文月份全称|`September`|
|月份|`%m`|两位数字月份，补零|`09`|
|月份|`%b`|英文月份缩写|`Sep`|
|月份|`%c`|数字月份，不补零|`9`|
|日期|`%D`|英文日期序数|`5th`|
|日期|`%d`|两位数字日期，补零|`05`|
|日期|`%e`|数字日期，不补零|`5`|
|小时|`%H`|24 小时制，两位，补零|`14`|
|小时|`%h`|12 小时制，两位，补零|`02`|
|小时|`%I`|同 `%h`，12 小时制|`02`|
|小时|`%k`|24 小时制，不补零|`14`|
|小时|`%l`|12 小时制，不补零|`2`|
|分钟|`%i`|两位分钟，补零|`30`|
|秒|`%s`|两位秒数，补零|`05`|
|秒|`%S`|同 `%s`|`05`|
|午前午后|`%p`|`AM` 或 `PM`|`PM`|

- 扩展：

|格式符|含义|范围 / 示例|
|---|---|---|
|`%a`|星期缩写|`Sun` ～ `Sat`|
|`%W`|星期全称|`Sunday` ～ `Saturday`|
|`%w`|星期数字|`0`＝星期日，`6`＝星期六|
|`%j`|一年中的第几天|`001` ～ `366`|
|`%f`|微秒|`000000` ～ `999999`|
|`%U`|周数，星期日为一周第一天|`00` ～ `53`|
|`%u`|周数，星期一为一周第一天|`00` ～ `53`|
|`%V`|周数，星期日为一周第一天|`01` ～ `53`，通常配合 `%X`|
|`%v`|周数，星期一为一周第一天|`01` ～ `53`，通常配合 `%x`|
|`%X`|周所属年份，星期日为第一天|4 位年份|
|`%x`|周所属年份，星期一为第一天|4 位年份|
|`%r`|12 小时制完整时间|`02:30:05 PM`|
|`%T`|24 小时制完整时间|`14:30:05`|
|`%%`|输出一个百分号|`%`|

- 常用组合:

| 格式字符串                  | 输出结果                            |
| ---------------------- | ------------------------------- |
| `%Y-%m-%d`             | `2026-09-05`                    |
| `%Y/%m/%d %H:%i:%s`    | `2026/09/05 14:30:05`           |
| `%M %D, %Y`            | `September 5th, 2026`           |
| `%b %e, %Y`            | `Sep 5, 2026`                   |
| `%Y-%m-%d %h:%i:%s %p` | `2026-09-05 02:30:05 PM`        |
| `%Y%m%d%H%i%s`         | `20260905143005`                |
| `%W, %M %D, %Y`        | `Saturday, September 5th, 2026` |
