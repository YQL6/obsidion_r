
| 语句                | 含义                                |
| ----------------- | --------------------------------- |
| CONTAINS SQL      | 过程里包含 SQL 语句，但既不读也不改数据（默认值，基本是摆设） |
| NO SQL            | 过程里不含 SQL 语句，纯计算/逻辑               |
| READS SQL DATA    | 只读数据（只有 SELECT，没有增删改）             |
| MODIFIES SQL DATA | 会修改数据（有 INSERT / UPDATE / DELETE） |
