| 数据结构 | 推荐实现类           | 理由                  |
| ---- | --------------- | ------------------- |
| 栈    | `ArrayDeque`    | 效率高，替代 `Stack` 类    |
| 队列   | `ArrayDeque`    | 效率高，替代 `LinkedList` |
| 优先队列 | `PriorityQueue` | 支持优先级排序             |
## 一、栈（Stack）：LIFO（后进先出）

Java 中不推荐使用遗留类 `java.util.Stack`（继承自 `Vector`，效率低且设计过时），而是使用 **`Deque` 接口** 作为栈。

### 1. 常用实现类

- **`ArrayDeque`**：基于数组，非线程安全，效率高（推荐首选）。
- **`LinkedList`**：基于链表，非线程安全，可作为栈使用。
### 2.核心方法（栈操作）
| 方法          | 说明            |
| ----------- | ------------- |
| `push(E e)` | 元素入栈（压入栈顶）    |
| `pop()`     | 元素出栈（弹出栈顶并移除） |
| `peek()`    | 查看栈顶元素（不移除）   |
```java
//使用 ArrayDeque 作为栈 
Deque<Integer> stack = new ArrayDeque<>(); stack.push(1); // 入栈 
stack.push(2); System.out.println(stack.pop()); // 输出 2（出栈）
 System.out.println(stack.peek()); // 输出 1（查看栈顶）
```

## 二、队列（Queue）：FIFO（先进先出）

Java 中使用 **`Queue` 接口** 定义队列操作，常用实现类如下。

### 1. 常用实现类
| 实现类             | 特点             | 适用场景          |
| --------------- | -------------- | ------------- |
| `ArrayDeque`    | 基于数组，非线程安全，效率高 | 普通队列（推荐首选）    |
| `LinkedList`    | 基于链表，非线程安全     | 普通队列          |
| `PriorityQueue` | 优先队列（元素按优先级排序） | 任务调度、TOP K 问题 |
|                 |                |               |
|                 |                |               |

### 2. 核心方法（队列操作）
| 操作   | 说明（抛出异常）    | 说明（返回特殊值）    |
| ---- | ----------- | ------------ |
| 入队   | `add(E e)`  | `offer(E e)` |
| 出队   | `remove()`  | `poll()`     |
| 查看队首 | `element()` | `peek()`     |
示例代码：
```java
// 使用 ArrayDeque 作为普通队列 
Queue<Integer> queue = new ArrayDeque<>(); queue.offer(1); // 入队 
queue.offer(2);
 System.out.println(queue.poll()); // 输出 1（出队） 
 System.out.println(queue.peek()); // 输出 2（查看队首） // 优先队列示例（默认自然排序，可自定义 Comparator） 
 Queue<Integer> priorityQueue = new PriorityQueue<>(); priorityQueue.offer(3); priorityQueue.offer(1); priorityQueue.offer(2); System.out.println(priorityQueue.poll()); // 输出 1（优先级最高）
```
## 三、双端队列（Deque）：两端可操作

`Deque` 接口继承自 `Queue`，支持在**头部和尾部**同时插入 / 删除元素，因此可同时作为栈、队列或双端队列使用。

### 1. 核心方法（双端操作）
| 操作  | 头部方法（抛出异常）      | 头部方法（返回特殊值）       | 尾部方法（抛出异常）     | 尾部方法（返回特殊值）      |
| --- | --------------- | ----------------- | -------------- | ---------------- |
| 插入  | `addFirst(E e)` | `offerFirst(E e)` | `addLast(E e)` | `offerLast(E e)` |
| 删除  | `removeFirst()` | `pollFirst()`     | `removeLast()` | `pollLast()`     |
| 查看  | `getFirst()`    | `peekFirst()`     | `getLast()`    | `peekLast()`     |
