哈希：
1. 哈希函数：将对象对应到哈希表中的下标
2. 哈希冲突：无法避免，只可能减少
3. 哈希函数得到的下标一样——》不一定为一个对象，不一样——》一定不是一个对象

字符串常用操作：匹配，比较，字串
所以字符串哈希函数：
1. s[i]存储字符串：1 ——n
2. 将字符串转化为整数，<mark style="background: #FF5582A6;">将字符串转化为整数存储，需要时转化回去</mark>
3. f(s) = ∑_{i=1}^{n} s[i] * b^l-i (mod M)    , l为字符串的长度，b是一个比最大字符大的整数(最好为质数），M是比最大字符大的质数
例如： s = "xyz" , f(s) = x * b^2 + y * b^1+z *  b^0;  与进制转换为10进制类似，此函数为b进制，若从0开始存储：f(s) = ∑_{i=1}^{n} s[i] * b^l-i-1 (mod M)
为什么选这个哈希函数：字符串一般是和子串向关的题目——》方便计算子串的哈希值

例：长度为n的字符串，s[0] ~s[n -1] , s= "eadfoi"' , 前缀子串的哈希值：
hash[0] "e"
hash[1] "ea"
————————
hash[4] "eadfo"
hash[5] "eadfoi"
共n + 1个子串，暴力求解O(N^2) ,for遍历到最后内部加一个for累加，类似前缀和优化——》O(N)——》hash[i - 1] 与hash[i]简单关系
hash[i] 与hash[i - 1] :
hash[0] = s[0];
hash[1] = s[0] * b + s[1] * b^0;
hash[2] = s[0] * b^2 + s[1] *b^1 + s[2]* * b^0;
hash[i] = hash[i - 1] * b + s[i];

>[!summary] + 重点公式
><mark style="background: #FF5582A6;">hash[i] = hash[i - 1]  *  b + s[i];</mark>
>注：忽略了取模，但是在最后加上任然一样
>求解公式与进制一样：111——》1111——》`` 111  *  2`` + 1
``` 
111 * 2
```


类比前缀和求区间和的关系：
s[l] ~s[r] 的子串：到r的前缀和 去掉 到l -1的前缀和 ，长度为 r - l + 1
暴力：h = s[r] * b^0 + s[r - 1] * b^1 + ... + s[l] * b^r-l;
前缀和：s[0]~s[l] ——》hash[l] ,s[0] ~ s[r] ——》hash[r]
h[l - 1] = s[0] * b^l-1-1 + s[1] * b^l-1-2 + ... + s[l-1] * b^0;
h[r]      = s[0]  * b^r - 1 + s[1] * b^r-2   + ...+ s[l - 1] * b^r-l+1+ ...+ s[r] * b^0;
看相同的部分：h[r] 都比h[l - 1]多乘r-1 - (l - 1 -1) = r - l + 1 * h[l - 1];
多余的部分：s[l] * b^l-r + s[l - 1] * b^r-l-1 + ... s[r] * b^0  = s[l] ~ s[r];
所以：h[r] = h[l - 1] * b^(r - l + 1)  + h——》h = h[l - 1] * b^(r - l + 1) - h[r]; 
>[!summary] + 重点公式
><mark style="background: #FF5582A6;">h = h[l - 1] * b^(r - l + 1) - h[r]; </mark>
注：快速求b^n 的方法——》类似前缀和方式<mark style="background: #FF5582A6;">预处理</mark>

以上为获得子串通过前缀字符串获得的方法——》<mark style="background: #FF5582A6;">滚动哈希</mark>

底层原理：
eadfoi hash[r] 
eadf    hash[l - 1]
oi要加入到h[l - 1]直接变为完整的字符串——》h[l - 1] * b^r-l+1 + h = h[r];
h = h[r] - h[l - 1] * b^r-l+1    与进制添加相同

时间复杂度为O(n)——》预处理base[i]/b[i]为O(n)  ,预处理前缀字符串的hash为O(n),求子串的hash为O(1)
求所有子串的个数为n* (n - 1) /2 , 找所有hash为O(n^2)

所以此方法好求子串

# 降低哈希碰撞问题

f(s) = ∑_{i=1}^{n} s[i] * b^l-i (mod M)——》范围[0 , M -1]——》尽量让M大，避免哈希碰撞
无符号类型超出范围，只保留类型范围内的二进制：0~2^64 -1 ,自动取余,默认2^64取余
>[!summary] + java的无符号
>java中无符号关键字，只需要long类型定义即可，不涉及符号操作作用同

速度：自然溢出 > 单hash > 双hash
安全：双hash > 单hash

# P3370 【模板】字符串哈希

## 题目描述

如题，给定 $N$ 个字符串（第 $i$ 个字符串长度为 $M_i$，字符串内包含数字、大小写字母，大小写敏感），请求出 $N$ 个字符串中共有多少个不同的字符串。


**友情提醒：如果真的想好好练习哈希的话，请自觉。**

## 输入格式

第一行包含一个整数 $N$，为字符串的个数。

接下来 $N$ 行每行包含一个字符串，为所提供的字符串。

## 输出格式

输出包含一行，包含一个整数，为不同的字符串个数。

## 输入输出样例 #1

### 输入 #1

```
5
abc
aaaa
abc
abcc
12345
```

### 输出 #1

```
4
```

## 说明/提示

### 数据范围

对于 $30\%$ 的数据：$N\leq 10$，$M_i≈6$，$M_{\max}\leq 15$。

对于 $70\%$ 的数据：$N\leq 1000$，$M_i≈100$，$M_{\max}\leq 150$。

对于 $100\%$ 的数据：$N\leq 10000$，$M_i≈1000$，$M_{\max}\leq 1500$。

### 样例说明

样例中第一个字符串 $\tt{abc}$ 和第三个字符串 $\tt{abc}$ 是一样的，所以所提供字符串的集合为 $\{\tt{aaaa},\tt{abc},\tt{abcc},\tt{12345}\}$，故共计 $4$ 个不同的字符串。
