数据结构简单算法：
```java
public int bs(int[] a , int tg , int n){  
    int l = 0 , r = n - 1;  
    while(l <= r){  
        int mid = (l + r) / 2;  
        if(a[mid] == tg){  
            return a[mid];  
        } else if (a[mid] > tg) {  
            r = mid - 1;  
        }else{  
            l = mid + 1;  
        }  
    }  
    return -1;  
}
```

# P1873 [COCI 2011/2012 #5] EKO / 砍树

## 题目描述

伐木工人 Mirko 需要砍 $M$ 米长的木材。对 Mirko 来说这是很简单的工作，因为他有一个漂亮的新伐木机，可以如野火一般砍伐森林。不过，Mirko 只被允许砍伐一排树。

Mirko 的伐木机工作流程如下：Mirko 设置一个高度参数 $H$（米），伐木机升起一个巨大的锯片到高度 $H$，并锯掉所有树比 $H$ 高的部分（当然，树木不高于 $H$ 米的部分保持不变）。Mirko 就得到树木被锯下的部分。例如，如果一排树的高度分别为 $20,15,10$ 和 $17$，Mirko 把锯片升到 $15$ 米的高度，切割后树木剩下的高度将是 $15,15,10$ 和 $15$，而 Mirko 将从第 $1$ 棵树得到 $5$ 米，从第 $4$ 棵树得到 $2$ 米，共得到 $7$ 米木材。

Mirko 非常关注生态保护，所以他不会砍掉过多的木材。这也是他尽可能高地设定伐木机锯片的原因。请帮助 Mirko 找到伐木机锯片的最大的整数高度 $H$，使得他能得到的木材至少为 $M$ 米。换句话说，如果再升高 $1$ 米，他将得不到 $M$ 米木材。

## 输入格式

第 $1$ 行 $2$ 个整数 $N$ 和 $M$，$N$ 表示树木的数量，$M$ 表示需要的木材总长度。

第 $2$ 行 $N$ 个整数表示每棵树的高度。

## 输出格式

$1$ 个整数，表示锯片的最高高度。

```
20 15 10 17
```

### 输出 #1

```
15
```

## 输入输出样例 #2

### 输入 #2

```

```

### 输出 #2


## 说明/提示

对于 $100\%$ 的测试数据，$1\le N\le10^6$，$1\le M\le2\times10^9$，树的高度 $\le 4\times 10^5$，所有树的高度总和 $>M$。
>[!summary]+ 思路
>首先一定能确定切树高度一定在0—max{各树的高度}——结果在一定范围，可以用二分法缩小范围，假定mid满足条件，看mid能否将题目中的无用条件推出（使用二分法前未用到的值），可以则用二分法，未用条件为tag,
>以结果推条件，二分法一般给一个无用条件
>若mid大于等于m,mid可能为答案，记录，可能在高一点，注意数组在大等于tg时r左移动，但是这里h是数组，而大于等于的是长度，应该是可以长度在低点，即高度在高一点，l向右移动

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        tree tree = new tree();
        int n = sc.nextInt();
        int m = sc.nextInt();
        int a[] = new int[n];
        for(int i = 0 ; i < n ; i++){
            a[i] = sc.nextInt();
        }
        System.out.println(tree.bs(a , m , n));
    }
}
class tree{
    public int bs(int[] a , int tg , int n ){
        int max = 400005;
        int l = 0 , r = max ;
        int ans = 0;
        while(l <= r ){
            int mid = (l + r) / 2;
            if(check(a , mid) >= tg){
                ans = mid;
                l = mid + 1;
            }else{
                r = mid - 1;
            }
        }
        return ans;
    }
    long check(int[] a , int mid){
        long sums = 0 ;
        int tmp = 0;
        for(int i = 0 ; i < a.length ; i++){
            tmp = a[i] - mid;
            if(tmp >= 0){
                sums += tmp;
            }
        }
        return sums;
    }
}
```

>[!summary]+ 重大错误
>l = mid 避免死循环要 l < r + 1 ,但是会少算r上的数！！！！
>为了不跳过，多加一个ans 记录符合条件的l，每次都记录而l跳向未知的区间！！！！
>死循环问题！！！
>避免跳过——>找最值就要避免
>return
>注意范围问题，可能用到long类型,


>[!summary]+ 总结!!!!!!!
>二分法问题：
>答案一定在一个范围中，要不断缩小范围逼近，题目中常给出无用条件使，二分法假定mid为答案来判断无用条件，常需要一个check函数来与无用条件来比较，check可难可简单,要注意check的解决
>注：数据结构中二分法找固定的值，可以直接跳过mid使范围更小，而最值问题要不断逼近过程中mid可能就是答案要避免跳数——>解决问题：
>1. 使用ans记录mid，有比ans更贴近/最值的就是更新，没有即为答案
>2. 不使用ans:
>	1. ans记录r:r > l , r = mid ,  L = mid + 1 , return r
>	2. ans记录l:r >= l , r = mid - 1  , l = mid + 1 , return r
>一定要写完举一个相近两个数的例子判断合不合理！！

 # P2678 [NOIP 2015 提高组] 跳石头

## 题目背景

NOIP2015 Day2T1

## 题目描述

一年一度的“跳石头”比赛又要开始了！

这项比赛将在一条笔直的河道中进行，河道中分布着一些巨大岩石。组委会已经选择好了两块岩石作为比赛起点和终点。在起点和终点之间，有 $N$ 块岩石（不含起点和终点的岩石）。在比赛过程中，选手们将从起点出发，每一步跳向相邻的岩石，直至到达终点。

为了提高比赛难度，组委会计划移走一些岩石，使得选手们在比赛过程中的最短跳跃距离尽可能长。由于预算限制，组委会至多从起点和终点之间移走 $M$ 块岩石（不能移走起点和终点的岩石）。

## 输出格式

一个整数，即最短跳跃距离的最大值。

>[!summary] + 思路
>最后要求的数——>范围，结果,与其有关的——>其中有无用条件与check
>条件——>结果（正常思维）：刚开始可以找到一个最短跳跃距离，按要求移走（满足不超过M块岩石即可），会有不情况下的最短跳跃距离
>结果——>条件（反推）：以mid反推无用条件，范围：1-起点到终点，假定mid为正确答案反推要移走多少块岩石
>反推：mid去看各区间是否符合条件，不满足——>移动

>[!summary] + check(双指针)
>now,next来模拟移动石头的变化，最终只需要移动的石头的数量，让next每次都移动，保证next后面有石头

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        int l , m , n;
        Scanner sc = new Scanner(System.in);
        l = sc.nextInt();
        n = sc.nextInt();
        m = sc.nextInt();
        int a[] = new int[n + 2];
        for(int i = 1 ; i <= n ; i++){
            a[i] = sc.nextInt();
        }
        a[0] = 0;
        a[n + 1] = l;
        Solution sol = new Solution();
        System.out.println(sol.minEatingSpeed(a,m));
    }
}
class Solution {
    public int minEatingSpeed(int[] a, int m) {
        int l = 1 , r = a[a.length - 1];
        int ans = 0;
        while(l <= r){
            int mid = l + (r - l)/2;
            if(check(a , mid , a.length - 1) <= m){
                ans = mid;
                l = mid + 1;
            }else {
                r = mid - 1;
            }
        }
        return ans;
    }
    public long check(int[] p , int mid , int n){
       int sums = 0 ,  now = 0 , next = 0;
       while(next < n){
           next++;
           if(p[next] - p[now] >= mid){
               now = next;
           }else{
               sums++;
           }
       }
        return sums;
    }
}
```

>+ 无用条件：反推对象，大概率要用数组建立与求解的答案mid间的关系
