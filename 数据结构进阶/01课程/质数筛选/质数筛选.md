<mark style="background: #FFB86CA6;">质数筛选法：找区间所有质数保存到数组中</mark>
方法：
1. 朴素算法
2. 埃氏算法
3. 欧拉算法
# 朴素算法
判断x是否为质数：√x---2中x % y == 0
最简单的方法：
```java
import java.util.Scanner;  
public class zs {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        int[] arr = new int[n];  
        int count = 0;  
        for(int i = 2 ; i <= n ; i++){  
            if(isPrime(i) == 1){  
                arr[count++] = i;  
            }  
        }  
        System.out.println("有" + count + "个质数");  
    }  
    public static int isPrime(int n){  
        for(int i = 2 ; i <= Math.sqrt(n) ; i++){  
            if(n % i == 0){  
                return 1;  
            }  
        }  
        return 0;  
    }  
}
```
时间复杂度：O(n^（3/2）)
优化：从2以后的偶数必是质数(无用)

# 埃氏算法
<mark style="background: #FF5582A6;">基本原理：一个合数可以被分解为若干个质数的乘积的，将质数的倍数去（最初找到2是质数）掉剩下的都是质数</mark>
注：1既不是质数也不是合数
步骤：先默认都是质数
1. 先把1删除(1既不是质数也不是合数)
2. 读取数组中当前最小的数2，然后把2的倍數删去
3. 读取数组中当前最小的数3，然后把3的倍数删去
4. 读取数组中当前最小的数5，然后把5的倍数删去 
5. 一直读取数组中当前最小的状态为true的数n，然后把n的倍数删去
删去的过程中总是会留一个数，后面的数到不了，前面的数删不掉它，它就是质数，例如：2删掉4，3的话2删不掉，5删不到3，所以3是质数，再将3删掉，就是留一个5，后面同理
```java
import java.util.Scanner;  
public class zs {  
    //设n <= 10^6  
    static boolean isPrime[] = new boolean[1000005];  
    static int p[] = new int[1000005];  
    static int count;  
    //默认值为false，所以默认false表示质数,只可以赋值false,true  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        isPrime[1] = true;  
        isPrime[0] = true;  
        for(int i = 2 ; i <= n ; i++){  
            if(isPrime[i] == false){  
                for(int j = 2 * i ; j <= n ; j += i){//用加法来实现j的倍数  
                    isPrime[j] = true;  
                }  
                p[count++] = i;  
            }  
        }  
        for(int i = 0 ; i < count ; i++){  
            System.out.print(p[i] + " ");  
        }  
        System.out.println("有" + count + "个质数");  
    }  
}
```
其中可能重复标记：2的倍数12，3的倍数12，合数的质因数都会标记，浪费时间
时间复杂度：O(nlogn)><mark style="background: #FF5582A6;">O(nlog(logn))</mark>>O(n)
# 欧拉筛法：
<mark style="background: #FF5582A6;">原理：合数只被最小质因数标记筛去（后面的质因数直接跳过），合数的质因数一定小于合数本身，质因数最小的一个一定小于合数本身</mark>
注：合数y ,质数 a ,a筛掉y,所以y >= a^2，例如：3筛去的一定大于9，6会被2筛掉，3一定不是6的最小质因数。所以a只能筛掉比a^2的数，a的2---a-1倍会被比a小的质数筛掉，<mark style="background: #FF5582A6;">反过来a^2的最小质因数一定是a,若a不能分解为其他质数则就这一个质因数对</mark>
<mark style="background: #FF5582A6;">由上所述为了让a做为最小质因数筛掉的合数一定是从a^2开始比a^2小的会被比a小的筛掉</mark>
>[!summary]+ 重点
>x = a * a;开始筛掉以a为最小质因数的数，x筛掉，x往后呢？x = a * i; 将i = a ; i++;枚举
>i若是比a小的质数的倍数(即i可以分解)，则x的最小质因数不是a，而a必定不可能是质数的倍数（质数不可能是质数的倍数）
><mark style="background: #FF5582A6;">由上所述将x的最小质因数的是否是a——>i是否为比a小的质因数的倍数</mark>
>由于外层是a的枚举，刚开始a,i相同，i枚举（内层for)与a的枚举都是a向后枚举），两者合一

改进后的代码：
```java
import java.util.Scanner;  
public class zs {  
    //设n <= 10^6  
    static boolean isPrime[] = new boolean[1000005];  
    static int p[] = new int[1000005];  
    static int count;  
    //默认值为false，所以默认false表示质数,只可以赋值false,true  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        isPrime[1] = true;  
        isPrime[0] = true;  
        for(int i = 2 ; i <= n ;i++){  
            if(isPrime[i] == false){  
                p[count++] = i;  
            }  
            for(int j = 1 ; j <= count ; j++){  
                int x = i * p[j];  
                if(x > n){
	                break;
                }
                isPrime[x] = true;  
                if (i % p[j] == 0) {  //核心：找到第一个能分解的最小质因数就不找了，后面都不是最小的；
                    break;  
                 }  
             }  
        }  
        System.out.println("有" + count + "个质数");  
    }  
}
```
>[!summary]+ 重点！！！！
>将内层for与外层for融合，for承担起处理每一个数与用已存在质数的倍数筛掉合数的倍数（原理：筛数时要从本身的平方开始，所以外层for可以不为并未到达自身的质数提供倍数），要让每一个以达到条件的质数提供倍数筛掉合数，加一个内层for
>内层加一个for为已经添加的质数都提供倍数，其中x为筛掉的合数，i为倍数，p[j]为质数，<mark style="background: #FF5582A6;">当i可以分解为更小的质数（即p[<j]）时,p[j]不为最小质因数，不重复筛掉，因为p[j]是在内层for中从小到大，所以说从小到大的过程中就判断是否能将i分解为更小的质因数</mark>
