递归（英语：Recursion)，在数学和计算机科学中是指在<mark style="background: #FF5582A6;">函数的定义中使用函数自身的方法</mark>，在计算机科学中还额外指一种通过<mark style="background: #FF5582A6;">重复将问题分解为同类的子问题而解决问题的方法</mark>。

<mark style="background: #FF5582A6;">难点：递归出口与边界条件，难于找全</mark>
技巧：画递归树，理解递归代码，写到最底层——》递归出口/边界条件

例：斐波那契数列
```java
int fib(int x){
	if(x == 0 || x==1){
		return 1;
	}
	return fib(x - 1) + fib(x - 2);
}
```

写递归代码：确定<mark style="background: #FF5582A6;">一次递归函数是解决什么问题的</mark>（即一层解决什么问题），将调用的自身<mark style="background: #FF5582A6;">当数来用</mark>，只考虑当前问题解决（解决第i个小问题，只考虑第i个小问题，不要向下分解）不要想下面的问题怎么解决，<mark style="background: #FF5582A6;">下面怎么展开不管</mark>

[lk汉诺塔问题](https://leetcode.cn/problems/hanota-lcci/)
在经典汉诺塔问题中，有 3 根柱子及 N 个不同大小的穿孔圆盘，盘子可以滑入任意一根柱子。一开始，所有盘子自上而下按升序依次套在第一根柱子上(即每一个盘子只能放在更大的盘子上面)。移动圆盘时受到以下限制:  
(1) 每次只能移动一个盘子;  
(2) 盘子只能从柱子顶端滑出移到下一根柱子;  
(3) 盘子只能叠在比它大的盘子上。

请编写程序，用栈将所有盘子从第一根柱子移到最后一根柱子。

**示例 1：**

 **输入**：A = [2, 1, 0], B = [], C = []
 **输出**：C = [2, 1, 0]

**示例 2：**

 **输入**：A = [1, 0], B = [], C = []
 **输出**：C = [1, 0]

**提示：**

1. A 中盘子的数目不大于 14 个。
>[!summary]+ 思路
>简化问题：将A，B、C，三个柱子上的盘子按要求从A移动到C，B作为辅助

![[数据结构进阶/01课程/递归，分治/汉诺塔问题分析|汉诺塔问题分析]]

>[!summary]+ 模拟过程
>1. 将1移到C上
>2. 将1移到辅助B上，2移到C上
>3. 将1，2移到B上-----a，将3移到C上------b，将1，2移到C上-----c
>a:n = 2
>b:n = 1
>c: n = 1
>将n = 3 拆解为几个小问题，需要n = 1,2的初始状态

>[!summary]+ 推广
>现将n = 1, 2所有方法抽象出来，包装成函数，有三个变量：起始位置，终点位置，辅助位置盘中数量
>解决n的汉诺塔：将n-1到2视为一个整体甲，1最大的视为一个整体乙，将甲移到B上，将乙移到C上——》甲要移动到C上 ········递归到n = 1时直接移动不在递归，n = 1为递出条件
>此时：甲：A->B这个就是一个小问题，把n-1个盘子从A移动到B，可以用C当媒介---递归
  甲：B->C这个也是一个小问题，把n-1个盘子从B移动到C，可以用A当媒介---递归   

>[!summary]+ 递推
>move(盘子数量 x ， 起始位置 s ， 站点位置 e , 媒介位置 h){
>	if(x = 1)    s——》h
>	1.x-1个盘子从s移向h
>	move（x-1，s，h，e）；
>	2.1个盘子从s移向e
>	move(1,s,e,h);
>	3.x-1个盘子移向e
>	move(x-1,h,e,s);
>}

```java
import java.util.*;  
public class ja{  
    public static void main(String args[]){  
            Scanner sc = new Scanner(System.in);  
            List<Integer> A = new ArrayList<Integer>();  
            List<Integer> B = new ArrayList<>();  
            List<Integer> C = new ArrayList<>();  
            int n = sc.nextInt();  
            for(int i = 0 ; i < n ; i++){  
                A.add(sc.nextInt());  
            }  
            Solution sl= new Solution();  
    }  
}  
class Solution {  
    public void move(int x , List<Integer> s , List<Integer> e , List<Integer> h){  
        if(x == 1){  
            int tmp = s.remove(s.size() - 1);  
            e.add(tmp);  
            return;  
        }  
        move(x - 1 , s , h ,e);  
        move(1 , s , e, h);  
        move(x - 1 , h , e , s);  
    }  
    public void hanota(List<Integer> A, List<Integer> B, List<Integer> C) {  
        int n = A.size();  
        move(n , A ,C , B);  
    }  
}
```

>[!summary]+ 递推问题分析
>首先确定解决啥问题：大问题分为小问题，<mark style="background: #FF5582A6;">小问题是什么，就解决什么问题</mark>，从小问题开始列举试试，递推出口用递推树试试
>例如：<mark style="background: #FF5582A6;">第i个小问题解决方法——》递归解决方法，进行抽象</mark>展开后暂时不想

动态规划：全局最优  所以找全部情况选最优:   最优子结构（大问题——》小问题+最优子问题
分治：分而治之，复杂问题——》<mark style="background: #FF5582A6;">若干给相同或不同的子问题</mark>，子问题<mark style="background: #FF5582A6;">相互独立</mark>，直到子问题可以求解，<mark style="background: #FF5582A6;">原问题的解即子问题的合并</mark>——》最优子问题

>[!summary]+ 动态规划，分治，递归
>递归:一种方法论，不是单独算法，其他算法常基于递归来写
>动态规划：dp就是基于递归实现，<mark style="background: #FF5582A6;">子问题重叠</mark>，子问题解决要类似
>分治：基于递归，<mark style="background: #FF5582A6;">子问题不重叠</mark>，解决方法可不同，不同子问题要为其单独写一个算法来解决


[lg53最大数组和](https://leetcode.cn/problems/maximum-subarray/)
给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

**示例 1：**

**输入：**nums = [-2,1,-3,4,-1,2,1,-5,4]
**输出：**6
**解释：**连续子数组 [4,-1,2,1] 的和最大，为 6 。

**示例 2：**

**输入：**nums = [1]
**输出：**1

**示例 3：**

**输入：**nums = [5,4,-1,7,8]
**输出：**23

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 10`

>[!summary]+思路
>思路：
>1.暴力：枚举起点和终点，计算区间内的和，取最大值。时间复杂度：O(n^2)
>2.分治：时间复杂度：O(nlogn)
>取中心点m=(l+r)/2。和最大的区间要么出现在中心点左边，要么出现在中心点右边，要么横跨中心点。
>所以问题分解为求这三部分的最大区间和，然后取最大值。---分成3个独立的小问题，分治。(1) 中心点左边的最大区间和：和原问题相同，递归。
>(2) 中心点右边的最大区间和：和原问题相同，递归。
>(3)横跨中心点的最大区间和：贪心求解---从中心点往左右两边延申。
>从中心点不断往左延申，同时记录最大值Imax 从中心点不断往右延申，同时记录最大
>rmax 横跨中心点的最大区间和：Imax+rmax
>3.动态规划：线性动态规划。时间复杂度O(n)。
>状态：dpli]=x 以第个元素结尾的和最大的区间，最大和是x
>初始状态：dp[0]=nums[0]
>转移方程：dpl]=max(dpli-1]+nums[i],nums[i])
>最终答案：max(dp[i])

>[!summary] + 注意
>此题分解小问题中两个小问题与大问题解法同，但是中间问题解法单独解决，一定不可以用动态规划（不是最优子问题）
>但是换一种拆分问题的方法就可以

```java
import java.util.*;  
public class ja{  
    public static void main(String args[]){  
            Scanner sc = new Scanner(System.in);  
            int n = sc.nextInt();  
            int nums[] = new int[n];  
            for(int i = 0 ; i < n ; i++){  
                nums[i] = sc.nextInt();  
            }  
            Solution sl= new Solution();  
            sl.maxSubArray(nums);  
    }  
}  
class Solution {  
    public int midmax(int[] nums , int l , int mid , int r){  
        int lmax = Integer.MIN_VALUE;  
        int lsum = 0;  
        for(int i = mid ; i >= l ; i--){  
            lsum += nums[i];  
            lmax = Math.max(lmax, lsum);  
        }  
        int rsum = 0;  
        int rmax = Integer.MIN_VALUE;  
        for(int i = mid + 1; i <= r ; i++){  
            rsum += nums[i];  
            rmax = Math.max(rsum , rmax);  
        }  
        return lmax + rmax;  
    }  
    public int max(int[] nums , int l , int r){  
        int mid = ( l + r) / 2;  
        if(l == r ){  
            return nums[l];  
        }  
        //处理左半部分  
        int lmax = max(nums , l , mid);  
        //处理右半部分  
        int rmax = max(nums , mid + 1 , r);  
        //处理中间部分  
        int cmax = midmax(nums , l , mid , r);  
        return Math.max(Math.max(lmax , rmax) , cmax);  
    }  
    public int maxSubArray(int[] nums) {  
        int max = max(nums , 0 , nums.length - 1);  
        return max;  
    }  
}
```
