<mark style="background: #FF5582A6;">尺取法需要满足的条件:区间权值和大小满足随区间长度单调变化,即当一个边界固定时,区间越
长区间权值和越小(或越大)。</mark>
<mark style="background: #FFB86CA6;">尺取法(滑动窗口/双指针法):一种利用双指针遍历获取满足条件的区间(滑动窗口)的算法。</mark>
>[!summary]+ 分析
>n的数组遍历所有区间：枚举边界r从1到n，1 - 1 ，2 - 2 ------n - n ，等差数列和 ，O（n^2）
>优化：一定不满足与一定不是答案的忽略

>[!summary]+ 思路
>
>其为一种线性算法。过程为:枚举r,不断得到合法区间。记(,r)为一个序列内以r为终点的合法区间，然后枚举I,随着的增大,区间不断缩小,直至不合法为止。时间复杂度为O(n)。
>r向右枚举，l也向右·枚举，过程中未叠加（l不向左回去），仅是向右移动
><mark style="background: #FF5582A6;">注：下标代替指针，注意自己创建的数组可以从0开始，容器的从1开始，递减->非正数，递增->非负数</mark>


尺取法的优点:不会去枚举到一定不满足条件的区间。不会枚举一定不是答案的区间

尺取法比直接暴力枚举区间效率高很多,尤其是数据量大的时候,所以说尺取法是一种高效的枚举
区间的方法,是一种技巧,一般用于求取有一定限制的区间个数或最短的区间等等。当然任何技巧
都存在其不足的地方,有些情况下尺取法不可行,无法得出正确答案,所以要先判断是否可以使用
尺取法再进行计算。

[LCR 008. 长度最小的子数组](https://leetcode.cn/problems/2VG8Kg/)
给定一个含有 `n` 个正整数的数组和一个正整数 `target` **。**

找出该数组中满足其和 `≥ target` 的长度最小的 **连续子数组** `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度**。**如果不存在符合条件的子数组，返回 `0` 。

**示例 1：**
**输入：**target = 7, nums = [2,3,1,2,4,3]
**输出：**2
**解释：**子数组 `[4,3]` 是该条件下的长度最小的子数组。
**示例 2：**
**输入：**target = 4, nums = [1,4,4]
**输出：**1
**示例 3：**
**输入：**target = 11, nums = [1,1,1,1,1,1,1,1]
**输出：**0
提示：
- `1 <= target <= 109`
- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 105`
```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int r,l;
        int  sums = 0;
        r = 0;
        l = 0;
        int length = 10005;
        while(r < nums.length){
            sums += nums[r];
            if(sums >= target){
                while(r >= l && sums - nums[l] >= target){
                    sums -= nums[l];
                    l++;
                }
                 if(r - l + 1 < length){
                    length = r -l + 1;
                }
            }
            r++;
        }
        return length == 10005 ? 0 : length ;
    }

}
```
>[!summary]+ 反思
>可以用前缀和，也可以用sums一直动态变化

[lk712](https://leetcode.cn/problems/subarray-product-less-than-k/)
给你一个整数数组 `nums` 和一个整数 `k` ，请你返回子数组内所有元素的乘积严格小于 `k` 的连续子数组的数目。

**示例 1：**

**输入：**nums = [10,5,2,6], k = 100
**输出：**8
**解释：**8 个乘积小于 100 的子数组分别为：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。
需要注意的是 [10,5,2] 并不是乘积小于 100 的子数组。

**示例 2：**

**输入：**nums = [1,2,3], k = 0
**输出：**0

**提示:** 

- `1 <= nums.length <= 3 * 104`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 106`
```java
import java.util.Scanner;  
public class lk {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int[] nums = new int[10005];  
        int target , n;  
        n = sc.nextInt();  
        for (int i = 0; i < n; i++) {  
            nums[i] = sc.nextInt();  
        }  
        target = sc.nextInt();  
        Solution sol = new Solution();  
        sol.numSubarrayProductLessThanK(nums, target);  
    }  
}  
class Solution {  
    public int numSubarrayProductLessThanK(int[] nums, int k) {  
        int r = 0 , l = 0 , sums = 1 ;  
        int count = 0 ;  
        while(r < nums.length){  
            sums = sums * nums[r];  
            while(r >= l && sums >= k){  
                sums /= nums[l];  
                l++;  
            }  
            count += r - l + 1;  
            r++;  
        }  
        return count;  
    }  
}
```
>[!summary]+ 反思
>乘法递增的底数位1，此题为递增，条件为小于

>[!summary]+ 总结
>因为单调变化，所以分情况来看：
>+  求长度最小的区间：根据递增还是递减看
>	+ 递增:
>		+ 条件为大于：求>最小min的区间，l左侧符合条件但是一定不是最小区间，右侧一定不满足，r向右移动符合条件，符合条件时让l向右移动，找最小区间
>		+ 条件为小于：r向有移动一直到不符合条件，此时，l右侧符合条件，l左侧不符合条件；符合条件期间以r为右界限的区间 此时可以记录下来符合条件的区间数：r - l + 1，不符合条件使l向右移动缩小范围使条件满足
>	+ 递减：求<max的区间，l右侧一定不满足，左侧左侧符合条件但是一定不是最小区间
>+ 求符合区间个数：思路同，仅是将符合条件的加上即可
