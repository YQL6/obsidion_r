# Floyd：
<mark style="background: #FF5582A6;">动态规划————状态转变依靠点的启动！！！实现状态的转移</mark>
<mark style="background: #FF5582A6;">适用情况：出现负边权的情况，无法处理存在负权回路的情况</mark>
时间复杂度：O(n^3)
```java
for(k = 1 , k<= n ; K++){//逐一启动各点
	for(int i = 1 ; i <= n ; i++){
		for(int j = 1 ; j <= n ; j++){
			if(dist[i][j] > dist[i][k] + dist[k][j]){
				dist[i][j] = dist[i][k] + dist[k][j];
				path[i][j] = path[k][j];
			}
		}
	}
}
```

# Dijkstra:
贪心算法，每次只能解决一个起点的最短路径问题
适用情况：<mark style="background: #FF5582A6;">不能处理负权边的问题</mark>（可以经过一个负数减小使之前的最小不为最小）
时间复杂度：O(n^2)

```java
for(int i = 1; i < n ; i++){//处理n - 1各点的最短路径
	1.找最短相邻的点
	2.标记找的点，更新visited
	3.按找的点更新相邻点,跟新dist
}
dist为最短距离，path为最短路径的前驱节点
```

两者相同操作：
```java
Dijkstra:dist[i] = dist[cur] + w;
Floye:dist[i][j] = dist[i][k] + dist[k][j];
```

以i为中转点，<mark style="background: #FF5582A6;">不断缩短</mark>i到j的距离，都对边进行<mark style="background: #FF5582A6;">松弛操作</mark>
Dijkstra:贪心+松弛

# Baliman-Ford: 
不断向四周节点询问邻接点来寻找最终节点，相邻节点在询问相邻节点，在询问过程中也对相邻节点到原点的最短距离更新，即对图中每一条边松弛

Bellman-Ford 算法所做的，就是不断尝试对图中的每一条边进行松弛。我们每进行一轮循环，就对图上所有的边都尝试进行一次松弛操作，当一次循环中没有成功的松弛操作时，算法停止：暴力遍历，无脑松驰。显然：每次循环是 O(E)的，那么最多会循环多少次呢?

在最短路存在的情况下，<mark style="background: #FF5582A6;">由于一次松弛操作会使最短路的边数至少+1一定会向下伸出一个边，一次最少一个，去掉起点，最大n - 1</mark>，而最短路的边数最多为n-1，因此整个算法最多执行 n-1轮松弛操作。故总时间复杂度为O(v * e)。

<mark style="background: #FF5582A6;">思路：开始就问路，只是有的路问了也没用，前面没有节点问，即使第一次问道了错路，到后面的问路操作也会改过来，这也是问路（松弛）的过程，不一定要问n - 1次，如果问到一定程度发现已是最优，停止，n - 1次只是保障</mark>
就是暴力，不断问路有没有

由于要问路看看是谁问的它，加一个数组pre来存放它是从哪条路问到的

适合用邻接表来遍历（适合遍历边）

适用情况：带负边权的图（不是贪心，不会锁定最短路问题），单源，负权回路不可（不是贪心，会来回执行，因此可反复更新，因此即使n - 1后也可以更新，通过此方法可以判断是否有负权边）
