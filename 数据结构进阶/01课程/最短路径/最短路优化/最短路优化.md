1. Ford（O(v^3）:多源，适用于解决出现负边权情况，无法处理负边权回路问题
2. Dijkstra(O(v^2)):单源，不可处理负边权情况
3. Beliman-Ford(O(v * e)):单源，可处理负边权情况，无法处理负边权回路问题
注：单源，无负边权时，边多选Beliman-Ford,点多，选Dijkstra算法

时间复杂度为O(n^2),优化:
原Dijkstra:
```java
import java.util.Scanner;  
import java.util.*;  
public class lk {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
  
    }  
}  
class Edge{  
    int to;  
    int w;  
    int next;  
    public Edge(int to, int w, int next) {  
        this.to = to;  
        this.w = w;  
        this.next = next;  
    }  
}  
class Graph_LG{  
    int head[] = new int[101];//节点为100  
    Edge edges[] = new Edge[head.length * ( head.length - 1 )];  
    int dist[] = new int[head.length];  
    int v[] = new int[head.length];  
    int count = 0;  
    public Graph_LG(){  
        for (int i = 0; i < head.length; i++) {  
            head[i] = -1;  
        }  
    }  
    public void add(int x , int y , int w){  
        edges[count] = new Edge(y, w, head[x]);  
        head[x] = count;  
        count++;  
    }  
    public void dfs(int x){  
        int n = head.length - 1;  
        for (int i = 1; i <= n; i++) {  
            dist[i] = Integer.MAX_VALUE;  
            v[i] = 0;  
        }  
        dist[x] = 0;  
        for(int i = 1; i <= n ; i++){//不在对起始点初始化，合并到for中一起操作  
            int cur = -1 , min = Integer.MAX_VALUE;  
            for(int j = 1; j <= n; j++){  
                if(v[j] == 0 && dist[j] < min){  
                    cur = j;  
                    min = dist[j];  
                }  
            }  
            if(cur == -1) break;  
            v[cur] = 1;  
            for(int j = head[cur]; j != -1 ; j = edges[j].next){  
                if(v[edges[j].to] == 0 && dist[edges[j].to] > dist[cur] + edges[j].w){  
                    dist[edges[j].to] = dist[cur] + edges[j].w;  
                }  
            }  
        }  
    }  
}
```
n：遍历n次，找n个最短距离，  n：遍历找n个点中最小的
降低时间复杂度：减小遍历找数的时间复杂度——》用小根堆——》要找最小值对应的编号——》<mark style="background: #FF5582A6;">数对</mark>（dist值+对应的编号）——》<mark style="background: #FF5582A6;">优先队列</mark>——》优化为小根堆，时间复杂度O(logn)

可能遇到的问题：
1. 如何找到disi值最小的i？遍历。O(n)
2. 如何快速找到dis值最小的i? 用小根堆进行优化，即用优先队列。O(log n)
3. 如何快速追历i点的邻接点?链式前向星（邻接表）存图。小于O(n)。
因为在完全图的情况下，一个点最多有n-1条边，但是大部分情况不可能是完全图。
4. 需要注意，点可能重复入队。
注意一个点可能会被更新多次而入堆多次 但是只有<mark style="background: #FF5582A6;">最后一次入堆才是正确的dis</mark> 同时也一定是在所有入堆操作结束后才会出堆所以直接开个数组判断有没有出堆过就好了当然也可以根据堆中元素的距离大小和点的
o最短路大小直接判断
得到 链式前向星存图的 堆优化版Dijikstra算法时间复杂度O(e * logV)。

入队：先入队start，后面没更新一次节点就入队一个节点，可能不是最短距离，多次入队，由多个同一个节点，不同距离的数值对，加一个v数组判断，第一次一定先出小的，会留下一个大的距离，v遍历后就舍弃

```java
    public void dfs2(int x){  
        int n = head.length - 1;  
        int visited[] = new int[n + 1];  
        for(int i = 1; i <= n ; i++){  
            visited[i] = 0;  
            dist[i] = Integer.MAX_VALUE;

        dist[x] = 0;  
        PriorityQueue<Node> q  = new PriorityQueue<>(new Comparator<Node>(){

        q.add(new Node(x,0));  
        while(!q.isEmpty()){  
            Node cur = q.poll();  
            if(visited[cur.id] == 1) continue;  
            visited[cur.id] = 1;  
            for(int j = head[cur.id]; j != -1 ; j = edges[j].next){  
  
                if(dist[edges[j].to] > dist[cur.id] + edges[j].w){  
                    dist[edges[j].to] = dist[cur.id] + edges[j].w;  
                    q.add(new Node(edges[j].to,dist[edges[j].to]));  
                }  
            }  
        }  
    }  
}
```

Beliman-Ford算法优化：
1. 每次遍历所有边，不是所有dist都更新，上一轮被更新的邻接点一定有机会被更新，剩下的节点可能因为边遍历的顺序不同，可能被更新
2. 所以记录上一次更新的节点，他的邻接点一定有机会被更新
3. 第i轮一定有机会被更新的点是<mark style="background: #FF5582A6;">上一轮（i - 1）被更新的点的邻接点</mark>
4. <mark style="background: #FF5582A6;">只松弛可能被更新的节点</mark>，没有可能的节点不松弛(即使第二次被松弛也是出现在被更新的邻接点)
松弛的轮数变多（原来可能到一定程度就停了），但一轮松弛的次数减少了

时间复杂度：最好每次松弛一条边：O(E) 最坏的情况：O(n * m)

实现：采用<mark style="background: #FF5582A6;">队列</mark>保存每次松弛的节点，取队列的节点找其边松弛操作

注：优化后为SPFA,只有出现负边区时才使用，不稳定，常常会被出题人卡数据，无负边权还是Dijkstra，稳定
注：即使优化后仍可以判断负权环——》统计每个节点的路径数目，cur[i] = cur[j] + 1

思路：
1. 起点入队
2. 循环出队，出队节点改为出队状态，用出对节点更新节点邻接点，若节点被更新还未入队，入队，更新状态为入队状态

```java
public void Beliman_Ford(int x ){  
    int n = head.length - 1;  
    int path[] = new int[n + 1];  
    for(int i = 1; i <= n ; i++){  
        dist[i] = Integer.MAX_VALUE;  
        v[i] = 0;  
        path[i] = 0;  
    }  
    ArrayDeque<Integer> q = new ArrayDeque<>();  
    v[x] = 1;  
    dist[x] = 0;  
    q.offer(x);  
    while(!q.isEmpty()){  
        int pre = q.poll();  
        v[pre] = 0;  
        for(int j = head[pre]; j != -1 ; j = edges[j].next){  
            if(dist[edges[j].to] > dist[pre] + edges[j].w){  
                dist[edges[j].to] = dist[pre] + edges[j].w;  
                path[edges[j].to] = path[pre] + 1;  
                if(path[edges[j].to] >= n){  
                    System.out.println("存在负边环，最短路径无");  
                    return;  
                }  
                if(v[edges[j].to] == 0){  
                    q.offer(edges[j].to);  
                    v[edges[j].to] = 1;  
                }  
            }  
        }  
    }  
}
```
