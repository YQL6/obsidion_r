图的存储：邻接表，边界矩阵，邻接矩阵，十字链表，多重邻接表
<mark style="background: #FF5582A6;">常用：邻接矩阵，邻接表的变形——》链式前向星</mark>
链式前向星：用数组实现链表——》静态数组，用指向下标代表指针

邻接表：
1. 有向图：
	1. 邻接表：1——n数组保存节点，后面挂指向弧头的节点
	2. 逆邻接表：1——n数组保存节点，后面挂谁指向的它
2. 无向图：1——n数组保存节点，后面挂相连的节点

由上所述，可得：用数组来模拟，用二维数组来模拟
邻接表存储无权图，直接转化为二维数组，a[x][i] = y表示顶点x到第i个邻接边为y,即x的第i条出边为<x,y>，需要存权值建对象类的数组

import java.util.Scanner;  
import java.util.*;  
public class lk {  
    static int visited[];  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int m = sc.nextInt();  
        int n = sc.nextInt();  
        ArrayList<ArrayList<Edge>> list = new ArrayList<>();  
        for(int i = 0; i < n; i++) {  
            list.add(new ArrayList<Edge>());  
        }  
        for (int i = 0; i < m; i++) {  
            int x = sc.nextInt();  
            int y = sc.nextInt();  
            int weight = sc.nextInt();  
            list.get(x).add(new Edge(y,weight));  
            list.get(y).add(new Edge(x,weight));  
        }  
        visited = new int[n];  
        for(int i = 0; i < n;i++){  
            dfs(list, i , n);  
        }  
    }  
    static void dfs(ArrayList<ArrayList<Edge>> list, int x ,int n){  
        if(visited[x] == 1){  
            return;  
        }  
        System.out.println(x);  
        visited[x] = 1;  
        for(int i = 0 ; i < list.get(x).size() ; i++){  
            int y = list.get(x).get(i).adj;  
            dfs(list , y , n);  
        }  
    }  
  
}  
class Edge {  
    int w;  
    int adj;  
    public Edge(int adj , int w){  
        this.w = w;  
        this.adj = adj;  
    }  
}

静态链表：
![[图片/2aba6a47b5ae1f1053c903327741c5a8.jpg]]
需要两个数组：
1. 头结点数组：head[],head[i]表示第i个节点的信息：指向edge数组的第一条节点，即edge[i]为第i节点第一个的边
2. 边集数组：edge[] ,edge[i] 表示第i条边，存储边的信息：to，w，next，next为下一个同弧头的边，类似数组，同节点的边靠next连接
注：初始化head[i]为-1
其实和链表一样的：下标——》地址，存放下标——》指针，缺失下标/指针 会丢失意义
这样模拟与链表一模一样！！！
注：逻辑上edge还是节点，存储上是连续的

```java
import java.util.Scanner;  
import java.util.*;  
public class lk {  
    static int count = 0;//保存edge用到哪了！！！  
    static int[] v;  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        int head[] = new int[n];  
        Edge[] edges = new Edge[n * (n - 1)];//完全图：n * (n - 1)  
        v = new int[n];  
      
    }  
    static void addEdge(int head[] , Edge edges[],int x, int y ,int w){  
        edges[count].next = head[x];  
        edges[count].w = w;//头插法  
        edges[count].to = x;//可能被拆开，to[count]  
        head[x] = count;  
        count++;  
    }  
}  
class Edge {  
    int w;  
    int next;  
    int to;  
    public Edge(int next , int w ,int to){  
        this.w = w;  
        this.next = next;  
        this.to = to;  
    }  
}
```
