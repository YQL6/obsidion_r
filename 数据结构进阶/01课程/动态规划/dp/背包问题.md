背包分类：
1. 混合背包：一下三种背包混合：
	1. 01背包：每个物品只有一个
	2. 完全背包：每个物品有无限个可以无限选
	3. 多重背包：对不同物品分类，不同分类的物品数量不同
2. 多重背包

# 01背包：
解决承重为j的背包怎么装最多价值的物品：
价值——》v[i]
重量——》w[i]

首先想到最优问题的思路——》贪心（性价比），但是背包装物品不能装半个东西，所以按性价比装可能会浪费空间；

动态规划：对于承重为j，装第i个物品的最高价值的状态——》j ， i为参数
1. 对与第i个物品：
	1. 装：转化为第i - 1个物品且承重为j - w[j]的状态的值 + 自身价值；dp[i - 1]  [j - w[i]] +  v[i];
	2. 不装：直接就是i - 1个物品且承重为j 的状态值；dp[i - 1]  [j];
2. 对两种状态取最值；
dp[i]  [j] = Math.max(dp[i - 1]  [j] , dp[i - 1]  [j - w[i]] + v[i]);

```java
for(int i = 0 ; i <= n_i ; i++){//j = 0无承重能力，一个都装不下
	dp[i][0] = 0;
}
for(int j = 0 ; j <= n_j ; j++){//i = 0无物品可装，一个都不装
	dp[0][j] = 0;
}
for(int i = 1 ; i <= n_i ; i++){//分别对各个物品分析
	for(int j = 1; j <= n_j ;j++){//对各种承重能力分析，为最终结果做铺垫
		if(j >= w[i]) dp[i][j] = Math.max(dp[i - 1][j] , dp[i - 1][j - w[i]] + v[i]);//可能不够装这个物品
		else dp[i][j] = dp[i - 1][j];
	}
}
```
优化——降维：dp[i][j] = Math.max(dp[i - 1]  [j] , dp[i - 1]  [j - w[i]] + v[i]);第i层的仅与第i- 1层有关；
所以可以将二维数组降维；使用滚动数组，刚开始是第0个物品；逐渐增加物品；而且由于对i - 1层的使用，所以要保留 i - 1层的东西直到完全替代；——》从后向前遍历；
```java
for(int j = 0 ; j <= n_j ; j++){
	dp[j] = 0;
}
for(int i = 1 ; i <= n_i ; i++){
	for(int j = n_j ; j >= w[i] ; j--){
		dp[j] = Math.max(dp[j - w[i]] + v[i], dp[j]);
	}
}
```

# 完全背包
在每种物品可以无限选且承重为j的情况下，怎么选最大价值

对第i个物品分析：
1. 不选：dp[i]  [j] =d[i - 1]  [j];
2. 选k个：dp[i]  [j] = Math.max(dp[i]  [j] , dp[i - 1]  [j - k* w[i]] + v[i] * k);

```java
for(int i = 0 ; i <= n_i ; i++){//j = 0无承重能力，一个都装不下
	dp[i][0] = 0;
}
for(int j = 0 ; j <= n_j ; j++){//i = 0无物品可装，一个都不装
	dp[0][j] = 0;
}
for(int i = 1 ; i <= n_i ; i++){
	for(int j = 1; j <= n_j ; j++){
		dp[i][j] = dp[i - 1][j];
		for(int k = w[i] ; j >= k ; k += w[i]){
			dp[i][j] = Math.max(dp[i][j] , dp[i - 1][j - k] + v[i] * k / w[i]);
		}
	}
}
```

优化：
如同01背包般降维——》但是要考虑多个i物品相加的情况——》正向遍历，因为前面已有最优，在最优基础上加；
```java
for(int j = 0 ; j <= n_j ; j++){
	dp[j] = 0;
}
for(int i = 1 ; i <= n_i ; i++){
	for(int j = w[i] ; j <= n_j ; j++){
		dp[j] = Math.max(dp[j - w[i]] + v[i], dp[j]);
	}
}
```
