一个状态/集合/事件中有多种事件，而事件有两种状态/多种状态，若使用dp全表示——》n为状态的数目，m为表示事件内的所有事件组成的状态需要的；dp[n]  [m];

优化：对事件内部的事件的描述用一维数字来描述——》事件的整体状态用数字来表示——》整体只用一维即可；

状态转移应该是二进制表示的整体状态的转移，所以要精确到位上的转移——》应用位运算

位运算：针对二进制位的运算，会使十进制的数在二进制下进行运算
1. &： x&y , 最低位开始/左端对齐，同1位1，其余为0 ， 3（11） & 2（10） = 2；在二进制位上：<mark style="background: #FF5582A6;">任何&1都为自身，&0为0</mark>，1&3 = 1；只有3的最小位为自己
2. |：   x|y   ，或运算；在二进制位上：<mark style="background: #FF5582A6;">任何数|1为1，任何数|0为自身</mark>
3. ^:   x^y ,异或运算，<mark style="background: #FF5582A6;">相同位0 ，不同为1</mark>；x = y时，x ^ y = 0,两者相等时二进制相同，对应位相同；<mark style="background: #FF5582A6;">任何数 ^ 0 = 任何数</mark> ； 相当于各位异或上0，
4. ~；按位取反，<mark style="background: #FF5582A6;">各位取反</mark>
5. <<:左移操作，最右边补0，相当于扩大2倍
6. >>:右移操作，最左边补正补0，右补1
注：不够位数的，正数补0，负数补1；

常用位运算：
1. 判断第i位是否为1：(1 << (i - 1)) & x——》将第i位的数位1，其他为0就剩下第i位，如果是1：>0
2. 将一个数字x二进制下第i位更改位0：x = x &  ~(1 << (i - 1))
3. 将一个数字x二进制下第i位更改为1：x = x |   (1 << (i - 1))
4. 将一个数字x二进制下最右边的第一个1更改为0：
	1. 分析问题：最右边第一个1，要么是最右边第一位，要么是1后面全是0，减1以后，最右边一为0，或第一个1被借位为0，后面为1，原来那些位上是0，相与后变0，第一个由于被借也是0，相与为0
	2. 分析可知：x = x & (x - 1);
5. 枚举集合的子集: 
```java
for(int s1 = s ; s1 != 0 ; s1 = s * (s1 - 1)){
	s2 = s ^ s1;//s1是子集，异或是不同为1，枚举过程中仅补集部分不同
}
```

状态转移：
使用场景：棋盘问题（一个棋子就是一个状态，一行就是一个集合，是一个数下一行由上一行判断，行与行间dp），集合类问题（n个物品选m个，一次谁选谁不选就是一个状态），连通性问题（从1开始走，全走后回到1距离最小，n个点，每一步里面的每个点状态）等；

使用题目满足的条件：
1. 需要保存一定状态数据（表示一种状态的一个数据值），状态数据的每个数据单元只有两种状态；
2. 实现一个数据类来补充，一般数据较小，一般事件里面不大于64；
