对DFS优化，BFS搜到正确答案就停，DFS遍历全部，复杂的很高
优化：减少状态空间的范围（答案范围），记忆搜索等，优化皆称为剪枝，<mark style="background: #FF5582A6;">为了减少不合理答案的枚举，重复情况不遍历</mark>
常用的剪枝方法：<mark style="background: #FF5582A6;">最优性/可行性剪枝，记忆化搜索</mark>
DFS模板：
```java
int ans = 最坏情况，now；
void dfs(传入数值){
	if(到达目的地) ans = 从当前选择最优解;
	for(遍历所有可能性){
		if(可行){
			操作；
			dfs(缩小规模)；
			回溯操作;
		}
	}
}
```
<mark style="background: #FF5582A6;">最优性剪枝：搜索一段答案后已有一个区域最优解，后面在遍历时发现搜索的解比已有的解差或是可以预见的判断当前的解不合法时，让他不要在搜索了</mark>
最优性剪枝的模板优化：
```java
int ans = 最坏情况，now；
void dfs(传入数值){
	if(now 比 ans 的答案还要差) return;
	if(到达目的地) ans = 从当前选择最优解;
	for(遍历所有可能性){
		if(可行){
			操作；
			dfs(缩小规模)；
			回溯操作;
		}
	}
}
```
可行性剪枝模板：
```java
int ans = 最坏情况，now；
void dfs(传入数值){
	if(当前已不合法) return;//根据可行性条件来判断
	if(到达目的地) ans = 从当前选择最优解;
	for(遍历所有可能性){
		if(可行){
			操作；
			dfs(缩小规模)；
			回溯操作;
		}
	}
}
```

# P1025 [NOIP 2001 提高组] 数的划分

## 题目描述

将整数 $n$ 分成 $k$ 份，且每份不能为空，任意两个方案不相同（不考虑顺序）。

例如：$n=7$，$k=3$，下面三种分法被认为是相同的。

$1,1,5$；   
$1,5,1$；   
$5,1,1$。

问有多少种不同的分法。

## 输入格式

$n,k$（$6<n \le 200,2  \le k  \le  6$）。

## 输出格式

$1$ 个整数，即不同的分法。

## 输入输出样例 #1

### 输入 #1

```
7 3

```

### 输出 #1

```
4

```

## 说明/提示

四种分法为：  
$1,1,5$；  
$1,2,4$；  
$1,3,3$；  
$2,2,3$。

**【题目来源】**

NOIP 2001 提高组第二题

>[!summary]+ 思路！！！
>先是看要找k个位置的数相加为n，dfs：第一个位置到第n个位置遍历，<mark style="background: #FF5582A6;">遇到答案ans++,但是全部排列（一个组合）才可以以此ans++，怎么办——》visited不可以，让一个组合出现以此——》固定顺序——》不严格递增</mark>
>优化缩小范围：最小从1开始遍历，最大是n - k + 1，到下一个位置遍历因为递增，所以最小从last的选数开始
>优化可行性剪枝：从一个位置开始只选最小的数也不能等于n，一定大于n，则从这个数开始，后面的枝不用遍历了，砍掉——》break——》为了判断位置多加一个参数stp判断位置

```java
import java.util.Scanner;
import java.util.*;
public class Main {
    static int ans = 0;
    static int n, k;
    public static void dsf(int n , int stp , int last , int sum){
        if(stp > k){
            if(sum == n){
                ans++;
            }
            return;
        }
        for(int i = last ; i <= n - k + 1; i++){
            if((k - stp + 1) * i + sum > n){
                break;
            }
            dsf(n , stp + 1, i , sum + i);
        }
    }
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        k = sc.nextInt();
        dsf(n , 1 , 1,0);
        System.out.println(ans);
    }
}
```

记忆性搜索优化：将<mark style="background: #FF5582A6;">递归条件的状态记录下来</mark>，当遇到与其相同的递归条件，<mark style="background: #FF5582A6;">直接取出</mark>，不在向下遍历（与动态规划的dp类似），比如：斐波那契数列，重复子问题多——》dp记录，相同的<mark style="background: #FF5582A6;">如果动态规划没思路，可以将问题看为遍历问题，</mark>加一个计划数组，计划数组更新过程就是状态转移方程
<mark style="background: #FF5582A6;">计划数组一般不过二维，过了二维就降维</mark>

# P1464 [PacNW 1999] Function

## 题目描述

对于一个递归函数 $w(a,b,c)$


- 如果 $a \le 0$ 或 $b \le 0$ 或 $c \le 0$ 就返回值 $1$。
- 如果 $a>20$ 或 $b>20$ 或 $c>20$ 就返回 $w(20,20,20)$
- 如果 $a<b$ 并且 $b<c$ 就返回 $w(a,b,c-1)+w(a,b-1,c-1)-w(a,b-1,c)$。
- 其它的情况就返回 $w(a-1,b,c)+w(a-1,b-1,c)+w(a-1,b,c-1)-w(a-1,b-1,c-1)$


这是个简单的递归函数，但实现起来可能会有些问题。当 $a,b,c$ 均为 $15$ 时，调用的次数将非常的多。你要想个办法才行。

注意：例如 $w(30,-1,0)$ 又满足条件 $1$ 又满足条件 $2$，请按照最上面的条件来算，答案为 $1$。

## 输入格式

会有若干行。

并以 $-1,-1,-1$ 结束。

## 输出格式

输出若干行，每一行格式：

`w(a, b, c) = ans`

注意空格。

## 输入输出样例 #1

### 输入 #1

```
1 1 1
2 2 2
-1 -1 -1
```

### 输出 #1

```
w(1, 1, 1) = 2
w(2, 2, 2) = 4
```

## 说明/提示

### 数据规模与约定

保证输入的数在 $[-9223372036854775808,9223372036854775807]$ 之间，并且是整数。

保证不包括 $-1, -1, -1$ 的输入行数 $T$ 满足 $1 \leq T \leq 10 ^ 5$。****
```java
import java.io.BufferedReader;  
import java.io.BufferedWriter;  
import java.io.IOException;  
import java.io.InputStreamReader;  
import java.io.OutputStreamWriter;  
  
public class Main {  
    // 记忆化数组：dp[a][b][c] 存储 w(a,b,c) 的结果，-1 表示未计算  
    static long[][][] dp = new long[21][21][21];  
  
    public static long w(int a, int b, int c) {  
        // 边界条件 1：任意值 ≤ 0，返回 1       
         if (a <= 0 || b <= 0 || c <= 0) {  
            return 1;  
        }  
        // 边界条件 2：任意值 > 20，返回 w(20,20,20)       
         if (a > 20 || b > 20 || c > 20) {  
            return w(20, 20, 20);  
        }  
        // 如果已计算过，直接返回缓存结果  
        if (dp[a][b][c] != -1) {  
            return dp[a][b][c];  
        }  
  
        long res;  
        // 条件 3：a < b 且 b < c       
         if (a < b && b < c) {  
            res = w(a, b, c - 1) + w(a, b - 1, c - 1) - w(a, b - 1, c);  
        } else {  
            // 其他情况  
            res = w(a - 1, b, c) + w(a - 1, b - 1, c) + w(a - 1, b, c - 1) - w(a - 1, b - 1, c - 1);  
        }  
  
        // 缓存计算结果  
        dp[a][b][c] = res;  
        return res;  
    }  
  
    public static void main(String[] args) throws IOException {  
        // 初始化 dp 数组为 -1（表示未计算）  
        for (int i = 0; i <= 20; i++) {  
            for (int j = 0; j <= 20; j++) {  
                for (int k = 0; k <= 20; k++) {  
                    dp[i][j][k] = -1;  
                }  
            }  
        }  
  
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
  
        String line;  
        while ((line = br.readLine()) != null) {  
            line = line.trim();  
            if (line.isEmpty()) continue;  
  
            String[] parts = line.split("\\s+");  
            long a = Long.parseLong(parts[0]);  
            long b = Long.parseLong(parts[1]);  
            long c = Long.parseLong(parts[2]);  
  
            // 结束输入的标志  
            if (a == -1 && b == -1 && c == -1) {  
                break;  
            }  
  
            long ans;  
            if (a <= 0 || b <= 0 || c <= 0) {  
                ans = 1;  
            } else if (a > 20 || b > 20 || c > 20) {  
                ans = w(20, 20, 20);  
            } else {  
                ans = w((int) a, (int) b, (int) c);  
            }  
  
            // 按格式输出结果  
            bw.write("w(" + a + ", " + b + ", " + c + ") = " + ans);  
            bw.newLine();  
        }  
  
        // 关闭流  
        br.close();  
        bw.flush();  
        bw.close();  
    }
}
```
