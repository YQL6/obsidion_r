<mark style="background: #FFB86CA6;">单调栈：栈底到栈顶严格递增或递减。</mark>
<mark style="background: #FF5582A6;">常用于求解元素左右大小边界问题：</mark>
1. 向左<mark style="background: #FF5582A6;">找（离他最近的）</mark>第一个比自身大的数。
2. 向左找第一个比自身小的数。
3. 向右找第一个比自身大的数。
4.  向右找第一个比自身小的数。

操作（以栈底到顶递增为例）：
1. 如果新的元素比栈顶元（最大）素大，就入栈
2. 如果新的元素较小，那就一直把栈内元素弹出来，直到栈顶比新元素小，新元素入栈

操作（以底到顶递减为例）：
1. 如果新的元素比栈顶（最小）元素小，就入栈
2. 如果新的元素较大，那就一直把栈内元素弹出来，直到栈顶比新元素小，新元素入栈
<mark style="background: #FF5582A6;">目的：不必要将数都放数组在，要将所有数都过一遍</mark>

元素间大小判断：对于当前遍历到的数，栈顶为答案。
1. 向左找第一个比自身大的数。左--->右 底到顶递减栈
2. 向左找第一个比自身小的数。左--->右 底到顶递增栈
3. 向右找第一个比自身大的数。右--->左 底到顶递减栈
4. 向右找第一个比自身小的数。右--->左 底到顶递增栈

元素间大小判断：对于栈顶 当前遍历到的数为答案。
1. 向左找第一个比自身大的数。右--->左 底到顶递减栈
2. 向左找第一个比自身小的数。右--->左底到顶递增栈
3. 向右找第一个比自身大的数。左--->右 底到顶递减栈
4. 向右找第一个比自身小的数。左--->右 底到顶递增栈

实际操作：
元素间大小判断：对于当前遍历到的数，栈顶为答案。
1. 向左找第一个比自身大的数。左-->右底到顶递减栈1
2. 如果a[i]入栈时，栈空，说明a[i]左边没有比它大的数
3. 用递减栈来保存已经遍历过的数，当枚举到第i个数时，栈中的数就是可能比第i 个数大的数，这个和栈顶比较。栈顶比i大 栈顶就是答案，否则就连续出栈，直到一个栈顶比i大位置，此时记录答案，再把i入栈
>[!summary]+核心
><mark style="background: #FF5582A6;">核心思想：自底向顶做递减栈，可以让判断数将比他小的挤走，找到第一个比他大的数/无比他大的数，会不会漏数？——》不会，被挤掉的是小数如果连栈里面的数都能挤掉，之前被挤掉的数就不算什么了，被挤掉的是大数，那么它连上面的数都挤不掉，上面的数一定是离他最近的大数，那些被挤掉但比a[i]大的数都到不了他们那里就被大数拦住了，一定不会过去</mark>


入栈时记录：
```java
import java.util.Scanner;  
import java.util.*;  
public class lk {  
    //从左向右找比a[i]大的最近的数  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        ArrayDeque<Integer> statck = new ArrayDeque<>();  
        int[] arr = new int[n];  
        int[] ans = new int[n];  
        for (int i = 0; i < n; i++) {  
            arr[i] = sc.nextInt();  
        }  
        for (int i = 0; i < n; i++) {  
            //先踢数，statck里面保存数据还是下标，看题目是最后要下标，还是数据  
            while(!statck.isEmpty() && statck.peek() <= arr[i]){  //严格递增等于不允许
                statck.pop();  
            }  
            //最近数判断  
            if(statck.isEmpty()){  
                ans[i] = -1;  
                  
            }else{  
                ans[i] = statck.pop();  
            }  
            statck.push(arr[i]);  
        }  
    }  
  
}
```
出栈时记录，什么时候出栈——》比他大的时候出栈：
1. 当栈为空时 直接入栈
2. 当遍历到a[i]，如果a[i]大于栈顶，就要出栈，a[i]就是连续出栈的数的答案，栈顶出栈时记录栈顶的答案，否则a[i]直接入栈
3. 遍历完后，若栈未空，执行出栈，栈中的数据无答案
```java
import java.util.Scanner;  
import java.util.*;  
public class lk {  
    //向左找第一个比自身大的数。右--->左 底到顶递减栈  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int n = sc.nextInt();  
        ArrayDeque<Integer> statck = new ArrayDeque<>();  
        int[] arr = new int[n];  
        int[] ans = new int[n];  
        for (int i = 0; i < n; i++) {  
            arr[i] = sc.nextInt();  
        }  
        for (int i = n - 1; i >= 0; i--) {  
            //踢数  
            while(!statck.isEmpty() && arr[i] > arr[statck.peek()]){//非严格递减，但是找到的是严格大于的数  
                //a[i]是栈顶的第一个大的数  
                ans[statck.pop()] =  arr[i];  
            }  
            statck.push(i);  
        }  
        while(!statck.isEmpty()){  
            ans[statck.pop()] = -1;  
        }  
    }  
  
}
```

两种方法区别：
1. while的区别：
	1. 左向右：a[i] >=statck.peek()——》条件是淘汰的数，剩下的数只有大于，所以结构严格的第一个大于的数
	2. 右向左：a[statck.pop()] > statck.peek()——》出栈直接记录，条件即记录的数据
2. statck中存的数不同：
	1. 左向右：数据/下标
	2. 右向左：下标
3. 记录时间：
	1. 左向右：入栈
	2. 右向左：出栈
4. 栈最终的处理：
	1. 左向右：不处理
	2. 右向左：出栈，记录-1，无数据

[lk42接雨水](https://leetcode.cn/problems/trapping-rain-water/)

***给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

**输入：**height = [0,1,0,2,1,0,1,3,2,1,2,1]
**输出：**6
**解释：**上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

**示例 2：**

**输入：**height = [4,2,0,3,2,5]
**输出：**9

**提示：**

- `n == height.length`
- `1 <= n <= 2 * 104`
- `0 <= height[i] <= 105`

>[!summary]+ 思路
>存水——》凹槽，右边界比左边界高——》单调栈可解决——》大数遇到小栈顶，取栈顶为凹槽底，去下一个栈顶为左，取（min{左，右} - 凹槽底）* 左下标 - 右下标 ，栈顶出栈，大数存入，下一个栈顶不动

多级凹槽，分多次运算：

```java
class Solution {  
    public int trap(int[] height) {  
        int length = height.length;  
        int sums = 0;  
        ArrayDeque<Integer> statck = new ArrayDeque<>();  
        statck.push(0);  
        for(int i = 1 ; i < length ; i++){  
            while(!statck.isEmpty() && height[statck.peek()] < height[i]){  
                int top = statck.pop();  
                if(!statck.isEmpty()){  
                    int x = statck.peek();  
                    sums += (Math.min(height[x],height[i]) - height[top]) * (x - i - 1);  
                }  
            }  
            statck.push(i);  
        }  
        return sums;  
    }  
}
```

```java
class Solution { 
	public int trap(int[] height) { 
		int left = 0;
		int right = height.length - 1; 
		int maxLeft = 0; 
		int maxRight = 0; 
		int sumRain = 0; 
		while (left < right) { 
			maxLeft = Math.max(height[left], maxLeft); 
			maxRight = Math.max(height[right], maxRight); 
			if (maxLeft < maxRight) { 
				sumRain += maxLeft - height[left]; left++; 
			} else { 
				sumRain += maxRight - height[right]; right--; 
			} 
		} 
			return sumRain; 
	} 
}
```
