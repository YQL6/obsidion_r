<mark style="background: #FF5582A6;">快速幂：a^n的计算</mark>
5^10的计算：
```java
int pow(int d , int m){
	int ans = d;
	for(int i = 2 ; i <= m ; i++){
		ans *= d;
	}
	return ans;
}
```
时间复杂度：O(n),不超过1s，n最大10^N
改进：
>[!summary]+ 改进
>5^10:10个5相乘是一个重复过程,可以变为5 * 5相乘，在以5 * 5为底数只需要5次，之后5*5也是重复的，变为2个5^4相乘在相乘一个5^2
><mark style="background: #FF5582A6;">不断合成</mark>
```java
//a^n，n为2^i,的计算
int a = 5;
a *= a;//5^2
a *= a;//5^4
a *= a;//5^8
a *= a;//5^16
//最终是5^16
//次方：1，2，4，8，16；a *= a; 次方扩大两倍：5^n ,n = 2^i;
```
由上所述：幂为2^i时，时间复杂度为O(logn)
进制转换：任何正整数都可以写为2^n相加的形式
5 = 2^2 + 2^0;
7 = 2^2 + 2^1 + 2^0;
10 = 2^3 + 2^1;
![[图片/1a335d8446621332ceeb7e96451fff39.jpg]]
为什么：任何数都可以转换为二进制，二进制可以表示为2^n相加的形式
由上所诉，可知算快速幂的基础：
1. a^n,n为2^i,的计算
2. 任意正整数可以表示为2^i
时间复杂度为O(logn)
<mark style="background: #FF5582A6;">所以二进制转化过程中与a^2^i相对应！！！</mark>
<mark style="background: #FF5582A6;">a^x计算为：</mark>
1. x写为二进制，再将x写为2^i相加的形式
2. 将a的幂相加变为a的幂相乘a的幂，其中个乘数为a^2^I以a *= a;计算
![[图片/ad281a89106ed4486fcf6e72dd12daed.jpg]]
>[!summary]+ 重点！！！
>不用将二进制求解与a^2^i相分开，在求解二进制的过程将二进制此位上的2^i求出来，若此位上的是1就乘上，不是就跳过,过程在图片中
```java
import java.util.Scanner;  
public class ja {  
    public static void main(String[] args) {  
        Scanner sc = new Scanner(System.in);  
        int d = sc.nextInt();//第一位二进制d^2^0  
        int m = sc.nextInt();  
        int sum = 1;  
        while(m != 0){  
            if(m % 2 == 1){  
                sum *= d;  
            }  
            d *= d;//下一个二进制位的d^2^i  
            m /= 2;  
        }  
    }  
}
```
注：时间复杂度：log(m),注意区分底数与幂
<mark style="background: #FF5582A6;">使用场景：过程处理数据使用，常常为了使数不过大常%上一个数但是不能结果%，要利用规律在每一步%</mark>
规律：[[数据结构进阶/基础知识|基础知识]]第八点

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        long d = sc.nextLong();//第一位二进制d^2^0
        long m = sc.nextLong();
        long p = sc.nextLong();
        long a = d ,b = m;
        long sum = 1;
        while(m != 0){
            if(m % 2 == 1){
               sum = (sum * d) % p;//之间过程的都要取模，保证不过大，符合中间过程
               //取模的规律，第一次也符合规律，虽然中间位取模但是有后面p计算
               //sum,d都是取模后的结果
            }
            d = (d * d) % p;//保存二进制位的数取模，从第一个开始就取模了，合理避免过大，也符合规律
            m /= 2;
        }
        System.out.println(a + "^" + b + " mod " + p + "=" + sum);
    }
}
```
