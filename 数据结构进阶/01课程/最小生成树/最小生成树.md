最小生成树：无向连通图

Kruskal:贪心，建立边集合，从小到大排序，从小到加入最小生成树并用并查集判断，时间复杂度取决于排序的时间复杂度——O(e ^2) / O(e loge) ， 只需要边集合数组

Prim:点启动，需要链式前向星，path,mark,dist，从起点更新，选最小的路径，同时找到更新的点，更新mark,dist,重复n - 1次，时间复杂度:O(n^2)
![[图片/b5f44d9cfcd60507f2fd31775aa90b39.jpg|1228]]
优化：寻找dist最小的节点——》优先队列 ，时间复杂度：O(v logv)

选择：时间复杂度
1. 稀疏图：Kruskal
2. 稠密图：Prim

# P1194 买礼物

## 题目描述

又到了一年一度的明明生日了，明明想要买 $B$ 样东西，巧的是，这 $B$ 样东西价格都是 $A$ 元。

但是，商店老板说最近有促销活动，也就是：

如果你买了第 $I$ 样东西，再买第 $J$ 样，那么就可以只花 $K_{I,J}$ 元，更巧的是，$K_{I,J}$ 竟然等于 $K_{J,I}$。

现在明明想知道，他最少要花多少钱。

## 输入格式

第一行两个整数，$A,B$。

接下来 $B$ 行，每行 $B$ 个数，第 $I$ 行第 $J$ 个为 $K_{I,J}$。

我们保证 $K_{I,J}=K_{J,I}$ 并且 $K_{I,I}=0$。

特别的，如果 $K_{I,J}=0$，那么表示这两样东西之间不会导致优惠。

注意 $K_{I,J}$ **可能大于** $A$。

## 输出格式

一个整数，为最小要花的钱数。

## 输入输出样例 #1

### 输入 #1

```
1 1
0

```

### 输出 #1

```
1
```

## 输入输出样例 #2

### 输入 #2

```
3 3
0 2 4
2 0 2
4 2 0

```

### 输出 #2

```
7
```

## 说明/提示

样例解释 $2$。

先买第 $2$ 样东西，花费 $3$ 元，接下来因为优惠，买 $1,3$ 样都只要 $2$ 元，共 $7$ 元。

（同时满足多个“优惠”的时候，聪明的明明当然不会选择用 $4$ 元买剩下那件，而选择用 $2$ 元。）

数据规模

对于 $30\%$ 的数据，$1\le B\le 10$。

对于 $100\%$ 的数据，$1\le B\le500,0\le A,K_{I,J}\le1000$。

2018.7.25新添数据一组

>[!summary]+ 思路
>买完i物品在买j物品,j物品的价格会变为Kij ,这样可以看作是i 到 j 的路径为 Kij ，所以秩序要求连接所有物品的最短距离即可，但是选择的<mark style="background: #FF5582A6;">物品自身无法确定</mark> ，所以<mark style="background: #FF5582A6;">引入一个虚拟点0 </mark>，来模拟原价格的路径
>最好使用边集合来解决，即Kruskal，避免建立过多的<mark style="background: #FF5582A6;">双向边</mark>

```java
import java.util.Scanner;
import java.util.*;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int A = sc.nextInt();
        int B = sc.nextInt();
        Graph graph = new Graph();
        for(int i = 1 ; i <= B ; i++){
            graph.add(0 , i , A);
        }
        for(int i = 1 ; i <= B; i++){
            for(int j = 1 ; j <= B ; j++){
                int w = sc.nextInt();
                if(w == 0){
                    continue;
                }
                graph.add(i, j ,w);
            }

        }
        int ans = graph.Prim();
        System.out.println(ans);
    }
}
class Edge{
    int to;
    int w;
    int next;
    public Edge(int to , int w ,int next){
        this.w = w;
        this.to = to;
        this.next = next;
    }
}
class Node{
    int id;
    int dist;
    public Node(int id , int dist){
        this.id = id;
        this.dist = dist;
    }
}
class Graph{
    int count = 0;
    int[] head = new int[1000];
    Edge[] edges = new Edge[1000 * 1000];
    int[] visited = new int[1000];
    int dist[] = new int[1000];
    int sum = 0;
    public Graph(){
        for(int i = 0 ; i < head.length ; i++){
            head[i] = -1;
            visited[i] = 0;
            dist[i] = 1005;
            
        }
    }
    public void add(int x , int y ,int w){
        edges[count] = new Edge(y , w, head[x]);
        head[x] = count;
        count++;
        edges[count] = new Edge(x , w, head[y]);
        head[y] = count;
        count++;
    }
    public int Prim(){
        PriorityQueue<Node> q =new PriorityQueue<>(new Comparator<Node>(){
            public int compare(Node a , Node b){
                return Integer.compare(a.dist , b.dist);
            }
        });
        dist[0] = 0;
        q.add(new Node(0 , dist[0]));
        while(!q.isEmpty()){
            Node cur = q.poll();
            if(visited[cur.id] == 1) continue;
            if(cur.dist == 1005){
                return -1;
            }
            visited[cur.id] = 1;
            sum += cur.dist;
            for(int i = head[cur.id] ; i != -1; i = edges[i].next){
                if(visited[edges[i].to] == 0 && edges[i].w < dist[edges[i].to] &&   edges[i].w > 0 ){
                    dist[edges[i].to] = edges[i].w;
                    q.add(new Node(edges[i].to , dist[edges[i].to]));
                }
            }
        }
        return sum;
    }
}
```
>[!summary]+ 重点
><mark style="background: #FF5582A6;">加一个虚拟点来模拟所有节点的原来状态，将所有物品的代价等价为边权</mark>
