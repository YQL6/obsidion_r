>[!summary] + 思路
>链表原地逆置
思路1：
若带头结点，先将头结点摘下。然后从第一个结点开始，挨个摘下每一个结点，摘下后用头插法建立新的链表。
思路2：双指针法
定义两个指针：pre和 cur；pre在前cur在后。
每次让 pre 的 next 指向 cur，实现一次局部反转。局部反转完成之后，pre和 cur同时往前移动一个位置。
循环上述过程，直至pre到达链表尾部。（注意，在循环过程中，需要记录pre->next)
><mark style="background: #FF5582A6;">特殊思路：递归，保存路径</mark>

<mark style="background: #FF5582A6;">注：原来1节点前无节点，可以看作NULL节点，相当于所有节点前有节点——》不做特殊处理，化特殊为普通</mark>——》<mark style="background: #FFF3A3A6;">统一处理</mark>——》有下述可知为了统一操作，pre = NULL,cur = head
<mark style="background: #FF5582A6;">节点指针区域改变（节点本身改变）会使指向下一个节点的地址缺失——》双指针，一个操作，一个模拟下一个节点位置（保存下一个节点）</mark>,题目较特殊需要两个指针配合操作，所以两个操作指针，一个地址指针
```java
class ListNode{  
    int val;  
    ListNode next;  
    ListNode(){}  
    ListNode(int val){  
        this.val = val;  
    }  
    ListNode(int val , ListNode next){  
        this.val = val;  
        this.next = next;  
    }  
  
}  
class Solution {  
    public ListNode reverseList(ListNode head) {  
        ListNode prev = null;  
        ListNode curr = head;  
        ListNode next = head;  //统一操作，防止NULL！！！
        while(curr != null){  
            next = curr.next;  
            curr.next = prev;  
            prev = curr;  
            curr = next;  
        }  
        return prev;  
    }  
}
```

[lk lcr140](https://leetcode.cn/problems/lian-biao-zhong-dao-shu-di-kge-jie-dian-lcof/)
给定一个头节点为 `head` 的链表用于记录一系列核心肌群训练项目编号，请查找并返回倒数第 `cnt` 个训练项目编号。

**示例 1：**

**输入：**head = [2,4,7,8], cnt = 1
**输出：**8

**提示：**

- `1 <= head.length <= 100`
- `0 <= head[i] <= 100`
- `1 <= cnt <= head.length`

>[!summary]+ 思路
>1. 纯暴力：length:遍历取得，length - cnt
>2. 原地倒转：倒过来，在遍历
>3. <mark style="background: #FF5582A6;">双指针：让一个快指针指向比慢指针的快cnt个节点</mark>，让一开始就让慢指针比快指针慢2个节点，慢指针到指定节点时，快指针就到NULL。两个指针一起移动

```java
import java.util.*;  
public class ja{  
    public static void main(String args[]){  
            Scanner sc = new Scanner(System.in);  
            int n = sc.nextInt();  
            ListNode head = null,p = null;  
            for(int i = 1 ; i <= n ; i++){  
                if(i == 1){  
                    head = new ListNode(sc.nextInt());  
                    p = head;  
                }else{  
                    ListNode listNode = new ListNode(sc.nextInt());  
                    p.next = listNode;  
                    p = listNode;  
                }  
                  
            }  
    }  
}  
class ListNode {  
    int val;  
    ListNode next;  
  
    ListNode() {  
    }  
  
    ListNode(int val) {  
        this.val = val;  
    }  
  
    ListNode(int val, ListNode next) {  
        this.val = val;  
        this.next = next;  
    }  
}  
  
class Solution {  
    public ListNode trainingPlan(ListNode head, int cnt) {  
        ListNode f = head;  
        ListNode cur = head;  
        while(cnt > 0 &&  f != null){  
            f = f.next;  
            cnt--;  
        }  
        if(f != null){  
            while(f != null){  
                f = f.next;  
                cur = cur.next;  
            }  
        }  
        return cur;  
    }  
}
```
