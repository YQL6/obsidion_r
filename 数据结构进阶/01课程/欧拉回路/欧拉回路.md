欧拉路径：所有边都遍历且仅一此，点可以重复遍历——》一笔画画出路线

欧拉图：
1. 半欧拉图：是欧拉路径，但是起始点与终点不是一个
2. 欧拉图：是欧拉路径，起始点与终点是一个

# 判断欧拉图
![[图片/1bdbfac8c21272db214849f21c3fc756.jpg]]
节点可以分为：
1. 普通节点：要有边进入节点，还要消耗边出去——》偶数度
2. 起始点：要消耗边出去，可以反复经过此节点，消耗偶数个边——》奇数度
3. 终点：消耗边进入，可以反复经过此节点，消耗偶数个边——》奇数度
以上为无向图。

有向图：
1. 普通节点：又有边进来，有边出去——》出度 = 入度
2. 起点：有边出去，可以反复经过此节点——》出度 - 入度 = 1；
3. 终点：要有边进来，可以反复经过此节点——》入度 - 出度 = 1；

总结：
无向图：
1. 欧拉图/欧拉回路：终点与起始点一个节点，奇数 + 奇数 = 偶数，所有节点都是偶数，起始点/终点那个都可以
2. 半欧拉图：起始点与终点不是一个节点，两个奇数节点，其他为偶数节点，一个为起始点，一个为终点

有向图：
1. 欧拉图/欧拉回路：终点与起始点是一个节点，入度 = 出度，那个节点都可以说起始点/终点
2. 半欧拉图：终点与起始点不是一个节点，一个入度 - 出度为1 ——终点，一个出度 - 入度为1——起始点，其他节点入度 = 出度

# 找路径

![[图片/cce4f8c6d955f3e996cb031f2e529c98.jpg|836]]
路径一定是可以拉成一条直线的——》拓扑排序的一条两排列的与欧拉回路排序相同
每个节点第二次遍历看作不同节点，有向图反过来
![[图片/ed1a944985a1a6a3520320fb9edc70b0.jpg]]
虽然 Hierholzer 算法的流程看起来较为复杂，但我们可以通过一段精妙的代码，将算法流程中的两个步骤合并到同一个深度优先搜索(DFS)过程中。
1. 选择一个<mark style="background: #FF5582A6;">合理的点作为起始点</mark>，遍历所有相邻边。
2. 深度优先搜索<mark style="background: #FF5582A6;">DFS</mark>，访问相邻顶点。将经过的边都不能再访问。
3. 如果当前顶点没有相邻边，则返回上层调用时将顶点入栈。
4.  最后将栈自顶向下输出，就是从起点出发的欧拉路径。
5. 起始点与终点重合就是欧拉路径
本质：DFS过程中未返回是一条靠前的边，遍历完后在将其
![[图片/632d5582d97ccf1836375c6243b5c018.jpg|948]]

思想：
1. 先沿着一条路走到死，即此节点无边可以遍历（终点/欧拉图是起始点），走到死的是终点
2. 途中可能有节点有环，遍历此节点的环将它插入第一条的对应节点的位置——》用栈实现
3. 不断重复，直到全部边遍历完毕

其实与DFS遍历对比发现一模一样先是走到死后加入栈，留出位置看看有没有环，有环就说明有边未遍历，遍历知道回到开始遍历的节点，加入栈中——》呈现出返回路径，即欧拉回路

![[图片/c49d7342b5b6385e4587f34f01a1b746.jpg]]
由于可能是无向边，要有两条边——》两条边相邻，若<mark style="background: #FF5582A6;">从0开始存储</mark>，如果遍历了i边，i为奇数，i+1是相同边，标记为已读，i为偶数，i- 1为相同边，标记为已读
优化：^:异或，相同为0，不同为1，让i^1 ,1变为二进制只有最低为是1，其他为0，0异或其他为自身，而<mark style="background: #FF5582A6;">最低位决定偶数还是奇数</mark>，异或1后奇偶互换

```java
class Edge{  
    int v;  
    int next;  
    int eid;  
    boolean visited;  
    public Edge(int v , int next , int eid){  
        this.v = v;  
        this.next = next;  
        this.eid = eid;  
    }  
}  
class Graph{  
    int head[] = new int[1000];  
    Edge edge[] = new Edge[1000 * 1000 * 2];  
    int count;  
    public ArrayDeque<Integer> node_ans = new ArrayDeque<>();  
    public ArrayDeque<Integer> edge_ans = new ArrayDeque<>();  
    public int[] ind = new int[1000];  
    public Graph(){  
        for(int i = 0 ; i < 1000 ; i++){  
            head[i] = -1;  
        }  
    }  
    public void add(int x , int y){  
        edge[count] = new Edge(y , head[x] , count);  
        edge[count].visited = false;  
        head[x] = count;  
        count++;  
        edge[count] = new Edge(x , head[y] , count);  
        head[y] = count;  
        edge[count].visited = false;  
        count++;//相同两条边相邻  
        ind[y]++;  
        ind[x]++;  
    }  
    public void dfs(){  
        int cur = -1;  
        for(int i = 0 ; i < 1000 ; i++){  
            if(ind[i] % 2 != 0){  
                cur = i;  
                break;  
            }  
        }  
        if(cur == -1){  
            cur = 0;  
        }  
        dfs_h(cur);  
    }  
    public void dfs_h(int x){  
        for(int i = head[x] ; i != -1 ; i = edge[i].next){  
            if(edge[i].visited == true){  
                continue;  
            }  
            edge[i].visited = true;  
            edge[i ^ 1].visited = true;//同一条边也设为已读  
            dfs_h(edge[i].v);  
            edge_ans.push(edge[i].eid);  
        }  
        node_ans.push(x);  
    }  
    public void dfs_h2(int x){  
        for(int i = head[x] ; i != -1 ; i = head[x]){  
            if(edge[i].visited == true){  
                head[x] = edge[i].next;  
                continue;  
            }  
            edge[i].visited = edge[i ^ 1].visited = true;  
            dfs_h2(edge[i].v);  
            edge_ans.push(edge[i].eid);  
        }  
        node_ans.push(x);  
    }  
}
```

# P7771 【模板】欧拉路径

## 题目描述

求有向图字典序最小的欧拉路径。

## 输入格式

第一行两个整数 $n,m$ 表示有向图的点数和边数。

接下来 $m$ 行每行两个整数 $u,v$ 表示存在一条 $u\to v$ 的有向边。

如果不存在欧拉路径，输出一行 `No`。

否则输出一行 $m+1$ 个数字，表示字典序最小的欧拉路径。

>[!summary] + 思考
>字典序最小：从左向右比较，若是前缀更短的最小
>为了字典序最小，应该从最小点开始搜索，若是有向图先遍历那个环，那个环后返回，在栈顶——》先遍历小的——》用ArrayList存储，无向图先遍历那个环那个环先
>后返回，在栈顶——》先遍历小的邻接点

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    // 数组扩容到1e5+10，覆盖绝大多数OJ数据范围，避免越界
    static int[] inDegree = new int[100015];  // 入度
    static int[] outDegree = new int[100015]; // 出度
    static int[] ptr = new int[100015];        // 邻接表访问指针，标记已处理的边
    static Deque<Integer> ans = new ArrayDeque<>();
    static ArrayList<ArrayList<Integer>> adj = new ArrayList<>();

    // 迭代版Hierholzer算法，彻底解决递归栈溢出问题
    public static void hierholzer(int start) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(start);

        while (!stack.isEmpty()) {
            int u = stack.peek();
            // 优先访问编号更小的邻接节点，保证字典序最小
            if (ptr[u] < adj.get(u).size()) {
                int v = adj.get(u).get(ptr[u]);
                ptr[u]++; // 指针后移，标记这条边已访问，避免重复处理
                stack.push(v);
            } else {
                // 所有边处理完毕，回溯时加入结果
                stack.pop();
                ans.push(u);
            }
        }
    }

    public static void main(String[] args) throws IOException {
        // 用BufferedReader替代Scanner，大幅提升大数据输入速度
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String[] firstLine = br.readLine().split(" ");
        int n = Integer.parseInt(firstLine[0]); // 题目要求的节点数n
        int m = Integer.parseInt(firstLine[1]); // 题目要求的边数m

        // 初始化邻接表：节点编号1~n，索引0闲置
        for (int i = 0; i <= n; i++) {
            adj.add(new ArrayList<>());
        }

        // 读入m条有向边
        for (int i = 0; i < m; i++) {
            String[] edge = br.readLine().split(" ");
            int u = Integer.parseInt(edge[0]);
            int v = Integer.parseInt(edge[1]);
            adj.get(u).add(v);
            inDegree[v]++;
            outDegree[u]++;
        }

        // 1. 严格校验欧拉路径/回路的度数条件
        int start = 1; // 默认起点（欧拉回路）
        int cntStart = 0; // 出度=入度+1的节点数（欧拉路径起点）
        int cntEnd = 0;   // 入度=出度+1的节点数（欧拉路径终点）
        boolean isLegal = true;

        for (int i = 1; i <= n; i++) {
            int diff = outDegree[i] - inDegree[i];
            if (diff == 1) {
                cntStart++;
                start = i; // 欧拉路径的起点固定为出度多1的节点
            } else if (diff == -1) {
                cntEnd++;
            } else if (Math.abs(diff) > 1) {
                // 度数差超过1，直接不合法
                isLegal = false;
                break;
            }
        }

        // 欧拉路径：恰好1个起点、1个终点；欧拉回路：起点终点数均为0
        if (!isLegal || !((cntStart == 0 && cntEnd == 0) || (cntStart == 1 && cntEnd == 1))) {
            System.out.println("No");
            return;
        }

        // 2. 邻接表升序排序，核心保证字典序最小
        for (int i = 1; i <= n; i++) {
            Collections.sort(adj.get(i));
        }

        // 3. 执行算法找路径
        hierholzer(start);

        // 4. 校验图的连通性：欧拉路径的节点数必须是边数+1，否则图不连通
        if (ans.size() != m + 1) {
            System.out.println("No");
            return;
        }

        // 5. 规范输出，处理末尾空格，避免格式错误
        StringBuilder sb = new StringBuilder();
        while (!ans.isEmpty()) {
            sb.append(ans.pop());
            if (!ans.isEmpty()) {
                sb.append(" ");
            }
        }
        System.out.println(sb);
    }
}
```

```java
import java.util.Scanner;
import java.util.*;
public class Main {
    static int[] ind = new int[100000];
    static int[] ord = new int[100000];
    static int[] visited = new int[100000];//保存要用邻接节点的第几个节点，之前的向相当于消掉
    static ArrayDeque<Integer> ans = new ArrayDeque<>();
    static ArrayList<ArrayList<Integer>> List = new ArrayList<>();

    public static void dfs(int x){
        for(int i = visited[x] ; i < List.get(x).size() ; i = visited[x]){
            visited[x]++;//下次访问的节点，向下一个
            dfs(List.get(x).get(i));

        }
        ans.push(x);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int start = 1;
        int n_v = sc.nextInt();
        int n_e = sc.nextInt();
        int flag = 1;
        int count[] = new int[2];//0表示入度 - 出度 ，1表示 出度 - 入度
        //int[][] arr = new int[n_v + 1][n_e +1];

        for(int i = 0 ;i <= n_v ; i++){
            List.add(new ArrayList<Integer>());
        }
        for(int i = 1 ; i <= n_e ; i++){
            int x = sc.nextInt();
            int y = sc.nextInt();
            List.get(x).add(y);
            ind[y]++;
            ord[x]++;
        }
        for(int i = 1 ; i <= n_v ; i++){
            if(Math.abs(ind[i] - ord[i]) > 1){
                System.out.println("No");
                return;
            }else{
                if(ind[i] - ord[i] == 1){
                    flag = 0;
                    count[0]++;
                }
                if(ind[i] - ord[i] == -1){
                    count[1]++;
                    start = i;
                }
            }
        }
        if(flag == 0 && (count[0] != 1 || count[1] != 1)){
            System.out.println("No");
            return;
        }
        for(int i = 1 ; i <= n_v ; i++){
            List.get(i).sort((x,y) -> Integer.compare(x , y));
        }
        dfs(start);
        while(!ans.isEmpty()){
            System.out.print(ans.pop() + " ");
        }
    }
}
```
