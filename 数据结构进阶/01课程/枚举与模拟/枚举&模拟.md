# 枚举
<mark style="background: #FF5582A6;"></mark><mark style="background: #FF5582A6;">枚举：是基于已有知识来猜测答案的一种问题求解策略</mark>。

>[!summary]+ 重点
>枚举的思想是不断地猜测，从可能的答案集合中—一尝试，然后再判断题目的条件是否成立。枚举每一种可能性。
1.找对答案集合 1~100最大的质数
2.答案成立的条件--》题目给出
3.减小枚举范围----》提高效率
4.选择合适的枚举顺序

对不同集合要进行不同搜索方式：
+ 普通搜索for,例如：1~100
+ 暴力搜索：bfs,dfs，例如：集合的集合
# 模拟
<mark style="background: #FF5582A6;">模拟:直接模拟题目中要求的操作来求解。</mark>

>[!summary]+ 重点
>莫拟题目通常具有码量大、操作多的特点。由于它码量大,经常会出现难以查错
的情况,如果在考试中写错是相当浪费时间的。但是其思路一般较为简单。
具体的操作步骤有可能需要自己分析得出。

<mark style="background: #FF5582A6;">总结：操做复杂，代码量大，操作难找，情况分析获得操作步骤</mark>
理解：
+ 找学校大门
	+ 按地图固定路线 ————枚举
	+  翻墙进入 ————算法优化


暴力算法：枚举+模拟
<mark style="background: #FFB86CA6;">使用场景·：其他算法不可用之时
</mark>

# 例题

# P1003 [NOIP 2011 提高组] 铺地毯

## 题目描述

为了准备一个独特的颁奖典礼，组织者在会场的一片矩形区域（可看做是平面直角坐标系的第一象限）铺上一些矩形地毯。一共有 $n$ 张地毯，编号从 $1$ 到 $n$。现在将这些地毯按照编号从小到大的顺序平行于坐标轴先后铺设，后铺的地毯覆盖在前面已经铺好的地毯之上。

地毯铺设完成后，组织者想知道覆盖地面某个点的最上面的那张地毯的编号。注意：在矩形地毯边界和四个顶点上的点也算被地毯覆盖。

## 输入格式

输入共 $n + 2$ 行。

第一行，一个整数 $n$，表示总共有 $n$ 张地毯。

接下来的 $n$ 行中，第 $i+1$ 行表示编号 $i$ 的地毯的信息，包含四个整数 $a ,b ,g ,k$，每两个整数之间用一个空格隔开，分别表示铺设地毯的左下角的坐标 $(a, b)$ 以及地毯在 $x$ 轴和 $y$ 轴方向的长度。

第 $n + 2$ 行包含两个整数 $x$ 和 $y$，表示所求的地面的点的坐标 $(x, y)$。

## 输出格式

输出共 $1$ 行，一个整数，表示所求的地毯的编号；若此处没有被地毯覆盖则输出 `-1`。

## 输入输出样例 #1

### 输入 #1

```
3
1 0 2 3
0 2 3 3
2 1 3 3
2 2

```

### 输出 #1

```
3

```

## 输入输出样例 #2

### 输入 #2

```
3
1 0 2 3
0 2 3 3
2 1 3 3
4 5
```

### 输出 #2

```
-1
```

## 说明/提示

【样例解释 1】

如下图，$1$ 号地毯用实线表示，$2$ 号地毯用虚线表示，$3$ 号用双实线表示，覆盖点 $(2,2)$ 的最上面一张地毯是 $3$ 号地毯。

![](https://cdn.luogu.com.cn/upload/image_hosting/q4izfzpb.png)

【数据范围】

对于 $30\%$ 的数据，有 $n \le 2$。  
对于 $50\%$ 的数据，$0 \le a, b, g, k \le 100$。  
对于 $100\%$ 的数据，有 $0 \le n \le 10^4$, $0 \le a, b, g, k \le {10}^5$。   

noip2011 提高组 day1 第 $1$ 题。

>[!summary]+ 重点
>时间复杂度：遍历仅是10^5,可遍历，其他方法不满足，枚举+模拟


>[!summary]+ 思路
>从后向前遍历地毯，有条件加上判断变量并且退出，结束无则为-1
>条件：点位于地毯范围

```java
import java.util.*;
public class Main {
    public static void main(String[] args){
        method me = new method();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        me.search(n,sc);
    }
}
class method{
    //建立个地毯数据存储空间
    int[] a = new int[10005];
    int[] b = new int[10005];
    int[] g = new int[10005];
    int[] k = new int[10005];
    //判断变量
    int flag = 0 ;
    public void search(int n, Scanner sc){
        for(int i = 1 ; i <= n ; i++){
            a[i] = sc.nextInt();
            b[i] = sc.nextInt();
            g[i] = sc.nextInt();
            k[i] = sc.nextInt();
        }
        int x = sc.nextInt();
        int y = sc.nextInt();
        for(int i = n ; i >=1 ; i--){
            if(x >= a[i] && x <= a[i] + g[i] && y >= b[i] && y <= b[i] + k[i]){
                System.out.println(i);
                flag = 1;
                break;
            }
        }
        if(flag == 0){
            System.out.println(-1);
        }
    }
}
```

>洛谷固定格式：public class Main 
>洛谷固定要求：Scanner必须一个
